From preferences to the best action

Lecture 1 describes a rational individual with four pieces of knowledge. The agent knows the actions A, the outcomes X, which outcome each action leads to, and its own preference. With all four, choosing is a calculation.

Value of an actionExam favourite
v(a) = u( c(a) )
First find the consequence, then score it.
Rational choiceExam favourite
a* ∈ arg maxa ∈ A v(a)   ⟺   v(a*) ≥ v(a) for every a
arg max is a set. If two actions tie for the top, both are rational.
Common mistake
The transcript sometimes wrote v(a*) > v(a) for every other a. That strict version only fits when the best action is unique. With ties the right condition is ≥.

Maximizing and satisficing

Machine learning is rational choice

A regression model that minimizes squared error L = (y − ŷ)² is maximizing the utility u = −(y − ŷ)². Changing the loss changes what counts as best. Rationality does not mean everyone wants the same thing. It means each agent consistently maximizes its own objective.

Loss as negative utility
min (y − ŷ)² ⟺ max −(y − ŷ)²
Minimizing a loss and maximizing its negative pick the same answer.

Decision trees: the movie problem

A decision tree draws a choice as a picture. Square nodes are choices, branches are actions, and leaves are outcomes with their payoffs. A tree is a graph with no cycles, so every leaf has exactly one path from the root.

Lecture 2 asks you to choose between two cinemas. INOX is 1 mile away and shows Aliens, Blade Runner and Casablanca. PVR is 3 miles away and shows Doctor Strange, Gone with the Wind and The Matrix. You rank the six films alphabetically from best to worst and give them utilities 6 down to 1.

Solve it with walking costs of 1 per mile
  1. Without walking, the best leaf is Aliens with utility 6, at INOX.
  2. Net payoff = film utility − miles walked.
  3. INOX: Aliens 6 − 1 = 5, Blade Runner 4, Casablanca 3.
  4. PVR: Doctor Strange 3 − 3 = 0, Gone with the Wind −1, The Matrix −2.
  5. Best: go to INOX and watch Aliens, net payoff 5

Now drag the PVR distance down to 0 in the animation, or move Aliens to PVR. The tree changes and so can the answer. That is the point of the tree: once the payoffs are written on the leaves, the choice follows mechanically.

Real world scenario: route planning

A navigation app builds the same kind of tree. Each junction is a decision node, each road a branch, and each arrival a leaf scored by minus the travel time. The cost of walking in the movie problem is the cost of a longer route here.

Problem 1.6: the fruit trees

You may plant at most two fruit trees. Each tree costs money to maintain but lowers your food bill. You care only about total spending, so lower is better.

TreeMaintenanceFood bill reductionNet change per tree
Apple$100$130−30
Orange$70$90−20
Pear$120$145−25
Spending after a planExam favourite
u(plan) = X + Σ maintenance − Σ reduction
X is what you spend with no trees. A smaller number is better.
Variety version
second tree of the same kind saves only half
Part (d) of the problem. Mixed pairs keep the full saving.
Part (a) and (b): list every action and its spending
  1. Actions: none, A, O, P, AA, OO, PP, AO, AP, OP. That is 10, since order does not matter.
  2. Single trees: A gives X − 30, O gives X − 20, P gives X − 25.
  3. Pairs: AA = X − 60, OO = X − 40, PP = X − 50, AO = X − 50, AP = X − 55, OP = X − 45.
  4. Lowest spending is X − 60: plant two apple trees
Part (d): a second tree of the same kind saves half
  1. AA: maintenance 200, saving 130 + 65 = 195, so X + 5.
  2. OO: maintenance 140, saving 90 + 45 = 135, so X + 5.
  3. PP: maintenance 240, saving 145 + 72.5 = 217.5, so X + 22.5.
  4. Mixed pairs and single trees do not change: AP is still X − 55.
  5. Lowest spending is now X − 55: plant one apple and one pear
Remember
A change in the payoff structure changed the rational choice. Nothing about the person's rationality changed, only the numbers on the leaves.

Problem 1.7: how much to spend on parks

A city has a budget of $20 million. By law, parks may receive at most 5%, which is $1 million. Spending c dollars gives a benefit that grows like a square root but has a cost that grows in a straight line.

BenefitExam favourite
v(c) = √400c − c80 = 20√c − c80
The action set is the interval A = [0, 1,000,000]. It is continuous, so we cannot list the actions, we must use calculus.
First order conditionExam favourite
v′(c) = 10√c − 180 = 0
Marginal benefit equals marginal cost.
Second order condition
v″(c) = −5 c−3/2 < 0
v is strictly concave, so a stationary point inside the interval is the unique maximum.
Part (b): solve with √(400c)
  1. Set 10 / √c = 1/80.
  2. Then √c = 800.
  3. Square both sides: c = 640,000.
  4. 640,000 lies inside [0, 1,000,000], and v is concave, so this is the maximum.
  5. c* = $640,000 and v(c*) = 20 × 800 − 8,000 = 8,000
Part (c): the benefit changes to √(1600c)
  1. Now v(c) = 40√c − c/80 and v′(c) = 20/√c − 1/80.
  2. Setting v′ = 0 gives √c = 1,600, so c = 2,560,000.
  3. That is more than the legal cap of 1,000,000, so it is not allowed.
  4. v is concave and its peak lies to the right of the cap, so v is increasing on the whole interval.
  5. c* = $1,000,000, a corner solution
Going deeper: The recipe for a one variable problem on an interval

To maximize v(c) on [L, U]: find every c with v′(c) = 0 inside the interval, then evaluate v at those points and at both ends L and U, and keep the largest. The second derivative tells you whether a stationary point is a peak (v″ < 0) or a valley (v″ > 0). For concave v the answer is the stationary point clipped to the interval: min(max(c₀, L), U).

One idea, four depths

Write down every choice, work out what each one gives you, and pick the one that gives the most. If there are too many choices to list, use a graph or calculus to find the top.

v(a) = u(c(a)) and a* ∈ arg max v. Discrete problems are solved by listing or by a decision tree. Continuous ones are solved with v′ = 0, a check of v″, and a comparison with the boundary.

With constraints, the Karush Kuhn Tucker conditions generalize the boundary check: at a corner the derivative need not be zero, but its sign must point out of the feasible set. Concavity turns these necessary conditions into sufficient ones.

Bounded rationality asks what to do when computing arg max is itself costly. Satisficing, anytime algorithms and the value of computation in metareasoning (Russell and Wefald) treat thinking time as one more action with a cost.
