Question 1. Give the PEAS description of a robot vacuum cleaner.
  1. Performance measure: how clean the floor is, the time taken and the power used.
  2. Environment: the rooms, the dirt, the furniture and the people.
  3. Actuators: wheels, brushes and the suction motor. Sensors: a dirt sensor, bump sensors and a camera.
  4. The environment is partially observable, stochastic and dynamic (chapter 1.1).
Question 2. A tree has root A with children B and C. B has children D and E. C has child F. List the order in which BFS and DFS visit the nodes (left child first).
  1. BFS goes level by level: A, then B and C, then D, E and F.
  2. DFS goes as deep as it can first: A, B, D, then back up to E, then C and F.
  3. BFS: A B C D E F. DFS: A B D E C F.
Question 3. Two fair dice are thrown. What is the chance the total is 7?
  1. There are 6 × 6 = 36 equally likely pairs.
  2. The pairs that give 7 are (1, 6), (2, 5), (3, 4), (4, 3), (5, 2) and (6, 1). That is 6 pairs.
  3. P = 6 ÷ 36 = 1 ÷ 6 ≈ 0.167
Question 4. MAX moves first. Move 1 lets MIN choose 3 or 5. Move 2 lets MIN choose 2 or 9. Which move should MAX play?
  1. MIN picks the smaller value: move 1 is worth min(3, 5) = 3, move 2 is worth min(2, 9) = 2.
  2. MAX picks the larger: max(3, 2) = 3.
  3. MAX plays move 1. The 9 looks tempting, but MIN would never allow it.
Question 5. How many rows does a truth table for P, Q, R and S need?
  1. Each symbol can be true or false.
  2. 2 × 2 × 2 × 2.
  3. 2⁴ = 16 rows

Tier 2: university semester and IIT course exams

Here the examiner gives a small graph, tree, net or MDP and asks you to run the algorithm by hand. Write the frontier or the table after every step.

Question 6. UCS and A* on one graph

Edges: S to A costs 1, S to B costs 5, A to B costs 2, A to G costs 6, B to G costs 1. Heuristic: h(S) = 3, h(A) = 3, h(B) = 1, h(G) = 0. Run UCS and A* and give the path and its cost.

Model answer
  1. UCS frontier (g values): S 0. Expand S: A 1, B 5. Expand A: B 3 (a cheaper way in), G 7. Expand B (3): G 4.
  2. UCS takes G out with cost 4. Path S, A, B, G.
  3. A* frontier (f = g + h): S 3. Expand S: A 4, B 6. Expand A: B 3 + 1 = 4, G 7. Expand B: G 4 + 0 = 4.
  4. A* also finds S, A, B, G with cost 4. Here h is consistent, so A* graph search is safe.
  5. both return S, A, B, G with cost 4

Question 7. Alpha beta on the tree of the slides

Leaves 2 3 5 9 0 1 7 5 under MAX, MIN, MAX. Find the root value and the pruned parts.
  1. The first MAX node is max(2, 3) = 3, so the MIN node above it has β = 3.
  2. The next MAX node reads 5, which is at least β = 3. MIN will never let play reach it, so the 9 is pruned.
  3. The left MIN node is 3, so the root has α = 3. On the right, the first MAX node is max(0, 1) = 1, so that MIN node is at most 1.
  4. That is below α = 3, so the whole last MAX node (7 and 5) is pruned.
  5. root = 3, the same as plain minimax

Question 8. Bayes rule with a sum in the bottom

It rains on 20 percent of days. The grass is wet on 90 percent of rainy days and on 10 percent of dry days. The grass is wet. P(rain | wet)?
  1. P(wet) = 0.9 × 0.2 + 0.1 × 0.8 = 0.18 + 0.08 = 0.26.
  2. P(rain | wet) = P(wet | rain) P(rain) ÷ P(wet) = 0.18 ÷ 0.26.
  3. ≈ 0.692

Question 9. One sweep of value iteration

The racing car MDP of chapter 10.1, γ = 0.9, starting from V = 0. Find V₁(cool) and V₁(warm).
  1. Cool: slow gives 1. Fast gives 0.5 × 2 + 0.5 × 2 = 2. So V₁(cool) = 2.
  2. Warm: slow gives 1. Fast gives −10. So V₁(warm) = 1.
  3. The next sweep gives V₂(cool) = 3.35 and V₂(warm) = 2.35, and the values reach 15.5 and 14.5.
  4. V₁ = (2, 1)

Question 10. Convert to CNF

Convert A ⇔ (B ∨ C) to conjunctive normal form.
  1. Replace ⇔ by two implications: (A ⇒ B ∨ C) ∧ (B ∨ C ⇒ A).
  2. Replace each ⇒: (¬A ∨ B ∨ C) ∧ (¬(B ∨ C) ∨ A).
  3. Push ¬ inwards with De Morgan: ¬(B ∨ C) is ¬B ∧ ¬C. Then distribute ∨ over ∧.
  4. (¬A ∨ B ∨ C) ∧ (¬B ∨ A) ∧ (¬C ∨ A)

Question 11 (numerical answer). BFS with b = 2 and the goal at depth 3. How many nodes are generated, not counting the root?
  1. Depth 1 has 2, depth 2 has 4, depth 3 has 8.
  2. 2 + 4 + 8.
  3. 14
Question 12 (multiple select). For the 8 puzzle, which are admissible? (a) misplaced tiles h₁ (b) Manhattan distance h₂ (c) max(h₁, h₂) (d) h₁ + h₂
  1. h₁ and h₂ are both exact costs of relaxed problems, so they never overestimate. (a) and (b) are true.
  2. The max of two admissible values is still below the true cost. (c) is true.
  3. The sum can overestimate: one tile one step away counts 1 in each, giving 2 when the true cost is 1. (d) is false.
  4. answer: a, b, c
Question 13 (numerical answer). P(A) = 0.5, P(B) = 0.4, P(A ∧ B) = 0.2. P(A ∨ B)?
  1. P(A ∨ B) = P(A) + P(B) − P(A ∧ B).
  2. 0.5 + 0.4 − 0.2.
  3. 0.7
Question 14 (numerical answer). The evidence has probability 0.01. About how many of 1,000 rejection samples are kept?
  1. Each sample agrees with the evidence with chance 0.01.
  2. 1,000 × 0.01.
  3. about 10. Likelihood weighting keeps all 1,000 and weights them instead
Question 15 (multiple choice). In standard first order logic, is ∀x P(x) ⇒ ∃x P(x) valid?
  1. Standard semantics needs at least one object in every model.
  2. If P holds for every object, it holds for that object, so some x has P(x).
  3. valid. It would fail only if empty domains were allowed
In the exam
Round only at the very end. A numerical answer type key often has a narrow range such as 0.69 to 0.70.
Lesson 5 of 6

Tier 4: proofs, derivations and critique

Exams in the style of MIT, Berkeley, Stanford, CMU and IISc reward a complete argument more than a final number. State the conditions, prove the claim, then say when it fails. Chapter 11.1 has five more proofs.

Question 16. If h₁ and h₂ are consistent, show that h = max(h₁, h₂) is consistent.

Model answer
  1. Take an edge from n to n′ with cost c. For each i, hᵢ(n) ≤ c + hᵢ(n′) ≤ c + h(n′), since h(n′) is at least hᵢ(n′).
  2. So both h₁(n) and h₂(n) are at most c + h(n′). Their max, h(n), is too.
  3. At the goal both are 0, so h(goal) = 0. So h is consistent, and it dominates each hᵢ, so A* expands no more nodes with it.

Question 17. Show that the two parents of a collider are independent when nothing is observed.

Model answer
  1. In the net B, E, A with A having parents B and E: P(b, e) = Σ over a of P(b) P(e) P(a | b, e).
  2. P(b) P(e) does not depend on a, so it comes out of the sum: P(b) P(e) Σ over a of P(a | b, e).
  3. The sum of a conditional distribution over its values is 1.
  4. P(b, e) = P(b) P(e), so B ⫫ E

Question 18. Derive the value of a fixed policy in closed form.

Model answer
  1. For a fixed policy π, the Bellman equation is linear: V(s) = R(s) + γ Σ P(s′ | s, π(s)) V(s′).
  2. In matrix form V = R + γ P_π V, so (I − γ P_π) V = R.
  3. For γ < 1 the matrix I − γ P_π can be inverted, because every eigenvalue of P_π has size at most 1.
  4. V^π = (I − γ P_π)⁻¹ R, which policy iteration uses for exact evaluation

Question 19. Show that UCS is optimal when every step cost is at least some ε > 0.

Model answer
  1. UCS takes nodes out in order of g. Every step adds at least ε, so g grows along any path, and only finitely many nodes have g below any bound.
  2. When the goal is taken out with cost C, every node with g < C has already been taken out.
  3. Any cheaper path to the goal would have a node with g < C on the frontier, which would come out first. So no cheaper path exists.
  4. With zero cost steps, UCS can loop forever on a zero cost cycle. That is why the ε condition is needed for completeness.

Critique questions

A critique question gives a claim and asks what is wrong. For example, "use greedy best first search because it is faster than A*". The answer: greedy search ignores the cost so far, so it is not optimal, and in tree search it can loop. Another favourite: "a Bayesian network arrow means cause". The answer: a network only encodes conditional independence. Many graphs give the same independences, and only a causal model with interventions (chapter 9.4) supports cause and effect.

In the exam
In proofs, name each condition when you use it: consistency, positive step costs, definite clauses, a finite domain, γ < 1. Examiners often ask what breaks when one fails.
One idea, four depths

At school you describe agents, follow BFS and DFS on a tree, count rows and cases, and pick a move by minimax.

At university you run UCS, A*, alpha beta, AC-3, enumeration and value iteration by hand, writing the frontier or table after each step.

In GATE and NPTEL papers you recognise the right fact fast, use quick checks to drop options and round only at the end.

At research universities you prove optimality, consistency and independence results, derive closed forms such as V = (I − γP)⁻¹R, and critique methods by their conditions.

Ten mistakes that cost marks

  1. Testing the goal when a node is added in UCS or A*, which can return a costlier path.
  2. Calling an admissible heuristic safe for graph search without checking consistency.
  3. Adding two admissible heuristics and calling the sum admissible.
  4. Forgetting to put arcs back on the AC-3 queue after a domain shrinks.
  5. Mixing up α and β in alpha beta: α is the value MAX can already guarantee on the path, β the value MIN can guarantee. Prune only when they cross.
  6. Using forward chaining on clauses that are not definite clauses.
  7. Unifying x with F(x) without the occurs check.
  8. Forgetting the base rate in Bayes rule.
  9. Saying a collider path is open with no evidence, or blocked when a descendant is observed.
  10. Using max in a SARSA update, or the action actually taken in a Q-learning update.
