Question 1: Cournot with a curved demand

The question (10 points). Market demand is p(q) = a/(q + 1) with a > 0. Two firms each have cost C(q) = cq with c > 0, and neither may choose qᵢ = 0. S1: if the firms choose quantities simultaneously to maximize profit, in the Nash equilibrium each firm produces (a − c)/3 and the price is a ÷ (2(a − c)/3 + 1). S2: if the firms collude as a monopoly with joint cost C*(q) = 2cq, no total quantity maximizes total profit. Options: A both true, B both false, C only S1 true, D only S2 true.

Profit of firm i
πi = a qiqi + qj + 1 − c qi
Price times own quantity, minus cost.
First order conditionExam favourite
a(qj + 1)(qi + qj + 1)² = c
The derivative of a qᵢ/(qᵢ + qⱼ + 1) is a(qⱼ + 1)/(Q + 1)².
Symmetric equilibriumExam favourite
q* = (a − 4c) + √a² + 8ac8c
From a(q + 1) = c(2q + 1)², a quadratic 4cq² + (4c − a)q + (c − a) = 0.
Joint monopolyExam favourite
Q* = √a2c − 1
From a/(Q + 1)² = 2c. Positive exactly when a > 2c.
Statement S1
  1. Set qᵢ = qⱼ = q in the first order condition: a(q + 1) = c(2q + 1)².
  2. Expand: 4cq² + (4c − a)q + (c − a) = 0. The positive root is q* = ((a − 4c) + √(a² + 8ac)) ÷ 8c.
  3. Try a = 10, c = 1: q* = (6 + √180) ÷ 8 = 2.4271, while (a − c)/3 = 3.
  4. Check directly: if the rival makes 3, producing 2.5 earns more than producing 3, so (3, 3) is not an equilibrium.
  5. S1 is false. The formula (a − c)/3b belongs to linear demand a − bq, not to a/(q + 1)
Statement S2
  1. Joint profit Π(Q) = aQ/(Q + 1) − 2cQ for Q > 0.
  2. Π′(Q) = a/(Q + 1)² − 2c = 0 gives Q* = √(a/2c) − 1, and Π″ = −2a/(Q + 1)³ < 0, so it is a maximum.
  3. Q* > 0 whenever a > 2c. With a = 10, c = 1, Q* = 1.236.
  4. Only when a ≤ 2c does profit fall from the start, so that no positive Q is best, since Q = 0 is ruled out.
  5. S2 claims no maximizer in general, which is false. Answer B: both statements are false
In the exam
The trap in S1 is pattern matching. (a − c)/3 is the textbook Cournot answer, but it comes from demand a − bq. With a different demand curve you must redo the first order condition.

Question 2: bananas and candy

The question (10 points). A banana costs $0.50 and a candy $0.25. You have $1.25 and you value money. The first banana is worth $1.20 to you and each further one half the previous ($0.60, $0.30, …). The first candy is worth $0.40, then $0.20, $0.10, … The two values do not affect each other. Should you spend all your money? Options: A yes, B no, C not enough information.

Buy one more unit whenExam favourite
marginal value ≥ price
Because you value money, a unit is worth buying only if it is worth more to you than what it costs.
UnitMarginal valuePriceWorth buying?
Banana 1$1.20$0.50Yes, +0.70
Banana 2$0.60$0.50Yes, +0.10
Banana 3$0.30$0.50No, −0.20
Candy 1$0.40$0.25Yes, +0.15
Candy 2$0.20$0.25No, −0.05
Solve it
  1. Every unit worth more than its price: two bananas and one candy.
  2. Cost: 2 × 0.50 + 0.25 = $1.25, exactly your cash.
  3. Value: 1.20 + 0.60 + 0.40 = $2.20.
  4. Net gain = 2.20 − 1.25 = $0.95, the best of all affordable baskets
  5. The best basket uses all the money, so the answer is A: yes, spend it all.
Remember
The answer depends on the numbers, not on a rule like "always spend" or "never spend". With $3 you would still stop at $1.25, because the third banana and the second candy are worth less than they cost.

Question 3: buying a lottery ticket

The question (10 points). A decision maker with u(w) = √w and wealth ₹400 is offered a lottery that pays ₹900 with probability 0.4 and ₹10 with probability 0.6, sold at ₹p. Options: A she will definitely buy if p < 18, B she will definitely buy if p = 18, C she will definitely buy if p > 18, D she will never buy.

Buy whenExam favourite
0.4 √400 − p + 900 + 0.6 √400 − p + 10 ≥ √400 = 20
Expected utility of final wealth after paying p and receiving the prize, against keeping ₹400.
Break even priceExam favourite
p* ≈ 267.99
Found by bisection. Below p* she buys, above it she does not.
Solve it
  1. At p = 18: 0.4 × √1282 + 0.6 × √392 = 0.4 × 35.805 + 0.6 × 19.799 = 14.322 + 11.879 = 26.20.
  2. 26.20 > 20, so she buys at 18. The left side falls as p rises, so she buys at every p < 18 too.
  3. The left side reaches 20 at about p* = 267.99. At p = 300 she refuses, so C fails, and D fails as well.
  4. A is true and B is true under this reading
Common mistake
This question has two true options under the standard reading (prizes added to wealth after paying p). If only one option may be marked, A is the safer choice because it covers every price below 18, and B is a special case. It is worth asking the instructor whether the question allows more than one answer.
Going deeper: Other readings and why they do not change the verdict

If wealth is ignored, the lottery alone has E[√X] = 0.4 × 30 + 0.6 × 3.162 = 13.90, a certainty equivalent of about ₹193, still far above 18. If she were risk neutral, the break even price would be the expected prize, 0.4 × 900 + 0.6 × 10 = ₹366. Under every sensible reading the price 18 is well below the break even price, so A and B hold and C and D fail.

Question 4: consumption with a convex payoff

The question (10 points). A decision maker lives for 3 periods and splits ₹K among them. Each period's payoff is u(xₜ) = xₜ², discounted by δ = ½, so v(x₁, x₂, x₃) = x₁² + ½x₂² + ¼x₃² with 0 ≤ xₜ ≤ K and x₁ + x₂ + x₃ = K. Find the optimal plan.

Objective
v = x₁² + ½ x₂² + ¼ x₃²
A convex function on the triangle x₁ + x₂ + x₃ = K.
AnswerExam favourite
(x₁, x₂, x₃) = (K, 0, 0),   v = K²
Spend everything in period 1.
Solve it
  1. u = x² has u″ = 2 > 0, so v is convex. Setting the derivatives to zero finds a minimum, not a maximum.
  2. A convex function on a triangle is maximized at a corner: (K, 0, 0), (0, K, 0) or (0, 0, K).
  3. The corner values are K², ½K² and ¼K².
  4. Best: (K, 0, 0) with total payoff K²
  5. Why not spread? Moving ε from period 1 to period 2 changes v by −2Kε + ε² + ½ε², which is negative for small ε.
What the Lagrange method would have given
  1. Interior first order conditions: 2x₁ = λ, x₂ = λ, ½x₃ = λ, so x₁ : x₂ : x₃ = 1 : 2 : 4.
  2. With K = 7 that is (1, 2, 4) and v = 1 + 2 + 4 = 7.
  3. The corner gives K² = 49. The stationary point is the minimum, as in lecture 4's x² example
One idea, four depths

Read the question carefully, do not trust a formula you remember from a different setting, and check the answer with numbers.

Q1: redo the first order conditions for the new demand. Q2: buy while marginal value ≥ price. Q3: compare expected utility of final wealth with the sure wealth. Q4: convex payoffs go to a corner.

Each question tests the second order condition in disguise: concavity guarantees that first order conditions find a maximum, and its failure (Q4) or the boundary (Q1, S2 with a ≤ 2c) changes the answer.

Existence of Cournot equilibria with general demand needs conditions such as decreasing marginal revenue (Novshek 1985). Convex intertemporal objectives appear in models of lumpy consumption and in risk seeking reinforcement learning, where policies collapse to extreme actions.
