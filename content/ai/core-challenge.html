How to attack a hard Core AI problem

Source: Original challenge problems written for this course in the style of exams at top universities (MIT 6.034, Berkeley CS188, Stanford CS221, CMU 15-381, IIT and IISc AI courses, and the GATE Data Science and AI paper). None is copied from a real past paper. They draw on AIMA 3rd ed. chapters 3 to 21, the uploaded slides on search, CSPs and games, and every earlier chapter of this subject. Every number was checked by running the code on this page.

What it is
A challenge problem mixes two or more ideas, hides a trap, or asks you to prove why a method works. This chapter has one challenge set for each step of Core AI, then proofs, then a guide for choosing a method.
Why we need it
Easy questions test whether you remember a formula. Hard questions test whether you know when the formula holds. Top exams almost always ask about the edge: an inconsistent heuristic, a collider that becomes open, a discount that breaks the bound.
How it works
Use the same five moves every time: name the model (search, CSP, game, logic, plan, Bayes net or MDP), write the formula, check its conditions, work the numbers one step at a time, and say what the answer means.
MoveAsk yourselfExample
1. Name the modelWhat are the states, actions, variables or rules?A route finder is a search problem with a step cost.
2. Write the formulaWhich equation decides the answer?f(n) = g(n) + h(n) for A*.
3. Check the conditionsDoes the theorem’s condition hold here?Is h consistent, or only admissible?
4. Work it step by stepCan a reader follow each line?Write the frontier after every expansion.
5. Say what it meansIs the answer sensible?A probability must lie between 0 and 1.
Remember
Each challenge below names the chapter that teaches the idea, so you can go back if a step is not clear.
Lesson 2 of 12

Challenge set 1: search and heuristics

Challenge 1. An admissible heuristic that still gives a wrong answer

Edges: S to A costs 4, S to B costs 1, B to A costs 1, A to G costs 4. The heuristic is h(S) = 0, h(A) = 0, h(B) = 5, h(G) = 0. Is h admissible? Is it consistent? What does A* graph search return if it never reopens a closed node? (Chapters 3.1 and 3.2.)

Model answer
  1. True costs to G: from A it is 4, from B it is 1 + 4 = 5, from S it is 1 + 1 + 4 = 6. Every h is at most the true cost, so h is admissible.
  2. Consistency needs h(B) ≤ c(B, A) + h(A) = 1 + 0 = 1. But h(B) = 5, so h is not consistent.
  3. Start: frontier S (f = 0). Expand S: A gets g = 4, f = 4. B gets g = 1, f = 1 + 5 = 6.
  4. A has the smaller f, so A is expanded first with g = 4 and closed. G gets g = 8, f = 8.
  5. Next B (f = 6). It finds A again with g = 2, but A is closed, so this better path is thrown away.
  6. G is popped with cost 8, but the best path S, B, A, G costs 6
In the exam
The fix: use a consistent heuristic, or let graph search reopen a closed node when a cheaper path to it turns up. Tree search with an admissible heuristic is always optimal, because it never closes anything.

Challenge 2. How much extra work does iterative deepening do?

Branching factor b = 10, solution depth d = 5. Count the nodes generated by BFS and by IDS.
  1. BFS generates b + b² + … + b⁵ = 10 + 100 + 1,000 + 10,000 + 100,000 = 111,110.
  2. IDS generates level i once for every limit from i to d, that is (d + 1 − i) times.
  3. IDS: 5 × 10 + 4 × 100 + 3 × 1,000 + 2 × 10,000 + 1 × 100,000 = 123,450.
  4. IDS does only about 11 percent more work, and needs only O(bd) memory

Challenge 3. Effective branching factor

A* generates N = 52 nodes and finds a solution at depth d = 5. Find the effective branching factor b*.
  1. b* is the branching factor of a uniform tree of depth d with N + 1 nodes: N + 1 = 1 + b* + (b*)² + … + (b*)⁵.
  2. So 53 = 1 + b* + (b*)² + (b*)³ + (b*)⁴ + (b*)⁵. Try b* = 2: the sum is 63, too big. Try 1.9: it is about 51.5, a little small.
  3. Halving the interval a few times gives b* ≈ 1.92.
  4. b* ≈ 1.92, the value given in AIMA section 3.6.1

Challenge set 2: constraint satisfaction and local search

Challenge 4. AC-3 alone solves this CSP

Variables X, Y and Z each have the domain 1, 2, 3, with constraints X < Y and Y < Z. Run AC-3. (Chapter 5.1.)

Model answer
  1. Arc X to Y: X = 3 has no larger Y, so remove it. X becomes 1, 2.
  2. Arc Y to X: Y = 1 has no smaller X, so remove it. Y becomes 2, 3.
  3. Arc Y to Z: Y = 3 has no larger Z, so remove it. Y becomes 2. Arc Z to Y: Z must be above 2, so Z becomes 3.
  4. Y changed, so the arc X to Y goes back on the queue. X = 2 has no larger Y now, so X becomes 1.
  5. X = 1, Y = 2, Z = 3, found with no search at all

Challenge 5. Why a tree shaped CSP is easy

A CSP has n = 10 variables, each with d = 3 values, and its constraint graph is a tree. Bound the work.
  1. Pick a root and order the variables so every parent comes before its children.
  2. Go backwards, making each arc from parent to child consistent. Each of the n − 1 arcs needs at most d² checks.
  3. Then assign values from the root down. Arc consistency means a good value is always left, so there is no backtracking.
  4. (n − 1) d² = 9 × 9 = 81 checks, against dⁿ = 59,049 full assignments

Challenge 6. Simulated annealing accepts a worse move

The current state has value 10. A random neighbour has value 8, so ΔE = −2 when we maximise. The temperature is T = 1. What is the chance of moving?
  1. A worse move is taken with probability e^(ΔE ÷ T).
  2. e^(−2 ÷ 1) = e^(−2).
  3. ≈ 0.135. At T = 10 it would be e^(−0.2) ≈ 0.819
Lesson 4 of 12

Challenge set 3: adversarial search

Challenge 7. Which leaves does alpha beta skip?

A MAX root has three MIN children with leaves 3 12 8, 2 4 6 and 14 5 2, read left to right. Find the minimax value and the leaves alpha beta never looks at. (Chapters 6.1 and 6.2.)

Model answer
  1. First MIN node: min(3, 12, 8) = 3. Now α = 3 at the root.
  2. Second MIN node: its first leaf is 2. Its value can only be 2 or less, and MAX already has 3.
  3. So the leaves 4 and 6 are pruned.
  4. Third MIN node: 14, then 5, then 2. None of 14 or 5 is at most 3, so all three are read. Its value is 2.
  5. root = max(3, ≤ 2, 2) = 3, with 7 of the 9 leaves read

Challenge 8. The best case for alpha beta

With perfect move ordering, how many leaves does alpha beta read for b = 3 and depth d = 4?
  1. Knuth and Moore (1975): the best case reads b^⌈d ÷ 2⌉ + b^⌊d ÷ 2⌋ − 1 leaves.
  2. 3² + 3² − 1.
  3. 17 leaves out of 3⁴ = 81. Search can go about twice as deep in the same time

Challenge 9. Expectimax is not safe under a change of scale

A chance node picks between leaves 0 and 4 with equal chance. Another branch gives 3 for sure. Replace every leaf x by x². Can MAX change its move?
  1. Before: the chance node is 0.5 × 0 + 0.5 × 4 = 2 and the sure branch is 3, so MAX picks the sure 3.
  2. After: the chance node is 0.5 × 0 + 0.5 × 16 = 8 and the sure branch is 9. MAX still picks the sure branch.
  3. Now try leaves 0 and 6 against a sure 4. Before squaring: 3 against 4, so MAX picks the sure branch. After squaring: 18 against 16, so MAX picks the gamble.
  4. minimax only needs the order of leaf values, expectimax needs the values themselves
Lesson 5 of 12

Challenge set 4: logic and inference

Challenge 10. A resolution proof

KB: P ⇒ Q, Q ⇒ R, P. Prove R by resolution. (Chapter 7.2.)

Model answer
  1. Turn the KB into clauses: ¬P ∨ Q, ¬Q ∨ R, P. Add the negated goal ¬R.
  2. Resolve ¬R with ¬Q ∨ R to get ¬Q.
  3. Resolve ¬Q with ¬P ∨ Q to get ¬P.
  4. Resolve ¬P with P to get the empty clause.
  5. KB ∧ ¬R is unsatisfiable, so KB ⊨ R

Challenge 11. Count the models

How many models over P, Q and R make (P ∨ Q) ∧ (¬P ∨ R) true?
  1. If P is true, the first clause holds and the second needs R true. Q is free: 2 models.
  2. If P is false, the second clause holds and the first needs Q true. R is free: 2 models.
  3. 2 + 2 = 4 models out of 8

Challenge 12. Unification and the occurs check

Unify Knows(John, x) with Knows(y, Mother(y)). Then try x with F(x).
  1. First arguments: John and y, so bind y to John.
  2. Second arguments: x and Mother(y), which is now Mother(John). Bind x to Mother(John).
  3. The most general unifier is y/John, x/Mother(John).
  4. x with F(x) fails: x would have to contain itself, which the occurs check forbids
In the exam
Forward chaining is complete for definite clauses only. Resolution is refutation complete for any clauses. A favourite exam trap gives a KB with a disjunction such as A ∨ B and asks for forward chaining.
Lesson 6 of 12

Challenge set 5: planning

Challenge 13. The Sussman anomaly

C is on A, and A and B are on the table. The goal is On(A, B) ∧ On(B, C). Why does solving one sub-goal at a time fail? (Chapters 8.2 and 8.3.)

Model answer
  1. Try On(A, B) first: move C to the table, put A on B. Now B is under A, and to get On(B, C) we must take A off again.
  2. Try On(B, C) first: put B on C. Now A is buried under C and B, and to get On(A, B) we must undo On(B, C).
  3. Either order undoes the sub-goal it reached first. The sub-goals interact.
  4. the shortest plan interleaves them: C to table, B on C, A on B

Challenge 14. Regress a goal through an action

Goal: At(B) ∧ Have(Milk). Action Go(A, B): precondition At(A), add At(B), delete At(A). Regress the goal.
  1. The action is relevant because it adds At(B), part of the goal. It deletes nothing in the goal.
  2. Regression removes what the action adds and adds its preconditions: (goal minus add list) plus preconditions.
  3. the new goal is At(A) ∧ Have(Milk)

Challenge 15. Resolve a threat

A partial order plan has a causal link from Buy to Cook that protects Have(Milk). Another step Drink deletes Have(Milk). Fix it.
  1. Drink is a threat: if it runs between Buy and Cook, Cook loses its precondition.
  2. Demotion puts Drink before Buy. Promotion puts Drink after Cook.
  3. pick whichever ordering keeps the plan consistent, and backtrack if neither does

Challenge set 6: probability and Bayesian networks

Challenge 16. A positive test for a rare disease

A disease affects 1 percent of people. The test is positive for 90 percent of the ill and for 10 percent of the healthy. P(ill | positive)?
  1. P(pos) = 0.9 × 0.01 + 0.1 × 0.99 = 0.009 + 0.099 = 0.108.
  2. Bayes rule: P(ill | pos) = 0.009 ÷ 0.108.
  3. ≈ 0.083. Most positives are healthy people, because healthy people are so many more

Challenge 17. Parameters saved by a Bayesian network

The burglary network has Boolean nodes B, E, A (parents B and E), J and M (parent A each). Count the numbers needed.
  1. B and E need 1 each. A needs 4, one for each pair of parent values. J and M need 2 each.
  2. 1 + 1 + 4 + 2 + 2 = 10.
  3. 10 numbers, against 2⁵ − 1 = 31 for the full joint table

Challenge 18. When does a collider open?

In the same network, are B and E independent? Are they independent given J?
  1. With no evidence, the only path B, A, E has a collider at A with nothing observed below it. It is blocked, so B and E are independent.
  2. J is a child of A. Observing a descendant of a collider opens it.
  3. B and E become dependent given J: explaining away
In the exam
The answer P(B | j, m) ≈ 0.284 from chapter 9.3 is worth knowing by heart. Exams often give the burglary tables and ask for it, or for P(J | b) by summing out A.
Lesson 8 of 12

Challenge set 7: MDPs and reinforcement learning

Challenge 19. Watch value iteration shrink its error

State s1 always pays 2 and stays. In s0, "stay" pays 1 and stays, "go" pays 0 and moves to s1. γ = 0.9. (Chapter 10.1.)

Model answer
  1. Exact values: V(s1) = 2 ÷ (1 − 0.9) = 20. Staying in s0 forever is worth 1 ÷ 0.1 = 10. Going is worth 0 + 0.9 × 20 = 18.
  2. So V(s0) = 18 and the best action in s0 is "go".
  3. Starting from 0, the biggest change in each sweep is 2, 1.8, 1.62, and so on: it shrinks by γ every time.
  4. that is the contraction property: ‖BU − BU′‖ ≤ γ ‖U − U′‖

Challenge 20. How many sweeps are enough?

With R_max = 1 and γ = 0.9, how many sweeps make the error at most ε = 0.1, using the bound N = ⌈log(2 R_max ÷ (ε (1 − γ))) ÷ log(1 ÷ γ)⌉ from AIMA?
  1. 2 R_max ÷ (ε (1 − γ)) = 2 ÷ (0.1 × 0.1) = 200.
  2. log 200 ÷ log(1 ÷ 0.9) ≈ 5.298 ÷ 0.1054 ≈ 50.3.
  3. N = 51 sweeps

Challenge 21. One Q-learning step

Q(s, a) = 2, α = 0.5, γ = 0.9. The agent gets r = 1 and the best Q in s′ is 3. Update Q(s, a).
  1. Target = r + γ max Q(s′, a′) = 1 + 0.9 × 3 = 3.7.
  2. Error = 3.7 − 2 = 1.7.
  3. Q(s, a) ← 2 + 0.5 × 1.7 = 2.85
Lesson 9 of 12

Proofs examiners ask for

At the top universities, about a third of the marks are for short proofs. Each model answer below names the assumption it uses, which is where marks are lost.

Proof 1. A* graph search with a consistent heuristic is optimal

Model answer
  1. If n′ is a successor of n, then g(n′) = g(n) + c(n, n′), so f(n′) = g(n) + c(n, n′) + h(n′) ≥ g(n) + h(n) = f(n) by consistency. So f never goes down along a path.
  2. Suppose A* expands a node n with a path that is not the cheapest. Some node m on the cheapest path to n is on the frontier, with f(m) ≤ f(n) on that path.
  3. Since f does not decrease, m would be expanded before n. Repeating the argument, the cheapest path reaches n first.
  4. So every node is first expanded with its cheapest g. The goal is too, and h(goal) = 0 gives f = the optimal cost.

Proof 2. Alpha beta returns the minimax value

Model answer
  1. At a MIN node with value v ≤ α, MAX above already has a choice worth α, so MAX will never choose this node. Its exact value cannot change the root.
  2. At a MAX node with v ≥ β, MIN above has a choice worth β and will avoid it. The same reasoning applies.
  3. Only these branches are cut, so every node on the principal line keeps its exact minimax value.

Proof 3. The Bellman update is a contraction

Model answer
  1. Write (BU)(s) = R(s) + γ max over a of Σ P(s′ | s, a) U(s′).
  2. For any two functions f and g, |max f − max g| ≤ max |f − g|.
  3. So |(BU)(s) − (BU′)(s)| ≤ γ max over a of Σ P(s′ | s, a) |U(s′) − U′(s′)| ≤ γ ‖U − U′‖.
  4. With γ < 1 the error shrinks each sweep, so there is one fixed point and value iteration reaches it from any start (Banach fixed point theorem).

Proof 4. Resolution is sound

Model answer
  1. Take clauses A ∨ ℓ and B ∨ ¬ℓ, and a model that makes both true.
  2. If ℓ is true in it, then ¬ℓ is false, so B must be true. If ℓ is false, A must be true.
  3. Either way A ∨ B is true. So every model of the parents is a model of the resolvent.

Proof 5. Tree shaped CSPs need no backtracking

Model answer
  1. Order the variables so each one comes after its parent, then make every parent to child arc consistent, last to first.
  2. Assign the root any value left in its domain. For each child, arc consistency guarantees a value that agrees with the parent’s value.
  3. Each variable has only one parent, so no other constraint can rule that value out. So the forward pass never fails, in O(n d²) time.

Lesson 11 of 12

From intuition to research

One idea, four depths

Every Core AI method answers one question: what should I do next? Search tries paths, logic proves facts, Bayes nets weigh chances, and RL learns from rewards.

Run each method by hand on a small example: A* with a table of f values, AC-3 on three variables, alpha beta with α and β written at every node, enumeration on the burglary net, and a value iteration sweep.

Know when each theorem holds: consistency for A* graph search, definite clauses for chaining, d-separation for independence, γ < 1 for contraction, and the conditions for Q-learning to converge (every pair visited forever, step sizes with Σ α = ∞ and Σ α² < ∞).

Research problems join the steps: learned heuristics for search (AlphaZero joins MCTS and deep networks), neuro symbolic reasoning, planning with learned models (MuZero), causal reinforcement learning, and large language models used as planners and checked by classical planners or verifiers.

Lesson 12 of 12

Chapter summary

  1. Use five moves on any problem: name the model, write the formula, check its conditions, work step by step, and say what the answer means.
  2. Search: an admissible but inconsistent h can fool A* graph search. IDS costs only about 11 percent more than BFS for b = 10.
  3. CSPs and games: AC-3 can solve a CSP alone, tree CSPs take O(n d²), alpha beta reads b^⌈d ÷ 2⌉ + b^⌊d ÷ 2⌋ − 1 leaves at best.
  4. Logic and planning: refute KB ∧ ¬α by resolution, use the occurs check, interleave interacting sub-goals, and fix threats by promotion or demotion.
  5. Uncertainty and RL: mind the base rate, open colliders by observing a descendant, and use the γ contraction to bound value iteration.
