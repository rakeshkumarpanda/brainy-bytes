Lesson 1 of 8

Local search for CSPs: min-conflicts

Source: slide Set 2, slides 78 and 79, and slide Set 4.

What it is
Min-conflicts starts with a complete assignment, maybe breaking many constraints, and repeatedly picks a variable that is in conflict and gives it the value that breaks the fewest constraints.
Why we need it
Backtracking builds a solution one variable at a time and can get lost deep in a huge tree. For many large CSPs, solutions are spread densely all over the space, so starting from a full guess and repairing it is much faster.
How it works
Assign every variable at random. Loop: if no constraint is broken, stop. Otherwise choose a conflicted variable at random, count the conflicts for each of its values, and move it to a value with the fewest conflicts (ties at random).
MIN-CONFLICTS (AIMA figure 6.8)
function MIN-CONFLICTS(csp, max_steps):
    current = a complete assignment (random, or greedy)
    for i = 1 to max_steps:
        if current is a solution: return current
        var = a randomly chosen conflicted variable
        value = the value v of var that minimises CONFLICTS(var, v, current)
        set var = value in current
    return failure

AIMA reports that min-conflicts solves even the million queens problem in about 50 steps on average after the initial assignment, and that a min-conflicts style method cut the time to schedule a week of Hubble Space Telescope observations from three weeks to around 10 minutes.

Lesson 2 of 8

Plateaux, tabu search and constraint weighting

Min-conflicts is hill climbing (chapter 4.1) with the number of broken constraints as the cost. It has the same traps: plateaux where every move keeps the same number of conflicts, and local minima.

FixIdea
Sideways movesAllow moves to a value with the same number of conflicts, so the search can cross a plateau
Tabu searchKeep a short list of recently visited states (or recently changed variables) and do not go back to them, so the search does not bounce between the same few states
Constraint weightingGive every constraint a weight, starting at 1. After each step, add 1 to the weight of every broken constraint. Minimise the total weight. Hard constraints that keep breaking become expensive, which changes the landscape and pushes the search out of local minima
Random restarts and random walkStart again, or sometimes make a random move instead of the best one
Online repairWhen the problem changes (a flight is cancelled), start min-conflicts from the old solution: only a few variables need to change
Common mistake
Local search cannot prove that a CSP has no solution. It just fails to find one. Backtracking with propagation can prove it, for example that 2 colours are not enough for Australia.
Lesson 3 of 8

Using the shape of the problem: independent parts and trees

Independent sub problemsExam favourite
connected components solved separately: O(dc · n ⁄ c) instead of O(dn)
Tasmania is not connected to the mainland, so colour it on its own. If n = 80 splits into 4 parts of 20 with d = 2: 4 × 2²⁰ ≈ 4 million against 2⁸⁰ ≈ 10²⁴.
Tree structured CSPExam favourite
solvable in O(n d²)
If the constraint graph is a tree (no loops), there is no need to backtrack at all.
The tree algorithm
  1. Pick any variable as the root and list the variables so that each parent comes before its children (a topological order).
  2. Backward pass: for j from n down to 2, make the arc (parent of Xj, Xj) arc consistent. This is called directional arc consistency.
  3. Forward pass: for j from 1 to n, give Xj any value consistent with its parent's value.
  4. each arc is revised once at cost d², so the total is O(n d²), and the forward pass never gets stuck

A chain A < B < C < D is a tree. After arc consistency each variable has two values left, and a forward pass in order A, B, C, D always finds a solution, for example A = 1, B = 2, C = 3, D = 4.

Lesson 4 of 8

Cutset conditioning and tree decomposition

What it is
Cutset conditioning turns a graph with loops into a tree by assigning a few variables first. Tree decomposition groups variables into overlapping clusters that form a tree.
Why we need it
Most real constraint graphs are not trees, but many are close to trees. Both methods use that closeness to get far below dn.
How it works
Cutset: choose a set S of variables whose removal leaves a tree (a cycle cutset). For every consistent assignment of S, remove the values in the rest that clash with it, and solve the remaining tree in O((n − c) d²). Tree decomposition: solve each cluster as a mega variable whose values are the cluster's solutions, and join the clusters with the tree algorithm.
Cutset conditioningExam favourite
O(dc · (n − c) d²)
c is the size of the cutset. Australia: removing SA leaves a tree (a chain plus T), so c = 1.
Tree decomposition
O(n dw+1)
w is the tree width: the size of the largest cluster minus 1. CSPs with small tree width are easy.
Worked example: Australia with the cutset {SA}
  1. Assign SA one of 3 colours.
  2. Remove that colour from WA, NT, Q, NSW and V. They now form the chain WA, NT, Q, NSW, V, plus T on its own.
  3. Solve that tree in O((n − 1) d²) = 6 × 9 = 54 checks at most.
  4. total work at most 3 × 54 = 162 checks, against 3⁷ = 2,187 assignments

The maths of problem structure

Backtracking worst case
O(dn)
For any CSP.
Tree CSP
O(n d²)
Linear in n.
Cutset
O(dc (n − c) d²)
Exponential only in the cutset size c.
Tree decomposition
O(n dw+1)
Exponential only in the tree width w.
Worked example: how much a tree saves
  1. n = 20 variables, d = 3 values, the graph is a tree.
  2. Backtracking worst case: 3²⁰ ≈ 3.5 × 10⁹.
  3. Tree algorithm: 20 × 3² = 180 checks.
  4. about 19 million times less work
Worked example: a cutset
  1. A graph of n = 30 variables with d = 2 becomes a tree after removing c = 3 variables.
  2. dc = 2³ = 8 assignments of the cutset.
  3. Each leaves a tree of 27 variables: 27 × 2² = 108 checks.
  4. 8 × 108 = 864 checks, against 2³⁰ ≈ 1.07 × 10⁹

Bottom line: use min-conflicts when solutions are plentiful and the problem is big or keeps changing. Use backtracking with MRV and MAC when solutions are rare or you need a proof. Check the graph shape first: a tree is solved in linear time.

Real world scenario: airline crew rescheduling

When a storm cancels flights, an airline must reassign crews quickly. Starting from scratch would move almost everyone. Min-conflicts style repair starts from yesterday's schedule, which is almost right, and changes only the crews involved in broken constraints. The new schedule is close to the old one, which crews and passengers prefer.

Lesson 7 of 8

From intuition to research

One idea, four depths

Min-conflicts is fixing a messy seating plan: put everyone somewhere, then keep moving one unhappy person to the seat where the fewest neighbours bother them, until everyone is happy.

Min-conflicts: random full assignment, then move a conflicted variable to its least conflicting value. Very fast on N queens, but incomplete. Tree CSPs: O(n d²) with a backward arc consistency pass and a forward assignment pass. Cutset conditioning: O(dc(n − c)d²). Tree decomposition: O(n dw+1).

Min-conflicts works well when the ratio of constraints to variables is low, because solutions are dense. Near the phase transition, where random problems switch from mostly solvable to mostly unsolvable, all methods slow down. Finding a minimum cycle cutset or an optimal tree decomposition is itself NP hard, so heuristics are used.

Modern local search solvers for SAT and CSP (WalkSAT, constraint weighting methods such as breakout) are competitive on random instances, and hybrid solvers run local search and systematic search together, sharing learned clauses. Tree width also explains why Bayesian network inference (chapter 9.3) is easy on some graphs and hard on others.

Lesson 8 of 8

Chapter summary

  1. Min-conflicts: start from a complete assignment, pick a conflicted variable at random, move it to the value with the fewest conflicts. AIMA reports about 50 steps for a million queens.
  2. It is hill climbing on the number of broken constraints: helped by sideways moves, tabu lists, constraint weighting and restarts. It cannot prove that no solution exists.
  3. Independent sub problems are solved separately. Tree structured CSPs take O(n d²): directional arc consistency backward, then assign forward with no backtracking.
  4. Cutset conditioning: assign a cycle cutset of size c, then solve the tree, O(dc(n − c)d²). Australia has the cutset {SA}.
  5. Tree decomposition: O(n dw+1) for tree width w.
