Lesson 1 of 10

Knowledge based agents

Source: Russell and Norvig, AIMA 4th ed., section 7.1. The uploaded slides stop at adversarial search, so this step follows the textbook.

What it is
A knowledge based agent keeps a knowledge base (KB): a set of sentences in a formal language that say what the agent believes about the world. It adds new sentences with TELL and asks questions with ASK. The answer to ASK must follow from what was told.
Why we need it
Search agents know only a fixed list of states and actions. They cannot use general facts such as "a breeze means a pit next door" in new situations. A KB lets an agent combine general rules with what it sees and work out facts it never saw directly.
How it works
Each time step: TELL the KB what the agent perceives, ASK the KB which action is best, TELL the KB that this action was taken, then act. The reasoning happens inside ASK, by an inference procedure.
KB-AGENT
function KB-AGENT(percept) returns an action
    persistent: KB, a knowledge base. t, a counter for time, at first 0
    TELL(KB, MAKE-PERCEPT-SENTENCE(percept, t))
    action = ASK(KB, MAKE-ACTION-QUERY(t))
    TELL(KB, MAKE-ACTION-SENTENCE(action, t))
    t = t + 1
    return action

This is the declarative way to build an agent: tell it what it needs to know and let it reason. The procedural way writes the behaviour straight into code. Real systems mix both.

Lesson 2 of 10

The wumpus world

Source: AIMA 4th ed., section 7.2.

A cave of 4 × 4 rooms. The agent starts in [1,1] facing right. One room holds the wumpus, a beast that eats anyone who enters its room. Some rooms hold bottomless pits. One room holds gold. The agent has one arrow.

PEAS partWumpus world
Performance+1000 for climbing out with the gold, −1000 for falling into a pit or being eaten, −1 for each action, −10 for using the arrow
Environment4 × 4 grid of rooms, agent starts in [1,1]. The wumpus and the gold are placed at random in other rooms, and each other room has a pit with probability 0.2
ActuatorsForward, TurnLeft, TurnRight, Grab, Shoot, Climb
SensorsStench (wumpus next door), Breeze (pit next door), Glitter (gold here), Bump (walked into a wall), Scream (the wumpus died)
Reasoning in the first moves
  1. In [1,1] the percept is [None, None, None, None, None]: no stench and no breeze. So [1,2] and [2,1] are safe.
  2. The agent moves to [2,1] and feels a Breeze. So there is a pit in [2,2] or [3,1], or both.
  3. It goes back and moves to [1,2]. It smells a Stench but feels no Breeze.
  4. No breeze in [1,2] means no pit in [2,2]. So the pit is in [3,1]. The stench in [1,2], with no stench in [2,1], puts the wumpus in [1,3].
  5. the agent has worked out facts it never saw directly: this is logical inference
Remember
Room names are [column, row]. [2,1] is one step right of the start, [1,2] is one step up.

Logic: syntax, semantics, models and entailment

Source: AIMA 4th ed., section 7.3.

IdeaMeaningExample
SyntaxWhich strings are well formed sentencesx + y = 4 is a sentence, x4y+ = is not
SemanticsWhen a sentence is true. A sentence is true or false in each possible worldx + y = 4 is true in the world where x = 2, y = 2
ModelA possible world, fixed exactly. In propositional logic: a true or false value for every symbolP = T, Q = F, R = T
M(α)The set of all models in which α is trueM(P ∨ Q) has 3 of the 4 models of P, Q

EntailmentExam favourite
KB ⊨ α if and only if M(KB) ⊆ M(α)
The more a KB says, the fewer models it has. If all of them make α true, α follows.
Property of an inference procedure iMeaning
KB ⊢i αProcedure i derives α from the KB
Sound (truth preserving)It derives only entailed sentences: if KB ⊢i α then KB ⊨ α
CompleteIt can derive every entailed sentence: if KB ⊨ α then KB ⊢i α
GroundingThe link between the sentences and the real world. It comes from the sensors and from learning, not from logic
Lesson 4 of 10

Propositional logic

Source: AIMA 4th ed., section 7.4.

The simplest logic. Atomic sentences are single symbols such as P, Q or P1,2 ("there is a pit in [1,2]"). True and False are also sentences. Complex sentences are built with five connectives.

ConnectiveNameRead asTrue when
¬Pnegationnot PP is false
P ∧ QconjunctionP and Qboth are true
P ∨ QdisjunctionP or Qat least one is true
P ⇒ Qimplicationif P then QP is false, or Q is true. False only for P = T, Q = F
P ⇔ QbiconditionalP if and only if Qboth have the same value

Precedence, from strongest to weakest: ¬, ∧, ∨, ⇒, ⇔. So ¬A ∧ B ∨ C ⇒ D means ((¬A ∧ B) ∨ C) ⇒ D.

Common mistake
P ⇒ Q is true whenever P is false. "If 5 is even, then Sam is smart" is true in propositional logic, whatever Sam is like. Implication does not mean that P causes Q.

A knowledge base for the wumpus world, and model checking

Source: AIMA 4th ed., sections 7.4.3 and 7.4.4. We ran the check ourselves and got the same numbers as the textbook.

Symbols: Px,y is true if there is a pit in [x,y], Bx,y if the agent feels a breeze in [x,y]. After the first two moves the KB holds:

NameSentenceMeaning
R1¬P1,1no pit in the start room
R2B1,1 ⇔ (P1,2 ∨ P2,1)a room is breezy if and only if a neighbour has a pit
R3B2,1 ⇔ (P1,1 ∨ P2,2 ∨ P3,1)the same rule for [2,1]
R4¬B1,1percept: no breeze in [1,1]
R5B2,1percept: breeze in [2,1]
Model checking
  1. There are 7 symbols: B1,1, B2,1, P1,1, P1,2, P2,1, P2,2, P3,1. So 2⁷ = 128 models.
  2. Only 3 of them make R1 to R5 all true: pits in [2,2] and [3,1], a pit in [2,2] only, or a pit in [3,1] only.
  3. P1,2 is false in all 3, so KB ⊨ ¬P1,2: [1,2] is safe.
  4. P2,2 is true in 2 and false in 1, so the KB entails neither P2,2 nor ¬P2,2. The agent cannot tell yet.
  5. KB ⊨ ¬P1,2, KB ⊨ P2,2 ∨ P3,1, but not KB ⊨ P2,2
TT-ENTAILS (truth table enumeration)
function TT-ENTAILS(KB, α): symbols = the symbols in KB and α
    return TT-CHECK-ALL(KB, α, symbols, { })

function TT-CHECK-ALL(KB, α, symbols, model):
    if symbols is empty:
        if PL-TRUE(KB, model): return PL-TRUE(α, model)
        else: return true          (a model where KB is false does not matter)
    P = FIRST(symbols), rest = REST(symbols)
    return TT-CHECK-ALL(KB, α, rest, model ∪ {P = true}) and
           TT-CHECK-ALL(KB, α, rest, model ∪ {P = false})

TT-ENTAILS is sound and complete, but it takes O(2n) time for n symbols, and O(n) space because it explores the models depth first.

Validity, satisfiability and equivalence

Source: AIMA 4th ed., section 7.5.1.

TermMeaningExample
Valid (a tautology)True in every modelP ∨ ¬P
SatisfiableTrue in at least one modelP ∧ Q
UnsatisfiableTrue in no modelP ∧ ¬P
Equivalent, α ≡ βTrue in exactly the same models. Same as α ⊨ β and β ⊨ αP ⇒ Q ≡ ¬P ∨ Q
Deduction theoremExam favourite
KB ⊨ α if and only if (KB ⇒ α) is valid
Entailment can be checked as validity.
Proof by contradiction (refutation)Exam favourite
KB ⊨ α if and only if (KB ∧ ¬α) is unsatisfiable
Assume α is false and show this is impossible. Resolution (chapter 7.2) works this way.
EquivalenceName
α ∧ β ≡ β ∧ α, α ∨ β ≡ β ∨ αcommutativity
(α ∧ β) ∧ γ ≡ α ∧ (β ∧ γ), and the same for ∨associativity
¬(¬α) ≡ αdouble negation
α ⇒ β ≡ ¬β ⇒ ¬αcontraposition
α ⇒ β ≡ ¬α ∨ βimplication elimination
α ⇔ β ≡ (α ⇒ β) ∧ (β ⇒ α)biconditional elimination
¬(α ∧ β) ≡ ¬α ∨ ¬β, ¬(α ∨ β) ≡ ¬α ∧ ¬βDe Morgan
α ∧ (β ∨ γ) ≡ (α ∧ β) ∨ (α ∧ γ), α ∨ (β ∧ γ) ≡ (α ∨ β) ∧ (α ∨ γ)distributivity

Deciding if a sentence is satisfiable (the SAT problem) was the first problem proved NP-complete (Cook, 1971). So we do not expect any method to beat 2n on every input, yet modern SAT solvers handle millions of symbols in practice.

Lesson 7 of 10

The maths: counting models

Number of modelsExam favourite
2n for n symbols
3 symbols: 8 models. 7 symbols: 128. 30 symbols: over 10⁹.
Number of different sentences up to equivalence
22n
Each sentence is fixed by the set of models where it is true, and there are 22n such sets. For n = 2 there are 16 different truth tables.
Entailment as sets
KB ⊨ α ⟺ M(KB) ⊆ M(α) ⟺ M(KB) ∩ M(¬α) = ∅
The last form is proof by contradiction.
Worked example: how many models make P ∨ Q true, with symbols P, Q, R?
  1. 2³ = 8 models in total.
  2. P ∨ Q is false only when P = F and Q = F. R can then be T or F: 2 models.
  3. 8 − 2 = 6.
  4. |M(P ∨ Q)| = 6 out of 8
Worked example: is (P ⇒ Q) ⇒ (¬Q ⇒ ¬P) valid?
  1. ¬Q ⇒ ¬P is equivalent to P ⇒ Q (contraposition).
  2. So the sentence is (P ⇒ Q) ⇒ (P ⇒ Q), which has the form α ⇒ α.
  3. α ⇒ α ≡ ¬α ∨ α, true in every model.
  4. valid

Bottom line: propositional logic is the simplest language with a clear meaning and sound, complete inference. Its weakness is that it cannot talk about many objects at once, which first order logic fixes.

Real world scenario: Where propositional reasoning is used

Hardware verification: chip makers check that a circuit design meets its specification by turning the question into a SAT problem. Software package managers (such as the ones for Linux) decide which versions of packages to install with SAT solvers. Planning systems such as SATPlan turn "is there a plan of length T" into one big propositional sentence.

Lesson 9 of 10

From intuition to research

One idea, four depths

A knowledge base is a list of facts and rules the agent believes. If something must be true in every world that fits these facts, the agent can be sure of it, even without seeing it.

Propositional logic has symbols and five connectives. KB ⊨ α means M(KB) ⊆ M(α). Truth table model checking is sound and complete but costs 2n. Validity, satisfiability and the deduction theorem connect entailment to SAT.

SAT is NP-complete (Cook 1971, Levin 1973). Random 3-SAT shows a sharp phase change near 4.26 clauses per symbol, where problems are hardest. Propositional logic is compact: the same set of models can need exponentially long sentences in one normal form and short ones in another.

Research looks at proof complexity (how long the shortest proof of an unsatisfiable formula must be in a given proof system), knowledge compilation into forms such as d-DNNF that answer many queries fast, and neurosymbolic systems that combine logic with learned models.

Lesson 10 of 10

Chapter summary

  1. A knowledge based agent TELLs its KB what it perceives and ASKs it what to do. The answers come from inference.
  2. In the wumpus world, the agent works out where pits and the wumpus are from breezes and stenches.
  3. A model fixes every fact. KB ⊨ α means α is true in every model of the KB: M(KB) ⊆ M(α). Sound procedures derive only entailed sentences, complete ones derive all of them.
  4. Propositional logic: symbols, ¬ ∧ ∨ ⇒ ⇔. P ⇒ Q is false only when P is true and Q is false.
  5. Model checking with a truth table is sound and complete but costs 2n. The wumpus KB R1 to R5 has 3 models out of 128 and entails ¬P1,2.
