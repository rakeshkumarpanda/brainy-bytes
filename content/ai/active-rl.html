Lesson 1 of 8

Active learning: explore or exploit

Source: AIMA 3rd ed., section 21.3.1 (4th ed., 22.3), Sutton and Barto (2018), chapter 2, and Auer, Cesa-Bianchi and Fischer (2002) for UCB1. The uploaded slides and transcripts do not cover this step.

What it is
In active RL the agent picks its own actions. It must balance exploitation (take the action that looks best now) and exploration (try other actions to learn whether they are better).
Why we need it
A purely greedy agent locks onto the first policy that looks good and never finds out that another route was better. A purely random agent learns a lot but never uses it. Both lose reward.
How it works
Explore more at first and less later. ε-greedy takes a random action with probability ε. An exploration function makes rarely tried actions look attractive. UCB adds a bonus that shrinks as an action is tried more often.
ε-greedy
with probability ε a random action, otherwise argmax over a of Q(s, a)
Simple and widely used.
Exploration function (AIMA)Exam favourite
f(u, n) = R⁺ if n < N_e, else u
Optimistic about actions tried fewer than N_e times.
UCB1
pick argmax over i of x̄ᵢ + √(2 ln n ÷ nᵢ)
Mean so far plus a bonus for uncertainty. Its regret grows only like log n.
GLIE
try every action infinitely often, and become greedy in the limit
A condition under which the learned policy becomes optimal.
Remember
The same trade off appears in the expectimax chapter (6.3) in UCT, which uses UCB1 inside Monte Carlo tree search to pick which move to try next.
Lesson 2 of 8

Q-learning

Source: Watkins (1989), Watkins and Dayan (1992), and AIMA 3rd ed., section 21.3.2.

What it is
Q-learning learns Q(s, a), the value of each action in each state, straight from experience. The agent acts, sees the reward and the next state, and moves Q(s, a) towards r + γ max over a′ of Q(s′, a′).
Why we need it
With Q the agent can pick the best action by looking up a table: no transition model is needed, neither for learning nor for choosing actions. That makes it model free all the way.
How it works
After each step (s, a, r, s′): Q(s, a) ← Q(s, a) + α (r + γ max over a′ of Q(s′, a′) − Q(s, a)). Act with ε-greedy or an exploration function. With every pair tried infinitely often and a Robbins Monro learning rate, Q converges to Q*.
Q-learning updateExam favourite
Q(s, a) ← Q(s, a) + α [r + γ max over a′ of Q(s′, a′) − Q(s, a)]
Off policy: the target uses the best next action.
SARSA update
Q(s, a) ← Q(s, a) + α [r + γ Q(s′, a′) − Q(s, a)]
On policy: a′ is the action the agent really takes next.
Greedy policy
π(s) = argmax over a of Q(s, a)
No model needed.
Worked example: one Q-learning update
  1. Q(s, a) = 0.2. The agent gets r = 0 and lands in s′, where the best Q value is 0.8. γ = 0.9, α = 0.5.
  2. Target: 0 + 0.9 × 0.8 = 0.72.
  3. Error: 0.72 − 0.2 = 0.52.
  4. Q(s, a) ← 0.2 + 0.5 × 0.52 = 0.46
Lesson 3 of 8

SARSA, on policy and off policy

Source: Rummery and Niranjan (1994), and Sutton and Barto (2018), section 6.5 and example 6.6 (cliff walking).

What it is
SARSA is named after the five things in its update: State, Action, Reward, next State, next Action. It learns the value of the policy it actually follows, exploration included. Q-learning learns the value of the greedy policy, whatever it does while exploring.
Why we need it
When exploration is costly, the difference matters. On a cliff edge, an exploring agent sometimes slips. SARSA learns to keep a safe distance. Q-learning learns the shortest path along the edge, which is optimal only for an agent that never explores.
How it works
Both use the same loop. SARSA chooses a′ first and uses Q(s′, a′) in the target. Q-learning uses max over a′ of Q(s′, a′) and may then take a different a′.
Q-learningSARSA
LearnsQ* of the greedy policy (off policy)Q of the ε-greedy policy it follows (on policy)
Cliff walking pathshortest, along the edge (13 steps)safer, one or two rows up
Reward while learninglower: it falls more while exploringhigher
Can learn fromany data, even another agent’sits own current policy only

Function approximation and deep Q-networks

Source: AIMA 3rd ed., section 21.4, Mnih and others (2015), Human level control through deep reinforcement learning, Nature, and Tesauro (1995).

What it is
A table with one entry per state is impossible for chess (about 10⁴⁰ positions) or for screen images. Function approximation replaces the table with a formula Q̂_θ(s, a) that has a few parameters θ, such as a weighted sum of features or a neural network.
Why we need it
The formula generalises: what is learned in one state carries over to similar states never seen before. A few thousand parameters can stand for billions of states.
How it works
Use the same TD target, and move θ a little in the direction that reduces the error: θ ← θ + α [r + γ max over a′ of Q̂(s′, a′) − Q̂(s, a)] ∇_θ Q̂(s, a). DQN does this with a deep network, plus a replay buffer of past steps and a slowly updated target network for stability.
Linear approximation
Û_θ(s) = θ₀ + θ₁ f₁(s) + ... + θₙ fₙ(s)
f are features, such as the x and y of a square.
Gradient TD updateExam favourite
θᵢ ← θᵢ + α [target − Q̂(s, a)] ∂Q̂ ÷ ∂θᵢ
For a linear Q̂ the derivative is just the feature value.
Worked example: a linear utility for the 4 × 3 world
  1. Û(x, y) = θ₀ + θ₁ x + θ₂ y with θ = (0.5, 0.2, 0.1). At (1,1): Û = 0.5 + 0.2 + 0.1 = 0.8.
  2. The observed reward to go is 0.705 (the true value), so the error is 0.705 − 0.8 = −0.095.
  3. With α = 0.1: θ₀ ← 0.5 + 0.1 × (−0.095) × 1 = 0.4905.
  4. θ₁ and θ₂ also fall by 0.0095, since x = y = 1
Common mistake
With function approximation, Q-learning can diverge: off policy data, bootstrapping and approximation together (the deadly triad). DQN’s replay buffer and target network were added to keep training stable.

The maths: the Bellman equation for Q and convergence

Bellman optimality for QExam favourite
Q*(s, a) = Σ P(s′ | s, a) [R(s, a, s′) + γ max over a′ of Q*(s′, a′)]
Q-learning is a sampled version of this.
ε-greedy action chances
best action: 1 − ε + ε ÷ |A|, each other action: ε ÷ |A|
The random choice can also pick the best action.
Convergence of Q-learning
every (s, a) tried infinitely often, Σ αₜ = ∞, Σ αₜ² < ∞
Watkins and Dayan, 1992, for tables.
UCB1 regret
expected regret after n pulls is O(log n)
Lai and Robbins (1985) showed log n is the best possible order.
Worked example: the optimal Q values of the corridor 0 1 2 3 (goal 3 gives +1, γ = 0.9)
  1. Q*(2, R) = 1: one step to the goal.
  2. Q*(1, R) = 0 + 0.9 × 1 = 0.9.
  3. Q*(0, R) = 0.9 × 0.9 = 0.81.
  4. Q*(1, L) = 0 + 0.9 × max Q*(0, ·) = 0.9 × 0.81.
  5. Q*(1, L) = 0.729

Bottom line: model based learning uses data best, model free learning is simpler and scales with function approximation. Modern systems such as AlphaZero and MuZero mix both.

Real world scenario: Deep reinforcement learning milestones

DQN (2015) learned 49 Atari games from screen pixels and the score, and played many of them as well as a professional human tester. AlphaGo (Silver and others, 2016) beat Lee Sedol at Go, combining policy and value networks with Monte Carlo tree search. RL from human feedback (Christiano and others, 2017, and later chat models) trains language models with a reward learned from people’s preferences.

Lesson 7 of 8

From intuition to research

One idea, four depths

To learn which choices are good, sometimes try something new. Keep a score for each choice in each situation and update it after every try.

Exploration (ε-greedy, exploration functions, UCB). Q-learning: Q ← Q + α(r + γ max Q′ − Q), off policy. SARSA: on policy. Function approximation with gradient TD.

GLIE conditions, Watkins and Dayan convergence for tabular Q-learning, regret bounds for bandits, maximisation bias in Q-learning and double Q-learning (van Hasselt, 2010), the deadly triad.

Research: sample efficient exploration (count based bonuses, curiosity), offline RL from fixed datasets, safe RL with constraints, and RL for reasoning in large language models.

Lesson 8 of 8

Chapter summary

  1. Active RL: the agent chooses actions and must balance exploration and exploitation. Greedy agents get stuck.
  2. ε-greedy, exploration functions f(u, n) and UCB1 make the agent try uncertain actions.
  3. Q-learning: Q(s, a) ← Q(s, a) + α [r + γ max Q(s′, a′) − Q(s, a)]. Off policy, model free, converges to Q*.
  4. SARSA uses the next action actually taken. On the cliff it learns a safer path than Q-learning.
  5. Function approximation and deep networks (DQN) scale Q-learning to huge state spaces, with care for stability.
