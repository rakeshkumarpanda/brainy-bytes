Lesson 1 of 3

A number for every outcome

Comparing outcomes two at a time gets tiring once there are many of them. A utility function does the work once: it gives each outcome a single real number so that bigger means better. Then choosing the best outcome is just finding the largest number.

Utility function
u : X → ℝ
A score for each outcome. It may stand for satisfaction, value, benefit or happiness. It is not money unless the model says so.
RepresentationExam favourite
x ⪰ y ⟺ u(x) ≥ u(y)
u represents ⪰ when the order of the numbers is exactly the order of the preference.
The two consequences
x ≻ y ⟺ u(x) > u(y),   x ∼ y ⟺ u(x) = u(y)
Strict preference matches a strictly larger number, and a tie matches equal numbers.
Common mistake
The slide transcript once read "u(x) = u(y) ⟺ x ⪰ y". That is a transcription slip. The correct condition for weak preference uses ≥. Equality belongs to indifference only.
Lecture example: A ≻ B, A ≻ C, B ∼ C
  1. We need u(A) larger than both u(B) and u(C), and u(B) = u(C).
  2. One choice: u(A) = 10, u(B) = 5, u(C) = 5.
  3. Another choice: u(A) = 100, u(B) = −10, u(C) = −10.
  4. Both satisfy u(A) > u(B) = u(C), so both represent the same preference.
Lesson 2 of 3

Ordinal and cardinal utility

If two different sets of numbers represent the same preference, which one is right? For a ranking, both are. Only the order matters, not the size of the gaps. Utility that carries only order is called ordinal.

Ordinal invarianceExam favourite
if f is strictly increasing,   v(x) = f( u(x) ) represents the same ⪰
Examples: 2u + 7, u³, eᵘ, and log u when u is positive. A decreasing f such as −u reverses the ranking.
Cardinal utility
u(A) − u(B) compared with u(C) − u(D)
Cardinal utility treats the size of a difference as meaningful. It needs more assumptions than ranking alone, and it returns in chapter 2.2 with lotteries.
Proof that an increasing f keeps the ranking
  1. Assume u represents ⪰ and f is strictly increasing, which means a ≥ b ⟺ f(a) ≥ f(b).
  2. Take any x and y. By representation, x ⪰ y ⟺ u(x) ≥ u(y).
  3. Apply f to both sides. Because f is strictly increasing, u(x) ≥ u(y) ⟺ f(u(x)) ≥ f(u(y)).
  4. So x ⪰ y ⟺ v(x) ≥ v(y), and v = f ∘ u represents ⪰.
Statement about u(A) = 10, u(B) = 5, u(C) = 1Ordinal meaningCardinal meaning
A is preferred to BYes, meaningfulYes, meaningful
A is twice as good as BNot meaningfulNot meaningful either. Ratios change with 2u + 7
The step from B to A is bigger than from C to BNot meaningfulMeaningful only when u is cardinal
Real world scenario: star ratings

A film site shows 1 to 5 stars. Saying a 5 star film is better than a 3 star film uses only order. Saying the 5 star film is worth as much as the 3 star film and the 2 star film together treats the stars as cardinal, which the ratings were never designed to support.

Lesson 3 of 3

When does a utility function exist?

The main theorem of lecture 1 says when a preference can be turned into numbers.

Existence theoremExam favourite
X finite and ⪰ complete and transitive ⟹ some u : X → ℝ represents ⪰
Three conditions: finitely many outcomes, completeness, transitivity.
Proof by construction, as given in class
  1. Find the top ranked outcomes, the x with x ⪰ y for every remaining y. Ties at the top all count.
  2. Give every one of them the same number, the largest still unused.
  3. Remove them from the set and repeat with what is left.
  4. Because X is finite, the process stops after at most |X| rounds.
  5. A ≻ B ∼ C ≻ D gives classes {A}, {B, C}, {D} and u = 3, 2, 2, 1
Why a top ranked outcome always exists
  1. Suppose no outcome is top ranked. Then every outcome is beaten by some other outcome.
  2. Start at any x₁. Some x₂ ≻ x₁. Some x₃ ≻ x₂. Keep going.
  3. X is finite, so some outcome must appear twice in this chain.
  4. The repeat creates a cycle, and transitivity of ≻ would give that outcome ≻ itself.
  5. That is impossible, so a top ranked outcome exists.

What breaks when a condition fails

Condition droppedWhat goes wrong
TransitivityA ≻ B ≻ C ≻ A would need u(A) > u(B) > u(C) > u(A), so u(A) > u(A). Impossible.
CompletenessReal numbers are always comparable, so any u would rank pairs the agent cannot rank.
FinitenessThe construction may never end. Lexicographic preference on the plane has no utility at all.

How many rankings are there?

With n outcomes and no ties, every ranking is an ordering of n objects, so there are n! of them. Five outcomes give 120 rankings. Twenty outcomes give 20! ≈ 2.43 × 10¹⁸. That is enormous but still finite, and finiteness is what the theorem needs. Allowing ties gives even more rankings.

Going deeper: Lexicographic preference: an infinite case with no utility

Order points (a, b) of the unit square by a first and use b only to break ties, as a dictionary orders words. This relation is complete and transitive. Suppose u represented it. For each a the interval from u(a, 0) to u(a, 1) is non empty, and the intervals for different a do not overlap. Each interval contains a rational number, so we would have uncountably many different rationals. That is impossible, so no utility function exists. Debreu showed that continuity of preferences is the extra condition that rescues the theorem for infinite sets.

One idea, four depths

If you can rank your choices without going round in circles, you can give each one a score, and the best choice is the one with the highest score.

u represents ⪰ when x ⪰ y exactly when u(x) ≥ u(y). For finite X a rational preference always has such a u, built by peeling off the best class. Any strictly increasing transform gives another valid u.

Ordinal utility is unique only up to strictly increasing transformations. Debreu's theorem extends existence to continuous preferences on connected separable spaces. Lexicographic preferences show that completeness and transitivity alone are not enough on infinite sets.

In learning from human feedback, a reward model is a learned utility over outputs fitted to pairwise comparisons, for example with the Bradley Terry model. Intransitive human judgments then show up as label noise that no single scalar reward can fit.
