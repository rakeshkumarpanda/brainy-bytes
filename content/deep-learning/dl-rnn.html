Lesson 1 of 9

Recurrent networks: one cell reused at every time step

Source: Goodfellow, Bengio and Courville (2016) sections 10.1 and 10.2, Elman (1990), and the Stanford CS224n notes on language models and RNNs.

What it is
A recurrent neural network (RNN) reads a sequence one item at a time and keeps a hidden state ht, a vector that summarises everything seen so far. At each step it combines the new input with the previous state using the same weights: ht = tanh(xtWxh + ht−1Whh + b). Drawing every step side by side is called unrolling the network.
Why we need it
Text, speech, sensor readings and prices arrive as sequences of varying length, and the meaning of each item depends on what came before. A dense network needs a fixed input size and cannot share what it learns across positions. An RNN handles any length with one small set of weights.
How it works
Feed the inputs in order and read the output you need: the last state for classifying a whole sequence, every state for tagging each item, or feed outputs back in to generate a sequence. Train with backpropagation through time (BPTT): unroll, run the usual backward pass, and add up the gradients of the shared weights from every step.

The long term dependency problem

Source: Bengio, Simard and Frasconi (1994), Hochreiter (1991), and Pascanu, Mikolov and Bengio, On the difficulty of training recurrent neural networks (ICML 2013).

What it is
A long term dependency is when an output depends on an input many steps earlier, such as a verb agreeing with a subject far back in the sentence. In BPTT the gradient that links them is a product of one Jacobian per step, so it shrinks or grows exponentially with the distance.
Why we need it
If the gradient vanishes, the network gets no learning signal from distant inputs and cannot learn to remember them. If it explodes, one update can wreck the weights. This is the main reason plain RNNs struggle beyond about 10 to 20 steps.
How it works
Clip the gradient norm (to around 1 to 5) to stop explosions. For vanishing, change the architecture: gated cells such as the LSTM and GRU, or attention (chapter 2.3), give information a path that is not squashed at every step.

In the exam
The task: see a number at step 1 with a marker, then noise as large as the signal, and output the number at the end. Always answering 0 scores 0.333. Lesson 3 of 9

LSTM: a memory cell with gates

Source: Hochreiter and Schmidhuber (1997), Gers, Schmidhuber and Cummins (2000), Jozefowicz, Zaremba and Sutskever (ICML 2015), and Olah, Understanding LSTM networks (2015).

What it is
A long short term memory (LSTM) cell adds a separate cell state ct and three gates, each a sigmoid between 0 and 1. The forget gate f decides how much old memory to keep, the input gate i how much of a new candidate g to write, and the output gate o how much of the memory to show as ht.
Why we need it
The cell state is updated by multiplying with f and adding, not by squashing through a weight matrix and tanh. When f is close to 1 the memory, and its gradient, pass through many steps almost unchanged. This lets LSTMs learn dependencies over hundreds of steps, which made them the standard for speech and translation from about 2014 to 2018.
How it works
Use an LSTM layer from your library, with a few hundred units. Initialise the forget gate bias to a positive value (1 is the common default, larger for long memories) so the cell remembers by default at the start of training.

On the same memory task, an LSTM with the usual forget bias of 1 learns 20 steps (error 0.0006) but fails at 60 steps (0.345). Lesson 4 of 9

GRU, bidirectional and sequence to sequence models

Source: Cho and colleagues (EMNLP 2014), Chung and colleagues, Empirical evaluation of gated recurrent neural networks (2014), Schuster and Paliwal, Bidirectional recurrent neural networks (1997), and Sutskever, Vinyals and Le (NeurIPS 2014).

What it is
A gated recurrent unit (GRU) is a simpler gated cell with two gates and no separate cell state. The update gate z mixes the old state with a candidate, and the reset gate r decides how much of the past the candidate may use. A bidirectional RNN runs one RNN forwards and another backwards and joins their states. A sequence to sequence (encoder decoder) model reads a whole input sequence into a state and then generates an output sequence from it.
Why we need it
The GRU has about three quarters of the weights of an LSTM and often performs about as well. Bidirectional models see both left and right context, which helps tagging and speech recognition. Encoder decoder models made neural machine translation possible, and their weakness, squeezing a long sentence into one vector, led directly to attention.
How it works
Try a GRU when you want a smaller, faster model and an LSTM when memory length matters most. Use bidirectional layers only when the whole sequence is available in advance, not for real time prediction. For generation, train the decoder with teacher forcing, feeding the true previous token, and sample at test time.

Worked example: one step of a scalar LSTM
  1. Suppose f = 0.9, i = 0.5, o = 0.5, candidate g = 0.4 and old memory ct−1 = 2.
  2. ct = 0.9 × 2 + 0.5 × 0.4 = 1.8 + 0.2 = 2.0
  3. The output gate scales the squashed memory.
  4. ht = 0.5 × tanh(2.0) = 0.5 × 0.964 = 0.482
  5. Backwards, ∂ct/∂ct−1 = f = 0.9 along the cell path. Over 20 steps that gives 0.920 ≈ 0.12, compared with a plain RNN where each factor also includes the weight and the tanh slope.
Going deeper: Why gates help, and what replaced recurrence

The LSTM cell path behaves like a residual connection through time: ct = ct−1 + (changes) when f is near 1, so the Jacobian is close to the identity, the same reason ResNets train (Greff and colleagues 2017 analyse which LSTM parts matter, finding the forget gate and output activation most important). Gating does not remove vanishing entirely: memories still decay as fk, and training is sequential, which limits speed on GPUs. Attention lets every output look directly at every input, with path length 1 between any two positions, and transformers dropped recurrence altogether in 2017. Recurrence has returned in new forms: linear recurrent and state space models such as S4 (Gu and colleagues 2022), Mamba (Gu and Dao 2023) and RWKV train in parallel like transformers but run with a constant cost per step like RNNs, which matters for very long sequences.

Chapter summary

  1. An RNN reads a sequence step by step with one shared cell and a hidden state. Train it with backpropagation through time, summing gradients over the unrolled steps.
  2. The gradient across k steps is a product of k Jacobians, so it vanishes or explodes. Clip gradients for explosions. Plain RNNs fail on dependencies longer than about 20 to 40 steps.
  3. The LSTM adds a cell state with forget, input and output gates: c = f ⊙ c + i ⊙ g, h = o ⊙ tanh(c). A positive forget bias makes it remember by default.
  4. The GRU uses two gates and fewer weights. Bidirectional RNNs see both directions. Encoder decoder models translate, trained with teacher forcing.
  5. Transformers replaced RNNs for most large tasks because they train in parallel and connect distant positions directly.
