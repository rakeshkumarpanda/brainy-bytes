Lesson 1 of 9

Autoencoders: compress, then rebuild

Source: Goodfellow, Bengio and Courville (2016) chapter 14, Hinton and Salakhutdinov (Science 2006), and Baldi and Hornik (1989).

What it is
An autoencoder is a network trained to output its own input. An encoder maps the input to a short code (also called the latent vector or bottleneck), and a decoder maps the code back to the input space. The loss is the reconstruction error, for example the mean squared difference between input and output.
Why we need it
The bottleneck forces the network to keep only what matters most, so the code is a compact summary learned without any labels. It is useful for compression, visualisation, denoising, anomaly detection and as a starting point for generative models.
How it works
Pick a code size much smaller than the input. Use the same kind of layers as for supervised learning (dense for tables, convolutions for images). A linear autoencoder with squared error learns the same subspace as PCA, so add nonlinear layers to capture curved structure.

Compressing 8 × 8 digits (64 pixels) to 2 numbers, PCA reaches a test error of 0.0534 and a nonlinear autoencoder 0.0357. With 8 numbers, PCA gives 0.0245 and the autoencoder 0.0147. Just predicting the average image gives 0.0743.

Denoising and anomaly detection

Source: Vincent and colleagues, Extracting and composing robust features with denoising autoencoders (ICML 2008), and Sakurada and Yairi, Anomaly detection using autoencoders with nonlinear dimensionality reduction (2014).

What it is
A denoising autoencoder receives a corrupted input, with added noise or missing parts, and is trained to output the clean original. An autoencoder used for anomaly detection is trained only on normal data, and an input that it rebuilds badly is flagged as unusual.
Why we need it
Denoising forces the network to learn the structure of the data rather than copy pixels, and it cleans real images, audio and sensor readings. Anomaly detection with reconstruction error needs no examples of the rare faults or frauds, which are often unknown in advance.
How it works
For denoising, add realistic corruption during training. For anomaly detection, choose a threshold on the reconstruction error from a validation set of normal data, for example the 99th percentile, and check it against any labelled anomalies you have.

In the exam
Adding noise with standard deviation 0.3 gives the test digits an error of 0.0524, and the denoising network brings it down to 0.0324. An autoencoder trained only on digits 0 to 4 rebuilds them with error 0.0322 but digits 5 to 9 with 0.0605, and using the error as an anomaly score separates the two groups with a ROC AUC of 0.901.

Real world scenario: Spotting faulty machines
A factory records vibration from healthy motors for a month and trains an autoencoder on it. In production, each new reading is rebuilt and its error is compared with a threshold set at the 99th percentile of healthy errors. A worn bearing produces vibration patterns the autoencoder never saw, so the error jumps and maintenance is called before the motor fails. No examples of failures were needed to build it.
Lesson 3 of 9

Variational autoencoders

Source: Kingma and Welling (ICLR 2014), Rezende, Mohamed and Wierstra (ICML 2014), Doersch, Tutorial on variational autoencoders (2016), and Higgins and colleagues (ICLR 2017).

What it is
A variational autoencoder (VAE) makes the encoder output a mean μ and a spread σ for the code, and samples z = μ + σε with ε from N(0, 1), the reparameterisation trick. The loss adds a KL divergence term that keeps each code distribution close to the prior N(0, I). Together the two terms are the negative evidence lower bound (ELBO).
Why we need it
A plain autoencoder’s codes can sit anywhere, with gaps between them, so decoding a random code gives nonsense. The KL term packs the codes into a smooth region around 0, so you can sample z from N(0, I), decode it, and get a new, realistic example, and moving through the code space changes the output gradually.
How it works
Use a Gaussian encoder that outputs μ and log σ² (more stable than σ), binary cross entropy or squared error for the reconstruction, and the closed form KL. Weight the KL by β to trade sharp reconstructions (small β) for a tidier, more disentangled code (large β).

In the exam
A VAE with a 2 number code trained on the digits for 200 epochs lowers its loss (negative ELBO) from 36.3 to 24.4 nats per image: reconstruction 21.75 plus KL 2.62. Different digits get different average codes, for example (−1.33, −0.39) for 1 and (1.33, 0.92) for 0. Decoding the point halfway between them gives a shape in between, a smooth path through the code space.

Discrete codes and latent spaces in modern models

Source: van den Oord, Vinyals and Kavukcuoglu, Neural discrete representation learning (VQ-VAE, NeurIPS 2017), Ramesh and colleagues, DALL-E (ICML 2021), and Rombach and colleagues, latent diffusion (CVPR 2022).

What it is
A vector quantised autoencoder (VQ-VAE) snaps each continuous code to the nearest vector in a learned codebook, so every image or patch becomes a token id. Modern image generators also run in the latent space of an autoencoder rather than on raw pixels.
Why we need it
Discrete tokens let a transformer model images, audio and video exactly as it models text. Working in a compact latent space cuts the cost of generation many times, which is why Stable Diffusion first encodes images to a latent 8 times smaller in each direction.
How it works
Learn the codebook with the autoencoder, using a straight through gradient for the snapping step and a commitment loss that keeps codes near their codebook vectors. More codebook entries keep more detail, at the cost of more bits per token.

In the exam
Snapping 8 number codes of the digits to a codebook of 4 vectors (2 bits per image) gives an error of 0.0549, 16 vectors (4 bits) give 0.0375 and 256 vectors (8 bits) give 0.0273, approaching the continuous code’s 0.0239. Each image becomes a single token id. Here the codebook is learned with k means on PCA codes, a simple stand in for a trained VQ-VAE.

σ = exp(½ log σ²)
Network outputs log σ² for stability.
ELBO gap
ln p(x) − ELBO = KL(q(z|x) || p(z|x))
Tight when q matches the true posterior.
Worked example: deriving the ELBO
  1. Start from the log likelihood and bring in the encoder distribution q(z|x).
  2. ln p(x) = ln ∫ p(x|z) p(z) dz = ln Eq[p(x|z) p(z) / q(z|x)]
  3. Jensen’s inequality moves the log inside the expectation, since ln is concave.
  4. ln p(x) ≥ Eq[ln p(x|z)] + Eq[ln p(z) − ln q(z|x)]
  5. The second term is minus a KL divergence.
  6. ln p(x) ≥ Eq[ln p(x|z)] − KL(q(z|x) || p(z)) = ELBO
  7. Example of the KL for one dimension with μ = 0 and σ = 0.5: ½(0 + 0.25 − 1 − ln 0.25) = ½(0.25 − 1 + 1.386) = 0.318.
Going deeper: Posterior collapse, disentanglement and better bounds

A strong decoder, such as an autoregressive one, can model the data without using z, and the KL term then pushes every q(z|x) onto the prior: posterior collapse. Remedies include KL annealing (start with β = 0 and raise it), free bits (no KL penalty below a set amount per dimension) and weaker decoders. A larger β encourages each code dimension to capture one factor of variation (β VAE, Higgins and colleagues 2017), though Locatello and colleagues (ICML 2019) proved that unsupervised disentanglement is impossible without inductive biases. Importance weighted autoencoders (Burda and colleagues 2016) tighten the bound with several samples, and hierarchical VAEs such as NVAE (Vahdat and Kautz 2020) reach image quality close to GANs. Diffusion models (chapter 3.3) can be viewed as a very deep hierarchical VAE with a fixed encoder.

Chapter summary

  1. An autoencoder learns an encoder and decoder that rebuild the input through a small code, trained on reconstruction error without labels.
  2. A linear autoencoder matches PCA. Nonlinear layers capture curved structure and rebuild better with the same code size.
  3. Denoising autoencoders clean corrupted inputs. Training on normal data and flagging high reconstruction error detects anomalies.
  4. A VAE outputs μ and σ, samples z = μ + σε, and adds KL = ½Σ(μ² + σ² − 1 − ln σ²). The loss is the negative ELBO, and sampling z from N(0, I) generates new data.
  5. VQ-VAE codes are codebook indices, turning images into tokens, and latent spaces make modern generators efficient.
