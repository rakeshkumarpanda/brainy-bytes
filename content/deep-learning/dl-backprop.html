Lesson 1 of 9

The chain rule on a computational graph

Source: Goodfellow, Bengio and Courville (2016) section 6.5, and the Stanford CS231n notes on backpropagation.

What it is
Backpropagation computes the gradient of the loss with respect to every weight by applying the chain rule backwards through a computational graph. The forward pass computes and stores every intermediate value. The backward pass starts from the loss with gradient 1 and, at each node, multiplies the incoming gradient by the node’s local derivative.
Why we need it
Training needs the gradient of one number, the loss, with respect to millions of weights. Backpropagation gets all of them for roughly the cost of two forward passes, whatever the number of weights. Without it, deep learning would be impossibly slow.
How it works
Learn three patterns. An add node passes its gradient unchanged to both inputs. A multiply node sends each input the gradient times the other input. A function node such as sigmoid multiplies by its own slope, σ(1 − σ). When a value feeds several nodes, add up the gradients that come back.

In the exam
For f = (x y + z) w followed by a sigmoid and a squared error, the backward pass gives ∂L/∂x = 0.0887 and ∂L/∂w = −0.1774. Nudging x and w by 0.00001 in each direction gives the same numbers to four decimals. This numerical check is how libraries test their gradients.

Automatic differentiation

Source: Linnainmaa (1970), Baydin, Pearlmutter, Radul and Siskind, Automatic differentiation in machine learning: a survey (JMLR 2018), and the PyTorch autograd documentation.

What it is
Automatic differentiation (autodiff) records each operation as it runs, building the graph on the fly, and then walks it backwards to compute exact gradients. Backpropagation is reverse mode autodiff. PyTorch, TensorFlow and JAX all work this way, so you write only the forward pass.
Why we need it
Deriving gradients by hand for every new model is slow and error prone. Autodiff gives exact derivatives (not approximations like finite differences) at a cost of a small constant times the forward pass, for any program built from differentiable pieces.
How it works
Each value stores its data, its gradient, its parents and a small function that pushes its gradient to the parents. backward() sorts the graph so every node comes after its inputs, sets the output gradient to 1, and calls those functions in reverse order. Reset gradients to 0 before each step, because they accumulate.

Backpropagation with matrices, and gradient checking

Source: Goodfellow, Bengio and Courville (2016) section 6.5.4, and the Stanford CS231n notes on gradient checks.

What it is
Real networks process a whole batch at once with matrix operations, and their gradients are matrix formulas too. For a dense layer Z = XW + b, the gradients are ∂L/∂W = XT(∂L/∂Z), ∂L/∂b = column sums of ∂L/∂Z, and ∂L/∂X = (∂L/∂Z)WT. A gradient check compares these with finite differences.
Why we need it
Vectorised gradients run fast on CPUs and GPUs. A gradient check catches the most common bug in a hand written backward pass, and it is worth running whenever you write a new layer.
How it works
Match shapes: a gradient always has the same shape as the thing it is a gradient of, which tells you where the transposes go. For softmax with cross entropy, the gradient of the scores is simply the probabilities minus the one hot labels, divided by the batch size. Check with the relative error |a − n| / (|a| + |n|), which should be below about 1e−7 in double precision.

Lesson 4 of 9

Vanishing and exploding gradients

Source: Hochreiter (1991), Bengio, Simard and Frasconi (1994), Glorot and Bengio (AISTATS 2010), He and colleagues (ICCV 2015 and CVPR 2016), and Pascanu, Mikolov and Bengio (ICML 2013).

What it is
Backpropagation multiplies by each layer’s weights and activation slope on the way down. If those factors are mostly below 1, the gradient shrinks exponentially with depth and early layers stop learning: vanishing gradients. If they are above 1, it grows exponentially: exploding gradients.
Why we need it
This is why deep networks were hard to train before about 2010, and why recurrent networks struggle with long sequences. The fixes, careful initialisation, ReLU, normalisation and residual connections, are what make 100 layer networks possible.
How it works
Initialise weights so the signal keeps its size: Xavier (Glorot) variance 2/(nin + nout) for tanh, He variance 2/nin for ReLU. Use ReLU family activations. Add normalisation layers and residual connections (chapter 1.3 and 2.1). Clip the gradient norm to stop explosions.

Worked example: the softmax and cross entropy gradient
  1. Scores z, probabilities pi = ezi / Σj ezj, true class k, loss L = −ln pk = −zk + ln Σj ezj.
  2. ∂L/∂zi = −[i = k] + ezi / Σj ezj = pi − [i = k]
  3. Example: p = (0.7, 0.2, 0.1) and k = 0.
  4. ∂L/∂z = (0.7 − 1, 0.2, 0.1) = (−0.3, 0.2, 0.1)
  5. The correct class’s score is pushed up, the others down, in proportion to how much probability they wrongly hold.
Going deeper: Memory, checkpointing and higher derivatives

Reverse mode needs the values from the forward pass, so its memory grows with the depth of the network and the batch size. For very deep or long models this, not compute, is often the limit. Gradient checkpointing (Chen and colleagues 2016) stores only some activations and recomputes the others during the backward pass, cutting memory for an n layer network from O(n) to O(√n) at the cost of about one extra forward pass. Autodiff can also be applied to itself: differentiating a gradient gives Hessian vector products in about the cost of two gradients, which second order methods and some meta learning algorithms use. JAX exposes this directly with jvp, vjp, grad and hessian transforms.

Chapter summary

  1. Backpropagation applies the chain rule backwards through a computational graph: store values going forward, multiply local slopes coming back.
  2. Add passes gradients through, multiply swaps its inputs, sigmoid multiplies by σ(1 − σ), and gradients add up where a value branches.
  3. Reverse mode autodiff gives every gradient for about the cost of a forward and a backward pass. PyTorch, TensorFlow and JAX do it for you.
  4. Matrix form: ∂L/∂W = XTG, ∂L/∂X = GWT, and softmax with cross entropy gives p − y. Always gradient check a new layer.
  5. Deep products of slopes cause vanishing or exploding gradients. Use ReLU, He or Xavier initialisation, and gradient clipping.
