Part 1

➡️What a vector is

A vector is an ordered list of numbers. You can picture it in two ways, and both are useful.

🏹 An arrow

v = [3, 2] is an arrow that goes 3 steps right and 2 steps up. It has a length (how far) and a direction (which way). Moving the arrow somewhere else does not change it.

📋 A list of features

A flat with 2 bedrooms, 85 square metres and 12 years old is the vector [2, 85, 12]. Each position always means the same thing. That position is called a component or feature.

The number of components is the dimension. [3, 2] lives in 2D, [2, 85, 12] in 3D. A 28 × 28 pixel photo of a digit is a vector with 784 numbers, so it lives in 784 dimensions. We cannot draw that, but every rule in this chapter works the same way there.

🧮 Writing a vector
v = [v₁, v₂, ..., vₙ]   or as a column   v₁v₂⋮vₙ
Books print vectors in bold (v) or with an arrow on top. ℝⁿ means "all vectors with n real numbers".
A GPS location is a vector [latitude, longitude]. A wind forecast is a vector: 20 km/h towards the north east is a length and a direction. A recipe is a vector of amounts [flour, sugar, eggs].
Every example in a dataset is a vector, called a feature vector. Words are turned into vectors called embeddings, where words with similar meaning point in similar directions. The weights of a model are a vector too.
🔍 Going deeper: vectors as they appear in real code and data

When you start writing machine learning code, vectors show up in a few standard shapes. Knowing their names saves a lot of confusion.

Kind of vectorWhat it looks likeExample
feature vectorone number per measured property[area 85, rooms 2, age 12] for one flat
one hot vectorall zeros except a single 1colour "green" out of [red, green, blue] is [0, 1, 0]
embeddinga few hundred learned numbers, no single one has an obvious meaninga 768 number vector for the word "river"
probability vectornon negative numbers that add up to 1a classifier output [0.7, 0.2, 0.1]

A one hot vector is how a model reads a category. You cannot feed the word "green" into a formula, and numbering colours 1, 2, 3 would wrongly say blue is "bigger" than red. Giving each category its own position with a single 1 keeps every category equally far from every other.

In code, a vector of n numbers usually has shape (n,). Libraries also talk about a row vector of shape (1, n) and a column vector of shape (n, 1). They hold the same numbers but behave differently in matrix multiplication (Chapter 4), so mixing them up is one of the most common beginner bugs.

A cricket player profile is a vector: [matches, runs, average, strike rate, wickets]. Two players with similar vectors have similar careers, which is exactly how sports apps suggest "players like this one".
Part 2

➕Adding, subtracting and scaling vectors

Vectors are added part by part: [3, 1] + [1, 2] = [4, 3]. As arrows, put the tail of the second at the tip of the first. The sum goes from the very start to the very end. Multiplying by a number (a scalar) stretches the arrow: 2 × [3, 1] = [6, 2]. A negative scalar flips it round.

🧮 Addition
a + b = [a₁ + b₁, a₂ + b₂, ...]
Only for vectors of the same size.
🧮 Scalar multiplication
k·a = [k·a₁, k·a₂, ...]
k > 1 stretches, 0 < k < 1 shrinks, k < 0 flips.
🧮 Linear combination
c₁·v₁ + c₂·v₂ + ... + cₖ·vₖ
Scale several vectors, then add them. This is the most important pattern in linear algebra.
A boat heads east at 4 km/h while the river pushes it north at 3 km/h. Its real velocity is [4, 0] + [0, 3] = [4, 3], so it moves at 5 km/h towards the north east. Pilots add wind vectors to plan every flight.
A neuron computes w₁x₁ + w₂x₂ + ... + b, a linear combination of the inputs. In word embeddings the famous example is king − man + woman ≈ queen: vector arithmetic captured a relationship of meaning.
🔍 Going deeper: the average of vectors and sliding between two vectors

Adding and scaling are enough to build two of the most useful tools in all of machine learning.

🧮 Centroid (average vector)
c = 1n (v₁ + v₂ + … + vₙ)
Add the vectors, then scale by 1 ÷ n. The result sits in the middle of the cloud of points.
🧮 Interpolation (lerp)
v(t) = (1 − t) a + t b,   0 ≤ t ≤ 1
t = 0 gives a, t = 1 gives b, t = ½ gives the halfway point. Every point in between lies on the straight segment from a to b.

Interpolation is how image generators "morph" one face into another. Each face is a vector of numbers inside the model, and stepping t from 0 to 1 walks along the straight line between them. Every step is a new face that blends the two.

Vector rules are the same as number rules you already know: a + b = b + a, (a + b) + c = a + (b + c), and k(a + b) = ka + kb. If a step would be fine with ordinary numbers, it is almost always fine with vectors of the same size.
Part 3

📏Length (norm) and distance

The length of a vector is called its norm. The usual one comes straight from Pythagoras: [3, 4] has length √(3² + 4²) = √25 = 5. There are other useful ways to measure size.

🧮 L2 norm (Euclidean)
‖v‖₂ = √(v₁² + v₂² + ... + vₙ²)
The straight line, as the crow flies.
🧮 L1 norm (Manhattan)
‖v‖₁ = |v₁| + |v₂| + ... + |vₙ|
Walking along city blocks.
🧮 Unit vector
û = v‖v‖
Same direction, length exactly 1. This is called normalising.
🧮 Distance between points
d(p, q) = ‖p − q‖
Subtract, then take the length.
NormValue for [3, −4]ML use
L25k nearest neighbours, k means, Ridge (L2) regularisation
L17Lasso (L1) regularisation, which pushes weights to exactly zero
L∞4adversarial examples that change each pixel by at most a tiny amount
Distances are only fair when features use similar scales. If one feature is salary in rupees (around 500000) and another is age in years (around 30), salary dominates every distance. Scale the features first, for example to a mean of 0 and a standard deviation of 1.
A 3, 4, 5 triangle is the easiest Pythagoras check to remember. Its multiples 6, 8, 10 and 30, 40, 50 work too, and so do 5, 12, 13 and 8, 15, 17.
🔍 Going deeper: the whole family of norms, and when to normalise

L1 and L2 are two members of one family, the Lp norms. Raise every absolute value to the power p, add, then take the p-th root.

🧮 Lp norm
‖v‖ₚ = (|v₁|ᵖ + |v₂|ᵖ + … + |vₙ|ᵖ)^(1/p)
p = 1 gives Manhattan, p = 2 gives Euclidean, and as p grows huge the biggest component wins, giving L∞ = max |vᵢ|.

Machine learning often uses the squared L2 norm, ‖v‖² = v₁² + … + vₙ², without the square root. It has the same smallest point, it is cheaper to compute, and its derivative is simply 2v, which makes the calculus in later chapters tidy.

When to normalise. Divide a vector by its length when only the direction matters, for example text embeddings for search, where a long document should not win just because it has more words. Do not normalise when the size itself carries meaning, such as a vector of prices or sensor readings.

Part 4

✖️The dot product

The dot product turns two vectors into one number. Multiply matching parts, then add: [2, 3] · [4, −1] = 2 × 4 + 3 × (−1) = 8 − 3 = 5. It also has a meaning in pictures: it measures how much two arrows point the same way.

🧮 Algebra form
a · b = a₁b₁ + a₂b₂ + ... + aₙbₙ = Σ aᵢbᵢ
Easy to compute, even in a million dimensions.
🧮 Geometry form
a · b = ‖a‖ ‖b‖ cos θ
θ (theta) is the angle between the arrows.

Almost every calculation in a neural network is a dot product. A neuron takes the dot product of its weights with the inputs, w · x + b. Attention in transformers takes dot products between "query" and "key" vectors to decide which words to focus on. GPUs are built to do billions of dot products per second.
🔍 Going deeper: why the two formulas for the dot product agree

It is surprising that "multiply and add" gives the same number as "length times length times cos of the angle". Here is why, using only Pythagoras and the law of cosines from school geometry.

Two more facts make the dot product easy to work with.

  • A vector dotted with itself is its squared length: v · v = ‖v‖². So [3, 4] · [3, 4] = 9 + 16 = 25 = 5².
  • It is a weighted sum. If w = [0.5, 2, −1] are weights and x = [4, 1, 3] are inputs, w · x = 2 + 2 − 3 = 1. Each input is counted with its own importance, and a negative weight means "this feature lowers the score".
Your shopping bill is a dot product: quantities [2 kg rice, 1 litre oil, 6 eggs] dotted with prices [60, 150, 7] gives 120 + 150 + 42 = 312.
Part 5

🎬Cosine similarity: how alike are two things

If you divide the dot product by both lengths, you get cos θ alone. This is cosine similarity. It ignores how long the arrows are and only compares their directions, which makes it perfect for comparing things of different sizes, like a short tweet and a long article about the same topic.

🧮 Cosine similarity
cos(a, b) = a · b‖a‖ ‖b‖
1 means same direction, 0 means unrelated, −1 means opposite. For counts, which are never negative, it stays between 0 and 1.
Streaming apps describe you and every film as vectors of tastes. The films whose vectors point closest to yours are the ones on your "Because you watched" row.
Search engines and chat assistants turn your question and every document into embedding vectors, then fetch the documents with the highest cosine similarity. This is called semantic search, and it is the "retrieval" in retrieval augmented generation (RAG).
Cosine similarity is the dot product of the two unit vectors. Normalise first, then a plain dot product gives the cosine. Vector databases store normalised vectors for exactly this reason.
🔍 Going deeper: cosine distance, and when cosine and Euclidean disagree

Many libraries ask for a distance, where smaller means more alike. Cosine similarity is turned into one by subtracting it from 1.

🧮 Cosine distance
1 − cos(a, b)
0 for the same direction, 1 for perpendicular, 2 for opposite.

Rule of thumb: use cosine when size is an accident (document length, how many ratings a user gave) and Euclidean when size is real information (two houses with very different areas really are different).

Part 6

🔦Projection: the shadow of a vector

Shine a light straight down onto a line. The shadow a vector casts on that line is its projection. It tells you how much of one vector lies along the direction of another.

🧮 Scalar projection (shadow length)
comp_b a = a · b‖b‖
A signed length. Negative means the shadow points backwards.
🧮 Vector projection (the shadow itself)
proj_b a = a · bb · b b
A vector along b. What is left over, a − proj_b a, is perpendicular to b.
Linear regression finds the projection of the target vector onto the space spanned by the feature columns. PCA (Chapter 5) projects data onto the few directions that keep the most information.
🔍 Going deeper: splitting a vector into "along" and "across"

Projection lets you split any vector a into two pieces that are perpendicular to each other: the part that runs along a direction b, and the part that is left over. This split is used again and again, in regression, in PCA and in the Gram Schmidt method of Chapter 13.

🧮 Decomposition
a = proj_b a + (a − proj_b a)
The first piece is parallel to b. The second piece is perpendicular to b, so its dot product with b is 0.

If b is already a unit vector (length 1), the formula becomes very short: proj_b a = (a · b) b. That is why so many algorithms normalise directions first.

Walking up a slope against the wind, only the part of the wind that blows straight down the slope slows you. The part blowing across the slope just pushes you sideways. That split is a projection.
Part 7

🧱Span, independence and basis

Take all the linear combinations of some vectors. Every point you can reach is called their span. With [1, 0] and [0, 1] you can reach any point in the plane: [5, −2] = 5·[1, 0] − 2·[0, 1].

✅ Linearly independent

No vector in the set can be built from the others. Each one adds a brand new direction. [2, 1] and [1, 3] are independent, and together they span the whole plane.

❌ Linearly dependent

At least one is a combination of the others, so it adds nothing new. [2, 4] = 2 × [1, 2], so these two only reach one line.

🧮 Basis and dimension
basis = a set of independent vectors that spans the space
Every basis of ℝⁿ has exactly n vectors. That number n is the dimension.
WordsPlain meaning
Spaneverywhere you can reach by scaling and adding
Independentno vector is wasted
Basisthe smallest set of building blocks that reaches everything
Dimensionhow many building blocks a basis needs
Orthonormal basisbuilding blocks of length 1 that are all perpendicular, such as [1, 0] and [0, 1]
If two features are dependent, for example height in cm and the same height in inches, the model gets no new information and linear regression becomes unstable. This problem is called multicollinearity. The rank of a data matrix (Chapter 4) counts its independent columns.
Red, green and blue light form a basis for the colours a screen can show. Every pixel is a linear combination r·red + g·green + b·blue.

The best way to feel span and independence is to play. Below, a and b are the two building blocks. The faint grid shows every point you can reach with whole number amounts of a and b, such as 2a − b. Drag b until it lies on the same line as a. The grid collapses onto a single line, the "area number" ad − bc becomes 0, and most targets can no longer be reached. That is linear dependence in one picture: two vectors that only reach a line instead of the whole plane.

In a dataset, if one column is (almost) a multiple of another, the data matrix behaves like the collapsed grid. The model cannot tell the two features apart, and their weights can swing wildly from one training run to the next. Dropping one of the pair, or adding L2 regularisation, fixes it.
