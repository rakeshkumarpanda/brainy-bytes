Part 1

⚙️What a function is

A function is a machine with one rule: every input gives exactly one output. A vending machine is a function. Press B4 and you always get the same snack. We write the machine as f and its output for input x as f(x), read "f of x".

📥 Domain

All the inputs the machine accepts. √x only accepts x ≥ 0 when we stay with real numbers, and 1 ÷ x refuses x = 0.

📤 Range

All the outputs it can produce. x² never gives a negative number, and the sigmoid function only gives values between 0 and 1.

🧮 Function notation
f(x) = 2x + 1  ⟹  f(3) = 2 × 3 + 1 = 7
Replace every x in the rule with the input, then work it out.

A graph draws every pair (x, f(x)) as a point. If a vertical line ever crosses the curve twice, it is not a function, because one input would have two outputs.

A trained model is a function f(x) = prediction. Its domain is the kind of data it was trained on, which is why a model trained on cat photos gives nonsense for an X ray. The output range is designed on purpose: a price model can output any number, a classifier squeezes its output into 0 to 1.
🔍 Going deeper: piecewise functions and functions you can undo

Many real rules change their formula part way along. These are piecewise functions: a different rule for each piece of the input. A mobile data plan that is free up to 2 GB and then charges per extra GB is one. So is ReLU, which is 0 for negative inputs and x for positive ones.

🧮 A piecewise function
f(x) = 0 if x < 0, and f(x) = x if x ≥ 0
This is ReLU. Each piece is simple, and together they make a bend that a neural network can use to build curved shapes.

Two more words describe how a function behaves, and both matter later.

WordMeaningExampleWhy ML cares
increasinga bigger input always gives a bigger (or equal) outputeˣ, the sigmoid, ln xthe order of scores is kept, so the biggest logit is still the biggest probability
one to oneno two inputs share an output2x + 1 yes, x² no (since 3² = (−3)² = 9)only one to one functions can be undone exactly, which is why logit can undo sigmoid
boundedoutputs stay between two fixed numberssigmoid between 0 and 1good for probabilities, but flat ends slow down learning

A useful way to think about any model: the input is the question, the function is the "rule of thumb" the model learned, and the output is its answer. Training only changes the rule, never the idea that one input gives one answer.

Part 2

📈Straight lines: slope and intercept

The simplest useful function is a straight line. Two numbers describe it completely.

🧮 Slope intercept form
y = m x + b
m is the slope (how much y climbs when x goes up by 1) and b is the intercept (the value of y when x = 0).
🧮 Slope from two points
m = y₂ − y₁x₂ − x₁ = riserun
Positive slope climbs, negative slope falls, zero slope is flat.
A taxi charges 50 to start and 12 per km. The fare is y = 12x + 50. The slope 12 is the price per km and the intercept 50 is the fare before you move at all.
Linear regression is "find the best m and b" for a cloud of points. With many inputs it becomes y = w₁x₁ + w₂x₂ + ... + b, and the slopes are called weights and the intercept is called the bias. Every neuron in a neural network starts with exactly this sum.
Slope is "rise over run", like a staircase: how far up for each step forward. Parallel lines have equal slopes. Perpendicular lines have slopes that multiply to −1.
🔍 Going deeper: building a line from what you know, and measuring how far off it is

There are three common ways to write the same straight line. Pick whichever matches the facts you have.

FormFormulaUse it when you know
slope intercepty = mx + bthe slope and where it crosses the y axis
point slopey − y₁ = m(x − x₁)the slope and any one point on the line
two pointm = (y₂ − y₁) ÷ (x₂ − x₁), then point slopetwo points on the line

Real data never sits exactly on a line. The vertical gap between a data point and the line, actual minus predicted, is called the residual. A positive residual means the point is above the line (the model guessed too low). Linear regression picks the line that makes the sum of the squared residuals as small as possible, which Chapter 11 works out in full.

A gym membership that costs 1000 to join and 500 a month is the line cost = 500 × months + 1000. After a year you have paid 500 × 12 + 1000 = 7000.
Part 3

🪣Quadratics and polynomials

A quadratic has an x² term: f(x) = ax² + bx + c. Its graph is a parabola, a U shape when a > 0 and an upside down U when a < 0. The bottom (or top) is called the vertex.

🧮 Quadratic formula
x = −b ± √(b² − 4ac)2a
Gives the roots, where the curve crosses y = 0.
🧮 Discriminant
D = b² − 4ac
D > 0: two roots. D = 0: one root. D < 0: no real roots.
🧮 Vertex
x = −b2a
The lowest point when a > 0. This is the minimum we look for in learning.

A polynomial adds more powers: 4x³ − x + 7 has degree 3. Higher degree means more bends, which lets the curve follow data more closely, sometimes too closely.

The squared error (y − ŷ)² is a parabola in the prediction ŷ. Its vertex sits exactly at ŷ = y, so "make the error as small as possible" is "find the bottom of the U". Polynomial regression adds x², x³ as extra inputs, and a degree that is too high memorises noise. That is called overfitting.
A ball thrown in the air follows a parabola. The vertex is the highest point it reaches, and the roots are where it leaves your hand and where it lands.
🔍 Going deeper: completing the square, and where the bottom of the U comes from

The vertex formula x = −b ÷ 2a is not magic. Rewrite the quadratic so the x appears only once, inside a square. This trick is called completing the square.

🧮 Vertex form
f(x) = a(x − h)² + k
The vertex is (h, k). If a > 0 the curve opens upward and k is the lowest value. If a < 0 it opens downward and k is the highest.

Play with the three numbers a, b and c below. Watch how a controls the width and direction, how c lifts the whole curve, and how the roots appear and vanish as the discriminant changes sign.

The mean squared error of a one weight model, L(w) = average of (wxᵢ − yᵢ)², expands into a quadratic in w: (average of xᵢ²) w² − 2 (average of xᵢyᵢ) w + (average of yᵢ²). Its vertex gives the best weight directly: w = average of xᵢyᵢ ÷ average of xᵢ². That is linear regression without an intercept, solved by school algebra.

🚀Exponential growth and the number e

In an exponential function the variable sits in the exponent: f(x) = aˣ. Each step multiplies instead of adding. With a > 1 it grows faster and faster, with 0 < a < 1 it shrinks towards zero but never reaches it.

Where e comes from

Put 1 rupee in a bank that pays 100% a year. Paid once, you get 2. Paid in two halves of 50%, you get 1.5 × 1.5 = 2.25. Paid every day, more still. As the payments get more frequent the amount does not explode. It settles at a special number called e ≈ 2.71828.

🧮 Euler number
e = lim (1 + 1n)ⁿ as n → ∞ ≈ 2.71828
Read lim as "the value it settles at when n grows without end".
🧮 Natural growth and decay
A(t) = A₀ e^(kt)
k > 0 grows, k < 0 decays. A₀ is the starting amount.
Bacteria in milk double every 20 minutes or so, which is why milk left out on a hot afternoon turns sour within hours. Radioactive carbon decays exponentially, which lets scientists date old bones.
eˣ appears in the sigmoid and softmax functions, in the normal distribution, and in learning rate schedules that decay exponentially. The derivative of eˣ is eˣ itself, which makes the calculus in Chapter 6 very neat.
🔍 Going deeper: doubling time, half life and the hunt for e

Exponential change has a fixed doubling time (for growth) or half life (for decay). It does not matter where you start: the time to double from 10 to 20 is the same as from 1000 to 2000.

🧮 Doubling time
T₂ = ln 2k ≈ 0.693k
For growth A₀e^(kt). The "rule of 72" says money at r% a year doubles in about 72 ÷ r years.
🧮 Half life
T½ = ln 2k for A₀e^(−kt)
Carbon 14 has a half life of about 5730 years, which is how old bones are dated.

Now the hunt for e. Put 1 rupee in a bank that pays 100% interest a year, but split the year into n equal periods. Each period pays 100% ÷ n, so after a year you have (1 + 1/n)ⁿ. Press Play to split the year finer and finer and watch the amount creep up and then settle.

It never passes 2.71828... however often the bank pays. That ceiling is e. It is the natural growth number because eˣ grows at a rate equal to its own size: at every moment its slope equals its height. No other base has that property, which is why calculus and probability formulas are written with e.

Exponential moving averages in optimisers such as Adam (Chapter 8) give older gradients weights that decay like 0.9, 0.9², 0.9³ and so on. The "memory" of the average is about 1 ÷ (1 − 0.9) = 10 steps.

🪵Logarithms: the undo button for powers

A logarithm answers the question "what power do I need?". Since 2³ = 8, log₂ 8 = 3. Since 10² = 100, log₁₀ 100 = 2. The natural log, ln, uses base e.

🧮 Definition
log_b(y) = x   means   bˣ = y
The log is the exponent. ln(x) means log base e, and log₂ counts doublings, or bits.
RuleIn symbolsExample

"Logs turn multiplying into adding". That single sentence explains slide rules, decibels, the Richter scale and why every ML loss for probabilities has a log in it.
Sound in decibels is a log scale: 10 dB more means 10 times the power. An earthquake of magnitude 7 shakes about 10 times harder than magnitude 6. Logs squeeze huge ranges into numbers people can handle.
A model gives each correct training answer a probability. The chance of getting all of them is a product of many numbers below 1, which a computer rounds to 0. Taking logs turns the product into a sum, which stays a normal sized number. That is why training minimises the negative log likelihood, also called log loss or cross entropy (Chapter 12).
ln(0) does not exist and ln of a negative number is not real. Code adds a tiny epsilon, as in log(p + 1e-12), so a predicted probability of exactly 0 does not crash training.
🔍 Going deeper: reading log scales and living with tiny probabilities

On an ordinary scale, equal steps mean equal differences: 0, 10, 20, 30. On a log scale, equal steps mean equal ratios: 1, 10, 100, 1000. That is why log scales show things that span huge ranges, such as earthquake energy, sound, star brightness, the number of COVID cases, or the loss of a model during training.

Here is the probability problem in real numbers. Suppose a model gives each of 1000 training answers a probability of 0.9. The chance of getting them all is 0.9¹⁰⁰⁰. Work it out with logs: log₁₀(0.9¹⁰⁰⁰) = 1000 × log₁₀ 0.9 = 1000 × (−0.0458) = −45.8, so the product is about 10⁻⁴⁶. A float32 cannot even hold numbers below about 10⁻⁴⁵, so it would be stored as 0. In log form it is simply −45.8, a perfectly ordinary number.

Log of a number between 0 and 1 is always negative. That is why losses are written as MINUS log probability, so that the loss is a positive number and smaller is better.
Part 6

〰️The S curve and other functions machine learning uses

Some functions show up in machine learning again and again. They are called activation functions because they decide how strongly a neuron "fires".

🧮 Sigmoid
σ(z) = 11 + e^(−z)
Squashes any number into (0, 1). σ(0) = 0.5. Used for probabilities of yes or no.
🧮 Tanh
tanh(z) = e^z − e^(−z)e^z + e^(−z)
Squashes into (−1, 1) and is centred on 0.
🧮 ReLU
ReLU(z) = max(0, z)
Zero for negatives, unchanged for positives. Fast, and the default in deep networks.
FunctionOutput rangeGood forWeak spot
Sigmoid0 to 1the last layer of a yes or no classifierflat at both ends, so learning slows down
Tanh−1 to 1hidden layers in older networks and RNNsalso flat at both ends
ReLU0 to ∞hidden layers of almost every modern networka neuron stuck below 0 stops learning
Softmax0 to 1, adding to 1choosing one class out of manyneeds care with large numbers
A dimmer switch is a sigmoid: turning the knob far to the left keeps the light off, far to the right keeps it fully on, and only the middle part changes the brightness quickly.
🔍 Going deeper: newer activations and why a network needs a bend at all

Suppose every layer of a network were a straight line with no activation. Layer 1 gives 2x + 1, and layer 2 applied to that gives 3(2x + 1) − 4 = 6x − 1, another straight line. However many layers you stack, a composition of linear functions is still linear. The network could never learn a curve. The activation function is the bend that makes depth worth having.

ActivationFormulaWhere it is used
Leaky ReLUmax(0.01x, x)keeps a small slope for negatives so neurons never fully die
Softplusln(1 + eˣ)a smooth ReLU whose slope is the sigmoid
GELUx · Φ(x), Φ is the normal CDFBERT, GPT style transformers
SiLU (Swish)x · σ(x)many modern networks, and inside the SwiGLU blocks of several large language models

GELU and SiLU look like ReLU from far away but are smooth near 0 and dip slightly below 0 for small negative inputs. That smoothness tends to make very deep networks train a little better, which is why newer models moved to them.

Part 7

🔗Composing, shifting and inverting functions

Composition feeds one function into another: (f ∘ g)(x) = f(g(x)). Work from the inside out. If g(x) = 3x − 1 and f is the sigmoid, then f(g(1)) = σ(2) ≈ 0.88.

An inverse function undoes another: f⁻¹(f(x)) = x. The square root undoes squaring for x ≥ 0, ln undoes eˣ, and the logit undoes the sigmoid.

🧮 Composition
(f ∘ g)(x) = f(g(x))
Order matters: f(g(x)) and g(f(x)) are usually different.
🧮 Logit, the inverse of sigmoid
logit(p) = ln p1 − p
p ÷ (1 − p) is called the odds. Logit turns a probability back into a score.
Change to f(x)What the graph does
f(x) + kmoves up by k
f(x − h)moves right by h
a · f(x)stretches up and down by a, and flips if a < 0
f(c · x)squeezes sideways by c
A neural network is one giant composition: layer 3 of layer 2 of layer 1 of the input. Logistic regression is the composition σ(w · x + b), a sigmoid of a straight line. The chain rule in Chapter 7 is the tool for working with such chains.
The graph of an inverse function is the mirror image of the original in the line y = x. Swap the x and y of every point and you have the inverse.
🔍 Going deeper: finding an inverse step by step

To find the inverse of a function, write y = f(x), swap the roles of x and y, and solve for y. Each step is plain algebra from Chapter 1.

Only one to one functions have an inverse. x² is not one to one (both 3 and −3 give 9), so we restrict it to x ≥ 0 before saying √x is its inverse. The sigmoid is one to one because it always increases, so every probability strictly between 0 and 1 has exactly one score.

In logistic regression the logit is linear in the inputs: ln(p ÷ (1 − p)) = w · x + b. So each weight wᵢ says how much the log odds change when feature i grows by 1. A weight of 0.693 doubles the odds, because e^0.693 = 2.
