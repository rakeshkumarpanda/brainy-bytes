Part 1

🔁What an agent really is

🧒 Beginner friendly

An agent is Claude plus tools plus a loop. Claude reads the goal, asks for a tool, your code runs it and sends back the result, and this repeats until Claude says it is done.

  1. You send the goal and the list of tools.
  2. Claude replies with stop_reason: "tool_use" and a tool_use block: a name and inputs.
  3. Your code runs the tool and sends a tool_result with the same id.
  4. Repeat until stop_reason is end_turn.
Claude never runs anything itself. It only asks. Your code decides what actually happens, which is where you put limits and checks.
Part 2

🧰Define tools Claude can use

🧒 Beginner friendly

A tool is a name, a description and an input schema. Claude chooses tools by reading the descriptions, so write them for a new colleague: what it does, when to use it and what each input means.

tools.py: two tool definitions · 📄 Ready to copy
TOOLS = [
    {
        "name": "check_stock",
        "description": "Look up how many bags of one item are in the store room. Use before ordering.",
        "input_schema": {
            "type": "object",
            "properties": {"item": {"type": "string", "description": "Item name, for example toor dal"}},
            "required": ["item"],
        },
    },
    {
        "name": "place_order",
        "description": "Order more bags of an item from the wholesaler. Only order when stock is low.",
        "input_schema": {
            "type": "object",
            "properties": {
                "item": {"type": "string"},
                "bags": {"type": "integer", "description": "How many bags to order"},
            },
            "required": ["item", "bags"],
        },

Part 3

✍️Build the loop by hand, step by step

🧒 Beginner friendly📄 agent.py📄 tools.py

Here is a shopkeeper's assistant. It checks the rice stock, sees it is low and places an order, in two rounds of tool use.

The agent loop written by hand · ▶ Real SDK code, run against a local stand-in API with scripted replies
📄 agent.py
import anthropic
from shop import STOCK, PRICE
from tools import TOOLS

client = anthropic.Anthropic()

def run_tool(name, args):
    """Your code does the real work. Claude only asks."""
    if name == "check_stock":
        return f"{STOCK.get(args['item'], 0)} bags of {args['item']} in stock"
    if name == "place_order":
        cost = args["bags"] * PRICE[args["item"]]
        return f"Order placed: {args['bags']} bags of {args['item']} for ₹{cost:,}"
    return f"Unknown tool {name}"

messages = [{"role": "user", "content": "Do we have enough basmati rice? If fewer than 10 bags, order 20."}]

for step in range(1, 11):                      # never loop for ever
    response = client.messages.create(
        model="claude-sonnet-5-5", max_tokens=2000, tools=TOOLS, messages=messages,
    )
    messages.append({"role": "assistant", "content": response.content})

    if response.stop_reason != "tool_use":     # Claude is finished
        print("FINAL:", response.content[0].text)
        break

    results = []
    for block in response.content:
        if block.type == "text":
            print(f"step {step} | Claude: {block.text}")
        if block.type == "tool_use":
            output = run_tool(block.name, block.input)
            print(f"step {step} | tool {block.name}({block.input}) -> {output}")
            results.append({"type": "tool_result", "tool_use_id": block.id, "content": output})
    messages.append({"role": "user", "content": results})

Part 4

🏃Less code with the tool runner

📄 runner.py

The SDK's tool runner writes the loop for you. Decorate a normal Python function with @beta_tool: the type hints become the schema and the docstring becomes the description.

The same agent with the tool runner and a spending limit · ▶ Real SDK code, run against a local stand-in API with scripted replies
📄 runner.py
import anthropic
from anthropic import beta_tool
from shop import STOCK, PRICE

client = anthropic.Anthropic()
LIMIT = 10_000   # rupees: bigger orders need the owner

@beta_tool
def check_stock(item: str) -> str:
    """Look up how many bags of one item are in the store room. Use before ordering.

    Args:
        item: Item name, for example toor dal.
    """
    return f"{STOCK.get(item, 0)} bags of {item} in stock"

@beta_tool
def place_order(item: str, bags: int) -> str:
    """Order more bags of an item from the wholesaler. Only order when stock is low.

    Args:
        item: Item name.
        bags: How many bags to order.
    """
    cost = bags * PRICE[item]
    if cost > LIMIT:                            # a safety gate in plain code
        return f"Not placed: ₹{cost:,} is over the ₹{LIMIT:,} limit. Ask the owner to approve."
    return f"Order placed: {bags} bags of {item} for ₹{cost:,}"

runner = client.beta.messages.tool_runner(
    model="claude-sonnet-5-5",
    max_tokens=2000,
    tools=[check_stock, place_order],
    messages=[{"role": "user", "content": "Do we have enough basmati rice? If fewer than 10 bags, order 20."}],
)

for message in runner:                          # the SDK runs the loop and calls your functions
    for block in message.content:
        if block.type == "text":
            print("Claude:", block.text)
        elif block.type == "tool_use":
            print("  calls", block.name, block.input)

🧠The Claude Agent SDK: Claude Code as a library

🧒 Beginner friendly

The Agent SDK gives your program the same tools, loop, permissions, hooks, skills and MCP support as Claude Code. You do not write tools for reading files or running commands. You just say which ones are allowed.

Install the Claude Agent SDK · ⌨️ Type this in your terminal
mkdir shop-agent && cd shop-agent
python3 -m venv .venv && source .venv/bin/activate
pip install claude-agent-sdk
export ANTHROPIC_API_KEY="sk-ant-..."
python agent.py
agent.py: an agent with Claude Code's own tools · 📄 Ready to copy
import asyncio
from claude_agent_sdk import query, ClaudeAgentOptions, AssistantMessage, ResultMessage

async def main():
    async for message in query(
        prompt="Read sales.csv, find the 3 slowest selling items this month and write reorder.md with advice.",
        options=ClaudeAgentOptions(
            allowed_tools=["Read", "Write", "Glob"],     # what it may do without asking
            permission_mode="acceptEdits",
            system_prompt="You help a small shop owner. Use simple words and rupees.",
        ),
    ):
        if isinstance(message, AssistantMessage):
            for block in message.content:
                if hasattr(block, "text"):
                    print(block.text)
                elif hasattr(block, "name"):
                    print("Tool:", block.name)
        elif isinstance(message, ResultMessage):
            print("Done:", message.subtype)

asyncio.run(main())

Start simple. Many jobs that sound like agents are a fixed chain of two or three calls. Use a real agent only when the steps cannot be known in advance. Then give it few tools, clear descriptions, a step limit and checks on anything risky.
