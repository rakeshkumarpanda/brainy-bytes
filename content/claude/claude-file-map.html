Part 2

🔎The real names behind the names people use

🧒 Beginner friendly
People sayWhat really exists
"rules.md"a folder: .claude/rules/, one Markdown file per topic, optional paths:
"skills.md"SKILL.md inside its own folder: .claude/skills/<name>/SKILL.md
"agents.md"one file per agent in .claude/agents/. A root AGENTS.md is shared instructions, read only when there is no CLAUDE.md
"prompt file"there is no prompt file Claude reads. Save a reusable prompt as a skill (/name), a legacy command in .claude/commands/, or an MCP prompt
"mcp.json".mcp.json at the project root, or ~/.claude.json for local and user scope
"memory.md"auto memory's MEMORY.md index, which Claude writes itself. Your own memory file is CLAUDE.md
"system prompt file"CLAUDE.md for Claude Code, Project instructions on claude.ai, the system field in the API

🧭Decide where an instruction belongs

🧒 Beginner friendly

Ask four questions in order. Must it happen every time? Use a hook. Is it about what Claude may do? Use permissions. Is it a procedure or only for some files? Use a skill or a path rule. Otherwise it is a short line in CLAUDE.md.

InstructionWhere it goes
Run tests with pytest, check with ruff check .CLAUDE.md, a short fact the whole team needs every session
Always run ruff format after every edit.claude/settings.json hook, because it must happen every time
Never let Claude run rm -rf or git push --force.claude/settings.json permissions, as a deny rule
API key for the payment sandbox is sk_test_123an environment variable or a secret store, never a Markdown file
Let Claude read our Jira tickets.mcp.json, an MCP server gives Claude that connection
Files in app/api use Pydantic models for every request.claude/rules/api.md with paths:, so it loads only for those files
The monthly invoice report, step by step with totals.claude/skills/<name>/SKILL.md, a procedure that loads when needed
A security reviewer that checks every change.claude/agents/<name>.md, a subagent with its own context
Explain like I am 10 and use cricket examples~/.claude/output-styles/<name>.md, how every answer sounds
My local URL is http://localhost:4100CLAUDE.local.md, your private notes for this project
Prices are stored in paise as integersCLAUDE.md, a rule everyone needs

greenleaf-shop/CLAUDE.md · 📄 Ready to copy
# GreenLeaf shop

Online plant shop. FastAPI back end, PostgreSQL, pytest.

## Commands
- Test one file: `pytest tests/test_cart.py -q`
- Before a commit: `ruff check . && mypy app`

## Rules
- Prices are stored in paise as integers. Format with `format_inr()`.
- IMPORTANT: never edit `app/generated/`. Run `make codegen`.
greenleaf-shop/.claude/settings.json · 📄 Ready to copy
{
  "permissions": {
    "allow": ["Bash(ruff check *)", "Bash(pytest *)", "mcp__claude-code-docs__*"],
    "deny": ["Read(./.env*)", "Bash(git push --force *)"]
  },
  "hooks": {
    "PostToolUse": [
      { "matcher": "Edit|Write",
        "hooks": [{ "type": "command", "command": "python3 \"$CLAUDE_PROJECT_DIR\"/.claude/hooks/format.py" }] }
    ]
  }
}

Part 5

🧒Build a homework helper, step by step

🧒 Beginner friendly📄 homework-helper/CLAUDE.md📄 homework-helper/.claude/skills/quiz-me/SKILL.md

This is small enough for a child and a parent to build together in 15 minutes.

  1. Make a folder called homework-helper.
  2. Save the CLAUDE.md below in it. These are the rules Claude follows every time.
  3. Save the quiz-me skill.
  4. Open Claude Code in the folder and pick the Learning output style.
  5. Type /quiz-me fractions.
homework-helper/CLAUDE.md · 📄 Ready to copy
# Riya's homework helper

Riya is 10 and in class 5. She is learning maths, science and English.

## How to help
- Never give the final answer first. Ask what she already knows, then give one hint.
- Use short sentences and examples from cricket, cooking and Bengaluru.
- After she answers, say what she did well, then what to fix.
- If she is stuck after three hints, show the answer step by step and ask her to try a similar one.

## Safety
- Do not ask for her full name, school, address or photos.
- For anything about health or feeling unsafe, tell her to talk to a parent or teacher.
homework-helper/.claude/skills/quiz-me/SKILL.md · 📄 Ready to copy
---
name: quiz-me
description: Make a 5 question practice quiz on a topic for a class 5 student, then mark the answers.
---

1. Ask which topic, if it is not given: $ARGUMENTS
2. Write 5 questions, easiest first. Number them.
3. Wait for all 5 answers.
4. Mark each with ✅ or ❌, explain each ❌ in one sentence, and give a score out of 5.
5. Finish with one star sticker line, for example "⭐ Fractions champion!"
Start the helper · ⌨️ Type this in your terminal
mkdir homework-helper && cd homework-helper
# save CLAUDE.md and the quiz-me skill from this page into the folder
claude
> /output-style learning
> /quiz-me fractions
What a session looks like · 💬 Prompt to try
Riya: what is 3/4 + 1/8
Claude: Good question! What do you need first when you add fractions with different bottoms?
Riya: the same bottom number?
Claude: Yes! Can you turn 3/4 into eighths? Think of a roti cut into 8 pieces.
What happens

The rules in CLAUDE.md make Claude give hints, not answers, in every session, with no need to repeat them.
