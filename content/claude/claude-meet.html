Part 1

👋What Claude is, in plain words

🧒 Beginner friendly

Claude is an AI model made by Anthropic. You write to it in normal language and it writes back. It can read and write text, look at images and PDFs, write and run code, and use tools you connect to it.

Think of a very well read helper who has just joined your team. It knows a lot in general but knows nothing about your work until you tell it. Most of this subject is about one skill: telling Claude the right things, in the right file, at the right time.

I want to...UseWhat it is
chat, write, plan, studyclaude.ai, the desktop app or the mobile appA chat window. Add files, use Projects and Skills.
let Claude work inside my files and codeClaude CodeAn agent that reads, edits and runs things in a folder. Works in the terminal, VS Code, JetBrains, the desktop app and the web.
put Claude inside my own app or scriptClaude APISend messages from code and get answers back.
You do not need to be a programmer for the first chapters. Every step names the exact button, file or command.

🧠The Claude models and when to pick each

🧒 Beginner friendly

Claude comes in a family of models. Bigger models think more deeply. Smaller ones are faster and cheaper. All four current models read up to 1 million tokens at once and can write up to 128 thousand tokens in one answer.

Model names and prices change over time. Before you build something that costs money, check the models page in the Claude docs.
Part 3

🔢Tokens and the context window

🧒 Beginner friendly

Claude does not read letters or whole words. It reads tokens, which are small pieces of text. A short word is usually one token. A long word may be two or three.

The context window is everything Claude can see at one moment: your messages, its replies, files you attach and any instructions. It is measured in tokens. 1 million tokens is roughly 555 thousand English words.

Estimate tokens from words · ▶ Runs
// Claude reads text as tokens: small pieces of words.
// The models page says 1M tokens is roughly 555,000 English words,
// so one word is about 1.8 tokens on average.
const TOKENS_PER_WORD = 1_000_000 / 555_000;

function estimateTokens(text) {
  const words = text.trim().split(/\s+/).filter(Boolean).length;
  return Math.round(words * TOKENS_PER_WORD);
}

const email = "Hi team, please send me the sales numbers for March before Friday. Thanks!";
console.log("words:", email.split(" ").length, "tokens about:", estimateTokens(email));

const book = 90_000;                       // a typical novel has about 90k words
console.log("novel tokens about:", Math.round(book * TOKENS_PER_WORD));
console.log("novels that fit in 1M tokens:", Math.floor(1_000_000 / (book * TOKENS_PER_WORD)));
Output
words: 13 tokens about: 23
novel tokens about: 162162
novels that fit in 1M tokens: 6

Price is also counted in tokens. Input tokens are what you send. Output tokens are what Claude writes, and they cost five times more.

What a daily job costs on each model · ▶ Runs
// Price per million tokens (MTok) from the official models page, October 2026.
const PRICES = {
  "claude-fable-5-1":  { input: 10,   output: 50 },
  "claude-opus-5-5":   { input: 4,    output: 20 },
  "claude-sonnet-5-5": { input: 2,    output: 10 },
  "claude-haiku-5-5":  { input: 0.10, output: 0.50 },   // "from" price
};

function costUSD(model, inputTokens, outputTokens) {
  const p = PRICES[model];
  return (inputTokens * p.input + outputTokens * p.output) / 1_000_000;
}

// Summarise 200 support emails: about 400 tokens in and 120 tokens out each.
for (const model of Object.keys(PRICES)) {
  const total = costUSD(model, 200 * 400, 200 * 120);
  console.log(model.padEnd(18), "$" + total.toFixed(4));
}
Output
claude-fable-5-1   $2.0000
claude-opus-5-5    $0.8000
claude-sonnet-5-5  $0.4000
claude-haiku-5-5   $0.0200
Even with a huge window, less is more. A focused page of the right facts beats a pile of loosely related files. Chapter 3 is all about this.
Part 4

🔁How a conversation really works

🧒 Beginner friendly

Claude has no hidden memory between messages. Each time you press send, the app sends the whole conversation so far, and Claude reads all of it again before replying.

Why long chats get slower and cost more · ▶ Runs
// A chat is a list of messages. Every time you send a new message,
// the WHOLE list goes to Claude again. Nothing is remembered in between.
const conversation = [];
let sent = 0;

function ask(text, reply) {
  conversation.push({ role: "user", content: text });
  sent += conversation.reduce((n, m) => n + m.content.split(" ").length, 0);
  conversation.push({ role: "assistant", content: reply });
}

ask("Plan a 3 day trip to Goa", "Day 1 beaches, day 2 forts, day 3 markets.");
ask("Make day 2 kid friendly", "Swap the forts for the science centre and a boat ride.");
ask("Now give me a packing list", "Sunscreen, hats, water bottles, swimwear, snacks.");

console.log("messages in the list:", conversation.length);
console.log("words Claude had to read in total:", sent);
console.log(conversation.map(m => m.role).join(" -> "));
Output
messages in the list: 6
words Claude had to read in total: 66
user -> assistant -> user -> assistant -> user -> assistant

Two habits follow from this:

  • Start a new chat when you switch to a new task. Old messages about the last task only distract.
  • Put facts Claude needs every time in a place that is loaded every time: project instructions in claude.ai, CLAUDE.md in Claude Code, or the system prompt in the API.
Part 5

✍️Your first useful prompt

🧒 Beginner friendly

A good prompt says who you are, what you have, what you want and what shape the answer should take. Here is one a home baker could send on any Sunday.

A first useful prompt · 💬 Prompt to try
I run a small home bakery. Every Sunday I get about 30 WhatsApp orders.
Here are this week's orders, pasted below.

Please:
1. Make a table with name, item, quantity and pickup time.
2. Add up how many of each item I need to bake.
3. List anyone who did not give a pickup time.

<orders>
Riya: 2 chocolate cakes, pickup 10am
Arjun: 12 cupcakes
Meera: 1 chocolate cake and 6 cupcakes, 4pm
</orders>
What happens

Claude returns a three column table, totals of 3 chocolate cakes and 18 cupcakes, and flags Arjun for a missing pickup time.

Notice the three numbered steps and the <orders> tags around the data. Numbered steps tell Claude the order of work. Tags show where the data starts and ends. Chapter 2 explains both.

Part 6

🗂️claude.ai Projects: instructions plus knowledge

🧒 Beginner friendly📄 claude.ai Project instructions📄 Project knowledge

A Project in claude.ai is a folder for chats about one topic. It has two places to put information:

📝 Project instructionsHow Claude should behave in every chat of this project: tone, rules, format, steps. Keep it short.
📚 Project knowledgeFiles Claude can look things up in: policies, price lists, style guides, past reports.
  1. Open claude.ai and choose Projects, then Create project.
  2. Give it a name and a short description.
  3. Paste your instructions into the project instructions box.
  4. Add files to the project knowledge.
  5. Start chats inside the project. Each one gets the instructions and can read the files.
Project instructions for a support team · 📄 Ready to copy
# Project instructions: "Shop Support Replies"

You help the support team of GreenLeaf, an online plant shop in Pune, write replies to customers.

## Tone
- Warm, short and clear. Most customers read on a phone.
- Use the customer's first name once, at the start.
- Never promise a refund. Say "I have passed this to our refunds team" instead.

## What to do with each message
1. Find the order number (format GL-12345). If it is missing, ask for it.
2. Check the policy files in this project before answering anything about returns or delivery.
3. End with one clear next step for the customer.

## Format
Plain text, no headings, at most 120 words.
  • Instructions: who Claude is helping, tone, steps to follow, output format, things it must never do.
  • Knowledge: facts that are too long for the instructions, such as a full returns policy.

Free accounts can create up to five projects. On paid plans, when the knowledge grows large, Claude searches it and pulls in only the relevant pieces.

Part 7

🧰Skills: teach Claude a task once

🧒 Beginner friendly📄 SKILL.md

A Skill is a folder with a file called SKILL.md. The file has a short name and description at the top and the steps for one task below. Claude reads only the name and description at first. When a request matches, it opens the full file. That way you can have many skills without filling the context window.

What a skill upload looks like · 📦 Upload in Settings, Capabilities
invoice-checker.zip
└── invoice-checker/
    ├── SKILL.md            <- required: name, description, then the steps
    ├── checklist.md        <- optional: extra detail Claude reads only when needed
    └── scripts/
        └── totals.py       <- optional: code Claude can run

To add a skill in claude.ai:

  1. Open Settings, then Capabilities, and turn on Code execution and file creation.
  2. In the Skills area, choose Upload skill and pick a ZIP file of the skill folder.
  3. Ask for the task in a normal chat, for example "check this invoice". Claude uses the skill when the description matches.

The same SKILL.md format works in Claude Code and the API. Chapter 7 builds skills step by step.

🛡️Safe habits from day one

🧒 Beginner friendly
  • Check important facts. Claude can be wrong and sound sure. Ask it to quote the source line from your file when facts matter.
  • Never paste passwords or API keys into a chat or a CLAUDE.md. Keys belong in environment variables.
  • Read before you approve. When Claude Code asks to run a command or edit a file, read what it wants to do.
  • Keep humans in charge of sending. Let Claude draft the email or the post. You press send.
🧑‍🏫 Real scenario: a teacherA maths teacher pastes a class list with phone numbers to make a seating plan. Better: replace phone numbers with roll numbers first. Claude only needs names and heights to plan seats.
