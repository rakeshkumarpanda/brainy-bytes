    How to use the playground
    
1. Pick a language and an example

    
Choose one of the seven languages. Each one has the same four examples: a greeting that reads your name, a shop bill, a report card that sorts students, and a program with a bug to find. Change them as much as you like. The playground keeps what you typed for each language on this device.

    
2. Autosuggest on or off

    
With Autosuggest on, the editor offers words while you type: keywords, functions, the names you already used, and short templates. Press Tab or Enter to take a suggestion. For example, type sout in Java or def in Python. With Autosuggest off, nothing pops up at all, not even with Ctrl+Space, so you write every letter yourself. That is good practice before a test.

    
3. Run all

    
Run all runs the whole program at once and shows everything it prints. Press Ctrl+Enter in the editor to do the same. If the program has a mistake, the line turns red and a short note explains the message in simple words.

    
Java, C# and C++ check the whole program before the first line runs, the same way javac, the C# compiler and g++ do. So byte b3 = b1 + b2; stops the program with a type error, even on a line that would never run. A value that does not fit its variable, a missing return, a name that is not declared and a statement that can never run are all caught this way.

    
4. Step line by line

    
Step line by line runs the program once and remembers every line it ran. Then you move through it with Next and Back, or press Play to watch it go. The highlighted line is the one about to run. The panel shows each function that is running, with its variables. A value that just changed is coloured, and so is a new variable. The output grows as the program prints. While you step, the code is read only. Press Edit code to change it again.

    
5. Input

    
Programs cannot stop and ask you questions here, so type the answers in the Input box first, one per line. For the greeting example, the Input box holds a name on the first line and an age on the second.

    
What runs your code

    

      
LanguageRuns on

      
PythonReal CPython 3 inside your browser (Pyodide). The first run downloads it once.

      
JavaScriptYour browser’s own JavaScript engine.

      
TypeScriptThe real TypeScript compiler checks the types, then your browser runs the result.

      
Java, C, C++, C#The playground’s own teaching runner, written to follow each language’s rules, with output and messages in the style of javac, gcc, g++ and .NET. It covers the language features and libraries that school and college courses use. Very advanced features, such as threads, files on disk and network access, are not available.

    

    
Nothing you type leaves your browser. Every program runs on your own device, in a separate worker, so the Stop button can always end a program that never finishes.
