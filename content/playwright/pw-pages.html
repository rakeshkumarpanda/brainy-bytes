Part 1

🧭Going to pages and waiting for them

🧒 Beginner friendly

page.navigate(url)page.goto(url)page.goto(url)page.goto(url) opens an address and waits until the page has loaded. You can say how far it should wait with the waitUntil option.

A relative address such as /login is joined to the base URL from the config. Many pages also move on by themselves after a click, for example after signing in. Then you wait for the new address.

Go, wait for the address, go back and reload · ✅ mvn test ran
📄 src/test/java/com/brainy/NavigationTest.java
package com.brainy;

import com.microsoft.playwright.Page;
import com.microsoft.playwright.junit.UsePlaywright;
import com.microsoft.playwright.options.AriaRole;
import com.microsoft.playwright.options.WaitUntilState;
import org.junit.jupiter.api.Test;
import java.util.regex.Pattern;

import static com.microsoft.playwright.assertions.PlaywrightAssertions.assertThat;

@UsePlaywright(ShopOptions.class)
public class NavigationTest {
  @Test
  void movingAroundTheShop(Page page) {
    page.navigate("/login", new Page.NavigateOptions().setWaitUntil(WaitUntilState.DOMCONTENTLOADED));
    System.out.println("1. " + page.url());

    page.getByLabel("Email").fill("asha@shop.example");
    page.getByLabel("Password").fill("s3cret");
    page.getByRole(AriaRole.BUTTON, new Page.GetByRoleOptions().setName("Sign in")).click();
    page.waitForURL("**/products");                 // the app moves on by itself
    System.out.println("2. " + page.url());

    page.goBack();
    assertThat(page).hasURL(Pattern.compile("/login$"));
    System.out.println("3. " + page.url());

    page.goForward();
    page.reload();
    assertThat(page).hasURL(Pattern.compile("/products$"));
    System.out.println("4. " + page.url() + " | " + page.title());
  }
}

What happens

After the click, the shop changes the address with its own script, so the test waits for the new URL with waitForURL. Back, forward and reload work like the browser buttons. The checks on the URL use a regular expression so they do not depend on the port.

⚠️
Do not wait for the network to go quiet. A chat widget or analytics script can keep it busy forever. Wait for what the user is waiting for: a URL, a heading or a message. Every check with expect already waits.
Part 2

🖼️Iframes

🧒 Beginner friendly

An iframe is a web page inside a web page. Payment forms, maps, videos and chat windows often live in iframes, because another company serves them. A locator on the main page does not see inside an iframe, so you step into it first.

Fill a card form that lives inside an iframe · ✅ mvn test ran
📄 src/test/java/com/brainy/FrameTest.java
package com.brainy;

import com.microsoft.playwright.FrameLocator;
import com.microsoft.playwright.Page;
import com.microsoft.playwright.junit.UsePlaywright;
import com.microsoft.playwright.options.AriaRole;
import org.junit.jupiter.api.Test;

import static com.microsoft.playwright.assertions.PlaywrightAssertions.assertThat;

@UsePlaywright(ShopOptions.class)
public class FrameTest {
  @Test
  void payInsideThePaymentIframe(Page page) {
    page.navigate("/frames");
    FrameLocator payment = page.frameLocator("iframe[title=\"Payment form\"]");

    payment.getByLabel("Card number").fill("4111 1111 1111 1111");
    payment.getByLabel("Expiry").fill("12/29");
    payment.getByRole(AriaRole.BUTTON, new FrameLocator.GetByRoleOptions().setName("Pay ₹219")).click();

    // The message appears in the main page, outside the iframe.
    assertThat(page.getByRole(AriaRole.STATUS)).hasText("Paid with card ending 1111");
    System.out.println("Frames on the page: " + page.frames().size());
  }

  @Test
  void aShortCardNumberIsRefused(Page page) {
    page.navigate("/frames");
    // Another way in: find the iframe element, then step into it.
    FrameLocator payment = page.getByTitle("Payment form").contentFrame();
    payment.getByLabel("Card number").fill("4111");
    payment.getByRole(AriaRole.BUTTON, new FrameLocator.GetByRoleOptions().setName("Pay ₹219")).click();
    assertThat(payment.getByRole(AriaRole.ALERT)).hasText("Card number must have 16 digits");
  }
}

What happens

frameLocator and contentFrame() both give you a way into the iframe, and every locator after it searches only inside. The page has two frames: the main page and the payment iframe.

🌍
Most real payment iframes come from another domain. Playwright handles that the same way, which older tools could not do easily. In tests, many teams use the payment company test card numbers, such as 4111 1111 1111 1111, in their sandbox.
Part 3

💬Alerts, confirms and prompts

Browser dialogs stop the page until someone answers. Playwright answers for you: with no handler, it dismisses them. To accept or to type an answer, register a handler before the click that opens the dialog.

Alerts, confirms and prompts · ✅ mvn test ran
📄 src/test/java/com/brainy/DialogTest.java
package com.brainy;

import com.microsoft.playwright.Page;
import com.microsoft.playwright.junit.UsePlaywright;
import com.microsoft.playwright.options.AriaRole;
import org.junit.jupiter.api.Test;

import static com.microsoft.playwright.assertions.PlaywrightAssertions.assertThat;

@UsePlaywright(ShopOptions.class)
public class DialogTest {
  @Test
  void withNoHandlerDialogsAreDismissed(Page page) {
    page.navigate("/widgets");
    page.getByRole(AriaRole.BUTTON, new Page.GetByRoleOptions().setName("Delete account")).click();
    assertThat(page.getByRole(AriaRole.STATUS)).hasText("Kept your account");
  }

  @Test
  void acceptAConfirmAndReadItsMessage(Page page) {
    page.navigate("/widgets");
    page.onDialog(dialog -> {
      System.out.println(dialog.type() + " | " + dialog.message());
      dialog.accept();
    });
    page.getByRole(AriaRole.BUTTON, new Page.GetByRoleOptions().setName("Delete account")).click();
    assertThat(page.getByRole(AriaRole.STATUS)).hasText("Account deleted");
  }

  @Test
  void typeAnAnswerIntoAPrompt(Page page) {
    page.navigate("/widgets");
    page.onceDialog(dialog -> dialog.accept("Weekly shop"));
    page.getByRole(AriaRole.BUTTON, new Page.GetByRoleOptions().setName("Rename list")).click();
    assertThat(page.getByRole(AriaRole.STATUS)).hasText("List renamed to Weekly shop");
  }
}

📁Downloads and uploads

A download is an event, like a popup. Start waiting first, then click, then use the download object.

Catch a download and read the file · ✅ mvn test ran
📄 src/test/java/com/brainy/DownloadTest.java
package com.brainy;

import com.microsoft.playwright.Download;
import com.microsoft.playwright.Page;
import com.microsoft.playwright.junit.UsePlaywright;
import com.microsoft.playwright.options.AriaRole;
import org.junit.jupiter.api.Test;
import java.nio.file.Files;
import java.nio.file.Paths;

import static org.junit.jupiter.api.Assertions.assertEquals;

@UsePlaywright(ShopOptions.class)
public class DownloadTest {
  @Test
  void downloadTheOrdersReport(Page page) throws Exception {
    page.navigate("/widgets");
    Download download = page.waitForDownload(() ->
        page.getByRole(AriaRole.LINK, new Page.GetByRoleOptions().setName("Download report")).click());

    System.out.println("File name: " + download.suggestedFilename());
    String text = Files.readString(download.path());
    System.out.println(text.trim());
    assertEquals("order,total", text.split("\n")[0]);
    download.saveAs(Paths.get("reports", download.suggestedFilename()));   // keep a copy
  }
}

Part 5

📡Listening to what the page does

A page fires events while you test it: console messages, uncaught errors, network requests and responses, new popups, dialogs and downloads. Listening to them lets a test notice problems the screen does not show.

Listen to console messages, page errors and requests · ✅ mvn test ran
📄 src/test/java/com/brainy/EventsTest.java
package com.brainy;

import com.microsoft.playwright.Page;
import com.microsoft.playwright.junit.UsePlaywright;
import com.microsoft.playwright.options.AriaRole;
import org.junit.jupiter.api.Test;
import java.util.ArrayList;
import java.util.List;

@UsePlaywright(ShopOptions.class)
public class EventsTest {
  @Test
  void catchConsoleMessagesAndPageErrors(Page page) {
    List<String> messages = new ArrayList<>();
    List<String> errors = new ArrayList<>();
    page.onConsoleMessage(msg -> messages.add(msg.type() + ": " + msg.text()));
    page.onPageError(errors::add);
    page.onRequest(request -> {
      if (request.url().contains("/api/")) System.out.println("request -> " + request.method() + " " + request.url());
    });
    page.navigate("/widgets");

    page.waitForConsoleMessage(new Page.WaitForConsoleMessageOptions().setPredicate(m -> m.type().equals("warning")),
        () -> page.getByRole(AriaRole.BUTTON, new Page.GetByRoleOptions().setName("Write to the console")).click());
    System.out.println(messages);

    page.getByRole(AriaRole.BUTTON, new Page.GetByRoleOptions().setName("Break the page")).click();
    page.waitForCondition(() -> !errors.isEmpty());
    System.out.println("Page error: " + errors.get(0));
  }
}

Part 6

🧪Running code inside the page

Sometimes you need something the page knows but does not show: a value in storage, a count, a computed style. evaluate runs a JavaScript function inside the page and brings the result back to your language. addInitScript runs code before the page's own scripts, which is useful to set a flag or fake something before the app starts.

Part 7

🌑Shadow DOM and web components

Web components hide their insides in a shadow root, so document.querySelector cannot find them. Design systems such as Salesforce Lightning and many company component libraries use them. Playwright locators look inside open shadow roots automatically.
