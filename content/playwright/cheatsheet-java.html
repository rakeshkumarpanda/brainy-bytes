What Playwright is and how it works

Open chapter

What Playwright is and the jobs teams use it for, the official languages, a fact based comparison with Selenium and Cypress, a first script in four languages, how one call travels through the client library, the driver and the browser protocol with real DEBUG=pw:api, pw:channel and pw:protocol logs, a first test with JUnit, pytest and Playwright Test, a recorded sign in walk, and what a test runner does for every test.

Key ideas

  • You write steps Open, type, click, check. In Java, Python, JavaScript or TypeScript.
  • Messages Each call becomes a small message. The driver is the same for every language.
  • Real browsers Real clicks and real typing. The page cannot tell it apart from a person.
  • It waits Visible, stable, enabled. No fixed sleeps, so far fewer flaky tests.
  • Remember Playwright drives real browsers through one driver, waits for elements before it acts, and works the same way in Java, Python, JavaScript and TypeScript.

package com.brainy;

import com.microsoft.playwright.*;

public class FirstScript {
  public static void main(String[] args) {
    try (Playwright playwright = Playwright.create()) {        // start the Playwright driver
      Browser browser = playwright.chromium().launch();         // start a real Chromium, with no window
      Page page = browser.newPage();                             // open a new tab
      page.navigate("http://localhost:4173/products");
      System.out.println("Title: " + page.title());
      page.screenshot(new Page.ScreenshotOptions()
          .setPath(java.nio.file.Paths.get("products.png")));  // save a picture of the page
    }                                                            // closing Playwright closes the browser too
  }
}

Tips and traps

  • Common mistake
    People often ask for Playwright in C, C++ or Go. There is no official Playwright for C or C++. For Go there is a community project, playwright-go, which is not made by the Playwright team. This subject sticks to the official languages so that every example is supported and up to date.Lesson: What Playwright is
  • In real teams
    In many companies you will join a project that already uses Selenium. Knowing both is useful. Many teams move to Playwright one test suite at a time, because the ideas are close: find an element, act on it, check the result.Lesson: Why teams pick Playwright
  • Remember
    The driver is the same Node.js program for every language. The Java jar and the Python package carry a copy of it and start it for you. This is why a new feature arrives in Java, Python, JavaScript and C# in the same release.Lesson: How one line travels to the browser
  • Remember
    The test method receives a Page because of @UsePlaywright(ShopOptions.class). JUnit creates a fresh context and page for each test. ShopOptions sets the base address, so navigate("/login") means http://localhost:4173/login.Lesson: From a script to a test

Tips and traps

  • Common mistake
    Keep one Playwright version per project and update on purpose. Each Playwright release expects its own browser builds. After you update the package, run the install command again, or the tests stop with an error that says the browser executable does not exist.Lesson: Install Playwright in your language
  • In real teams
    Codegen picks locators the same way you should: role and accessible name first, then label, placeholder or text, and a test id only when nothing better exists. When the recorded locator looks odd, the page itself is often missing a label, which is worth reporting to the developers.Lesson: Record a test with codegen
  • In real teams
    Turn on format on save and a linter in your editor from day one.Lesson: Your editor
  • Remember
    Pin exact versions in your project (no ^ in package.json, == in requirements.txt). Then a teammate and the CI server always run the same Playwright, and an update is a change you can see and review.Lesson: Updating Playwright safely

Browsers, contexts, pages and devices

Open chapter

Key ideas

  • Browser Start once, about 0.5 s. Shared by many tests.
  • Context A fresh, empty profile. Its own cookies, storage and permissions.
  • Page One tab. Tabs in a context share the login.
  • Emulation Size, locale, time zone, location. Set on the context, nothing on your computer changes.
  • Remember Start one browser, give every test a new context, and set what the site should see, such as a phone or a German user, with context options.

package com.brainy;

import com.microsoft.playwright.*;
import java.util.List;

public class Main {
  public static void main(String[] args) {
    try (Playwright playwright = Playwright.create()) {
      Browser browser = playwright.chromium().launch(new BrowserType.LaunchOptions()
          .setHeadless(true)          // no window. Use false to watch it work
          .setSlowMo(100)             // wait 100 ms before every action
          .setArgs(List.of("--lang=en-GB")));
      System.out.println("Browser type: " + browser.browserType().name());
      System.out.println("Version: " + browser.version());
      System.out.println("Connected: " + browser.isConnected());
      System.out.println("Contexts so far: " + browser.contexts().size());
      browser.close();
      System.out.println("Connected after close: " + browser.isConnected());
    }
  }
}

A persistent profile that survives a restart
src/main/java/com/brainy/Main.java
package com.brainy;

import com.microsoft.playwright.*;
import java.nio.file.Files;
import java.nio.file.Path;

public class Main {
  public static void main(String[] args) throws Exception {
    Path profile = Files.createTempDirectory("shop-profile-");
    try (Playwright playwright = Playwright.create()) {
      // First visit: a real profile folder on disk, like a person's Chrome profile.
      BrowserContext context = playwright.chromium().launchPersistentContext(profile, new BrowserType.LaunchPersistentContextOptions());
      Page page = context.pages().get(0);
      page.navigate("http://localhost:4173/");
      page.evaluate("localStorage.setItem('theme', 'dark')");
      context.close();

      // Second visit with the same folder: the data is still there.
      context = playwright.chromium().launchPersistentContext(profile, new BrowserType.LaunchPersistentContextOptions());
      page = context.pages().get(0);
      page.navigate("http://localhost:4173/");
      System.out.println("theme = " + page.evaluate("localStorage.getItem('theme')"));
      context.close();
    }
  }
}

  • Remember
    The pattern in page.route is a glob: ** matches any part of the address, including slashes, and * matches any part between two slashes. A regular expression works too. Routes added with context.route catch requests from every page of the context, including new tabs.Lesson: Mock an API

Open chapter

  • Layers One job each. Data, API, pages.

package com.brainy.shop.config;

import java.io.IOException;
import java.io.InputStream;
import java.util.Properties;

// Settings that change between machines (a laptop, CI, staging) live here and nowhere else.
// Order: -DbaseUrl=..., then the BASE_URL environment variable, then config.properties.
public final class Config {
  private static final Properties FILE = new Properties();

  static {
    try (InputStream in = Config.class.getResourceAsStream("/config.properties")) {
      if (in != null) FILE.load(in);
    } catch (IOException e) {
      throw new IllegalStateException("Cannot read config.properties", e);
    }
  }

  private Config() {}

  public static String get(String key, String envName) {
    String value = System.getProperty(key);
    if (value == null) value = System.getenv(envName);
    if (value == null) value = FILE.getProperty(key);
    return value;
  }

  public static String baseUrl() {
    return get("baseUrl", "BASE_URL");
  }

  public static boolean headless() {
    return Boolean.parseBoolean(get("headless", "HEADLESS"));
  }
}

package com.brainy.shop.api;

import com.brainy.shop.data.User;
import com.microsoft.playwright.APIRequestContext;
import com.microsoft.playwright.APIResponse;
import com.microsoft.playwright.options.RequestOptions;

import java.util.Map;
import java.util.regex.Matcher;
import java.util.regex.Pattern;

// Fast set up through the API, so UI tests only click what they are testing
public class ShopApi {
  private final APIRequestContext request;

  public ShopApi(APIRequestContext request) {
    this.request = request;
  }

  public String signIn(User user) {
    APIResponse response = request.post("/api/login",
        RequestOptions.create().setData(Map.of("email", user.email(), "password", user.password())));
    if (!response.ok()) throw new IllegalStateException("Sign in failed for " + user.email() + ": " + response.status());
    Matcher token = Pattern.compile("\"token\":\"(\\w+)\"").matcher(response.text());
    if (!token.find()) throw new IllegalStateException("No token in " + response.text());
    return token.group(1);
  }

  public void addToCart(String token, int productId, int qty) {
    APIResponse response = request.post("/api/cart", RequestOptions.create()
        .setData(Map.of("productId", productId, "qty", qty))
        .setHeader("Authorization", "Bearer " + token));
    if (!response.ok()) throw new IllegalStateException("Could not add product " + productId + ": " + response.status());
  }
}

import com.brainy.shop.api.ShopApi;
import com.brainy.shop.config.Config;

import com.brainy.shop.data.Users;

import com.microsoft.playwright.APIRequest;
import com.microsoft.playwright.APIRequestContext;
import com.microsoft.playwright.Browser;
import com.microsoft.playwright.BrowserContext;
import com.microsoft.playwright.BrowserType;
import com.microsoft.playwright.Page;
import com.microsoft.playwright.Playwright;
import com.microsoft.playwright.Tracing;
import org.testng.ITestResult;
import org.testng.annotations.AfterClass;
import org.testng.annotations.AfterMethod;
import org.testng.annotations.BeforeClass;
import org.testng.annotations.BeforeMethod;

import java.nio.file.Paths;

// Every test class extends BaseTest. TestNG runs classes in parallel, and each class has its own
// Playwright and browser, so nothing is shared between threads.
public abstract class BaseTest {
  private Playwright playwright;
  private Browser browser;
  private APIRequestContext request;
  private BrowserContext context;
  protected Page page;
  protected ShopApi api;
  protected LoginPage loginPage;
  protected ProductsPage productsPage;
  protected CartPage cartPage;

  @BeforeClass(alwaysRun = true)        // alwaysRun: also when a group such as smoke is chosen
  public void launchBrowser() {
    playwright = Playwright.create();
    browser = playwright.chromium().launch(new BrowserType.LaunchOptions().setHeadless(Config.headless()));
    request = playwright.request().newContext(new APIRequest.NewContextOptions().setBaseURL(Config.baseUrl()));
    api = new ShopApi(request);
  }

  @BeforeMethod(alwaysRun = true)
  public void openPage() {
    context = browser.newContext(new Browser.NewContextOptions().setBaseURL(Config.baseUrl()));
    context.tracing().start(new Tracing.StartOptions().setScreenshots(true).setSnapshots(true));
    page = context.newPage();
    loginPage = new LoginPage(page);
    productsPage = new ProductsPage(page);
    cartPage = new CartPage(page);
  }

  // A fresh session made through the API: fast, and no two tests share a cart
  protected String signInThroughApi(User user) {
    String token = api.signIn(user);
    context.addInitScript("window.localStorage.setItem('token', '" + token + "')");
    return token;
  }

  protected String signInThroughApi() {
    return signInThroughApi(Users.ASHA);
  }

  // Report listeners call this when a test fails. TestNG calls them before closePage(), so the page is still open.
  public byte[] screenshot() {
    return page.screenshot();
  }

  @AfterMethod(alwaysRun = true)
  public void closePage(ITestResult result) {
    if (result.isSuccess()) {
      context.tracing().stop();
    } else {                                      // keep a trace only for a failed test
      String name = getClass().getSimpleName() + "." + result.getMethod().getMethodName();
      context.tracing().stop(new Tracing.StopOptions().setPath(Paths.get("traces", name + ".zip")));
    }
    context.close();
  }

  @AfterClass(alwaysRun = true)
  public void closeBrowser() {
    request.dispose();
    playwright.close();
  }
}

package com.brainy.shop.reporting;

import com.aventstack.extentreports.ExtentReports;
import com.aventstack.extentreports.ExtentTest;
import com.aventstack.extentreports.MediaEntityBuilder;
import com.aventstack.extentreports.reporter.ExtentSparkReporter;
import org.testng.IReporter;
import org.testng.ISuite;
import org.testng.ITestResult;
import org.testng.xml.XmlSuite;

import java.util.ArrayList;
import java.util.Base64;
import java.util.Comparator;
import java.util.Date;
import java.util.List;

// TestNG calls generateReport once, after the whole suite. It writes target/extent/index.html
public class ExtentReporter implements IReporter {
  @Override
  public void generateReport(List<XmlSuite> xmlSuites, List<ISuite> suites, String outputDirectory) {
    ExtentSparkReporter spark = new ExtentSparkReporter("target/extent/index.html");
    spark.config().setDocumentTitle("Brainy Shop tests");
    spark.config().setReportName("Brainy Shop, nightly run");
    ExtentReports extent = new ExtentReports();
    extent.attachReporter(spark);
    extent.setSystemInfo("Browser", "Chromium");

    List<ITestResult> all = new ArrayList<>();
    for (ISuite suite : suites) {
      suite.getResults().values().forEach(r -> {
        all.addAll(r.getTestContext().getPassedTests().getAllResults());
        all.addAll(r.getTestContext().getFailedTests().getAllResults());
        all.addAll(r.getTestContext().getSkippedTests().getAllResults());
      });
    }
    all.sort(Comparator.comparingLong(ITestResult::getStartMillis));
    for (ITestResult result : all) add(extent, result);
    extent.flush();
  }

  private void add(ExtentReports extent, ITestResult result) {
    ExtentTest test = extent.createTest(result.getMethod().getMethodName())
        .assignCategory(result.getTestClass().getRealClass().getSimpleName());
    for (String group : result.getMethod().getGroups()) test.assignCategory(group);
    test.getModel().setStartTime(new Date(result.getStartMillis()));   // the real times, not the report time
    test.getModel().setEndTime(new Date(result.getEndMillis()));
    switch (result.getStatus()) {
      case ITestResult.SUCCESS -> test.pass("Passed");
      case ITestResult.SKIP -> test.skip("Skipped");
      default -> {
        test.fail(result.getThrowable());
        if (result.getAttribute("screenshot") instanceof byte[] png) {
          String base64 = Base64.getEncoder().encodeToString(png);
          test.fail("Screenshot at failure", MediaEntityBuilder.createScreenCaptureFromBase64String(base64).build());
        }
      }
    }
  }
}

package com.brainy.shop.reporting;

import org.testng.ITestContext;
import org.testng.ITestListener;
import org.testng.ITestResult;

// One line per test, then a short summary when the run ends
public class SummaryListener implements ITestListener {
  @Override
  public void onTestSuccess(ITestResult result) { line("PASS", result); }

  @Override
  public void onTestFailure(ITestResult result) { line("FAIL", result); }

  @Override
  public void onTestSkipped(ITestResult result) { line("SKIP", result); }

  @Override
  public void onFinish(ITestContext context) {
    System.out.printf("%d passed, %d failed, %d skipped%n", context.getPassedTests().size(),
        context.getFailedTests().size(), context.getSkippedTests().size());
    context.getFailedTests().getAllResults()
        .forEach(r -> System.out.println("  to look at: " + r.getMethod().getMethodName()));
  }

  private void line(String status, ITestResult r) {
    double seconds = (r.getEndMillis() - r.getStartMillis()) / 1000.0;
    System.out.printf("%s  %s (%.1f s)%n", status, r.getMethod().getMethodName(), seconds);
  }
}

package com.brainy;

import com.microsoft.playwright.ConsoleMessage;
import com.microsoft.playwright.Page;
import com.microsoft.playwright.junit.UsePlaywright;
import com.microsoft.playwright.options.AriaRole;
import org.junit.jupiter.api.Test;

import static org.junit.jupiter.api.Assertions.assertEquals;

@UsePlaywright(ShopOptions.class)
public class CollectTest {
  @Test
  void readsConsoleMessagesAndPageErrorsAfterTheFact(Page page) {
    page.navigate("/widgets");
    page.getByRole(AriaRole.BUTTON, new Page.GetByRoleOptions().setName("Write to the console")).click();
    page.getByRole(AriaRole.BUTTON, new Page.GetByRoleOptions().setName("Break the page")).click();
    page.waitForCondition(() -> !page.pageErrors().isEmpty());

    // New in 1.56: the page keeps its recent console messages, errors and requests, no listener needed
    for (ConsoleMessage m : page.consoleMessages()) System.out.println("console." + m.type() + ": " + m.text());
    for (String e : page.pageErrors()) System.out.println("page error: " + e);
    System.out.println("requests so far: " + page.requests().size());
    assertEquals(1, page.pageErrors().size());
  }
}
