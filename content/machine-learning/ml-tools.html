Lesson 1 of 12

The ML toolbox at a glance

Source: NumPy 2.4 user guide, pandas 3.0 user guide and scikit-learn 1.8 "Getting started".

What it is
Almost every Python ML project uses the same small set of libraries: NumPy for fast arrays of numbers, pandas for tables, scikit-learn for classic models, and later PyTorch or TensorFlow for deep learning.
Why we need it
Plain Python lists are flexible but slow for millions of numbers, and they have no idea of rows, columns or models. These libraries give you fast maths, easy tables and ready, tested models, so you can focus on the problem.
How it works
pandas is built on NumPy, and scikit-learn takes NumPy arrays or pandas tables as input. You load and clean data with pandas, turn it into arrays, and pass them to a scikit-learn model.

NumPy arrays

Download this program (.py)Save it, open it in any editor and run it with python3 numpy_basics.py.
What it is
A NumPy array is a grid of numbers that all have the same type, stored side by side in memory. It can be 1D (a vector), 2D (a matrix) or more.
Why we need it
ML is mostly maths on big tables of numbers. Arrays let you write that maths in one line (marks + 5) and run it in fast compiled code instead of a slow Python loop.
How it works
Operations act on every item at once. This is called vectorisation. A test such as marks >= 50 makes a True or False array (a mask), and marks[mask] keeps only the matching items.
Download this program (.py)Save it, open it in any editor and run it with python3 why_vectorise.py.
Common mistake
A NumPy array holds one type. np.array([1, 2.5]) turns everything into floats, and np.array([1, "a"]) turns everything into text. Check .dtype when results look strange.

Lesson 4 of 12

NumPy maths for models

Most models turn an input into a prediction with a dot product: multiply each feature by its weight and add the results. With many examples at once this becomes a matrix times a vector. NumPy writes both in one symbol, @.

Download this program (.py)Save it, open it in any editor and run it with python3 numpy_maths.py.
Dot productExam favourite
w · x = w1x1 + w2x2 + ... + wdxd
np.dot(w, x) or w @ x. The core of linear models and neurons.
Predictions for many rowsExam favourite
ŷ = X w
X is n × d, w is d long, ŷ is n long. In NumPy: X @ w.
Shape rule for matrix product
(n × d) @ (d × k) = (n × k)
The inner sizes must match.
Remember
Use np.random.default_rng(seed) for random numbers. The seed makes your results repeatable, which matters when you compare models.

pandas DataFrames

Download this program (.py)Save it, open it in any editor and run it with python3 pandas_basics.py.
What it is
A DataFrame is a table with named columns and a row label (the index). Each column is a Series and can have its own type: numbers, text, dates.
Why we need it
Real data arrives as CSV files, Excel sheets and database tables with mixed types and missing values. pandas reads all of them and lets you filter, fix and summarise in a few readable lines.
How it works
Select a column with df["col"], filter rows with a mask df[df["score"] > 80], pick by label with df.loc[row, col] and by position with df.iloc[i, j]. Read files with pd.read_csv("file.csv").

In the exam
loc uses labels and includes the end: df.loc[0:2] gives 3 rows. iloc uses positions and stops before the end: df.iloc[0:2] gives 2 rows.

The scikit-learn API: estimators and transformers

Download this program (.py)Save it, open it in any editor and run it with python3 sklearn_api.py.
What it is
Every scikit-learn object follows one pattern. An estimator learns from data with fit. A transformer (such as a scaler) also has transform, which changes data. A predictor (a model) has predict.
Why we need it
One shared pattern means you can swap a logistic regression for a random forest by changing one line, and you can chain steps safely in a Pipeline.
How it works
fit(X, y) learns and stores results in attributes that end with an underscore (mean_, coef_). transform(X) applies them. fit_transform does both on training data. A Pipeline runs every step in order and fits each one only on the data you train it on, which prevents leakage.
MethodWho has itWhat it does
fit(X, y)Every estimatorLearn from training data. Learned values end with _
transform(X)Transformers (scalers, encoders)Change data using what fit learned
fit_transform(X)Transformersfit, then transform the same data (training data only)
predict(X)ModelsGive predictions for new rows
predict_proba(X)Most classifiersGive the probability of each class
score(X, y)ModelsAccuracy for classifiers, R2 for regressors
get_params(), set_params()Every estimatorRead or change hyperparameters
In the exam
Call fit_transform on the training set and only transform on the test set. Calling fit on the test set too is a form of data leakage.

The maths behind the tools

Mean along an axisExam favourite
meanj = (1/n) Σi Xij
axis=0 gives one mean per column j.
Standard deviationExam favourite
std = √( (1/n) Σ (xi − mean)2 )
NumPy uses 1/n by default (ddof=0). pandas uses 1/(n − 1) (ddof=1).
Standard scalingExam favourite
z = (x − mean) / std
What StandardScaler does to each column.
Memory of an array
bytes = number of values × bytes per value
A 1,000 × 1,000 float64 array uses 8,000,000 bytes, about 8 MB.
Broadcast result size
sizek = max(ak, bk) when ak = bk or one of them is 1
Checked from the right end of the shapes.
Worked example: scale one column by hand
  1. Values 2, 4, 6. Mean = (2 + 4 + 6) / 3 = 4.
  2. Squared gaps: 4, 0, 4. Average = 8 / 3 ≈ 2.667.
  3. std = √2.667 ≈ 1.633 (NumPy style, dividing by n).
  4. z = (2 − 4)/1.633, 0, (6 − 4)/1.633 = −1.225, 0, 1.225
  5. After scaling, the column has mean 0 and standard deviation 1. StandardScaler gives exactly these numbers.
Going deeper: Why NumPy is fast

A Python list holds pointers to separate objects spread around memory, and every + goes through Python’s type checks. A NumPy array is one block of raw numbers, so the loop can run in C, use CPU vector instructions (SIMD) that add several numbers per cycle, and read memory in order, which keeps the CPU cache full. That is why the same sum can be 10 to 100 times faster.

Lesson 10 of 12

From beginner to expert

One idea, four depths

NumPy holds numbers in fast arrays, pandas holds tables, scikit-learn holds ready models. Together they are the everyday tools of ML in Python.

Use vectorised NumPy maths and masks, mind shapes and axes, clean and summarise tables with pandas (groupby, merge, fillna), and use fit, transform and predict in scikit-learn, chained with a Pipeline.

Know the broadcasting rules, views against copies, dtype pitfalls (int overflow, float precision), pandas index alignment, and why fitting transformers inside a pipeline per cross validation fold prevents leakage.

NumPy arrays are strided views over a memory buffer, so slicing and transposing change only strides, not data. Libraries share memory through the buffer protocol and Apache Arrow, which pandas 3.0 uses for its default string type. scikit-learn follows the estimator contract (Buitinck and others, 2013) that keeps all state in fit and hyperparameters in __init__.

Beginner
Make arrays and DataFrames, select rows and columns, and call fit and predict.
Intermediate
Use axis and broadcasting with confidence, build features with groupby and merge, and use Pipelines.
Expert
Reason about memory layout, views and copies, and write your own scikit-learn compatible transformer.

Chapter summary

  1. NumPy arrays hold numbers of one type in one block of memory. Maths on them is vectorised and fast.
  2. Shape is the size along each axis. axis=0 works down the rows (one answer per column), axis=1 across.
  3. Broadcasting compares shapes from the right and stretches sizes of 1. Unequal sizes that are not 1 raise an error.
  4. Predictions of linear models are dot products: X @ w.
  5. pandas DataFrames are tables with named columns. Use df["col"], masks, loc (labels) and iloc (positions).
  6. groupby splits, applies and combines. merge joins tables. isna, fillna and dropna handle missing values.
  7. scikit-learn: fit learns, transform changes data, predict answers. fit_transform on train, transform on test. Pipelines keep it safe.
