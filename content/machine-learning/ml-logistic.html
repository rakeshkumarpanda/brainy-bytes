Lesson 1 of 12

From a score to a probability

Source: James, Witten, Hastie and Tibshirani, An Introduction to Statistical Learning chapter 4.3, Hastie, Tibshirani and Friedman, The Elements of Statistical Learning chapter 4.4, Bishop, Pattern Recognition and Machine Learning chapter 4.3, the Stanford CS229 notes, and the scikit-learn 1.8 user guide.

What it is
Logistic regression is a classification model: it predicts the probability that an example belongs to the positive class (spam, sick, will buy). It computes a linear score z = w·x + b and squashes it with the sigmoid σ(z) = 1 / (1 + e−z) into a number between 0 and 1.
Why we need it
Linear regression gives any number, even −3 or 1.7, which makes no sense as a probability. Logistic regression gives a real probability, so you can rank cases, choose your own threshold, and combine it with costs. It is fast, explainable, and the standard baseline for every yes or no problem.
How it works
The score z is the log odds: ln(p / (1 − p)) = w·x + b. Each weight says how much one unit of a feature changes the log odds. Predict class 1 when p ≥ 0.5, which is the same as z ≥ 0, so the decision boundary is the straight line (or plane) w·x + b = 0.

Real world scenario: a credit score

A bank adds points for income and years at the same job and takes points away for missed payments: that total is the score z. A table then turns the score into "chance of paying back". Logistic regression learns both the points (the weights) and the table (the sigmoid) from past customers.

Lesson 2 of 12

Training with log loss

What it is
Logistic regression is trained by minimising log loss (binary cross entropy): −[y ln p + (1 − y) ln(1 − p)], averaged over the examples. There is no closed form answer, so we use gradient descent or a faster solver.
Why we need it
Squared error with a sigmoid gives a bumpy, non convex loss and weak gradients when the model is confidently wrong. Log loss is convex, punishes confident mistakes heavily, and comes straight from maximum likelihood for yes or no data (Foundations 2.3).
How it works
The gradient is surprisingly simple: ∂L/∂w = (1/n) Σ (pi − yi) xi, the same shape as linear regression with p in place of ŷ. Repeat w ← w − η × gradient until the loss stops falling.

Logistic regression in scikit-learn

What it is
LogisticRegression in scikit-learn gives predict (the class), predict_proba (the probabilities) and coef_ (the weights). Put a StandardScaler before it so the solver converges and the weights are comparable.
Why we need it
This is the version you will use in real projects. It handles many features, regularisation and several classes, and it is fast enough for millions of rows.
How it works
Fit on the training data. Use predict_proba when you need a ranking or your own threshold, and predict for the default 0.5 threshold. After scaling, a larger |weight| means a feature with more influence on the log odds.

Common mistake
LogisticRegression adds an L2 penalty by default (C = 1.0). If you see a ConvergenceWarning, scale the features or raise max_iter. Do not just ignore it.
Lesson 4 of 12

Choosing the threshold

What it is
The model gives a probability. The threshold turns it into a decision: class 1 if p ≥ threshold. 0.5 is only the default.
Why we need it
Mistakes have different costs. Missing a cancer (a false negative) is far worse than an extra check (a false positive). A spam filter is the opposite: losing a real email is worse than letting one spam through.
How it works
Lower the threshold to catch more positives (higher recall) at the cost of more false alarms (lower precision). Raise it for the reverse. Pick the threshold on validation data using the real costs. Supervised 4.1 covers precision, recall and ROC curves in detail.

In the exam
Here 1 means malignant. Moving the threshold from 0.5 down to 0.2 cuts the missed cancers from 2 to 1, and the price is a precision drop from 1.0 to 0.852 (more healthy people sent for extra tests).
Lesson 5 of 12

More than two classes: softmax

What it is
For k classes, multinomial logistic regression (softmax regression) computes one score per class and turns the scores into probabilities with the softmax: pj = ezj / Σ ezm.
Why we need it
Many problems have more than two answers: which flower species, which digit, which product category. Softmax gives one probability per class, and they add up to 1.
How it works
Learn one weight vector per class (coef_ has shape classes × features). The class with the largest score has the largest probability. The loss is categorical cross entropy, −ln of the probability given to the true class. scikit-learn uses softmax automatically when there are more than two classes.
Download this program (.py)Save it, open it in any editor and run it with python3 softmax_iris.py.
SoftmaxExam favourite
pj = ezj / Σm ezm
Subtract the largest score first so ez never overflows. The answer does not change.
Remember
One versus rest (OvR) is the other way to do multi class: train k separate yes or no models and pick the most confident. Softmax trains them together and gives probabilities that add up to 1, so it is usually preferred.
Lesson 6 of 12

Reading the weights: odds ratios

What it is
ew is the odds ratio: how many times the odds of class 1 are multiplied when that feature goes up by 1, holding the others fixed.
Why we need it
Doctors, banks and policy makers want answers like "smokers have three times the odds of the disease". Odds ratios give exactly that from a fitted model.
How it works
Fit the model on unscaled features if you want the answer in natural units (per year, per smoker). Take e to the power of each weight. An odds ratio above 1 raises the chance, below 1 lowers it, and 1 means no effect.
Download this program (.py)Save it, open it in any editor and run it with python3 odds_ratio.py.
Common mistake
Odds are not probabilities. Tripling the odds from 0.1 to 0.3 moves the probability from 9% to 23%, not to 27%. Near 50% the effect on probability is largest.
Lesson 7 of 12

Curved boundaries and the penalty C

What it is
The decision boundary of logistic regression is a straight line (a plane in more dimensions). Adding polynomial features (x12, x22, x1x2) lets it draw curves. The parameter C controls the penalty: C is 1/α, so a small C means a strong penalty.
Why we need it
Real classes are often not split by a straight line, like an inner ring of one class inside a ring of the other. And with many features, an unpenalised model overfits or, if the classes are perfectly separable, its weights grow without limit.
How it works
Put PolynomialFeatures, StandardScaler and LogisticRegression in one pipeline. Tune C on a log scale with cross validation (LogisticRegressionCV does it for you).

In scikit-learn, C is the inverse of the penalty strength. C = 0.001 shrinks the weights a lot (underfits, 0.891), C = 1 is best here (0.981), and C = 100 hardly penalises (0.963, slightly overfit). Ridge uses α, where a bigger number means a stronger penalty, so do not mix them up.

Bottom line: logistic regression is the first classifier to try. Move to trees or boosting when the boundary is clearly not linear.

Going deeper: Generative vs discriminative

Logistic regression is discriminative: it models P(y | x) directly. Naive Bayes and LDA are generative: they model P(x | y) and P(y) and use Bayes rule. If the classes are Gaussian with a shared covariance, the posterior of LDA has exactly the logistic form, but logistic regression makes fewer assumptions. Ng and Jordan (2002) showed generative models can reach their (higher) error faster with little data, while logistic regression reaches a lower error with more data.

Worked example: one prediction and its loss
  1. w = 2, b = −5, a student studied x = 3 hours and passed (y = 1).
  2. Score z = 2 × 3 − 5 = 1.
  3. p = σ(1) = 1 / (1 + e−1) = 1 / 1.368 = 0.731.
  4. loss = −ln(0.731) = 0.313
  5. Gradient for w on this row: (p − y) x = (0.731 − 1) × 3 = −0.807, so w goes up and the next prediction is higher.
Going deeper: Why the gradient is so clean

For one example, L = −[y ln σ(z) + (1 − y) ln(1 − σ(z))]. Using σ′ = σ(1 − σ), dL/dz = −y(1 − σ) + (1 − y)σ = σ − y. Then by the chain rule dL/dw = (σ − y)x. The Hessian is XTSX with S = diag(p(1 − p)), which is positive semi definite, so the loss is convex. Newton’s method on this loss is called iteratively reweighted least squares (IRLS).

Logistic regression gives the chance that something is a yes. It adds up weighted features into a score and squashes the score into 0 to 1 with an S shaped curve.

Chapter summary

  1. Logistic regression predicts P(y = 1 | x) = σ(w·x + b). The score is the log odds.
  2. The sigmoid maps any score to 0 to 1, with σ(0) = 0.5. The boundary w·x + b = 0 is a straight line.
  3. Train by minimising log loss. It is convex, and its gradient is (1/n)Σ(p − y)x.
  4. predict_proba gives probabilities. Choose the threshold from the costs of false negatives and false positives.
  5. Softmax handles k classes: one score per class, probabilities add up to 1, loss = −ln ptrue.
  6. Odds ratio ew: how the odds multiply per unit of a feature.
  7. Polynomial features give curved boundaries. C = 1/α: small C means a strong penalty.
