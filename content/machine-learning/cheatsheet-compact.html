Step 1Foundations · Start here

1.1What machine learning is: learning from examples

  • Machine learning Learn the rule from examples instead of writing it. Mitchell: performance P on task T improves with experience E.
  • The loop Guess, measure the loss, adjust parameters against the slope (gradient descent), repeat. Learning rate sets the step size.
  • Kinds Supervised (labels: regression for numbers, classification for categories), unsupervised (no labels), reinforcement (rewards), plus semi and self supervised.
  • Words Features are inputs (X), label is the answer (y). Parameters are learned, hyperparameters are chosen.
  • Generalise Judge a model on unseen test data. High training score with low test score means overfitting.
  • scikit-learn model = Model(), model.fit(X, y), model.predict(X_new), model.score(X_test, y_test). X is 2D.
  • A modelŷ = f(x, θ)
  • Mean squared error (loss for numbers)MSE = (1/n) Σ (yi − ŷi)2
  • One gradient descent stepθnew = θ − η × (slope of the loss at θ)
  • Trap A learning rate that is too big makes the guess jump past the best value and the loss can grow. One that is too small makes learning very slow. Choosing it well is part of the job.
  • Exam A quick test: "Is there a right answer for each example in my data?" Yes means supervised. No means unsupervised. "Does the system learn by acting and getting rewards?" means reinforcement.
  • Exam Parameters are learned by the model. Hyperparameters are set by you. The learning rate is a hyperparameter, the slope of a line is a parameter. Interviewers love this question.
  • Trap Never measure a model only on its training data. The score will look great and mean nothing. Always keep a separate test set, and look at it only at the end.
  • Trap X must be two dimensional: a list of rows, even when there is only one feature. Write [[1], [2], [3]], not [1, 2, 3]. Passing a flat list is the most common first error in scikit-learn.

1.2The machine learning project: from a question to a working model

  • Frame first Goal, output type, data known at prediction time, metric, success level, baseline. Ask if ML is needed at all.
  • Project loop Frame, get data, explore and clean, split, baseline, train and tune, evaluate, deploy, monitor (CRISP-DM plus monitoring).
  • Three sets Train learns, validation chooses, test scores once. Stratify rare classes, split time by time, keep groups together. Fix random_state.
  • Baseline DummyRegressor (mean) and DummyClassifier (most frequent) set the bar every model must beat.
  • Leakage Never train on information unavailable at prediction time. Fit preprocessing on training data only.
  • Uncertainty SE of an accuracy = √(p(1 − p)/n). Range about p ± 2 SE. Four times the data halves the SE.
  • Uncertainty of a test accuracySE = √(p(1 − p) / n)
  • Rough 95% rangep ± 2 × SE
  • Mean absolute errorMAE = (1/n) Σ |yi − ŷi|
  • Trap Look at the data, but do the deep exploration on the training part only, after splitting. If you study the test set too, you start choosing features that fit it, and your final score becomes too optimistic.
  • Exam Fix random_state (the seed) so the split is the same every time you run the program. Otherwise your scores change from run to run and you cannot compare models.
  • Trap A model that cannot beat the baseline usually means a bug, leakage the other way, or features that carry no signal. Check the data before trying a bigger model.
  • Exam If a score looks too good to be true, it usually is. Hunt for leakage before you celebrate.

1.3Python tools for ML: NumPy, pandas and scikit-learn

  • NumPy Arrays of one dtype, vectorised maths, masks (a[a > 0]), shape, reshape, .T, np.random.default_rng(seed).
  • Axis axis=0 goes down rows (one value per column), axis=1 across columns (one per row). The named axis disappears.
  • Broadcasting Compare shapes from the right. Sizes must be equal or 1. (n, d) minus (d,) centres every column.
  • pandas DataFrame and Series. df["c"], masks, loc (labels, end included), iloc (positions). groupby with agg or transform, merge, isna, fillna.
  • scikit-learn fit learns (attributes end in _), transform changes, predict answers. fit_transform on train, transform on test, Pipelines.
  • Dot productw · x = w1x1 + w2x2 + ... + wdxd
  • Predictions for many rowsŷ = X w
  • Mean along an axismeanj = (1/n) Σi Xij
  • Standard deviationstd = √( (1/n) Σ (xi − mean)2 )
  • Standard scalingz = (x − mean) / std
  • Trap A NumPy array holds one type. np.array([1, 2.5]) turns everything into floats, and np.array([1, "a"]) turns everything into text. Check .dtype when results look strange.
  • Exam axis=0 "collapses" the rows. A tip to remember: the axis you name is the one that disappears from the shape. (4, 3).mean(axis=0) has shape (3,).
  • Exam loc uses labels and includes the end: df.loc[0:2] gives 3 rows. iloc uses positions and stops before the end: df.iloc[0:2] gives 2 rows.
  • Trap transform keeps one value per original row, so you can put it back into the table as a feature. agg gives one row per group. Mixing them up is a common mistake.
  • Exam Call fit_transform on the training set and only transform on the test set. Calling fit on the test set too is a form of data leakage.

Step 2Foundations · Maths you need

2.1Linear algebra for ML: vectors, distances and matrices

  • Vectors An example is a feature vector. Dot product a·b = Σ aibi = ||a|| ||b|| cos θ. 0 means orthogonal.
  • Distances Euclidean √Σ(ai−bi)2, Manhattan Σ|ai−bi|, cosine a·b/(||a|| ||b||). Scale features first.
  • Matrices Matrix times vector: one dot product per row. (n×k)(k×m) = n×m. AB ≠ BA. (AB)T = BTAT.
  • Linear model ŷ = X w + b. Each weight is the change in prediction per unit of its feature.
  • Inverse det [[a,b],[c,d]] = ad − bc. Inverse exists only if det ≠ 0. Use np.linalg.solve. Dependent columns mean multicollinearity.
  • Eigen A v = λ v. Sum of eigenvalues = trace, product = determinant. Base of PCA.
  • Euclidean distance (L2)d(a, b) = √( Σ (ai − bi)2 )
  • Length (norm) of a vector||v||2 = √(v12 + ... + vd2), ||v||1 = Σ |vi|
  • Cosine similaritycos θ = a · b / (||a|| ||b||)
  • Linear model for all examplesŷ = X w + b
  • 2 × 2 determinantdet [[a, b], [c, d]] = a d − b c
  • Projectionprojd(x) = ((x · d) / (d · d)) d
  • Eigen equationA v = λ v
  • Dot product and anglea · b = ||a|| ||b|| cos θ
  • Squared distance expanded||a − b||2 = ||a||2 + ||b||2 − 2 a · b
  • Trap The order of components matters. [age, height] and [height, age] are different vectors. Every example must use the same feature order.
  • Exam Distances only make sense when features are on similar scales. Height in centimetres (around 170) would swamp age in years (around 25). Scale features first (Foundations 3.2).
  • Exam Matrix multiplication is not commutative: A B is usually not B A, and B A may not even exist when the shapes do not match.
  • Trap Perfectly correlated features (one column is a multiple of another) make XTX impossible to invert. This is called multicollinearity. Drop one of the features or use ridge regression.

2.2Calculus for ML: derivatives, gradients and gradient descent

  • Derivative Slope at a point, the limit of (f(x+h) − f(x))/h. Power rule n xn−1. ex to ex, ln x to 1/x, σ′ = σ(1 − σ).
  • Chain rule d/dx f(g(x)) = f′(g(x)) g′(x). Slopes along a chain multiply. Base of backpropagation.
  • Gradient Vector of partial derivatives, points uphill. Update w ← w − η∇L.
  • Learning rate Too small is slow, too big diverges. On a x2, need η < 1/a. Feature scaling helps.
  • Variants Batch (all rows), SGD (1 row), mini-batch (32 to 512). Epoch = one pass. Steps per epoch = n / batch size.
  • Convexity Convex losses (linear and logistic regression) have one minimum. Networks have local minima and saddles.
  • Gradient∇f(w) = [∂f/∂w1, ∂f/∂w2, ..., ∂f/∂wd]
  • Gradient descent updatew ← w − η ∇L(w)
  • MSE gradient for a line∂L/∂w = (2/n) Σ (ŷi − yi) xi, ∂L/∂b = (2/n) Σ (ŷi − yi)
  • Convex test (one variable)f′′(x) ≥ 0 everywhere
  • Derivativef′(x) = limh→0 (f(x + h) − f(x)) / h
  • Chain ruled/dx f(g(x)) = f′(g(x)) g′(x)
  • Gradient descentwt+1 = wt − η ∇L(wt)
  • Exam An epoch is one full pass over the training data. With 1,000 rows and a batch size of 100, one epoch has 10 update steps.
  • Trap Gradient descent finds a point where the gradient is near 0. For a convex loss this is the best answer. For a non convex loss it may be a local minimum or a saddle point.

2.3Probability and statistics for ML

  • Rules Complement 1 − P(A). Or: P(A) + P(B) − P(A and B). And: P(A) P(B | A). Conditional P(A | B) = P(A and B) / P(B).
  • Bayes rule P(A | B) = P(B | A) P(A) / P(B), with P(B) from total probability. Rare events: false alarms dominate.
  • Distributions Bernoulli p, binomial np and np(1 − p), Poisson λ and λ, normal μ and σ2. 68, 95, 99.7 rule.
  • Describe Mean, median, Var = E[X2] − E[X]2, sample std uses n − 1. Correlation in [−1, 1], not causation.
  • CLT Averages become normal. Standard error σ / √n. 95% interval: estimate ± 1.96 SE.
  • Likelihood and losses MLE maximises Σ log P(x | θ). Normal noise gives MSE, Bernoulli gives log loss. Gaussian prior gives L2. Cross entropy −Σ p log q.
  • Bayes ruleP(A | B) = P(B | A) × P(A) / P(B)
  • Total probabilityP(B) = P(B | A) P(A) + P(B | not A) P(not A)
  • BinomialP(X = k) = C(n, k) pk (1 − p)n−k
  • Normal densityf(x) = (1 / (σ√(2π))) e−(x − μ)2 / (2σ2)
  • Mean (expected value)E[X] = Σ x P(x), sample mean x̄ = (1/n) Σ xi
  • VarianceVar(X) = E[(X − μ)2] = E[X2] − (E[X])2
  • Correlationr = Cov(X, Y) / (σX σY)
  • Standard error of the meanSE = σ / √n
  • LikelihoodL(θ) = Πi P(xi | θ)
  • Log likelihoodlog L(θ) = Σi log P(xi | θ)
  • Coin MLEp̂ = heads / n
  • EntropyH(p) = −Σ pi log2 pi
  • Cross entropyH(p, q) = −Σ pi log qi
  • KL divergenceKL(p || q) = Σ pi log(pi / qi) = H(p, q) − H(p)
  • z scorez = (measured − expected under null) / standard error
  • 95% confidence intervalestimate ± 1.96 × standard error
  • Conditional probabilityP(A | B) = P(A and B) / P(B)
  • Bayes ruleP(A | B) = P(B | A) P(A) / P(B)
  • Expectation and varianceE[X] = Σ x P(x), Var(X) = E[X2] − E[X]2
  • Standard errorSE = σ / √n
  • Log likelihoodlog L(θ) = Σ log P(xi | θ)
  • Cross entropyH(p, q) = −Σ p log q
  • Exam Ignoring the prior is called the base rate fallacy. It is a common exam trap and a real problem in fraud and disease detection, where the event you look for is rare.
  • Trap The sample standard deviation divides by n − 1 instead of n (ddof=1 in numpy, the default in pandas). This small change corrects for the fact that the sample mean is closer to the data than the true mean is. The program shows 12.9 with n and 13.79 with n − 1.
  • Exam Correlation is not causation. Ice cream sales and drownings both rise in summer, but one does not cause the other. Correlation also only measures straight line relations: y = x2 on symmetric x has correlation 0.
  • Exam The program shows KL(p || q) = 0.5108 but KL(q || p) = 0.3681. KL divergence is not a true distance because swapping the two distributions changes the answer.
  • Trap A p value is not the chance that the null hypothesis is true. If you test 20 useless features at the 0.05 level, about one will look significant by luck. Correct for many tests (for example the Bonferroni correction divides α by the number of tests).

Step 3Foundations · Working with data

3.1Data cleaning: missing values, types, outliers and joins

  • Inspect shape, dtypes, isna().sum(), duplicated().sum(), unique(), describe(). Write down problems before fixing.
  • Missing values dropna or fillna. Median for numbers, mode for categories, plus a missing flag. Fit the imputer on training data only.
  • MCAR, MAR, MNAR Pure chance, depends on other columns, depends on the missing value. Dropping is only unbiased under MCAR.
  • Types and text str.strip, str.lower, replace, to_numeric and to_datetime with errors="coerce", astype, drop_duplicates.
  • Outliers IQR fences Q1 − 1.5 IQR and Q3 + 1.5 IQR (robust). |z| > 3 can be masked. Fix, remove, clip or keep.
  • Combine merge on a key: inner, left, right, outer. Check row counts. melt makes long data, pivot makes wide data.
  • IQR fenceslow = Q1 − 1.5 × IQR, high = Q3 + 1.5 × IQR, IQR = Q3 − Q1
  • z scorez = (x − mean) / std
  • Quantile position (pandas linear method)position = (n − 1) × q, then interpolate between the two nearest sorted values
  • IQR fencesQ1 − 1.5 IQR and Q3 + 1.5 IQR
  • Mean after mean fillingmean stays the same, variance shrinks by the factor (nknown − 1)/(n − 1) or so
  • Trap Fitting the imputer on the whole dataset before splitting lets test rows influence the fill value. That is data leakage (Foundations 1.2). Put the imputer inside a Pipeline so it is fitted on the training part only.
  • Exam The z score rule missed the 150 in the program: z = 2.97, just under 3. The outlier itself raised the mean and the standard deviation, which hid it. This is called masking. The IQR rule uses quartiles, which one extreme value cannot move, so it is more robust.

3.2Features: encoding, scaling, engineering and selection

  • Encoding One hot for unordered (handle_unknown="ignore"), ordinal for a real order, target encoding with cross fitting for many categories.
  • Scaling Standard (x − μ)/σ, min max to 0 to 1, robust (x − median)/IQR, log1p for skew. Trees need none.
  • No leakage Fit scalers, encoders, imputers and selectors on training data only, inside a Pipeline and ColumnTransformer.
  • New features Date parts, ratios, bins (pd.cut), logs, group aggregates, sin and cos for cycles, polynomial and interaction terms.
  • Text CountVectorizer counts words. TF-IDF = tf × idf, idf high for rare words.
  • Selection Filter (F test, mutual information), wrapper (RFE), embedded (L1, tree importance). Choose k with cross validation.
  • TF-IDF (scikit-learn smooth version)tfidf(t, d) = tf(t, d) × (ln((1 + N) / (1 + df(t))) + 1), then each row is scaled to length 1
  • Standardisationz = (x − μ) / σ
  • Min maxx′ = (x − min) / (max − min)
  • Robustx′ = (x − median) / IQR
  • Number of polynomial columnsC(d + p, p) − 1
  • Exam Trees split on one feature at a time with thresholds like "income > 52". Multiplying a feature by 1,000 moves the threshold but not the split, so tree models do not need scaling.
  • Trap Only build features from information you would have at prediction time. "Number of support calls in the month after cancelling" predicts cancelling perfectly, and is useless (and leaky) for a real prediction.
  • Trap The number of columns grows fast. With d features and degree p there are C(d + p, p) − 1 columns: 10 features at degree 3 gives 285 columns. Use regularisation (Supervised 1.2) to stop the extra columns from overfitting.
  • Trap Selecting features on the whole dataset and then cross validating is leakage: the test folds helped choose the features, so the score is too optimistic. Put the selector inside the Pipeline, as the k loop in the program does.
  • Exam Target encoding replaces a category by the average target for that category. Using a row’s own target to encode it leaks the answer. scikit-learn’s TargetEncoder avoids this with cross fitting: each row is encoded with means from the other folds, and rare categories are pulled towards the overall mean. That is why its numbers in the program differ a little from the plain shop means.

Step 1Supervised Learning · Regression

1.1Linear regression: fit the best straight line

  • Model and loss ŷ = b0 + Σbjxj. Minimise Σ(y − ŷ)2. Slope = cov(x, y)/var(x), line through (x̄, ȳ).
  • Solving Normal equation w = (XTX)−1XTy (use solve), or gradient descent with scaled features.
  • Metrics MAE, MSE, RMSE, R² = 1 − SSE/SST, adjusted R². Always on test data.
  • Assumptions Linear, independent errors, equal spread, normal errors for p values. Check residuals for curves and funnels.
  • Outliers Squared loss is pulled by outliers. Huber or absolute loss is robust. Median minimises absolute error.
  • Inference statsmodels OLS gives standard errors, p values and confidence intervals. Correlated features make weights unstable.
  • Simple linear regressionb1 = Σ(xi − x̄)(yi − ȳ) / Σ(xi − x̄)2, b0 = ȳ − b1x̄
  • Least squares lossL(b) = Σ (yi − ŷi)2
  • Normal equationw = (XTX)−1XTy
  • Huber lossLδ(e) = e2/2 if |e| ≤ δ, otherwise δ|e| − δ2/2
  • Adjusted R²R²adj = 1 − (1 − R²)(n − 1)/(n − d − 1)
  • Modelŷ = Xw (X has a first column of 1s)
  • LossL(w) = ||y − Xw||2
  • Gradient∇L = −2XT(y − Xw)
  • R²R² = 1 − SSE/SST, SST = Σ(y − ȳ)2
  • Exam A feature can be statistically significant and still useless for prediction, or very useful for prediction while its p value is unclear because it is correlated with another feature. Prediction (machine learning) and inference (statistics) answer different questions.

1.2Polynomial regression and regularisation: ridge, lasso, elastic net

  • Fit diagnosis Underfit: both errors high (bias). Overfit: train low, test high (variance). Choose complexity on validation data.
  • Ridge Penalty αΣw2. w = (XTX + αI)−1XTy. Shrinks, never zeros. Fixes multicollinearity.
  • Lasso Penalty αΣ|w|. Soft threshold sets weak weights to 0, so it selects features. Coordinate descent.
  • Elastic net Mix with l1_ratio. Keeps correlated groups together. Safe default.
  • Practice Scale first (Pipeline). Tune α with RidgeCV, LassoCV, ElasticNetCV on a log grid. Extend the grid if the best is at the edge.
  • Theory L1 diamond vs L2 ball. Ridge = Gaussian prior, lasso = Laplace prior. Ridge shrinks along SVD directions by d2/(d2 + α).
  • Soft threshold (one lasso update)wj = sign(ρ) max(|ρ| − α, 0) / zj
  • Ridgemin ||y − Xw||2 + α||w||22, w = (XTX + αI)−1XTy
  • Lassomin (1/2n)||y − Xw||2 + α||w||1
  • Elastic netmin (1/2n)||y − Xw||2 + αr||w||1 + (α(1 − r)/2)||w||22
  • Exam In the program the true model uses 3 of 10 features. At α = 0.5, lasso keeps exactly those 3 and sets the other 7 to 0. Ridge with α = 10 keeps all 10 with small weights.

Step 2Supervised Learning · Classification

2.1Logistic regression: probabilities for classification

  • Model P(y = 1 | x) = σ(w·x + b), σ(z) = 1/(1 + e−z). Score = log odds. Boundary w·x + b = 0.
  • Training Minimise log loss (convex). Gradient (1/n)Σ(p − y)x. No closed form, use lbfgs or gradient descent.
  • Threshold Default 0.5. Lower it for higher recall, raise it for higher precision. Choose from costs on validation data.
  • Multi class Softmax pj = ezj/Σez, loss −ln ptrue. Or one versus rest.
  • Interpretation Odds ratio ew per unit. Scale features for comparable weights.
  • Penalty C = 1/α, small C = strong L2 penalty. Needed for separable data. Polynomial features give curved boundaries.
  • Sigmoidσ(z) = 1 / (1 + e−z)
  • Logistic modelP(y = 1 | x) = σ(w·x + b)
  • Log odds (logit)ln(p / (1 − p)) = w·x + b
  • Log lossL = −(1/n) Σ [yi ln pi + (1 − yi) ln(1 − pi)]
  • Gradient∂L/∂w = (1/n) Σ (pi − yi) xi
  • Softmaxpj = ezj / Σm ezm
  • Modelp = σ(w·x + b), σ(z) = 1 / (1 + e−z)
  • Sigmoid derivativeσ′(z) = σ(z)(1 − σ(z))
  • Log loss and gradientL = −(1/n)Σ[y ln p + (1 − y) ln(1 − p)], ∇wL = (1/n) XT(p − y)
  • Softmax and its losspj = ezj / Σezm, L = −ln ptrue
  • Trap LogisticRegression adds an L2 penalty by default (C = 1.0). If you see a ConvergenceWarning, scale the features or raise max_iter. Do not just ignore it.
  • Exam Here 1 means malignant. Moving the threshold from 0.5 down to 0.2 cuts the missed cancers from 2 to 1, and the price is a precision drop from 1.0 to 0.852 (more healthy people sent for extra tests).
  • Trap Odds are not probabilities. Tripling the odds from 0.1 to 0.3 moves the probability from 9% to 23%, not to 27%. Near 50% the effect on probability is largest.
  • Exam In scikit-learn, C is the inverse of the penalty strength. C = 0.001 shrinks the weights a lot (underfits, 0.891), C = 1 is best here (0.981), and C = 100 hardly penalises (0.963, slightly overfit). Ridge uses α, where a bigger number means a stronger penalty, so do not mix them up.

2.2k nearest neighbours: learn from similar examples

  • Algorithm Store data. For a query: distances to all, sort, k nearest, majority vote (or average for numbers). No training, slow prediction O(nd).
  • Choosing k Small k overfits, large k underfits. k = 1 gives 100% training accuracy. Cross validate, odd k for two classes.
  • Distance Euclidean, Manhattan, Minkowski p, cosine for text. Scale features first, always.
  • Variants weights="distance" (1/d). KNeighborsRegressor. NearestNeighbors for similarity search.
  • High dimensions Distances concentrate, nearest is barely nearer than farthest. Select features or use PCA first.
  • Speed and theory k-d tree and ball tree for low d, approximate search (HNSW) for embeddings. 1-NN error at most twice Bayes error.
  • Minkowski distanced(a, b) = (Σ |ai − bi|p)1/p
  • Cosine similaritycos(a, b) = a·b / (||a|| ||b||)
  • Weighted KNN predictionŷ = Σ (1/di) yi / Σ (1/di) over the k nearest
  • KNN classificationŷ = most common class among the k nearest Nk(x)
  • KNN regressionŷ = (1/k) Σi ∈ Nk(x) yi
  • Euclidean distanced = √Σ(ai − bi)2
  • Cost of brute force predictionO(n × d) per query
  • Exam In the program, k = 1 scores 1.0 on training data but only 0.86 in cross validation. The best is around k = 7 (0.913), and k = 101 underfits (0.82). Training accuracy is useless for choosing k.
  • Trap Foundations 3.2 showed scaling raise KNN accuracy on the wine data from 0.691 to 0.949. Scaling is not optional for KNN.

2.3Naive Bayes: classify by counting clues

  • Rule P(c | x) ∝ P(c)ΠP(xj | c). Features independent given the class. Pick argmax of log P(c) + Σlog P(xj | c).
  • Smoothing P(w | c) = (nw,c + α)/(nc + αV). Prevents zeros. Use logs to avoid underflow.
  • Variants MultinomialNB counts (text), BernoulliNB 0 or 1 (absence counts), GaussianNB numbers (mean, variance), ComplementNB imbalanced text.
  • Strengths One pass of counting, little data, many features, no scaling. Great text baseline.
  • Weaknesses Overconfident probabilities, no feature interactions, correlated features double counted. Calibrate if probabilities matter.
  • Theory Generative. Linear boundary for text. Ng and Jordan: faster to its (higher) best error than logistic regression.
  • Naive Bayes ruleP(c | x1, ..., xd) ∝ P(c) Πj P(xj | c)
  • Predictionŷ = argmaxc [log P(c) + Σj log P(xj | c)]
  • Laplace (add alpha) smoothingP(w | c) = (nw,c + α) / (nc + αV)
  • Gaussian likelihoodp(xj | c) = (1 / √(2πσjc2)) exp(−(xj − μjc)2 / (2σjc2))
  • Bayes ruleP(c | x) = P(x | c) P(c) / P(x)
  • Naive assumptionP(x1, ..., xd | c) = Πj P(xj | c)
  • Multinomial likelihoodP(w | c) = (nw,c + α) / (nc + αV)
  • Log scorescore(c) = log P(c) + Σ log P(xj | c)
  • Exam BernoulliNB also uses the words that are missing: a message without "meeting" is a little more likely to be spam. MultinomialNB ignores missing words entirely.

2.4Support vector machines: the widest street

  • Margin Boundary w·x + b = 0, edges ±1, width 2/|w|. Hard margin: min ½|w|2 with y(w·x + b) ≥ 1.
  • Soft margin min ½|w|2 + CΣmax(0, 1 − y f(x)). Small C: wide street, strong regularisation.
  • Support vectors Points on or inside the margin (α > 0). Others can move without changing the model.
  • Kernels Linear x·z, poly (γx·z + r)d, RBF exp(−γ|x − z|2). Kernel trick: dot products only.
  • Practice Scale first. Grid search C and γ on a log scale. Big γ overfits. SVC up to about 104 to 105 rows, else LinearSVC or SGD.
  • Extras SVR uses an ε tube. No built in probabilities (Platt scaling). Dual solved by SMO in libsvm.
  • Decision ruleŷ = sign(w·x + b)
  • Margin widthwidth = 2 / |w|
  • Soft margin objectiveminw,b ½|w|2 + C Σi max(0, 1 − yi(w·xi + b))
  • Epsilon insensitive lossL = max(0, |y − f(x)| − ε)
  • Hard margin primalmin ½|w|2 subject to yi(w·xi + b) ≥ 1
  • Soft margin primalmin ½|w|2 + CΣξi, yi(w·xi + b) ≥ 1 − ξi, ξi ≥ 0
  • Kernel predictionf(x) = Σi∈SV αiyiK(xi, x) + b
  • RBF kernelK(x, z) = exp(−γ|x − z|2)
  • Exam As C grows the street shrinks from 8.73 to 3.43 and the number of support vectors drops from 162 to 83, because fewer points are allowed inside the street. Step 3Supervised Learning · Trees and ensembles

3.1Decision trees: a chain of yes or no questions

  • Model A chain of yes or no questions. Leaf = majority class (classification) or mean (regression). No scaling needed.
  • Impurity Gini 1 − Σp2, entropy −Σp log2p. Split minimises (nL/n)I(L) + (nR/n)I(R). IG = drop in entropy.
  • Overfitting Full trees memorise. Use max_depth, min_samples_leaf, max_leaf_nodes, or ccp_alpha from cost_complexity_pruning_path with CV.
  • Regression Step function, minimises squared error, cannot extrapolate.
  • Importance feature_importances_ (impurity, biased to many valued features). permutation_importance on test data is safer.
  • Weakness High variance, axis parallel cuts, greedy. Fixed by ensembles: forests (3.2) and boosting (3.3).
  • Gini impurityG = 1 − Σk pk2
  • EntropyH = −Σk pk log2 pk
  • Information gainIG = H(parent) − Σchild (nchild/n) H(child)
  • Cost complexityRα(T) = R(T) + α |T|
  • Leaf prediction (regression)ŷleaf = mean of yi in the leaf
  • Weighted impurity of a splitIsplit = (nL/n) I(L) + (nR/n) I(R)
  • Cost complexityRα(T) = R(T) + α|T|
  • Exam The weather example is the classic one from Quinlan: splitting 14 days by outlook gives an information gain of 0.247 bits, because overcast days are all "play". In practice Gini and entropy choose the same split most of the time, and Gini is a little faster since it needs no logarithm.
  • Exam With depth 1 the tree knows only two numbers (0.59 and −0.7), so 0.5, 1.5 and 3.0 all get the same prediction. Depth 5 has 23 steps and follows the sine curve closely, including some of its noise. A tree can never predict outside the range of the training targets, so it cannot extrapolate a trend.
  • Exam Five bootstrap samples of the same data give three different root features and between 12 and 19 leaves. Each tree is a reasonable model, but they disagree. That disagreement is variance, and averaging removes it.

3.2Random forests: many trees vote

  • Idea Average many trees: vote or mean probability for classes, mean for numbers. Reduces variance, keeps low bias.
  • Bagging Bootstrap sample of n rows with replacement. About 63.2% distinct rows, 36.8% out of bag (OOB score).
  • Randomness max_features at each split: sqrt(p) for classification, all for regression. Decorrelates trees.
  • Variance ρσ2 + (1 − ρ)σ2/B. Lower ρ beats more B.
  • Settings n_estimators 200 to 500 (more never overfits), max_features, min_samples_leaf, oob_score=True, n_jobs=-1.
  • Variants BaggingClassifier for any model, ExtraTrees (random cuts, no bootstrap). Compare with a linear baseline.
  • Chance a row is left outP(out of bag) = (1 − 1/n)n → 1/e ≈ 0.368
  • Variance of an averageVar = ρσ2 + (1 − ρ)σ2 / B
  • Bagged prediction (regression)f̂(x) = (1/B) Σb f̂b(x)
  • Bagged prediction (classification)ŷ = majority vote of ŷb, or argmax of the mean class probabilities
  • Out of bag share(1 − 1/n)n → e−1 ≈ 0.368
  • Variance of the forestρσ2 + (1 − ρ)σ2/B
  • Exam This formula is the heart of random forests and appears in The Elements of Statistical Learning, equation 15.1. Lower correlation between trees matters more than more trees.
  • Exam With one random feature per split the trees agree least (0.864) but each is weak. With all features (None) the forest is just bagging: the trees agree more (0.919) and test accuracy drops to 0.924. sqrt, here 5 of 30 features, balances the two and scores best (0.953).

3.3Boosting: small trees that fix each other

  • Idea Add shallow trees in sequence. Each fits the current mistakes. F = F0 + ηΣhm. Reduces bias.
  • AdaBoost α = ½ln((1 − ε)/ε). Wrong points × eα, right × e−α. Exponential loss, noise sensitive.
  • Gradient Fit trees to −∂L/∂F: y − F (squared), y − p (log loss), sign(y − F) (absolute).
  • Tuning Small learning rate (0.05 to 0.1), many trees with early stopping, depth 3 to 6, subsample 0.8, L2 penalty.
  • Libraries XGBoost (2nd order, w* = −G/(H + λ)), LightGBM (histograms, leaf wise), CatBoost (categories), sklearn HistGB.
  • Versus Forest: parallel deep trees, variance, never overfits with more trees. Boosting: sequential shallow trees, bias, overfits.
  • Say of a weak learnerαm = ½ ln((1 − εm)/εm)
  • Weight updatewi ← wi e−αm yi hm(xi), then normalise
  • Gradient boosting updateFm(x) = Fm−1(x) + η hm(x), hm fitted to −∂L/∂Fm−1
  • Additive modelFM(x) = F0 + η Σm=1M hm(x)
  • Pseudo residualsrim = −∂L(yi, F)/∂F at F = Fm−1(xi)
  • AdaBoost sayα = ½ ln((1 − ε)/ε)
  • XGBoost leaf weightw* = −G / (H + λ)
  • Exam The labels + + − − + + − − cannot be split by any single cut. After round 1 the two points it got wrong (x = 5 and 6) carry 0.25 each instead of 0.125, so round 2 picks a stump that gets them right. Three stumps together classify all 8 points. AdaBoost is gradient boosting with the exponential loss e−yF(x).
  • Exam With learning rate 1.0 the best test error comes after just 1 tree and then gets much worse (6,489 after 500 trees). With 0.1 the best is after 15 trees. With 0.01 it is after 180 trees, the lowest error of the three (3,180), and still close to it after 500. Smaller steps are slower but safer.
  • Exam On this dataset scaled logistic regression is best (0.981) and AdaBoost close behind (0.977). The breast cancer features are mostly linearly related to the label, so a linear model is hard to beat. Boosting shines on larger tables with nonlinear effects and interactions. Always include a simple baseline.

4.1Metrics: measuring a model properly

  • Confusion TP, FP (false alarm), FN (miss), TN. sklearn rows = true, columns = predicted.
  • Rates Precision TP/(TP+FP), recall TP/(TP+FN), specificity TN/(TN+FP), F1 = 2PR/(P+R), Fβ.
  • Imbalance Accuracy misleads. Use recall, precision, balanced accuracy, PR AUC. Compare with DummyClassifier.
  • Threshold Choose from costs with predict_proba. Lower threshold = more recall, less precision.
  • Curves ROC: TPR vs FPR, AUC = ranking probability. PR curve for rare positives (baseline = positive share).
  • Regression and probabilities MAE robust, RMSE punishes big errors, R² vs mean. Log loss and Brier for probabilities.
  • Precisionprecision = TP / (TP + FP)
  • Recall (sensitivity, TPR)recall = TP / (TP + FN)
  • F1 scoreF1 = 2PR / (P + R)
  • F beta scoreFβ = (1 + β2) PR / (β2P + R)
  • False positive rateFPR = FP / (FP + TN) = 1 − specificity
  • MAEMAE = (1/n) Σ|yi − ŷi|
  • RMSERMSE = √((1/n) Σ(yi − ŷi)2)
  • R²R² = 1 − SSE / SST
  • Log lossL = −(1/n) Σ[y ln p + (1 − y) ln(1 − p)]
  • Accuracy(TP + TN) / (TP + FP + FN + TN)
  • Precision, recallP = TP/(TP + FP), R = TP/(TP + FN)
  • Fβ(1 + β2)PR / (β2P + R)

  • Exam Predicting "never fraud" scores 99.1% accuracy and catches none of the 89 frauds: recall 0 and balanced accuracy 0.5, the same as guessing. Always look at the class you care about.
  • Exam AUC equals the share of (positive, negative) pairs where the positive gets the higher score. Here 12 of 16 pairs are ordered correctly, so AUC = 0.75, exactly what scikit-learn reports. This ranking view is the Mann and Whitney U statistic.
  • Exam Four predictions are off by 10 and one by 100. MAE is 28, but RMSE is 45.6, pulled up by the single big miss because it is squared. If that miss matters, RMSE tells you. If it is a rare outlier you can live with, MAE is fairer.

4.2Validation: honest estimates of performance

  • Splits Train fits, validation chooses, test reports once. Stratify classes. Retrain on train + validation at the end.
  • Cross validation k folds, each validates once. cross_val_score(model, X, y, cv=5). Report mean ± std. Shuffle sorted rows.
  • Splitters StratifiedKFold (classes), GroupKFold (groups=), TimeSeriesSplit (time), LeaveOneOut (tiny data).
  • Leakage Preprocessing on all data, target leaks, group and time leaks, duplicates. Fix: Pipeline, right splitter, drop future features.
  • Learning curves High bias: curves meet low, get a better model. High variance: gap closing, get more data or regularise.
  • Selection bias Best of many CV scores is optimistic. Use a locked test set or nested CV.
  • Cross validation estimateCV = (1/k) Σi=1k score(model trained without fold i, fold i)
  • K fold estimateCVk = (1/k) Σi Ei
  • Standard error of the meanSE = s / √k
  • Fold sizen / k rows validate, n(k − 1)/k train
  • Fits for a grid searchk × (number of settings) + 1 refit

  • Exam Each patient’s label is random, so there is nothing real to learn. With plain KFold the forest scores 0.88 because it recognises the patients from their other rows. GroupKFold reveals the truth: 0.535, close to guessing. This mistake appears in published medical studies.
  • Exam The data is pure noise with random labels, so the honest answer is about 0.5. Choosing the 20 best of 5,000 features on all rows, and only then cross validating, reports 0.85. Doing the same selection inside a pipeline gives 0.48. This exact error is the "wrong way" to do cross validation in The Elements of Statistical Learning, section 7.10.2.

Step 1Unsupervised Learning · Clustering

1.1k-means: grouping points around centres

  • Algorithm Choose k centres. Repeat: assign each point to the nearest centre, move each centre to its points’ mean. Minimises inertia Σ|x − μ|2.
  • Local minima Always converges, not always to the best. k-means++ starts (P ∝ D2) and n_init > 1.
  • Choosing k Elbow of inertia vs k, silhouette (b − a)/max(a, b) in [−1, 1], plus the purpose of the clusters.
  • Practice Scale features. KMeans(n_clusters, n_init, random_state). predict for new points. MiniBatchKMeans for big data.
  • Limits Round, similar sized clusters. Straight boundaries. Outliers pull centres. Switch to DBSCAN, hierarchical or GMM.
  • Theory Coordinate descent, NP hard globally, hard assignment limit of EM for spherical Gaussians.
  • k-means objective (inertia)J = Σi |xi − μc(i)|2
  • Update stepμk = (1/|Ck|) Σi∈Ck xi
  • Silhouette of a points = (b − a) / max(a, b)
  • ObjectiveJ(c, μ) = Σi |xi − μc(i)|2
  • Assign stepc(i) = argmink |xi − μk|2
  • Update stepμk = mean of the points with c(i) = k
  • k-means++ seedingP(choose x) = D(x)2 / Σ D(x′)2
  • Exam The start is deliberately bad: all three centres begin in the bottom left group. k-means still converges in three rounds, but to a poor answer with inertia 40.5, because the two groups on the right share one centre. It found a local minimum, not the best clustering. Good starting centres matter.
  • Exam The data was made with 4 groups, but two of them are close together. The elbow is around k = 3 or 4 and the silhouette prefers k = 3 (0.696 against 0.634). Neither is wrong: at a coarse level there are 3 groups. The final choice depends on what the clusters are for.
  • Exam On the two moons k-means cuts straight across both shapes (ARI 0.24). On a tight blob next to a wide one, it moves the boundary into the wide blob and steals its edge points (ARI 0.61), because it always splits halfway between centres.

1.2Hierarchical clustering and DBSCAN

  • Agglomerative Start with n clusters, merge the closest two n − 1 times. Dendrogram of merge heights, cut at the biggest jump or at the k you need.
  • Linkages Single min (chains), complete max (compact), average mean, Ward rise in squared error (round, default, Euclidean only).
  • DBSCAN Core: at least minPts within eps (self included). Clusters grow through core points. Border joins, rest is noise −1. No k, any shape.
  • Settings minPts about 2 × features. eps at the knee of the sorted k distance plot. Scale first.
  • HDBSCAN and OPTICS Handle different densities. HDBSCAN needs only min_cluster_size. OPTICS reachability plot valleys.
  • Costs and theory Agglomerative n2 memory. Single linkage = MST. DBSCAN about n log n with an index, n2 worst case.
  • Ward merge costΔ(A, B) = (|A||B| / (|A| + |B|)) |μA − μB|2
  • Single linkaged(A, B) = mina∈A, b∈B d(a, b)
  • Complete linkaged(A, B) = maxa∈A, b∈B d(a, b)
  • Ward merge costΔ(A, B) = |A||B| / (|A| + |B|) · |μA − μB|2

  • Core point|Nε(p)| ≥ minPts

1.3Gaussian mixture models and EM

  • Model p(x) = Σ πk N(x | μk, Σk). Weights add to 1. Each component has its own mean and covariance.
  • EM E step: rik by Bayes rule. M step: Nk = Σ r, π = Nk/n, weighted means and covariances. Likelihood never falls, local maxima.
  • Practice GaussianMixture(n_components, covariance_type, n_init). predict_proba for soft labels. Scale features.
  • Choosing BIC = p ln n − 2 ln L (lower is better) for K and covariance_type. AIC penalises less.
  • Uses Soft clustering, density estimation, anomaly scores with score_samples, sampling, BayesianGaussianMixture for automatic K.
  • Theory ELBO and Jensen, k-means as the hard spherical limit, collapse to a point prevented by reg_covar, label switching.
  • Mixture densityp(x) = Σk πk N(x | μk, σk2)
  • Responsibility (E step)rik = πk N(xi | μk, σk2) / Σj πj N(xi | μj, σj2)
  • Log likelihoodln L = Σi ln Σk πk N(xi | μk, Σk)
  • E steprik = πk N(xi | μk, Σk) / Σj πj N(xi | μj, Σj)
  • M step: weights and meansNk = Σi rik, πk = Nk / n, μk = (1/Nk) Σi rik xi
  • M step: covariancesΣk = (1/Nk) Σi rik (xi − μk)(xi − μk)T
  • BIC and AICBIC = p ln n − 2 ln L, AIC = 2p − 2 ln L

  • Exam The two clusters are long and flat, one above the other. k-means splits them left and right (ARI about 0), because that gives the smaller squared distances. 2.1Principal component analysis (PCA)

  • Idea Orthogonal directions of decreasing variance. Eigenvectors of the covariance matrix, eigenvalues are their variances.
  • Steps Centre (and scale if units differ), covariance or SVD, sort by eigenvalue, keep top k, project Z = Xc Vk.
  • Choosing k explained_variance_ratio_, scree elbow, PCA(0.95), or cross validation of the next model.
  • Facts λ = s2/(n − 1). Reconstruction error = sum of dropped eigenvalues. Max variance = min squared distance.
  • Pitfalls Unscaled mixed units, fitting before the split, ignoring labels, sign flips, only straight directions.
  • Variants Kernel PCA for curves, randomized and IncrementalPCA for big data, TruncatedSVD for sparse text.
  • Covariance matrixC = XcT Xc / (n − 1)
  • Eigen equationC v = λ v
  • ProjectionZ = Xc Vk
  • First componentv1 = argmax|v| = 1 vT C v
  • SolutionC v1 = λ1 v1, variance = λ1
  • Explained variance ratioλj / Σi λi
  • SVD routeXc = U S VT, λj = sj2 / (n − 1)
  • Reconstruction error(1/(n − 1)) |Xc − Xc Vk VkT|2 = Σj > k λj
  • Exam Hours and scores rise together, so almost all the variation lies along one line. The first component keeps 99.97% of the variance, so each student can be described by one number instead of two with almost no loss. The direction (0.16, 0.99) is mostly along the score axis, because scores vary in tens of points and hours only in single hours. The scaling lesson comes back to this.
  • Exam Each digit image has 64 pixel values. The first 2 components keep only 28.5% of the variance, which is enough for a rough picture but not for detail. 21 components keep 90% and 29 keep 95%, so more than half of the 64 numbers are close to redundant.
  • Exam In the wine data, proline goes up to 1680 while hue stays below 1.71. Unscaled, the first component explains 99.8% of the variance, but almost all of that is proline, which tells you nothing new. After scaling, the first component explains 36.2% and is led by flavanoids and total phenols, a real combination of related features.
  • Exam Two circles, one inside the other, cannot be separated by any straight direction, so one PCA component gives 45% accuracy, no better than guessing. Kernel PCA with gamma 2 turns them into one number that separates them perfectly. With gamma 15 the kernel is too narrow and accuracy drops to 71%, so gamma needs tuning.
  • Exam A linear autoencoder with a squared error loss and k hidden units learns the same subspace as PCA with k components, though not necessarily the same axes. So PCA is the simplest autoencoder.

2.2Manifold learning: t-SNE, UMAP, MDS and Isomap

  • Manifolds Low dimensional surface in high dimensions. PCA flattens, manifold methods unroll. Isomap: k neighbour graph, shortest paths, classical MDS.
  • MDS Map from a distance table. Classical MDS: B = −½ J D(2) J, top eigenvectors. Metric MDS minimises stress.
  • t-SNE Gaussian pj|i with perplexity 2H, Student t qij, minimise KL(P | Q), early exaggeration, init="pca".
  • Reading maps Trust neighbours. Not sizes, not gaps. Try several perplexities and seeds. No transform. Not for model input.
  • UMAP Fuzzy neighbour graph, cross entropy, n_neighbors and min_dist, fast, transforms new points, umap-learn package.
  • Costs Exact t-SNE O(n2), Barnes-Hut O(n log n). Floyd and Warshall O(n3). PCA to 50 first speeds things up.
  • Stressstress = Σi < j (dij − |zi − zj|)2
  • High dimensional affinitypj|i = exp(−|xi − xj|2 / 2σi2) / Σk≠i exp(−|xi − xk|2 / 2σi2)
  • Map affinity (Student t)qij = (1 + |yi − yj|2)−1 / Σk≠l (1 + |yk − yl|2)−1
  • PerplexityPerp(Pi) = 2H(Pi)
  • Classical MDSB = −½ J D(2) J, J = I − (1/n) 1 1T, Z = Vk Λk1/2
  • IsomapDgeo = shortest paths in the k neighbour graph, then classical MDS on Dgeo
  • t-SNE costKL(P | Q) = Σi≠j pij log(pij / qij)
  • t-SNE gradient∂C/∂yi = 4 Σj (pij − qij)(yi − yj)(1 + |yi − yj|2)−1
  • Exam The swiss roll is a flat sheet rolled up in 3D. PCA squashes it flat and mixes the layers, so its best axis follows the position along the roll with a rank correlation of only 0.19. Isomap unrolls it almost perfectly (1.0), spectral embedding nearly so (0.998), and LLE reaches 0.916. All three need a sensible number of neighbours.

3.2Association rules and market basket analysis

  • Measures support P(A ∩ B), confidence P(B | A), lift P(A ∩ B)/P(A)P(B). Lift 1 independent, below 1 negative.
  • Trap High confidence with a very common B can still mean lift below 1. Always check lift.
  • Apriori Subsets of frequent sets are frequent. Count level by level, join, prune candidates with infrequent subsets.
  • Rules Each frequent k itemset gives 2k − 2 rules. Filter by support, confidence, lift. Leverage and conviction.
  • Scale FP-Growth prefix tree, no candidates, two scans. PCY and SON for massive data. Pair counts via XTX.
  • Caution Many tests give chance patterns. Rules are correlations, not causes.
  • Supportsupp(A ⇒ B) = P(A ∩ B)
  • Confidenceconf(A ⇒ B) = P(B | A) = supp(A ∩ B) / supp(A)
  • Liftlift = conf(A ⇒ B) / supp(B) = P(A ∩ B) / (P(A) P(B))
  • Supportsupp(X) = |{{t : X ⊆ t}}| / n
  • Confidenceconf(A ⇒ B) = supp(A ∪ B) / supp(A)
  • Liftlift(A ⇒ B) = supp(A ∪ B) / (supp(A) supp(B))
  • Apriori propertyX ⊆ Y ⇒ supp(X) ≥ supp(Y)
  • Exam Bread is in 7 of 10 baskets, butter in 5, and both in 5. So every basket with butter also has bread. Confidence(bread ⇒ butter) = 0.5 / 0.7 = 0.714, and lift = 0.714 / 0.5 = 1.43: buying bread makes butter 43% more likely than in a random basket.

1.1Agents, rewards and returns

  • Loop State, action, reward, next state. The agent picks actions with a policy π(a | s).
  • Return Gt = rt+1 + γ Gt+1. γ in [0, 1]. Constant reward r gives r / (1 − γ).
  • Goal Maximise the expected return. The best policy is π*.
  • Trade off Explore to learn, exploit to earn. ε greedy is the simplest balance.
  • Gymnasium reset(seed) gives obs and info. step(a) gives obs, reward, terminated, truncated, info. Truncated is not terminal.
  • When to use Actions change future data and feedback is a delayed score. Watch for reward hacking and sample cost.
  • ReturnGt = Σk=0∞ γk rt+k+1
  • Recursive formGt = rt+1 + γ Gt+1
  • Policyπ(a | s) = P(At = a | St = s)
  • ReturnGt = Σk≥0 γk rt+k+1 = rt+1 + γ Gt+1

  • Exam The random agent stepped right, left, left, right, right, right, right. Six moves cost −1 each and the treasure gave +10, so the total was 4. Going right three times in a row would have scored 8. The agent did not know that. Learning means finding it out from experience.

1.2Multi armed bandits

  • Problem One state, k arms, unknown means. Maximise total reward or minimise regret Tμ* − Σ μat.
  • Update Q ← Q + (r − Q)/N. Constant α for drifting arms.
  • ε greedy Random arm with chance ε, else greedy. Simple, but linear regret with fixed ε.
  • UCB argmax Q + c√(ln t / N). Untried arms first. Logarithmic regret. Tune c.
  • Thompson Beta(1 + wins, 1 + losses). Draw from each, pull the best draw. Probability matching.
  • Context Contextual bandits (LinUCB) choose per context. Bandits beat fixed A/B tests on reward, A/B tests give cleaner answers.
  • Running averageQn+1 = Qn + (rn − Qn) / n
  • Regretregret(T) = T μ* − Σt μat
  • UCB scoreAt = argmaxa [Q(a) + c √(ln t / N(a))]
  • Action valueq*(a) = E[Rt | At = a]
  • Incremental formQ ← Q + (1/N)(r − Q)
  • UCBargmaxa Q(a) + c √(ln t / N(a))
  • Beta posteriorBeta(1, 1) + s clicks and f misses ⇒ Beta(1 + s, 1 + f), mean (1 + s)/(2 + s + f)
  • Exam The running average gives 4, 5, 5, 6, 5, exactly the plain average at each point, without storing the rewards. With a constant step size of 0.5 the estimate forgets the past: after three rewards of 1 and then rewards of 10 it climbs to 8.859 within three pulls. A constant step size suits arms whose payouts drift over time.
  • Exam Averaged over 500 experiments of 1,000 pulls, greedy chooses the best arm only 25% of the time and earns 0.497 per pull. ε = 0.1 earns the most, 0.705, picking the best arm 68% of the time. ε = 0.3 explores too much: it knows the best arm but still pulls a random one 30% of the time.

  • Exam Over 5,000 visitors and 200 repeats, Thompson sampling earned 323 clicks against 305.3 for an A/B test that split the first half of visitors evenly and then showed the winner. 1.3Markov decision processes and Bellman equations

  • Markov Next state depends only on the current state. Chain: P with rows adding to 1. dt+k = dtPk, stationary π = πP.
  • MDP (S, A, p, R, γ). MDP + fixed policy = MRP. MRP: V = R + γPV, V = (I − γP)−1R.
  • Values vπ(s) = E[G | s], qπ(s, a) = E[G | s, a]. v = Σ π q, q = Σ p (r + γv).
  • Optimality v*(s) = maxa Σ p (r + γv*). Greedy on q* is optimal. Nonlinear, solved iteratively.
  • Convergence Bellman operator is a γ contraction, unique fixed point, error shrinks by γ per sweep.
  • Gridworld Random policy values −14 to −22, optimal values = −distance to exit. Greedy on vπ improves π.
  • Markov propertyP(St+1 | St, St−1, ..., S0) = P(St+1 | St)
  • k steps aheaddt+k = dt Pk
  • Stationary distributionπ = π P, Σ πi = 1
  • State valuevπ(s) = Eπ[Gt | St = s]
  • Action valueqπ(s, a) = Eπ[Gt | St = s, At = a]
  • Linksvπ(s) = Σa π(a|s) qπ(s, a), qπ(s, a) = Σs′,r p(s′, r | s, a)[r + γ vπ(s′)]
  • MDP(S, A, p, R, γ), p(s′, r | s, a) = P(St+1 = s′, Rt+1 = r | St = s, At = a)
  • MRP solutionV = (I − γP)−1 R
  • Bellman expectationvπ(s) = Σa π(a|s) Σs′,r p(s′, r | s, a)[r + γ vπ(s′)]
  • Bellman optimalityv*(s) = maxa Σs′,r p(s′, r | s, a)[r + γ v*(s′)]

Step 2Reinforcement Learning · Solving MDPs

2.1Dynamic programming: policy and value iteration

  • DP Known model, sweeps of Bellman backups over all states. Stop when max change < θ.
  • Evaluation v(s) ← Σ π(a|s) Σ p (r + γv(s′)). Error shrinks by γ per sweep. In place is fine.
  • Policy iteration Evaluate, then greedy improve. Improvement theorem. Few iterations, stops when the policy is stable.
  • Value iteration v(s) ← maxa Σ p (r + γv(s′)), then greedy extraction. Many cheap sweeps.
  • Examples Gridworld −14 to −22, FrozenLake start 0.542 (slippery, γ 0.99), gambler bets boldly at 25, 50, 75.
  • Limits GPI is the pattern of all RL. DP needs a model and suffers the curse of dimensionality. LP solves MDPs in polynomial time.
  • Policy evaluation updatevk+1(s) = Σa π(a|s) Σs′,r p(s′, r | s, a)[r + γ vk(s′)]
  • Policy evaluationvk+1 = rπ + γ Pπ vk
  • Greedy improvementπ′(s) = argmaxa qπ(s, a)
  • Policy improvement theoremqπ(s, π′(s)) ≥ vπ(s) for all s ⇒ vπ′(s) ≥ vπ(s) for all s
  • Value iterationvk+1(s) = maxa Σs′,r p(s′, r | s, a)[r + γ vk(s′)]

2.2Monte Carlo and temporal difference learning

  • MC V(s) ← V(s) + α(G − V(s)). Full returns, no model, unbiased, high variance, needs episode ends.
  • TD(0) δ = r + γV(s′) − V(s), V(s) ← V(s) + αδ. Bootstraps, online, lower variance, biased.
  • Compare TD usually faster on Markov problems. Batch MC fits returns, batch TD fits the Markov model (example 6.4).
  • Step size Constant α tracks change but fluctuates. Robbins Monro: Σ α = ∞, Σ α2 < ∞.
  • n step and λ Gt:t+n mixes n rewards and a bootstrap. TD(λ) weights (1 − λ)λn−1. Traces decay by γλ.
  • Warning Deadly triad: function approximation + bootstrapping + off policy can diverge.
  • Monte Carlo updateV(St) ← V(St) + α[Gt − V(St)]
  • TD(0) updateV(St) ← V(St) + α[Rt+1 + γV(St+1) − V(St)]
  • TD errorδt = Rt+1 + γV(St+1) − V(St)
  • ReturnGt = Rt+1 + γGt+1
  • TD(0)V(s) ← V(s) + α[r + γV(s′) − V(s)]
  • n step returnGt:t+n = Σk=0n−1 γkRt+k+1 + γnV(St+n)

2.3SARSA and Q learning

  • Action values Learn Q(s, a), act with argmax. No model needed. Explore with ε greedy.
