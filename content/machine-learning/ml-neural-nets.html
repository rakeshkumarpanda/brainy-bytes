Lesson 1 of 9

From one neuron to the perceptron

Source: McCulloch and Pitts (1943), Rosenblatt (1958), Novikoff (1962), and Goodfellow, Bengio and Courville (2016) section 6.1.

What it is
An artificial neuron computes a weighted sum of its inputs plus a bias, z = w · x + b, and passes it through an activation function. The perceptron uses a step activation: output 1 if z > 0, else 0. Its learning rule adds the input to the weights when it should have fired and subtracts it when it should not.
Why we need it
Every deep network is built from these units. The perceptron is the simplest learning machine that draws a decision boundary, and its failure on XOR explains why we need hidden layers.
How it works
For each training point compute the prediction ŷ. If it is wrong, update w += η(y − ŷ)x and b += η(y − ŷ). Repeat over the data until an epoch has no mistakes. If a separating line exists, this always stops.

In the exam
On 40 points that a line can separate, the perceptron makes no mistakes after epoch 6. It learns AND in 6 epochs and OR in 4, but after 100 epochs on XOR it still predicts [1, 1, 0, 0] for targets [0, 1, 1, 0]. Minsky and Papert’s 1969 book made this limit famous.

a = φ(w · x + b)

Perceptron ruleExam favourite
w ← w + η(y − ŷ)x,   b ← b + η(y − ŷ)
Only wrong predictions change anything.
Convergence boundExam favourite
mistakes ≤ (R / γ)2

Multilayer networks and why hidden layers matter

Source: Rumelhart, Hinton and Williams (Nature 1986), Cybenko (1989), Hornik (1991), and Goodfellow, Bengio and Courville (2016) sections 6.1 to 6.4.

What it is
A multilayer perceptron (MLP) stacks layers of neurons: inputs, one or more hidden layers, and an output layer. Each layer computes h = φ(Wx + b). The hidden layers learn new features of the input, and the output layer combines them.
Why we need it
Without a nonlinear activation, stacked layers collapse into one linear map and can only draw straight boundaries. With it, the universal approximation theorem says one hidden layer with enough units can approximate any continuous function on a bounded region as closely as we like. Depth makes many functions far cheaper to represent.
How it works
Choose the layer sizes and activations, initialise weights randomly, compute the forward pass, measure the loss, and adjust every weight with gradient descent using backpropagation (chapter 1.2). For classification, end with a sigmoid (two classes) or softmax (many classes) and use cross entropy.

A network with 3 tanh hidden units learns XOR: the loss falls from 0.7471 to 0.0018 in 3000 steps and the outputs become 0, 0.998, 0.998 and 0.003. The hidden values show what happened: each input point got new coordinates in which a single line separates the two classes.

Lesson 3 of 9

Activation functions

Source: Nair and Hinton (ICML 2010), Glorot, Bordes and Bengio, Deep sparse rectifier neural networks (AISTATS 2011), Hendrycks and Gimpel, Gaussian Error Linear Units (2016), and Goodfellow, Bengio and Courville (2016) section 6.3.

What it is
The activation function decides what each neuron passes on. Sigmoid squashes to (0, 1), tanh to (−1, 1), ReLU keeps positive values and zeroes negative ones, leaky ReLU lets a small slope through for negatives, and GELU is a smooth version of ReLU used in transformers. The output layer uses softmax to turn scores into class probabilities.
Why we need it
Backpropagation multiplies the slopes of the activations layer after layer. Sigmoid’s slope is at most 0.25 and almost 0 for large inputs, so gradients vanish in deep sigmoid networks. ReLU has slope 1 for positive inputs, which is a main reason deep networks became trainable around 2010.
How it works
Use ReLU or GELU in hidden layers by default. Use sigmoid for a single probability output, softmax for several classes, and no activation for regression outputs. Watch for dead ReLU units that output 0 for every input, and try leaky ReLU if many die.
Download this program (.py)Save it, open it in any editor and run it with python3 activations.py.
In the exam
Sigmoid’s slope is 0.25 at 0 and 0.007 at ±5. Tanh’s slope is 1 at 0 but 0 at ±5 (to three decimals). ReLU’s slope is exactly 1 for every positive input. Multiplying ten sigmoid slopes of at most 0.25 can shrink a gradient by a factor of about one millionth.

MLPs in practice with scikit-learn

Source: scikit-learn 1.8 documentation, Neural network models (supervised), MLPClassifier.

What it is
scikit-learn’s MLPClassifier and MLPRegressor train fully connected networks with backpropagation and the Adam optimiser. You choose the hidden layer sizes, the activation and the regularisation strength alpha, and call fit and predict like any other model.
Why we need it
For small tabular problems an MLP in scikit-learn is the quickest way to try a neural network and compare it with logistic regression, trees or boosting under the same cross validation. For images, text or large data, use a deep learning library such as PyTorch or JAX, which run on GPUs.
How it works
Scale the inputs (MLPs are sensitive to feature scales), start with one or two hidden layers of 32 to 128 units, set max_iter high enough to converge, and tune alpha and the layer sizes with cross validation. Check training against test accuracy for overfitting.
Download this program (.py)Save it, open it in any editor and run it with python3 mlp_moons.py.
In the exam
On two noisy half moons, logistic regression reaches 0.861 test accuracy. An MLP with 2 hidden units (9 weights) does no better, 0.856. With 32 units it reaches 0.883, and with two layers of 32 (1185 weights) 0.900, while training accuracy climbs to 0.952. More capacity fits the curve better, but the gap between train and test grows too.

Worked example: XOR with two ReLU units, built by hand
  1. Hidden units h1 = ReLU(x1 + x2) and h2 = ReLU(x1 + x2 − 1). Output y = h1 − 2h2.
  2. (0, 0): h = (0, 0), y = 0
  3. (0, 1) and (1, 0): h = (1, 0), y = 1
  4. (1, 1): h = (2, 1), y = 2 − 2 = 0
  5. Two hidden units and three layers of arithmetic compute XOR exactly, which no single perceptron can.
Going deeper: Why depth helps

The universal approximation theorem promises that one hidden layer is enough, but not that it is efficient. Some functions need exponentially many units in a shallow network yet only a modest number in a deep one. A classic example is the parity of n bits (XOR of all of them): a deep network can compute it with a number of units that grows in proportion to n, while a network with one hidden layer of threshold units needs a number that grows exponentially. Montufar and colleagues (2014) showed that deep ReLU networks can carve the input space into exponentially more linear regions than shallow ones with the same number of units. In practice depth also matches the structure of data such as images, where edges combine into parts and parts into objects.

Lesson 9 of 9

Chapter summary

  1. A neuron computes φ(w · x + b). The perceptron uses a step function and fixes its mistakes by adding or subtracting the input.
  2. The perceptron converges when a line separates the classes, within (R/γ)2 mistakes, but it can never learn XOR.
  3. A multilayer perceptron adds hidden layers with nonlinear activations. Hidden units learn new features, and one hidden layer can approximate any continuous function.
  4. ReLU and GELU are the default hidden activations. Sigmoid and tanh saturate and cause vanishing gradients. Softmax turns scores into probabilities.
  5. scikit-learn’s MLPClassifier is a quick way to try networks on tabular data. Scale the inputs and watch the train and test gap.
