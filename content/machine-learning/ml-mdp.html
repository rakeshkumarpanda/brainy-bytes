Lesson 1 of 9

The Markov property and Markov chains

Source: Sutton and Barto (2018) section 3.1, and Norris, Markov Chains (1997) chapter 1.

What it is
A process has the Markov property when the future depends only on the present state, not on how it got there. A Markov chain is a set of states plus a transition matrix P, where P[i][j] is the chance of moving from state i to state j in one step. Each row adds up to 1.
Why we need it
If the state holds everything that matters, the agent can decide using the state alone and forget the past. That makes planning possible. Markov chains also power PageRank, text generation by n grams, queueing models and MCMC sampling.
How it works
Write the states, fill the transition matrix, and push a probability distribution forward with dnext = d P. After many steps most chains settle into a stationary distribution π with π = πP, whatever the start.

Lesson 2 of 9

Markov reward processes and decision processes

Source: Sutton and Barto (2018) sections 3.1 to 3.5, and Silver, UCL Course on RL lecture 2.

What it is
A Markov reward process (MRP) adds a reward R(s) to each state of a Markov chain and a discount γ. The value V(s) is the expected discounted return starting from s. A Markov decision process (MDP) adds actions: the tuple (S, A, P, R, γ), where P(s′ | s, a) depends on the action chosen. An MDP plus a fixed policy π is again an MRP.
Why we need it
The MDP is the standard language of RL. Every algorithm in this section, from dynamic programming to deep Q networks, solves an MDP or an estimate of one. Writing a problem as an MDP shows what the state must contain and what the agent controls.
How it works
Values satisfy the Bellman equation V(s) = R(s) + γ Σs′ P(s′ | s) V(s′). In matrix form V = R + γPV, so V = (I − γP)−1 R. For small problems solve this directly. For large ones, repeat the equation as an update until the values stop changing.

State values and action values for a policy

Source: Sutton and Barto (2018) section 3.5 and example 4.1, the 4 × 4 gridworld.

What it is
For a policy π, the state value vπ(s) is the expected return from s when following π. The action value qπ(s, a) is the expected return from s if you first take action a and then follow π. They are linked: v is the π weighted average of q, and q is the reward plus the discounted value of the next state.
Why we need it
Values turn a long future into one number per state, so the agent can compare choices locally. The action value is especially useful: picking the action with the largest q needs no model of the environment, which is the key to Q learning.
How it works
Build the MRP that the policy creates, then solve its Bellman equation. Here the policy moves in all four directions with chance 1/4 on a 4 × 4 grid with exits in two corners and a cost of −1 per move.

Lesson 4 of 9

Optimal values and the Bellman optimality equation

Source: Bellman, Dynamic Programming (1957), and Sutton and Barto (2018) section 3.6.

What it is
The optimal value v*(s) is the largest value any policy can reach from s, and q*(s, a) the largest action value. They satisfy the Bellman optimality equation: v*(s) = maxa Σ p(s′, r | s, a)[r + γ v*(s′)]. Any policy that is greedy with respect to q* is optimal.
Why we need it
Every finite MDP has at least one deterministic optimal policy, and all optimal policies share the same v* and q*. So the whole problem of acting well reduces to finding q*, and then acting is just taking the argmax.
How it works
The max makes the optimality equation nonlinear, so there is no single matrix solve. It is solved by repeating it as an update (value iteration), by alternating evaluation and greedy improvement (policy iteration), or from samples without a model (Q learning). The next chapters do each one.
Optimal values in the 4 × 4 gridworld, by reasoning
  1. Every move costs −1 and moves are certain, so the best policy walks the shortest path to the nearer exit.
  2. v*(s) = −(number of moves to the nearer exit).
  3. Cell 6 (row 1, column 2) is 3 moves from both corners, so v*(6) = −3, against −20 for the random policy.
  4. q*(6, up) = −1 + v*(2) = −1 + (−2) = −3, and q*(6, right) = −1 + v*(7) = −3 as well. Several actions can be optimal.
EquationRelatesLinear?Solved by

Going deeper: Why the Bellman update always converges

Write the update as an operator T on value functions: (TV)(s) = maxa Σ p(s′, r | s, a)[r + γV(s′)]. For any two value functions U and V, the largest difference between TU and TV is at most γ times the largest difference between U and V. So T is a contraction in the max norm when γ < 1, and by the Banach fixed point theorem it has exactly one fixed point, v*, which repeated updates reach from any start, with the error shrinking by a factor γ each sweep. The same argument works for the expectation operator of a fixed policy. With γ = 1 convergence needs every policy to reach a terminal state eventually, as in the gridworld.

Worked example: one Bellman expectation backup
  1. State s has two actions, each chosen with chance 0.5. γ = 0.9.
  2. Action a gives reward 1 and leads to a state with value 10. Action b gives reward 0 and leads to a state with value 4.
  3. q(s, a) = 1 + 0.9 × 10 = 10, q(s, b) = 0 + 0.9 × 4 = 3.6
  4. v(s) = 0.5 × 10 + 0.5 × 3.6 = 6.8
  5. The optimality backup would instead take the max: v*(s) = 10 if those next values were optimal.
Going deeper: Partially observable MDPs

When the agent sees only an observation o that hides part of the state (a robot with noisy sensors, a card game with hidden hands), the process is a POMDP. The fix in theory is a belief state: the probability distribution over true states given all observations so far, updated with Bayes’ rule. The belief is Markov, so a POMDP is an MDP over beliefs, but that MDP has continuous states and is very hard to solve exactly. Practical agents approximate it by stacking recent observations (as DQN stacks 4 Atari frames) or by giving the policy a memory such as a recurrent network.

Chapter summary

  1. Markov property: the next state depends only on the current one. A chain is states plus a transition matrix P.
  2. Distributions move as d Pk. Most chains settle at a stationary distribution π = πP.
  3. An MRP adds rewards: V = R + γPV, so V = (I − γP)−1R. An MDP adds actions: (S, A, p, R, γ).
  4. vπ(s) and qπ(s, a) are expected returns. v is the π average of q, and q is reward plus discounted next v.
  5. The Bellman optimality equation uses a max. A policy greedy with respect to q* is optimal.
  6. The Bellman operator is a γ contraction, so repeated backups converge to a unique answer.
