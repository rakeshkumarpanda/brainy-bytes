Vectors: every example is a list of numbers

Source: Strang, Introduction to Linear Algebra (5th edition), Deisenroth, Faisal and Ong, Mathematics for Machine Learning (2020), and the Stanford CS229 linear algebra review.

What it is
A vector is an ordered list of numbers, such as [21, 160, 55] for age, height and weight. Each number is one component. A vector with d numbers lives in d dimensional space.
Why we need it
ML models only understand numbers. Every example, whether a house, a photo or a sentence, is first turned into a vector of features. Then "similar examples" means "nearby vectors", and models can do maths on them.
How it works
Vectors add component by component, can be multiplied by a number (scaled), and two vectors give one number with the dot product: multiply matching components and add.
Download this program (.py)Save it, open it in any editor and run it with python3 vectors_by_hand.py.
Real world scenario: a song on a music app

A music app can describe every song with numbers: tempo, loudness, how much it sounds like dance music, how acoustic it is, and so on. Each song becomes a vector. When you like a song, the app looks for songs whose vectors are close to it. "Songs like this one" is really "nearby vectors".

Common mistake
The order of components matters. [age, height] and [height, age] are different vectors. Every example must use the same feature order.

Euclidean distance (L2)Exam favourite
d(a, b) = √( Σ (ai − bi)2 )
The straight line distance. Used by k nearest neighbours and k means.
Manhattan distance (L1)
d(a, b) = Σ |ai − bi|
The city block distance. Less hurt by one huge gap.
Length (norm) of a vectorExam favourite
||v||2 = √(v12 + ... + vd2), ||v||1 = Σ |vi|
The distance from the origin. Ridge regression punishes L2, lasso punishes L1.
Cosine similarityExam favourite
cos θ = a · b / (||a|| ||b||)
1 for the same direction, 0 for a right angle, −1 for opposite. Used for text and embeddings.

Lesson 3 of 11

Matrices: tables of numbers that transform vectors

What it is
A matrix is a rectangle of numbers with rows and columns. An n × d matrix has n rows and d columns. Your whole dataset is a matrix X: one row per example, one column per feature.
Why we need it
A matrix lets us do many dot products at once. Multiplying the data matrix by a weight vector gives every prediction in one step. In a neural network, each layer is a matrix.
How it works
Matrix times vector: each row of the matrix is dotted with the vector. Matrix times matrix: entry (i, j) is row i of the first dotted with column j of the second. The inner sizes must match.

A linear model is a matrix product

Download this program (.py)Save it, open it in any editor and run it with python3 linear_model_as_matrix.py.
Linear model for all examplesExam favourite
ŷ = X w + b
X is n × d, w has d weights, b is one number added to every prediction.
One prediction
ŷi = w · xi + b = w1xi1 + ... + wdxid + b
Each weight says how much the prediction changes when its feature grows by 1.
Bias trick
add a column of 1s to X, then ŷ = X w
b becomes just another weight, which makes the maths shorter.

Linear regression, logistic regression, support vector machines and every layer of a neural network start with this same product. Learning means finding good numbers for w and b.

Systems of equations, inverse, determinant and rank

Download this program (.py)Save it, open it in any editor and run it with python3 solve_system.py.
What it is
A system of linear equations asks for the unknowns w that make A w = y true. The determinant tells if a square system has exactly one answer, and the rank counts how many rows (or columns) give truly new information.
Why we need it
Fitting a line to data leads to such a system (the normal equation in Supervised 1.1). When two features say the same thing, for example size in m2 and size in square feet, the matrix loses rank and the answer becomes unstable.
How it works
If det(A) ≠ 0, A has an inverse and w = A−1 y. In code use np.linalg.solve, which is faster and more accurate than computing the inverse. If det(A) = 0, the columns are linearly dependent.
2 × 2 determinantExam favourite
det [[a, b], [c, d]] = a d − b c
How much the matrix scales areas. 0 means it squashes the plane to a line.
2 × 2 inverse
[[a, b], [c, d]]−1 = (1 / (a d − b c)) [[d, −b], [−c, a]]
Swap a and d, change the signs of b and c, divide by the determinant.
Rank
rank(A) = number of linearly independent columns
Full rank means no column is a mix of the others.
Common mistake
Perfectly correlated features (one column is a multiple of another) make XTX impossible to invert. This is called multicollinearity. Drop one of the features or use ridge regression.

Projections and eigenvectors: a first look

Download this program (.py)Save it, open it in any editor and run it with python3 projection_and_eigen.py.
What it is
A projection is the shadow of a vector on a direction. An eigenvector of a matrix is a direction the matrix only stretches, by a number called the eigenvalue, without turning it.
Why we need it
Least squares regression projects the label vector onto the space of the features. PCA (Unsupervised 2.1) finds the eigenvectors of the covariance matrix, which are the directions where the data spreads the most.
How it works
Projection of x on direction d: ((x · d) / (d · d)) d. Eigenvectors solve A v = λ v. NumPy finds them with np.linalg.eig, or np.linalg.eigh for symmetric matrices.
ProjectionExam favourite
projd(x) = ((x · d) / (d · d)) d
The closest point to x on the line through d.
Eigen equationExam favourite
A v = λ v
v keeps its direction, its length is multiplied by λ.
Eigenvalues of a 2 × 2 matrix
λ2 − (a + d) λ + (a d − b c) = 0
Sum of eigenvalues = a + d (the trace), product = the determinant.

Lesson 8 of 11

The maths, all in one place

Dot product and angleExam favourite
a · b = ||a|| ||b|| cos θ
Dot product 0 means the vectors are at a right angle (orthogonal).
Shape of a product
(n × k)(k × m) = (n × m)
The inner k must match. Each entry needs k multiplies.
Transpose of a product
(A B)T = BT AT
The order flips.
Squared distance expandedExam favourite
||a − b||2 = ||a||2 + ||b||2 − 2 a · b
Lets libraries compute all pairwise distances with one matrix product.
Cauchy Schwarz
|a · b| ≤ ||a|| ||b||
Why cosine similarity is always between −1 and 1.
Worked example: invert a 2 × 2 matrix
  1. A = [[2, 1], [1, 3]].
  2. det = 2 × 3 − 1 × 1 = 5.
  3. Swap 2 and 3, change the signs of the 1s: [[3, −1], [−1, 2]].
  4. A−1 = (1/5) [[3, −1], [−1, 2]] = [[0.6, −0.2], [−0.2, 0.4]]
  5. Check: A A−1 = [[2 × 0.6 + 1 × (−0.2), ...]] = [[1, 0], [0, 1]]. Then w = A−1 (5, 10) = (1, 3).
Going deeper: Why the expanded distance formula matters

To find the nearest neighbours of m query points among n stored points, the naive way computes m × n distances with d subtractions each. Using ||a − b||2 = ||a||2 + ||b||2 − 2 a · b, all the dot products come from one matrix product Q XT, which BLAS libraries run at near peak hardware speed. scikit-learn’s pairwise_distances and FAISS do this. The cost is some floating point error for nearly equal points, so results are clipped at 0.

Lesson 9 of 11

From beginner to expert

One idea, four depths

A vector is a list of numbers that describes one thing. Close vectors mean similar things. A matrix is a table that can turn many vectors into predictions at once.

Know dot products, L1 and L2 norms, Euclidean and cosine distances, matrix products and their shape rule, transposes, inverses, determinants and rank, and that ŷ = X w + b is the heart of linear models.

Think of X w as a combination of the columns of X, so least squares projects y onto the column space. Rank deficiency and ill conditioning (a large ratio of largest to smallest singular value) make solutions unstable, which regularisation fixes.

The spectral theorem says every real symmetric matrix is Q Λ QT with orthonormal Q. The singular value decomposition X = U Σ VT generalises this to any matrix and gives the best low rank approximation (Eckart Young theorem), the base of PCA, latent semantic analysis and low rank adapters such as LoRA.

Beginner
Add and scale vectors, compute dot products and distances, multiply a matrix by a vector.
Intermediate
Write a linear model as X w + b, check shapes, solve systems with NumPy, explain determinant and rank.
Expert
Use projections, eigenvectors and the SVD, and reason about conditioning and multicollinearity.

Chapter summary

  1. A vector is a list of numbers. Every example becomes a feature vector, and similar examples are close vectors.
  2. Dot product: multiply matching components and add. a · b = ||a|| ||b|| cos θ.
  3. Euclidean (L2) distance is the straight line, Manhattan (L1) the sum of gaps, cosine compares directions. Scale features first.
  4. A matrix is a table. Matrix times vector is one dot product per row. Shapes: (n × k)(k × m) = (n × m).
  5. A linear model for all examples is ŷ = X w + b.
  6. det(A) ≠ 0 means A has an inverse. Use np.linalg.solve. Rank counts independent columns. Dependent features cause multicollinearity.
  7. Projections and eigenvectors (A v = λ v) are the base of least squares and PCA.
