Lesson 1 of 10

Curves, underfitting and overfitting

Source: James, Witten, Hastie and Tibshirani, An Introduction to Statistical Learning chapters 6.2 and 7.1, Hastie, Tibshirani and Friedman, The Elements of Statistical Learning chapter 3.4, Tibshirani (1996), Zou and Hastie (2005), and the scikit-learn 1.8 user guide.

What it is
Polynomial regression is linear regression on x, x2, x3 and so on, so it can fit curves. A model that is too simple underfits: it misses the pattern. A model that is too flexible overfits: it memorises the noise in the training data and fails on new data.
Why we need it
Every model has to find the right amount of flexibility. Overfitting is the most common reason a model that looked great in a notebook fails in real use.
How it works
Fit models of growing complexity and compare training error with test (or validation) error. Training error keeps falling. Test error falls, then rises again once the model starts fitting noise. Pick the complexity at the bottom of the test curve, or keep a flexible model and add a penalty (regularisation).

Real world scenario: learning for an exam

One student only reads the chapter titles and fails (underfitting). Another memorises last year’s answers word for word and fails too, because this year’s questions are different (overfitting). The student who learns the ideas does well on new questions. That is the model we want.

Lesson 2 of 10

Ridge regression (L2): keep weights small

What it is
Ridge regression adds a penalty α Σ wj2 to the squared error. The model now has to balance fitting the data with keeping its weights small.
Why we need it
Huge weights are a sign of overfitting: the curve bends wildly to pass through every point. Ridge also fixes multicollinearity: when two features are almost copies, plain least squares gives unstable, opposite weights, while ridge shares the weight between them.
How it works
Minimise ||y − Xw||2 + α||w||2. The solution is w = (XTX + αI)−1XTy, which always exists. Larger α means stronger shrinking. α = 0 is plain least squares. Scale the features first, because the penalty treats all weights the same.

Lesson 3 of 10

Lasso (L1): weights that become exactly zero

What it is
Lasso adds the penalty α Σ |wj| instead of squares. It shrinks weights too, but it pushes many of them all the way to exactly 0, so it also selects features.
Why we need it
When you have many features and suspect that only a few matter, lasso gives a smaller model that is easier to explain and cheaper to run, and it often predicts better because it ignores the noise features.
How it works
The absolute value has a sharp corner at 0. For a weak feature, the penalty’s pull towards 0 is stronger than what the data gains from a small weight, so the best weight is exactly 0. scikit-learn solves lasso with coordinate descent, updating one weight at a time with a "soft threshold".

Soft threshold (one lasso update)Exam favourite
wj = sign(ρ) max(|ρ| − α, 0) / zj
ρ is how much feature j explains the remaining error. If |ρ| ≤ α the weight becomes 0.
In the exam
In the program the true model uses 3 of 10 features. At α = 0.5, lasso keeps exactly those 3 and sets the other 7 to 0. Ridge with α = 10 keeps all 10 with small weights.
Lesson 4 of 10

Elastic net: the best of both

What it is
Elastic net uses both penalties: α (r Σ|w| + (1 − r)/2 Σw2), where r is l1_ratio. r = 1 is lasso and r = 0 is ridge.
Why we need it
When several features are strongly correlated, lasso tends to pick one at random and drop the others. Elastic net keeps the group together and still sets truly useless features to 0. It is a safe default when you are not sure which penalty suits the data.
How it works
Choose l1_ratio (often 0.1 to 0.9) and α with cross validation (ElasticNetCV). The L2 part makes the problem behave well with correlated features and the L1 part gives sparsity.

Lesson 5 of 10

Choosing alpha with cross validation

What it is
α is a hyperparameter: you choose it, the training does not learn it. RidgeCV, LassoCV and ElasticNetCV try many values and keep the one with the best cross validated score.
Why we need it
Too small an α leaves the overfitting in place. Too large an α shrinks the real signal away (underfitting). The right value depends on the data, so it must be measured, not guessed.
How it works
Give a list of α values (usually spaced by factors of 10). For each one, cross validation trains on part of the training data and scores on the rest. The best α is then used to fit on all the training data. The test set is touched only once at the end.
Download this program (.py)Save it, open it in any editor and run it with python3 choose_alpha.py.
Remember
With 65 polynomial features on 309 training rows, plain least squares overfits (test R² 0.225). Ridge and lasso both lift it to about 0.37, and lasso does it with only 14 of the 65 features.
Recipe for a regularised linear model
  1. Put StandardScaler before the model in a Pipeline, so every weight is penalised fairly.
  2. Use RidgeCV for a quick, stable model, LassoCV when you want fewer features, ElasticNetCV for correlated groups.
  3. Search α on a log scale, for example 0.001, 0.01, ..., 1000.
  4. If the best α is at the edge of your list, extend the list.
  5. Report the test score of the final model once.

Going deeper: Why L1 makes zeros: the geometry

Penalised regression is the same as least squares under a budget: minimise the error while Σw2 ≤ t (ridge) or Σ|w| ≤ t (lasso). The ridge budget is a circle (a sphere in more dimensions) and the lasso budget is a diamond with corners on the axes. The error contours are ellipses around the least squares answer, and the best point is where the first ellipse touches the budget. A round ball is usually touched at a point with every weight non zero, while a diamond is usually touched at a corner, where some weights are exactly 0.

The maths, all in one place

RidgeExam favourite
min ||y − Xw||2 + α||w||22, w = (XTX + αI)−1XTy
Always solvable because XTX + αI can be inverted for α > 0.
LassoExam favourite
min (1/2n)||y − Xw||2 + α||w||1
This is the exact scaling scikit-learn uses.
Elastic netExam favourite
min (1/2n)||y − Xw||2 + αr||w||1 + (α(1 − r)/2)||w||22
r is l1_ratio.
Ridge on one scaled feature
wridge = wols × s / (s + α)
s = Σx2. Shrinks by a factor, never to 0.
Lasso on one scaled feature
wlasso = sign(wols) max(|wols| − α′, 0)
Moves by a fixed amount and stops at 0.
Worked example: ridge on one feature by hand
  1. Data x = 1, 2, 3 and y = 2, 4, 6 (no intercept). Σxy = 2 + 8 + 18 = 28, Σx2 = 14.
  2. Least squares: w = 28 / 14 = 2.
  3. Ridge with α = 7: w = Σxy / (Σx2 + α) = 28 / 21.
  4. w = 1.333
  5. The penalty pulled the weight from 2 down to 1.333. With α = 0 we get 2 back.
Going deeper: Regularisation as a prior, and the bias variance view

Ridge is the MAP estimate under a normal prior w ~ N(0, (σ2/α)I), and lasso under a Laplace prior (Foundations 2.3). Ridge adds bias (the weights are pulled towards 0) but cuts variance by a larger amount when features are correlated or n is small, so the expected test error drops. In terms of the singular values dj of X, ridge multiplies each component of the least squares fit by dj2/(dj2 + α), shrinking most the directions the data supports least. The effective degrees of freedom are Σ dj2/(dj2 + α).

Chapter summary

  1. Polynomial features let a linear model fit curves. Too low a degree underfits, too high overfits.
  2. Underfitting: both errors high (high bias). Overfitting: training error low, test error high (high variance).
  3. Ridge adds αΣw2: shrinks all weights, never to 0, shares weight among correlated features. Closed form (XTX + αI)−1XTy.
  4. Lasso adds αΣ|w|: sets weak weights to exactly 0, so it selects features.
  5. Elastic net mixes both and keeps correlated groups together.
  6. Always scale features before a penalty. Pick α with RidgeCV, LassoCV or ElasticNetCV on a log scale.
  7. L1 makes zeros because its budget is a diamond with corners on the axes.
