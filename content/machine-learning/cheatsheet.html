What machine learning is: learning from examples

Open chapter

what ML is, the learning loop, kinds of learning, the vocabulary, generalisation and your first scikit-learn models.

Key ideas

  • Machine learning Learn the rule from examples instead of writing it. Mitchell: performance P on task T improves with experience E.
  • The loop Guess, measure the loss, adjust parameters against the slope (gradient descent), repeat. Learning rate sets the step size.
  • Kinds Supervised (labels: regression for numbers, classification for categories), unsupervised (no labels), reinforcement (rewards), plus semi and self supervised.
  • Words Features are inputs (X), label is the answer (y). Parameters are learned, hyperparameters are chosen.
  • Generalise Judge a model on unseen test data. High training score with low test score means overfitting.
  • scikit-learn model = Model(), model.fit(X, y), model.predict(X_new), model.score(X_test, y_test). X is 2D.

Formulas

A modelExam favourite
ŷ = f(x, θ)
x is the input, θ (theta) are the parameters, ŷ (y hat) is the prediction.
Lesson: The maths of learning
Mean squared error (loss for numbers)Exam favourite
MSE = (1/n) Σ (yi − ŷi)2
Average of the squared gaps between true answers y and predictions ŷ over n examples.
Lesson: The maths of learning
Accuracy (score for categories)
accuracy = correct predictions / all predictions
Between 0 and 1. Higher is better.
Lesson: The maths of learning
One gradient descent stepExam favourite
θnew = θ − η × (slope of the loss at θ)
η (eta) is the learning rate. Move against the slope, because the slope points uphill.
Lesson: The maths of learning
Learning as a search
θ* = the θ that makes the average loss on the training data smallest
Training is finding θ*. Generalisation asks if θ* also works on new data.

Tips and traps

  • Remember
    Machine learning is not magic and not always the right tool. If a simple fixed rule works (for example "a password must have 8 characters"), write the rule. Use ML when the rule is hard to write but examples are easy to get.Lesson: What machine learning is
  • Common mistake
    A learning rate that is too big makes the guess jump past the best value and the loss can grow. One that is too small makes learning very slow. Choosing it well is part of the job.Lesson: The learning loop: guess, check, adjust, repeat
  • In the exam
    A quick test: "Is there a right answer for each example in my data?" Yes means supervised. No means unsupervised. "Does the system learn by acting and getting rewards?" means reinforcement.Lesson: The kinds of machine learning
  • In the exam
    Parameters are learned by the model. Hyperparameters are set by you. The learning rate is a hyperparameter, the slope of a line is a parameter. Interviewers love this question.Lesson: The words of machine learning
  • Common mistake
    Never measure a model only on its training data. The score will look great and mean nothing. Always keep a separate test set, and look at it only at the end.Lesson: Learning, not memorising: generalisation
  • Common mistake
    X must be two dimensional: a list of rows, even when there is only one feature. Write [[1], [2], [3]], not [1, 2, 3]. Passing a flat list is the most common first error in scikit-learn.Lesson: Your first models with scikit-learn
  • Remember
    AI, ML and deep learning are nested: every deep learning model is a machine learning model, and machine learning is one part of artificial intelligence. The Artificial Intelligence subject draws these as nested circles.Lesson: Machine learning compared with similar ideas

The machine learning project: from a question to a working model

Open chapter

framing, the project stages, fair data splits, baselines, error analysis, leakage, deployment and monitoring.

Key ideas

  • Frame first Goal, output type, data known at prediction time, metric, success level, baseline. Ask if ML is needed at all.
  • Project loop Frame, get data, explore and clean, split, baseline, train and tune, evaluate, deploy, monitor (CRISP-DM plus monitoring).
  • Three sets Train learns, validation chooses, test scores once. Stratify rare classes, split time by time, keep groups together. Fix random_state.
  • Baseline DummyRegressor (mean) and DummyClassifier (most frequent) set the bar every model must beat.
  • Leakage Never train on information unavailable at prediction time. Fit preprocessing on training data only.
  • Uncertainty SE of an accuracy = √(p(1 − p)/n). Range about p ± 2 SE. Four times the data halves the SE.

Linear algebra for ML: vectors, distances and matrices

Open chapter

vectors and distances, matrices and products, the linear model, inverses, rank, projections and eigenvectors.

Key ideas

  • Vectors An example is a feature vector. Dot product a·b = Σ aibi = ||a|| ||b|| cos θ. 0 means orthogonal.
  • Distances Euclidean √Σ(ai−bi)2, Manhattan Σ|ai−bi|, cosine a·b/(||a|| ||b||). Scale features first.
  • Matrices Matrix times vector: one dot product per row. (n×k)(k×m) = n×m. AB ≠ BA. (AB)T = BTAT.
  • Linear model ŷ = X w + b. Each weight is the change in prediction per unit of its feature.
  • Inverse det [[a,b],[c,d]] = ad − bc. Inverse exists only if det ≠ 0. Use np.linalg.solve. Dependent columns mean multicollinearity.
  • Eigen A v = λ v. Sum of eigenvalues = trace, product = determinant. Base of PCA.

Formulas

Euclidean distance (L2)Exam favourite
d(a, b) = √( Σ (ai − bi)2 )
The straight line distance. Used by k nearest neighbours and k means.

d(a, b) = Σ |ai − bi|
The city block distance. Less hurt by one huge gap.

Anomaly detection

Open chapter

Robust scores, Isolation Forest, LOF, one class SVM and elliptic envelope, and evaluation for rare events.

Key ideas

  • Robust rules Median and MAD score (x − med)/(1.4826 MAD), flag above 3.5. IQR fences Q1 − 1.5 IQR, Q3 + 1.5 IQR. z scores suffer masking.
  • Isolation Forest Random feature, random cut. Anomalies isolate fast. s = 2−E[h]/c(n), near 1 anomalous. 256 row samples. contamination sets the cut off.

  • Other models One class SVM (nu, gamma), elliptic envelope (one robust Gaussian, Mahalanobis), GMM log density. Match the shape of normal.
  • Evaluation PR AUC, precision at k, recall at a budget. Not accuracy. Threshold from costs. Refit for drift.
  • Modes Outlier detection on dirty data, novelty detection on clean data, supervised models when labelled anomalies are plentiful.
