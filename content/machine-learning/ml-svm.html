Lesson 1 of 11

The widest street

Source: Cortes and Vapnik (1995), Hastie, Tibshirani and Friedman, The Elements of Statistical Learning chapter 12, Bishop, Pattern Recognition and Machine Learning chapter 7, the Stanford CS229 SVM notes, Pegasos (2007), Platt (1998), and the scikit-learn 1.8 user guide section 1.4.

What it is
A support vector machine (SVM) is a classifier that draws the boundary with the widest margin: the widest empty street between the two classes. The training points on the edges of the street are the support vectors.
Why we need it
When many lines separate the training data, logistic regression and the perceptron just pick one of them. The SVM picks the one that stays furthest from both classes, which tends to classify new points better. Only a few points decide the boundary, so the model is compact, and with kernels it can draw curved boundaries too.
How it works
Write the boundary as w·x + b = 0 and scale w so the street edges are w·x + b = +1 and −1. The width of the street is then 2 / |w|. Training finds the smallest |w| for which every point is on the correct side of its edge.

Three of the six points have w·x + b equal to exactly +1 or −1: those are the support vectors. The other three are further away (±1.4) and could move freely without changing the line.

Which side of the line the point is on.
Margin widthExam favourite
width = 2 / |w|
A smaller |w| means a wider street.
Real world scenario: a road between two villages

Engineers must build a straight road between two villages and want it as wide as possible without knocking down any house. The houses closest to the road on each side fix where its edges go. Houses further back do not matter at all. Those closest houses are the support vectors.

Lesson 2 of 11

Soft margin, hinge loss and C

What it is
Real data overlaps, so no street is perfectly empty. The soft margin SVM lets some points sit inside the street or on the wrong side, and charges each one a hinge loss. The setting C says how much each violation costs.
Why we need it
Without the soft margin, one mislabelled point could make the problem impossible or force a tiny street. C lets you trade a wide, simple street (small C) against getting more training points right (large C), the same bias and variance trade off as in regularisation.
How it works
The hinge loss of a point is max(0, 1 − y(w·x + b)): zero when the point is on its side beyond the edge, growing linearly once it enters the street. Training minimises ½|w|2 + C × (sum of hinge losses).

Lesson 3 of 11

Kernels: curved boundaries

What it is
A kernel is a function K(x, z) that measures how similar two points are. Swapping the plain dot product for a kernel lets the SVM draw curved boundaries, as if it had added many new features, without ever building them.
Why we need it
Many datasets, like a ring of one class around another, cannot be split by any straight line. Adding features such as x2 makes them separable, but building thousands of such features by hand is slow. The kernel trick gets the same result at the cost of computing K for pairs of points.
How it works
The SVM solution only uses the data through dot products xi·xj. Replace each one with K(xi, xj). In scikit-learn, choose SVC(kernel="rbf"), "poly" or "linear".

Tuning C and gamma, and scaling

What it is
An RBF SVM has two knobs. C controls how hard it tries to get every training point right. γ (gamma) controls how far the influence of one training point reaches: large γ means a short reach and a wiggly boundary.
Why we need it
With bad settings the same model ranges from badly underfitting to badly overfitting. SVMs also measure distances, so a feature in thousands drowns a feature in fractions unless you scale them first.
How it works
Always put a StandardScaler in a pipeline before the SVM. Then search C and γ on a log scale (0.001, 0.01, 0.1, 1, 10, 100) with cross validation, using GridSearchCV.

Lesson 5 of 11

How an SVM is trained

What it is
The SVM objective is convex, so it has one best answer and no bad local minima. Libraries solve it either in the dual form (libsvm, used by SVC) or directly in the primal form with gradient style methods (liblinear, SGD, Pegasos).
Why we need it
Knowing how training works explains the practical rules: SVC gets slow beyond tens of thousands of rows because the dual works with every pair of points, while LinearSVC and SGDClassifier scale to millions of rows but only draw straight boundaries.
How it works
Pegasos, below, is stochastic subgradient descent on the soft margin objective: for each point inside the street, step w towards y x, and always shrink w a little. That is all a linear SVM needs.
Download this program (.py)Save it, open it in any editor and run it with python3 pegasos.py.
Remember
Twenty lines of NumPy reach 97.5% accuracy, and the mean hinge loss falls from 0.257 to 0.086 over 30 passes. The learned w = (0.86, 0.87) points from class −1 towards class +1, as expected.
Going deeper: The dual problem and SMO

With Lagrange multipliers αi ≥ 0 the soft margin problem becomes: maximise Σαi − ½Σi,j αiαjyiyj xi·xj subject to 0 ≤ αi ≤ C and Σαiyi = 0. Then w = Σαiyixi. Only support vectors have αi > 0, and the data appears only through dot products, which is why the kernel trick works. Platt’s SMO algorithm (1998) solves the dual by updating two α values at a time, each update in closed form. libsvm, behind scikit-learn’s SVC, uses an improved SMO, and its time grows between n2 and n3 in the number of rows.

Lesson 6 of 11

Support vector regression

What it is
Support vector regression (SVR) predicts numbers. It fits a tube of half width ε (epsilon) around the curve and ignores every error smaller than ε. Only points on or outside the tube become support vectors.
Why we need it
Ignoring small errors makes SVR robust to noise and gives a compact model. With an RBF kernel it fits smooth curves.
How it works
The loss is max(0, |y − f(x)| − ε), the epsilon insensitive loss. A bigger ε means a wider tube, fewer support vectors and a rougher fit.

Remember

A weighted vote of the support vectors.

Worked example: why the width is 2 / |w|
  1. Take a point x+ on the edge w·x + b = +1 and walk straight across the street to x− on the edge w·x + b = −1.
  2. Walking straight across means moving along the unit normal w / |w|: x+ = x− + m × w / |w|, where m is the width.
  3. Put it into the edge equation: w·x− + m |w| + b = 1, and w·x− + b = −1.
  4. −1 + m|w| = 1, so m = 2 / |w|
  5. For the program’s data, w = (0.4, 0.4), |w| = 0.566, width = 3.536, as printed.
Going deeper: Why the hinge loss is a good stand in

The loss we really care about is the 0 or 1 error, which is flat almost everywhere and impossible to optimise directly. The hinge loss max(0, 1 − yf) is the tightest convex upper bound on it that also asks for a margin. Logistic regression uses log(1 + e−yf), another convex bound that never reaches zero, which is why every point influences it. Both are consistent: with enough data and a rich enough model, minimising either gives the Bayes optimal classifier (Bartlett, Jordan and McAuliffe, 2006).

Chapter summary

  1. An SVM picks the boundary with the widest margin. Width = 2 / |w|, so it minimises |w|.
  2. Only the support vectors, the points on or inside the margin, decide the boundary.
  3. The soft margin allows violations with the hinge loss max(0, 1 − y f(x)). Small C means a wider street and more regularisation.
  4. The kernel trick replaces dot products with K(x, z) to draw curved boundaries. RBF is the default kernel.
  5. Tune C and γ together on a log grid, and always scale the features first.
  6. SVC (libsvm) suits up to tens of thousands of rows. Use LinearSVC or SGDClassifier for more.
  7. SVR fits an ε tube and ignores small errors.
