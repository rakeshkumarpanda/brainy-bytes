Lesson 1 of 10

Small trees that fix each other’s mistakes

Source: Freund and Schapire (1997), Friedman, Greedy Function Approximation (2001), Chen and Guestrin, XGBoost (2016), Ke and others, LightGBM (2017), Prokhorenkova and others, CatBoost (2018), The Elements of Statistical Learning chapter 10, and the scikit-learn 1.8 user guide section 1.11.

What it is
Boosting builds a strong model from many weak ones, added one after another. Each new small tree is trained to fix what the model so far still gets wrong. The final model is the sum of all the trees.
Why we need it
A random forest averages independent deep trees and mainly cuts variance. Boosting adds shallow trees in sequence and mainly cuts bias, so it can reach higher accuracy. Gradient boosted trees (XGBoost, LightGBM, CatBoost, HistGradientBoosting) win most competitions on tabular data.
How it works
Start from a constant (the average). Each round: compute the residuals y − F(x), fit a small tree to them, and add a fraction of it (the learning rate) to F. Repeat for hundreds of rounds, and stop when a validation score stops improving.

Real world scenario: a student marking their own practice tests

A student takes a practice test, marks it, and spends the next session only on the questions they got wrong. Then they test again and repeat. Each session is short, but each one targets what is still weak. Boosting trains its trees the same way, and like the student it can over practise the same few odd questions if it never stops.

Lesson 2 of 10

AdaBoost: reweight the hard examples

What it is
AdaBoost (adaptive boosting, Freund and Schapire) was the first practical boosting method. Each round trains a weak classifier on weighted data, gives it a say α based on its weighted error, and increases the weights of the examples it got wrong.
Why we need it
It showed that many classifiers barely better than guessing can be combined into a very accurate one. It is still a good, simple method, and it explains the idea behind all boosting: focus the next learner on the current mistakes.
How it works
With weighted error ε, the say is α = ½ ln((1 − ε)/ε). Wrong points are multiplied by eα, right points by e−α, then all weights are rescaled to sum to 1. The final classifier is sign(Σ αm hm(x)).

Lesson 3 of 10

Gradient boosting: descent in function space

What it is
Gradient boosting (Friedman, 2001) generalises the residual idea to any loss. Each new tree is fitted to the negative gradient of the loss with respect to the current predictions, the direction that lowers the loss fastest.
Why we need it
With squared error the negative gradient is just the residual y − F(x), which is why the hand made version works. With log loss for classification it is y − p, the gap between label and predicted probability. The same algorithm then handles regression, classification, ranking and custom losses.
How it works
F0 = best constant. For m = 1 to M: compute pseudo residuals ri = −∂L/∂F(xi), fit a small tree to them, set each leaf value to the best step for the loss, and update Fm = Fm−1 + η × tree.

Lesson 4 of 10

Learning rate, number of trees and early stopping

What it is
The key settings are the learning rate η (shrinkage), the number of trees, and the size of each tree (max_depth or num_leaves). Unlike a forest, boosting does overfit if you add too many trees.
Why we need it
A smaller learning rate needs more trees but usually reaches a better test score, because many careful steps generalise better than a few big ones. Early stopping picks the number of trees for you by watching a validation set.
How it works
Set a small learning rate (0.05 to 0.1), allow many trees, and turn on early stopping. Keep trees shallow (depth 3 to 6). Add subsampling of rows (subsample 0.8) and features for extra regularisation.

Lesson 5 of 10

XGBoost, LightGBM, CatBoost and HistGradientBoosting

What it is
Modern libraries add speed and regularisation to gradient boosting. XGBoost uses second order gradients and a penalty on leaf values. LightGBM bins features into histograms and grows trees leaf by leaf. CatBoost handles categorical features natively. scikit-learn’s HistGradientBoosting follows the LightGBM design.
Why we need it
They train on millions of rows in minutes, handle missing values, and are the standard choice for tabular data in industry and competitions.
How it works
All four share the same core ideas, so the settings carry over: learning rate, number of trees with early stopping, tree size (max_depth or num_leaves), row and column subsampling, and L1 or L2 penalties.

Worked example: one AdaBoost round
  1. Eight points, each weight 0.125. The best stump misclassifies 2 points.
  2. Weighted error ε = 2 × 0.125 = 0.25.
  3. α = ½ ln(0.75 / 0.25) = ½ ln 3 = 0.549.
  4. wrong: 0.125 e0.549 = 0.2165, right: 0.125 e−0.549 = 0.0722
  5. The sum is 2 × 0.2165 + 6 × 0.0722 = 0.866. Dividing gives 0.25 and 0.083, as the program prints.
Going deeper: Why boosting works, and when it fails

Schapire (1990) proved that weak learnability implies strong learnability: any learner slightly better than chance can be boosted to arbitrary accuracy. AdaBoost’s training error falls exponentially, at most exp(−2Σγm2) where γm = 0.5 − εm. Its test error often keeps improving after training error reaches zero, explained by the growth of the voting margins (Schapire and others, 1998). Friedman, Hastie and Tibshirani (2000) showed AdaBoost is forward stagewise fitting of an additive model under exponential loss. The exponential loss punishes wrong points heavily, so AdaBoost is sensitive to label noise, and Long and Servedio (2010) proved that any convex potential booster can be defeated by random label noise. Gradient boosting with log loss and shrinkage is more robust.

Chapter summary

  1. Boosting adds small trees in sequence, each fixing what the model still gets wrong. It mainly reduces bias.
  2. AdaBoost reweights wrong examples by eα, with α = ½ ln((1 − ε)/ε).
  3. Gradient boosting fits each tree to the negative gradient of the loss: the residual y − F for squared error, y − p for log loss.
  4. A small learning rate with many trees generalises better. Boosting overfits with too many trees, so use early stopping.
  5. Keep trees shallow, subsample rows and features, and add L1 or L2 penalties.
  6. XGBoost, LightGBM, CatBoost and HistGradientBoosting are fast implementations of the same idea.
  7. Compare with a forest and a linear baseline: boosting is often, not always, the best.
