Lesson 1 of 9

From prediction to control: action values and SARSA

Source: Sutton and Barto (2018) sections 5.3, 5.4 and 6.4, and Rummery and Niranjan (1994).

What it is
To choose actions without a model, learn action values Q(s, a) instead of state values, because picking argmaxa Q(s, a) needs no knowledge of where actions lead. SARSA is TD control: after each step it updates Q(s, a) towards r + γQ(s′, a′), where a′ is the next action the agent actually takes. Its name lists what one update uses: S, A, R, S′, A′.
Why we need it
With state values alone, the agent would need the model to look one step ahead. Action values carry that information directly. SARSA learns while acting, keeps exploring with ε greedy, and slowly improves its own policy, which is generalised policy iteration with samples.
How it works
Initialise Q to 0. Choose a from s ε greedily. Each step: take a, observe r and s′, choose a′ from s′ ε greedily, update Q(s, a) += α[r + γQ(s′, a′) − Q(s, a)], then move on with s ← s′ and a ← a′. Use Q = 0 for terminal states.

In the exam
On the cliff walk SARSA earns an average of −24.42 per episode over its last 100 episodes while still exploring with ε = 0.1. Its greedy path climbs to the top row before heading right. The path is longer than needed, but a random step there costs one move, not a fall of −100.

Lesson 2 of 9

Q learning: learning the best policy while exploring

Source: Watkins (1989), Watkins and Dayan, Q-learning (1992), and Sutton and Barto (2018) section 6.5.

What it is
Q learning updates towards r + γ maxa′ Q(s′, a′): the value of the best next action, whatever action the agent takes next. It is off policy: it learns the optimal greedy policy (the target policy) while following an exploring policy (the behaviour policy).
Why we need it
It is the most famous RL algorithm and the basis of DQN. It converges to q* in a table as long as every state and action keeps being tried and the step sizes shrink suitably, no matter how the agent explores. That freedom lets it learn from old data, from other agents or from humans.
How it works
Same loop as SARSA, but the target uses the max over next actions, so the next action does not need to be chosen before the update. Act ε greedily, update with the max, and act greedily once training is done.
Download this program (.py)Save it, open it in any editor and run it with python3 q_learning_cliff.py.
In the exam
Q learning finds the truly shortest path, straight along the cliff edge (13 moves, reward −13). Yet while it still explores, its average reward is only −70.01, far worse than SARSA’s, because ε greedy steps near the edge keep sending it over the cliff. Q learning values the policy it would follow without exploring, SARSA values the policy it really follows.
Q learning updateExam favourite
Q(S, A) ← Q(S, A) + α[R + γ maxa Q(S′, a) − Q(S, A)]
The sample version of the Bellman optimality equation.
Lesson 3 of 9

Expected SARSA, and comparing the three

Source: van Seijen, van Hasselt, Whiteson and Wiering, A Theoretical and Empirical Analysis of Expected Sarsa (2009).

What it is
Expected SARSA replaces the sampled next action with the average over what the policy might do: target r + γ Σa′ π(a′|s′) Q(s′, a′). With a greedy target policy it becomes Q learning, and with the behaviour policy it is an on policy method like SARSA, but with less noise.
Why we need it
Removing the randomness of the next action lowers the variance of every update, so expected SARSA can use larger step sizes and usually learns faster and more stably than SARSA, at a little more computation per step.
How it works
Compute the ε greedy probabilities of the next state’s actions, take the probability weighted average of their Q values, and use it in the target.

Lesson 4 of 9

Maximisation bias and double Q learning

Source: van Hasselt, Double Q-learning (NeurIPS 2010), and Sutton and Barto (2018) section 6.7, example 6.7.

What it is
Taking the max of noisy estimates overestimates the max of the true values: if all true values are 0, some estimates will be above 0 by chance, and the max picks them. This maximisation bias makes Q learning favour actions whose values are merely uncertain. Double Q learning keeps two tables: one chooses the best next action, the other estimates its value.
Why we need it
Overestimation can steer an agent towards bad but noisy options and slow learning a lot. The double estimator removes the bias, and the same idea in Double DQN improved Atari results substantially.
How it works
Keep Q1 and Q2. Each step, flip a coin and update one of them, say Q1, with the target r + γQ2(s′, argmaxa Q1(s′, a)). Act ε greedily on Q1 + Q2.

In the exam
In state A, going left leads to B, where every action pays −0.1 on average with a lot of noise, so left is a mistake. Plain Q learning still goes left in 86% of episodes at episode 10 and 16% at episode 300, because the max over B’s noisy estimates looks positive. Double Q learning goes left only 40% of the time at episode 10 and settles at the best possible 5% (the random ε moves) by episode 50.

Worked example: the same transition, three targets
  1. Q(s, a) = 2, reward 1, γ = 0.9, α = 0.5. Next state values Q(s′, ·) = 3, 1, 1, 1, and the agent will next take an action worth 1.
  2. Q learning: target 1 + 0.9 × 3 = 3.7, new Q = 2 + 0.5 × 1.7 = 2.85
  3. SARSA: target 1 + 0.9 × 1 = 1.9, new Q = 2 + 0.5 × (−0.1) = 1.95
  4. Expected SARSA with ε = 0.2: probabilities 0.85, 0.05, 0.05, 0.05, so E[Q] = 2.55 + 0.15 = 2.7.
  5. Expected SARSA: target 1 + 0.9 × 2.7 = 3.43, new Q = 2 + 0.5 × 1.43 = 2.715
Going deeper: Off policy learning with importance sampling

Monte Carlo and n step methods can also learn off policy, but their targets contain actions chosen by the behaviour policy b, not the target policy π. The fix is to reweight each return by the importance sampling ratio ρ = Πk π(Ak|Sk) / b(Ak|Sk) over the actions after the first. Ordinary importance sampling is unbiased but can have huge variance, while weighted importance sampling divides by the sum of the ratios and is biased but far steadier. One step Q learning avoids ratios altogether because its target already uses the target policy’s choice, the max. This is why Q learning is the natural off policy method, and why multi step off policy methods such as Retrace need careful corrections.

Chapter summary

  1. Control needs action values Q(s, a), because argmax over Q needs no model.
  2. SARSA (on policy) targets r + γQ(s′, a′) with the action really taken next. It learns safe behaviour under exploration.
  3. Q learning (off policy) targets r + γ max Q(s′, ·). It learns q* while exploring, walks the cliff edge, and earns less while learning.
  4. Expected SARSA averages over next actions: lower variance, often the best of both.
  5. Maximisation bias: the max of noisy estimates is too high. Double Q learning selects with one table and evaluates with another.
  6. Convergence needs every pair tried often (GLIE) and suitable step sizes.
