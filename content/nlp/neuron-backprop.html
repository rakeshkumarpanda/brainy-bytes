A neuron: weigh, add, squash

The lecture moves from one input to two. Each flower has a length and a width, and is red (type 1) or blue (type 0). A mystery flower of length 4.5 and width 1 has an unknown colour. A neuron answers with a number between 0 and 1.

One idea, four depths

A neuron is a tiny voting machine. Each input gets a vote strength (the weight). It adds the votes and then says "how sure am I" as a number from 0 to 1.

One sigmoid neuron is logistic regression: a linear score z = w·x + b followed by σ. Its output is read as P(class 1 | x), and the decision boundary σ(z) = 0.5 is the straight line z = 0.

With cross entropy loss, logistic regression is a convex problem whose gradient is (σ(z) − y)x. The notebook uses squared error instead, which works here but is not convex and gives weaker gradients when the neuron is confidently wrong.

Every output layer of a word2vec, RNN or transformer model is this same unit, generalised from σ to softmax over a vocabulary. Calibration of these probabilities and their behaviour far from the training data are active research topics.

Lesson 2 of 4

Why the sigmoid, and where to draw the line

A plain linear score can be any number from −∞ to +∞. A value like 12 or −7 has no probabilistic meaning and no natural cutoff. The sigmoid fixes that: it squeezes the score into (0, 1), so we can read it as a probability and use 0.5 as the cutoff.

Decision rule
class 1 if σ(z) ≥ 0.5, which is the same as z ≥ 0
The boundary is the line w₁·length + w₂·width + b = 0.
Inverse of the sigmoid (logit)
z = ln p1 − p
p = 0.8 needs z = ln 4 = 1.386.
Symmetry
σ(−z) = 1 − σ(z)
Used again in negative sampling.

Real world scenario: spam filter

An email filter adds up weighted clues: the word "free", a strange sender, many links. The sigmoid turns the total into "92 percent spam". The filter only moves the mail when the number passes a threshold, and that threshold can be moved to make it stricter or more relaxed.

Remember
The 0.5 threshold is a choice, not a law. A cancer screening test may use 0.2 to miss fewer cases. Changing the threshold moves the decision line without retraining.
Lesson 3 of 4

Backpropagation is the chain rule

To train, the notebook picks a random flower, predicts, measures the squared cost and nudges w₁, w₂ and b downhill. The slope of the cost with respect to each weight comes from the chain rule, one link at a time. The notebook names every link, and so do we.

The three linksExam favourite
∂cost∂w₁ = ∂cost∂pred · ∂pred∂z · ∂z∂w₁ = 2(pred − target) · σ′(z) · length
For w₂ the last link is width, for b it is 1.
Slope of the sigmoidExam favourite
σ′(z) = σ(z)(1 − σ(z))
Largest at z = 0, where it is 0.25. Called sigmoid_p in the notebook.
Worked step on the blue flower (2, 1) with η = 0.1
  1. Forward: z = 1.5, pred = 0.8176, cost = (0.8176 − 0)² = 0.6684.
  2. dcost/dpred = 2 × 0.8176 = 1.6351. dpred/dz = 0.8176 × 0.1824 = 0.1491.
  3. dcost/dz = 1.6351 × 0.1491 = 0.2439. dcost/dw₁ = 0.2439 × 2 = 0.4878.
  4. w₁ ← 0.5 − 0.1 × 0.4878 = 0.4512. w₂ and b also drop, and the next prediction is lower
Common mistake
Do not forget the σ′(z) link. Without it you are differentiating a straight line, not a neuron.
In the exam
A typical question gives ŷ = σ(wx + b) or tanh(wx + b), one data point and the cost, and asks for ∂L/∂w, the predicted value, and the direction w moves.

The flowers notebook, line by line

The class notebook trains the neuron for 10,000 steps, each on one random flower, with learning rate 0.1. Every 100 steps it adds the cost over all eight flowers to a list so that you can plot it going down. After training the mystery flower scores 0.9917: red.

flowers 1.ipynb, the training cells (numpy and matplotlib parts trimmed)
data = [[3, 1.5, 1], [2, 1, 0], [4, 1.5, 1], [3, 1, 0],        [3.5, .5, 1], [2, .5, 0], [5.5, 1, 1], [1, 1, 0]]mystery_flower = [4.5, 1]def sigmoid(x):    return 1/(1+np.exp(-x))def sigmoid_p(x):    return sigmoid(x) * (1-sigmoid(x))def train():    w1, w2, b = np.random.randn(), np.random.randn(), np.random.randn()    iterations, learning_rate = 10000, 0.1    for i in range(iterations):        point = data[np.random.randint(len(data))]        z = point[0] * w1 + point[1] * w2 + b        pred = sigmoid(z)        target = point[2]        dcost_dpred = 2 * (pred - target)        dpred_dz = sigmoid_p(z)        dcost_dz = dcost_dpred * dpred_dz        w1 = w1 - learning_rate * dcost_dz * point[0]        w2 = w2 - learning_rate * dcost_dz * point[1]        b = b - learning_rate * dcost_dz * 1    return w1, w2, bw1, w2, b = train()z = w1 * mystery_flower[0] + w2 * mystery_flower[1] + bprint(sigmoid(z))print("close to 0 -> blue, close to 1 -> red")

What each part does
  1. np.random.randn() gives each weight a random start, so every run begins somewhere different.
  2. One random flower per step is stochastic gradient descent: cheap, noisy steps that still head downhill on average.
  3. The cost list is only for watching. It plays no part in the updates.
  4. The final picture colours a 20 × 20 grid by the prediction. The colours split along the straight line where z = 0.
Going deeper: squared error against cross entropy for a sigmoid

With squared error the gradient is 2(σ − y)σ(1 − σ)x. If the neuron is confidently wrong, for example σ = 0.001 when y = 1, the factor σ(1 − σ) is about 0.001 and learning almost stops. With binary cross entropy L = −[y ln σ + (1 − y) ln(1 − σ)] the σ′ term cancels and the gradient is simply (σ − y)x, strong exactly when the mistake is big. That is why classification layers use cross entropy, and why the RNN chapters do too.
