Tokens and types

Two words you will use all through the course. A token is one occurrence of a word in running text. A type is a distinct word. "the cat sat on the mat" has 6 tokens but 5 types, because "the" appears twice. The vocabulary of a corpus is its set of types.

Tokens and typesExam favourite
N = number of tokens,   V = |vocabulary| = number of types
FreqDist calls these N() (outcomes) and B() (samples).
Type token ratio
TTR = VN
Higher means more varied vocabulary. It falls as a text gets longer, so only compare texts of similar length.

Words become numbers

A classmate in lecture 2 put it plainly: computers understand only numbers, so give each vocabulary word an index ("water" → 1) and count. That is exactly how every NLP system starts, from n-gram models to transformers.

Sentence segmentation

Splitting at every full stop sounds easy until you meet "Dr.", "p.m.", "3.50" or "U.S.". The notebook used NLTK's Punkt sentence tokenizer. Punkt is unsupervised: it was trained on a large amount of plain English text and learned which words are usually abbreviations, which pairs of words go together, and which words usually start a sentence. The pretrained English model ships with NLTK, so no hand written list is needed.

Python with NLTK, as run in the class notebook
import nltknltk.download('punkt_tab')from nltk.tokenize import sent_tokenizedata = "All work and no play make Dr. jack a dull boy. It's a beautiful day out there in Jodhpur. Don't you think, it will rain today?"sentences = sent_tokenize(data)print(sentences)
Output recorded in the notebook
['All work and no play make Dr. jack a dull boy.', "It's a beautiful day out there in Jodhpur.", "Don't you think, it will rain today?"]

Three sentences, with "Dr." correctly kept inside the first one even though the next word "jack" is lower case. The animation lets you switch the rules on and off.

Remember
Full stops are ambiguous in English: end of sentence, abbreviation, decimal point, or part of an email address. Segmentation is a classification problem for every full stop.

Word tokenisation

Word tokenisation splits a sentence into tokens. NLTK's word_tokenize first splits sentences with Punkt and then applies the Penn Treebank conventions to each sentence.

ConventionExampleWhy
Punctuation is its own tokenboy. → boy, .So "boy" and "boy." are one type
Contractions split offDon't → Do, n't   It's → It, 'sn't is the word not, 's can be is or a possessive

Why tokenisation is harder than it looks

  • Hyphens and compounds: state-of-the-art, New Delhi, ice cream. One token or several?
  • Numbers, dates and links: 3.50, 28/10/2026, www.iitj.ac.in should not be cut at the dots.
  • Languages without spaces: Chinese and Japanese need a segmenter just to find word boundaries.
  • Rich morphology and code mixing: Hindi and Marathi attach many endings, and Indian social media mixes Hindi and English in one sentence.
Real world scenario: a search engine for a railway helpdesk

Users type "can't book tatkal", "cannot book Tatkal" and "cant book tatkal". If the tokenizer keeps "can't" whole and lower casing is off, these become three different queries. Splitting the contraction (ca, n't), lower casing and mapping n't and not to one form makes all three match the same help article.

Lesson 4 of 5

Beyond words: subword tokens

A word level vocabulary has a hard edge. Any word not seen in training is out of vocabulary (OOV), and chapter 4 shows how badly that hurts a language model. Modern systems avoid the edge by splitting rare words into smaller pieces.

Byte pair encoding (Sennrich et al., 2016) on a tiny corpus
  1. Start with characters plus an end of word mark: low ×5, lower ×2, newest ×6, widest ×3.
  2. Count adjacent pairs, weighted by word count. e s appears 6 + 3 = 9 times, the most frequent pair.
  3. Merge it into one symbol es, then count again. es t (9) and est _ (9) come next.
  4. Then l o (5 + 2 = 7). After a few thousand merges, common words are single tokens and rare words split into known pieces.
One idea, four depths

A computer reads text by cutting it into pieces called tokens, usually words and punctuation marks. It then gives every different piece a number.

Sentence segmentation and word tokenisation are rule or model based. Types are distinct tokens, and the vocabulary is the set of types. Unknown words in new text are a problem for word level models.

Subword tokenisers such as BPE, WordPiece (BERT) and unigram language model tokenisation (SentencePiece) learn a vocabulary of pieces from data, so any word can be written with known pieces and OOV disappears. The vocabulary size, often 30,000 to 100,000, trades sequence length against embedding table size.

Tokenisation affects fairness and cost: languages written in non Latin scripts are often split into many more tokens per sentence, so they cost more and fit less text in a context window. Research looks at tokenizer free byte models, better multilingual vocabularies and how token boundaries affect arithmetic and spelling in large models.

Reading text files in Python

The notebook also practised reading a corpus from a file, because real corpora live on disk. Three habits are worth keeping.

Python, from the notebook file exercise
with open('document.txt') as f:      # with closes the file for you    lines = f.readlines()             # a list, one item per lineprint(lines[-1])                      # the last linelast = ""with open('document.txt') as f:    for line in f:                    # read one line at a time        last = line                   # only the newest line is keptprint(last)

Good Luck!
Good Luck!
  • Use with open(...). The file is closed even if an error happens inside the block.
  • read() gives one long string, readlines() a list of lines. For a huge corpus loop over the file object so only one line is in memory.
  • Modes: "r" read, "w" overwrite, "a" append to the end.
