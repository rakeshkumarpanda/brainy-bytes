Lesson 1 of 5

The idea of attention

Attention fixes the bottleneck. On each step of the decoder, it uses a direct connection to the encoder to focus on a particular part of the source sentence. Instead of one fixed summary vector, each decoder state gets a different, dynamic context, which is a function of all the encoder states.

Translating "il a m’ entarté" with attention
  1. The encoder produces one state for each source word: il, a, m’, entarté.
  2. To write "he", the decoder state compares itself with all four. The scores are highest for "il", so most attention goes there.
  3. The weighted mix of encoder states (the context) is joined with the decoder state to predict "he".
  4. For "hit" and "pie" the attention moves to "entarté", the word that means "hit with a pie". One source word can feed several target words.

Real world scenario: a human translator with the source open

A professional translator does not read a long paragraph once, close the book and write the translation from memory. They keep the source open and look back at the relevant phrase for every sentence they write. Attention gives the decoder the same open book.

Lesson 2 of 5

Attention in equations

Let the encoder states be h1, ..., hN ∈ ℝd and the decoder state at step t be st ∈ ℝd. Attention has three steps: score, normalise, mix.

1. ScoresExam favourite
et = [stTh1, ..., stThN] ∈ ℝN
One dot product per source position.
2. Attention distributionExam favourite
αt = softmax(et) ∈ ℝN
Non-negative weights that add to 1.
3. Attention output (context)Exam favourite
at = ∑i=1N αit hi ∈ ℝd
A weighted average of the encoder states.
4. Use it
ŷt = softmax(Wo[at, st])
Concatenate the context with the decoder state and continue as before.
Common mistake
The weights depend on the decoder state, so they change at every output step. That is what makes the context dynamic. A common exam slip is to compute one set of weights for the whole sentence.
Going deeper: attention as soft dictionary lookup

A dictionary returns the value whose key matches the query exactly. Attention compares the query st with every key hi, turns the similarities into weights with softmax, and returns a weighted average of the values. In the general form keys and values can differ: output = ∑ softmax(q·ki) vi. Transformers use exactly this with learned projections for q, k and v.

The lecture problem, fully worked

A sequence-to-sequence RNN uses dot-product attention. The encoder outputs four hidden states of dimension 2: [2, 0], [−1, 2], [1, −1] and [0, 1]. At one decoding step the decoder state is [1, −2]. Compute the context vector.

Step by step
  1. Scores, s·hi: 1×2 + (−2)×0 = 2, then 1×(−1) + (−2)×2 = −5, then 1×1 + (−2)×(−1) = 3, then 1×0 + (−2)×1 = −2.
  2. Exponentials: e2 = 7.3891, e−5 = 0.0067, e3 = 20.0855, e−2 = 0.1353. Sum = 27.6167.
  3. α = (0.2676, 0.0002, 0.7273, 0.0049)
  4. First component: 0.2676 × 2 + 0.0002 × (−1) + 0.7273 × 1 + 0.0049 × 0 = 1.2622.
  5. Second component: 0.2676 × 0 + 0.0002 × 2 + 0.7273 × (−1) + 0.0049 × 1 = −0.7219.
  6. at ≈ [1.262, −0.722]
hiscoreweightreading
[2, 0]20.2676second most relevant
[−1, 2]−50.0002points away from s, ignored

In the exam
Show the scores, the softmax and the weighted sum as three separate lines. Keep 4 decimals in the weights, and check that they add to 1 (0.2676 + 0.0002 + 0.7273 + 0.0049 = 1.0000).
Lesson 4 of 5

Ways to compute the scores

The dot product needs the decoder and encoder states to have the same size and gives no learnable control. Several variants exist. All of them compute a score ei from hi and s, then use the same softmax and weighted sum.

Basic dot productExam favourite
ei = sThi
Needs ds = dh. No parameters.
Multiplicative (bilinear, Luong)Exam favourite
ei = sTW hi,   W ∈ ℝds × dh
Works for different sizes. ds × dh parameters.
Reduced rank multiplicative
ei = (Us)T(Vhi),   U ∈ ℝk × ds, V ∈ ℝk × dh
k much smaller than d. The form transformers use.
Additive (Bahdanau)Exam favourite
ei = vT tanh(W1hi + W2s)
A small neural network scores each pair. da is its hidden size.
Scaled dot product
ei = sThi√d
Keeps scores from growing with d, so the softmax does not saturate.
Scaled scores on the lecture problem
  1. d = 2, so divide the scores 2, −5, 3, −2 by √2 = 1.414.
  2. Scaled scores: 1.414, −3.536, 2.121, −1.414.
  3. α = (0.3232, 0.0023, 0.6554, 0.0191), context ≈ [1.300, −0.632]
  4. The weights spread out a little because the scores are closer together.

Why attention is so helpful

Attention significantly improved NMT and quickly spread to every encoder-decoder task, for example abstractive summarisation (Rush et al. 2015).

BenefitWhy
better translationsthe decoder can focus on the relevant source words
solves the bottleneckthe decoder reads the source directly instead of through one vector
helps vanishing gradientsthere is a shortcut from every decoder step to every source word
interpretabilitythe attention weights show what the decoder was looking at
alignment for freethe model learns which source word matches which target word without being told
Soft alignment
  1. Plot αt for every output step t as a row of a matrix: target words down, source words across.
  2. For English to French the matrix is close to the diagonal, because word order is similar.
  3. "European Economic Area" and "zone économique européenne" show a reversed block: the model learned the adjective order.
  4. No one supplied alignments, the network learned them from translation pairs only
One idea, four depths

When the model writes each translated word, it looks back at the source sentence and decides which words to pay attention to, like a person pointing at the words they are translating.

Score each encoder state against the decoder state, softmax the scores, and take the weighted average as the context. Variants differ only in the score: dot, multiplicative, additive or scaled.

Attention is a differentiable soft lookup: a query is compared with keys and returns a mix of values. Its cost is O(N) per decoder step, O(NT) for a translation, and it gives direct gradient paths between any two positions.

Self-attention applies the same lookup within one sequence. Removing recurrence entirely and stacking multi-head self-attention gives the transformer (Vaswani et al. 2017), the basis of BERT, GPT and every current large language model.
