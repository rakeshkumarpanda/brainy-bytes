Enum

Some values come from a fixed menu: days of the week, traffic light colours, coffee sizes. An enum turns that menu into a type, so nobody can order a size that does not exist.

Part 1

🍽️Why enums

An enum is a type with a fixed list of named values. It arrived in Java 5.

Before enums, people used int constants like static final int SMALL = 1;. Nothing stopped someone from passing 42 where a size was expected. With an enum, the compiler only accepts the listed values.

Only real sizes are possible · ▶ Runs
enum Size { SMALL, MEDIUM, LARGE }
class Main {
    static int price(Size s) {
        return switch (s) {
            case SMALL -> 80;
            case MEDIUM -> 120;
            case LARGE -> 160;
        };
    }
    public static void main(String[] args) {
        System.out.println(price(Size.MEDIUM));
        // price(42);  would not compile: 42 is not a Size
    }
}
Output
120
Java enums are far more powerful than C enums. They are full classes, so they can have fields, constructors and methods, and they can implement interfaces.
Part 2

📝Declaring and using an enum

A traffic light · ▶ Runs
enum Light { RED, AMBER, GREEN }
class Main {
    public static void main(String[] args) {
        Light now = Light.GREEN;
        System.out.println(now);
        System.out.println(now == Light.GREEN);
    }
}
Output
GREEN
true
  • Each constant is implicitly public static final, and it is an object of the enum type.
  • Printing a constant prints its name, because Enum's toString() returns the name.
  • Constants can be compared safely with ==, because each exists exactly once.
  • An enum can be declared at top level or inside a class, but not inside a method (before Java 16). Top level enums may be public or default. Nested ones may also be private, protected or static.
  • The semicolon after the last constant is optional, unless more members follow.
Java snippet
enum Light { RED, AMBER, GREEN }          // fine
enum Light { RED, AMBER, GREEN; }         // also fine
enum Light { RED, AMBER, GREEN; int x; }  // semicolon required before other members
Part 3

🎛️Enums in switch

Enums have been allowed in switch since Java 5. Inside the cases, write the constant name without the enum name.

Classic switch on an enum · ▶ Runs
enum Light { RED, AMBER, GREEN }
class Main {
    public static void main(String[] args) {
        for (Light l : Light.values()) {
            switch (l) {
                case RED: System.out.println("Stop"); break;
                case AMBER: System.out.println("Get ready"); break;
                case GREEN: System.out.println("Go");
            }
        }
    }
}
Output
Stop
Get ready
Go
Every label must be a constant of that enum · ❌ Does not compile
enum Light { RED, AMBER, GREEN }
class Main {
    public static void main(String[] args) {
        Light l = Light.RED;
        switch (l) { case RED: break; case BLUE: break; }
    }
}
❌ Compile error
cannot find symbol
symbol:   variable BLUE
A switch expression over an enum that lists every constant needs no default branch. If someone later adds a constant, the compiler points at every switch that forgot it.
Part 4

🧬java.lang.Enum

Every enum is automatically a child of java.lang.Enum. Since a class can extend only one class, an enum cannot extend anything else, and nobody can extend an enum.

An enum cannot extend a class · ❌ Does not compile
class Base { }
enum Light extends Base { RED }
❌ Compile error
'{' expected

The compiler's message here is only "'{' expected", because enum syntax has no place for extends at all.

An enum can still implement any number of interfaces.

Implementing an interface · ▶ Runs
interface Describable { String describe(); }
enum Planet implements Describable {
    MERCURY, EARTH;
    public String describe() { return name().charAt(0) + name().substring(1).toLowerCase() + " is planet number " + (ordinal() + 1) + " in this list"; }
}
class Main {
    public static void main(String[] args) {
        for (Planet p : Planet.values()) System.out.println(p.describe());
    }
}
Output
Mercury is planet number 1 in this list
Earth is planet number 2 in this list

From Enum every constant inherits name(), ordinal(), compareTo(), equals(), hashCode() and toString(). Enums are also Comparable and Serializable.

Part 5

🔢values(), ordinal() and valueOf()

MethodGives
Day.values()an array of all constants, in declaration order (added by the compiler)
d.ordinal()the position of the constant, starting at 0
d.name()the exact name as written
Day.valueOf("MON")the constant with that exact name
a.compareTo(b)the difference of their ordinals
Walking through the week · ▶ Runs
enum Day { MON, TUE, WED, THU, FRI, SAT, SUN }
class Main {
    public static void main(String[] args) {
        for (Day d : Day.values()) System.out.print(d + ":" + d.ordinal() + " ");
        System.out.println();
        Day d = Day.valueOf("FRI");
        System.out.println(d.compareTo(Day.MON) + " " + Day.values().length);
    }
}
Output
MON:0 TUE:1 WED:2 THU:3 FRI:4 SAT:5 SUN:6 
4 7
valueOf is case sensitive · 💥 Crashes at run time
enum Day { MON, TUE }
class Main {
    public static void main(String[] args) { System.out.println(Day.valueOf("mon")); }
}
💥 Runtime error
Exception in thread "main" java.lang.IllegalArgumentException: No enum constant Day.mon
Do not store ordinals in a database. Adding a constant in the middle changes every number after it. Store the name instead.
Part 6

🏗️Constructors, fields and methods

An enum can hold data. Give it fields and a constructor, and pass values in brackets after each constant.

Coffee sizes with prices · ▶ Runs
enum Coffee {
    SMALL(80), MEDIUM(120), LARGE(160);              // each calls the constructor
    private final int price;
    Coffee(int price) {
        this.price = price;
        System.out.println("constructor for " + name());
    }
    int price() { return price; }
}
class Main {
    public static void main(String[] args) {
        System.out.println("main starts");
        System.out.println(Coffee.LARGE.price());
        System.out.println(Coffee.SMALL.price());
    }
}
Output
main starts
constructor for SMALL
constructor for MEDIUM
constructor for LARGE
160
80
  • The constructor runs once for every constant, when the enum class is loaded. That is why all three lines print as soon as the enum is first used.
  • Enum constructors are always private. You can never call new Coffee(100).
  • Constants with no brackets use the no-argument constructor.
No new for enums · ❌ Does not compile
enum Coffee { SMALL; }
class Main {
    public static void main(String[] args) { Coffee c = new Coffee(); }
}
❌ Compile error
enum classes may not be instantiated
Mixing constructors · ▶ Runs
enum Rating {
    BAD, OKAY("meh"), GREAT("wow");
    final String sound;
    Rating() { this("silence"); }
    Rating(String s) { sound = s; }
}
class Main {
    public static void main(String[] args) {
        for (Rating r : Rating.values()) System.out.println(r + " → " + r.sound);
    }
}
Output
BAD → silence
OKAY → meh
GREAT → wow
Part 7

🎭Constant-specific bodies

Each constant can override a method with its own body. Declare the method abstract in the enum and every constant must provide it.

A calculator where each operation knows its job · ▶ Runs
enum Op {
    PLUS("+")  { int apply(int a, int b) { return a + b; } },
    MINUS("-") { int apply(int a, int b) { return a - b; } },
    TIMES("×") { int apply(int a, int b) { return a * b; } };
    final String symbol;
    Op(String symbol) { this.symbol = symbol; }
    abstract int apply(int a, int b);
}
class Main {
    public static void main(String[] args) {
        for (Op op : Op.values()) System.out.println("7 " + op.symbol + " 3 = " + op.apply(7, 3));
    }
}
Output
7 + 3 = 10
7 - 3 = 4
7 × 3 = 21
Constant-specific bodies replace long switch statements. Adding a new operation means adding one constant, not hunting down every switch.
Part 8

🚀An enum with main

An enum is a class, so it can have a main method and be run directly. Remember that constants must come first.

Running an enum · ▶ Runs
enum Fish {
    STAR, GUPPY;
    public static void main(String[] args) {
        System.out.println("Enum main, " + Fish.values().length + " fish");
    }
}
Output
Enum main, 2 fish
Constants must be the first thing · ❌ Does not compile
enum Fish {
    static int count;
    STAR, GUPPY;
}
❌ Compile error
enum constant expected here

Part 10

🗃️EnumSet and EnumMap

Java has collections built specially for enums. They are faster and smaller than general purpose ones, because they use the ordinal internally.

Working days and a timetable · ▶ Runs
enum Day { MON, TUE, WED, THU, FRI, SAT, SUN }
class Main {
    public static void main(String[] args) {
        EnumSet<Day> weekend = EnumSet.of(Day.SAT, Day.SUN);
        EnumSet<Day> work = EnumSet.complementOf(weekend);
        System.out.println(work);
        System.out.println(EnumSet.range(Day.TUE, Day.THU));
        EnumMap<Day, String> gym = new EnumMap<>(Day.class);
        gym.put(Day.FRI, "legs");
        gym.put(Day.MON, "arms");
        System.out.println(gym);              // always in declaration order
    }
}
Output
[MON, TUE, WED, THU, FRI]
[TUE, WED, THU]
{MON=arms, FRI=legs}
