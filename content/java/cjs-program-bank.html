🔢Arithmetic, swaps and characters

15 / 2 is 7 in Java because both operands are int. Cast one of them first, (double) a / b, to get 7.5. Casting the result instead, (double) (a / b), gives 7.0, because the fraction was already lost.

Part 3

🧮Number programs

A factor of n divides it with no remainder. Counting digits uses a do while loop so that 0 counts as one digit. The closed path program counts the loops in each digit: 0, 4, 6 and 9 have one, 8 has two, so 6784 → 1 + 0 + 2 + 1 = 4.

Math.pow always returns a double, so Math.pow(3, 10) prints 59049.0. For whole number powers, multiply in a loop with a long, or use the fast power method from the methods chapter.
Part 4

🔄Reverse, palindrome, Armstrong and neon

Reversing uses n % 10 to take the last digit and n / 10 to drop it. Java's % keeps the sign, so −123 becomes −321 with no special case, and 120 becomes 21 because a leading zero has no value. The session's tricky input is 1534236469: its reverse, 9646324351, is larger than Integer.MAX_VALUE (2147483647), so the program must build the reverse in a long and check the range.

Armstrong

The sum of each digit raised to the number of digits equals the number: 1³ + 5³ + 3³ = 1 + 125 + 27 = 153.

Neon

The digits of the square add up to the number: 9² = 81 and 8 + 1 = 9.

Part 5

🔤String programs

Two items need a careful reading. "aabbbccccdddda" must print a:2 b:3 c:4 d:4 a:1, so it counts runs of the same letter, not totals, which is why the final a stands alone. "aa" in maaamaaahhaaaaa occurs 8 times only if matches may overlap: "aaa" holds "aa" twice, and "aaaaa" four times. Searching again from index + 1 instead of index + 2 is what allows the overlap.

🔁Repeated characters and words

"First repeating character" has two common meanings, and interviewers accept either if you say which one you chose. In "data driven tests" the first letter met for a second time while scanning is a, at index 3. The earliest letter that repeats at all is d, because d appears again in "driven". The program prints both.

Set.add returns false when the value is already there. That single call both checks and records, so the first repeated word is found in one pass.

Part 8

🐘Running totals and numbers beyond long

The running total item starts at 5 and adds each value of [−4, 1, 3, 5]: 1, 2, 5, 10, then adds those results: 1 + 2 + 5 + 10 = 18. For numbers beyond long (about 9.2 × 1018), Java has BigInteger, which grows as needed and uses methods instead of operators.

Python's int has no size limit, and JavaScript has BigInt with literals such as 12n. In Java, Long.MAX_VALUE + 1 silently wraps to the most negative long, with no exception.
