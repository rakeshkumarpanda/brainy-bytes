Part 1

🏷️Identifiers

An identifier is any name you invent in a program. It can name a class, a method, a variable or a label.

Spot the identifiers
class Test {                       // Test is an identifier
    public static void main(String[] args) {   // main, String, args are identifiers
        int x = 10;                    // x is an identifier
    }
}

The rules

  1. Allowed characters are letters, digits, the dollar sign $ and the underscore _. Letters from other alphabets also work, but stick to plain English letters so everyone can type your names.
  2. An identifier cannot start with a digit. total123 is fine and 123total is not.
  3. Java is case sensitive. number, Number and NUMBER are three different names.
  4. There is no length limit, but names longer than about 15 characters get tiring to read.
  5. Reserved words such as int or if cannot be used as names.
  6. Names of built-in classes such as String or Runnable are legal names, but using them confuses every reader.

int Number = 20;
int NUMBER = 30;
System.out.println(number + " " + Number + " " + NUMBER);

From Java 9 to Java 21 a single underscore _ on its own was not allowed as a name. Since Java 22 it has a new job: it marks an unnamed variable, a placeholder you promise never to read, as in catch (Exception _). Names that merely contain an underscore, like max_value, have always been fine.

🚫Reserved words

Some words already have a fixed meaning in Java, so you cannot use them as names. Classic Java has 53 reserved words: 50 keywords plus 3 reserved literals.

Data types (8)

byte short int long float double boolean char

Flow control (11)

if else switch case default while do for break continue return

Modifiers (11)

public private protected static final abstract synchronized native strictfp transient volatile

Exception handling (6)

try catch finally throw throws assert

Class related (6)

class interface extends implements package import

Object related (4)

new instanceof super this

Return type (1)

void says a method returns nothing.

Unused (2)

goto const are reserved but do nothing, so nobody can bring their messy C habits back.

Newer keyword (1)

enum arrived in Java 1.5. (assert arrived in 1.4 and strictfp in 1.2.)

Reserved literals (3)

true false null are values, not keywords, but you still cannot use them as names.
Every reserved word is written in lowercase. NULL, True and String are not reserved words.
Words that sound like keywords but are not: main, String, length, delete, include, sizeof, then, exit. In Java the keyword is extends, never extend, and implements, never implement.
Newer Java added contextual keywords such as var (Java 10), record and yield (Java 14 to 16), and sealed, permits (Java 17). They act like keywords only in special positions, so old code that used them as variable names keeps compiling.

Where does −128 to 127 come from

A byte has 8 bits. The leftmost bit is the sign bit: 0 means positive and 1 means negative. Positive numbers are stored directly, and negative numbers are stored in two's complement form. That leaves 7 bits for the size of the number.

range of an n-bit signed type = −2n−1 to 2n−1 − 1 byte: n = 8 → −27 to 27 − 1 = −128 to 127

Which type when

  • byte: raw data from files or the network, where memory matters.
  • short: rarely used today. It was popular on old 16-bit machines.
  • int: the everyday whole number. Integer literals are int by default.
  • long: when int is too small, such as file sizes in bytes or milliseconds since 1970.
  • float or double: numbers with a decimal point. double is the default and is more precise.
  • char: one Unicode character. Java uses 2 bytes because it supports far more than the 128 ASCII characters.
  • boolean: yes or no answers.
Because the size of every type is fixed on every computer, a Java program behaves the same on Windows, Linux and a phone. In C, the size of int can change from machine to machine. That is one reason Java is called robust.
Money and float do not mix. 0.1 + 0.2 is not exactly 0.3 in binary floating point. Use BigDecimal for money.

Integral literals are int by default. Add L (or l, which looks too much like 1) to make a long.

Floating point literals

Decimal point literals are double by default. Add f or F for a float, and you may add d or D to make the double obvious.

Part 5

↔️Widening and narrowing

Java converts a smaller type into a bigger one automatically. This is called widening or implicit type casting, and it never loses information about the size of the number.

byte → short → int → long → float → double char → int → long → float → double

Going the other way is narrowing. It can lose data, so you must ask for it with a cast, like (byte) 130.

Narrowing with a cast · ▶ Runs
int big = 130;
byte b = (byte) big;           // keeps only the lowest 8 bits
System.out.println(b);
double d = 9.99;
int whole = (int) d;           // the decimal part is cut off, not rounded
System.out.println(whole);
Output
-126
9
130 = 1000 00102 → as a signed byte = −128 + 2 = −126
An int constant may be stored in a byte, short or char without a cast if its value fits. A plain int variable may not, because the compiler cannot be sure what value it holds. Mark the variable final and it becomes a constant again.
A variable needs a cast · ❌ Does not compile
int i = 10;
byte b = i;
❌ Compile error
incompatible types: possible lossy conversion from int to byte
A final constant does not · ▶ Runs
final int i = 10;
byte b = i;
System.out.println(b);
Output
10
Part 6

📦Arrays

An array is an indexed group of a fixed number of values of the same type. Its biggest strength is reading or writing any slot instantly by index. Its biggest weakness is that the size can never change after creation.

1. Declaring

Java snippet
int[] a;     // recommended: the type int[] is clearly separate from the name
int a[];
int []a;

You cannot give the size while declaring. int[6] a; is a compile error. For two dimensions all of these work: int[][] a; int a[][]; int [][]a; int[] a[]; int[] []a; int []a[];

int[] a, b; makes both arrays one dimensional. int[] a[], b; makes a two dimensional and b one dimensional. A dimension written before a name only works for the first name, so int[] []a, []b; does not compile.

2. Creating

Every array is an object, so it is created with new. The size is required at this point.

Arrays are objects with odd class names · ▶ Runs

System.out.println(a.getClass().getName());

System.out.println(new String[2].getClass().getName());
System.out.println(new int[2][3].getClass().getName());
Output

[D
[Ljava.lang.String;
[[I
  • Size 0 is allowed: new int[0].
  • A negative size compiles but fails at run time with NegativeArraySizeException.
  • The size may be a byte, short, char or int. A long size is a compile error.

Java has no true matrix. A two dimensional array is an array of arrays, so each row can have its own length. Such arrays are called jagged arrays, and they save memory.

7. Anonymous arrays

An array created without a name, used once and thrown away. The size must not be written because Java counts the values for you.

Pass an array without naming it · ▶ Runs
class Main {
    static int sum(int[] x) {
        int total = 0;
        for (int v : x) total += v;
        return total;
    }
    public static void main(String[] args) {
        System.out.println(sum(new int[]{10, 20, 30, 40}));
    }
}
Output
100

8. What can go inside

  • Primitive arrays accept anything that can be widened to their type. An int[] accepts byte, short, char and int values, and a double[] accepts every numeric type and char.
  • Object arrays accept their own type or any child type. A Number[] can hold an Integer or a Double, but not a String.
  • Interface arrays accept objects of classes that implement the interface. A Runnable[] can hold a Thread.
Child objects in a parent array · ▶ Runs
Number[] n = new Number[3];
n[0] = 10;          // autoboxed Integer
n[1] = 10.5;        // autoboxed Double
n[2] = 7L;          // autoboxed Long
System.out.println(Arrays.toString(n));
Output
[10, 10.5, 7]

9. Assigning one array variable to another

Element level promotions do not apply to whole arrays. A char can become an int, but a char[] can never become an int[]. A child type array can be assigned to a parent type variable, so a String[] fits in an Object[].

🗃️Types of variables

Variables can be grouped in two ways.

By the value they hold

Primitive variables hold a value directly, like int x = 10;

Reference variables hold a link to an object, like Student s = new Student();

By where they are declared

Instance variables belong to each object. Static variables belong to the class. Local variables live inside a method, block or constructor.

Shared versus personal · ▶ Runs

When you run java Test, the JVM starts, creates the main thread, finds Test.class, loads it (static variables are born here), runs main(), then unloads the class and shuts down.
An array's elements always get default values, even when the array is a local variable. int[] a = new int[3]; inside a method gives three zeros. Only the variable a itself needs to be initialized.
Part 8

🎒Var-arg methods

Before Java 1.5, a method had a fixed number of parameters. Need to add 2, 3 or 10 numbers and you wrote several methods. Var-arg methods accept any number of arguments, including zero.

One method, any number of values · ▶ Runs
class Main {
    static int sum(int... x) {           // x is really an int[]
        int total = 0;
        for (int v : x) total += v;
        return total;
    }
    public static void main(String[] args) {
        System.out.println(sum());
        System.out.println(sum(10, 20));
        System.out.println(sum(10, 20, 30, 40));
        System.out.println(sum(new int[]{5, 5}));
    }
}
Output
0
30
100
10

Rules

  1. Write the three dots after the type: int... x, int ...x and int...x all work. int x... and int. ..x do not.
  2. Normal parameters may come first: m(char ch, String... s).
  3. The var-arg must be the last parameter, and there can be only one of them.
  4. Inside the method a var-arg is an array, so m(int... x) and m(int[] x) cannot exist together in one class.
  5. A var-arg method has the lowest priority. It is chosen only when no other method matches, much like default in a switch.
Var-arg must be last · ❌ Does not compile
class Main {
    static void m(int... x, String s) { }
    public static void main(String[] args) { }
}
❌ Compile error
varargs parameter must be the last parameter
Var-arg loses when an exact match exists · ▶ Runs
class Main {
    static void m(int x) { System.out.println("int version"); }
    static void m(int... x) { System.out.println("var-arg version"); }
    public static void main(String[] args) {
        m();
        m(10);
        m(10, 20);
    }
}
Output
var-arg version
int version
var-arg version
main(String[] args) can be written as main(String... args). And int[]... x is the same as int[][] x.
Part 9

🚪The main() method

The compiler does not care whether a class has a main() method. The JVM checks it at run time, and if it cannot find the exact form it stops with an error.

Java snippet
public static void main(String[] args)
WordWhy it is there
publicso the JVM can call it from outside the class
staticso the JVM can call it without creating an object first
voidmain returns nothing to the JVM
mainthe name the JVM is programmed to look for
String[] argsthe command line arguments

Changes the JVM still accepts

  • Swap modifier order: static public void main
  • Write the array any legal way: String args[], String []args, or as a var-arg String... args
  • Rename the parameter: String[] hello
  • Add final, synchronized or strictfp
A dressed up but valid main · ▶ Runs
class Main {
    final static synchronized strictfp public void main(final String... hi) {
        System.out.println("Still runs");
    }
}
Output
Still runs

Overloading and inheritance

You may overload main, but the JVM only calls the String[] version. Others run only when you call them yourself. A child class also inherits a parent's static main, so running the child class runs the parent's main unless the child declares its own, which hides the parent version.

Overloaded main · ▶ Runs
class Main {
    public static void main(String[] args) {
        System.out.println("String[] main");
        main(5);
    }
    public static void main(int x) {
        System.out.println("int main: " + x);
    }
}
Output
String[] main
int main: 5
public static int main(String[] args) compiles fine, but the JVM refuses to start it, because the return type must be void. Since Java 7, a class with only a static block and no main also refuses to run.
Java 25 added a shorter starter form for small programs, where a simple void main() can be the entry point. Interviews, exams and most real projects still use the classic signature above.

JavaBean conventions

A JavaBean is a simple class with private fields and public getter and setter methods. Many tools find your data by these method names, so the names matter.

A tiny JavaBean · ▶ Runs
class Main {
    public static void main(String[] args) {
        StudentBean s = new StudentBean();
        s.setName("Meera");
        s.setTopper(true);
        System.out.println(s.getName() + " topper? " + s.isTopper());
    }
}
class StudentBean {
    private String name;
    private boolean topper;
    public String getName() { return name; }                  // getter: get + Name, no arguments
    public void setName(String name) { this.name = name; }    // setter: set + Name, one argument, void
    public boolean isTopper() { return topper; }              // boolean getter may use is
    public void setTopper(boolean topper) { this.topper = topper; }
}
Output
Meera topper? true

Listener methods follow the same idea. To register a listener named MyActionListener, the method is addMyActionListener(MyActionListener l), and to remove it, removeMyActionListener(MyActionListener l). Names like registerMyActionListener break the convention.
