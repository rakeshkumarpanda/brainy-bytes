Regular Expressions

A regular expression is a tiny language for describing text patterns: ten digits, a word starting with a capital, anything that looks like an email. Learn it once and use it in Java, testing tools and every editor.

Part 1

🧩What is a regular expression

A regular expression (regex) describes a group of strings that follow one pattern. For example, [6-9][0-9]{9} describes every Indian mobile number.

  • Validation: is this a valid email, PIN code or password.
  • Search: find every phone number in a document.
  • Find and replace: tidy up spaces or reformat dates.
  • Splitting: break a line into words.
  • Compilers, editors and test tools all use pattern matching under the hood.
In Java source code, a backslash inside a String must be doubled. The regex \d is written "\\d".
Part 2

🔧Pattern and Matcher

Java's regex classes live in java.util.regex.

  • Pattern is the compiled form of a regex: Pattern p = Pattern.compile("ab");
  • Matcher searches a target string: Matcher m = p.matcher("abbbabbaba");
  • m.find() moves to the next match and returns true, or false when there are no more.
  • m.start() is where the match starts, m.end() is one past where it ends, and m.group() is the matched text.
Find every ab · ▶ Runs
Pattern p = Pattern.compile("ab");
Matcher m = p.matcher("abbbabbaba");
int count = 0;
while (m.find()) {
    count++;
    System.out.println(m.start() + "..." + m.end() + " " + m.group());
}
System.out.println("matches: " + count);
Output
0...2 ab
4...6 ab
7...9 ab
matches: 3
Part 3

🔤Character classes

Square brackets match one character from a set.

ClassMatches one
[abc]a, b or c
[^abc]any character except a, b and c
[a-z]any lowercase letter
[A-Z]any uppercase letter
[a-zA-Z]any letter
[0-9]any digit
[a-zA-Z0-9]any letter or digit
[^a-zA-Z0-9]anything that is not a letter or digit (a special character)
Same target, different classes · ▶ Runs
class Main {
    static void show(String regex, String target) {
        Matcher m = Pattern.compile(regex).matcher(target);
        StringBuilder sb = new StringBuilder();
        while (m.find()) sb.append(m.start()).append(m.group()).append(' ');
        System.out.printf("%-14s %s%n", regex, sb);
    }
    public static void main(String[] args) {
        String t = "a3b#k@9z";
        show("[abc]", t);
        show("[^abc]", t);
        show("[a-z]", t);
        show("[0-9]", t);
        show("[^a-zA-Z0-9]", t);
    }
}
Output
[abc]          0a 2b 
[^abc]         13 3# 4k 5@ 69 7z 
[a-z]          0a 2b 4k 7z 
[0-9]          13 69 
[^a-zA-Z0-9]   3# 5@

🧰Predefined character classes

ClassSame asMatches one
\swhitespace (space, tab, new line)
\Sanything except whitespace
\d[0-9]a digit
\D[^0-9]anything except a digit
\w[a-zA-Z0-9_]a word character

Predefined classes in action · ▶ Runs
String t = "a7b k@9_";
for (String regex : new String[]{"\\s", "\\d", "\\D", "\\w", "\\W", "."}) {
    Matcher m = Pattern.compile(regex).matcher(t);
    int n = 0;
    while (m.find()) n++;
    System.out.println(regex + " matches " + n + " characters");
}
Output
\s matches 1 characters
\d matches 2 characters
\D matches 6 characters
\w matches 6 characters
\W matches 2 characters
. matches 8 characters
A literal dot must be escaped: "\\.". Without the backslash, . matches every character, which is a classic bug when splitting on dots.
Part 5

🔢Quantifiers

Quantifiers say how many times something may repeat.

QuantifierMeans
aexactly one a
a+one or more a
a*zero or more a
a?zero or one a
a{3}exactly three a
a{2,4}two to four a
a{2,}two or more a
Four quantifiers, one target · ▶ Runs
class Main {
    static void show(String regex, String target) {
        Matcher m = Pattern.compile(regex).matcher(target);
        StringBuilder sb = new StringBuilder();
        while (m.find()) sb.append(m.start()).append(":").append(m.group().isEmpty() ? "∅" : m.group()).append("  ");
        System.out.println(regex + "\t" + sb);
    }
    public static void main(String[] args) {
        String t = "abaabaaab";
        show("a", t);
        show("a+", t);
        show("a*", t);
        show("a?", t);
    }
}
Output
a	0:a  2:a  3:a  5:a  6:a  7:a  
a+	0:a  2:aa  5:aaa  
a*	0:a  1:∅  2:aa  4:∅  5:aaa  8:∅  9:∅  
a?	0:a  1:∅  2:a  3:a  4:∅  5:a  6:a  7:a  8:∅  9:∅

The ∅ marks an empty match: a* and a? are allowed to match zero characters, so they also succeed between letters and at the very end.

Quantifiers are greedy: they grab as much as they can. Add ? to make them lazy: <.+?> matches one HTML tag instead of everything from the first < to the last >.
Part 6

✂️Splitting text

Both Pattern and String can split text around a regex.

Splitting on spaces and on dots · ▶ Runs
String line = "Brainy   Bytes rocks";
System.out.println(Arrays.toString(line.split("\\s+")));
System.out.println(Arrays.toString("www.brainybytes.com".split("\\.")));
System.out.println(Arrays.toString("www.brainybytes.com".split(".")));       // the dot trap
System.out.println(Arrays.toString(Pattern.compile("[,;]").split("tea,coffee;milk")));
Output
[Brainy, Bytes, rocks]
[www, brainybytes, com]
[]
[tea, coffee, milk]

The third line prints an empty array: every character matched the unescaped dot, so only empty pieces were left, and trailing empty strings are removed.

StringTokenizer

The older java.util.StringTokenizer splits on a set of delimiter characters (whitespace by default). It does not understand regex, and new code usually uses split.

StringTokenizer · ▶ Runs
StringTokenizer st = new StringTokenizer("19-10-2026", "-");
System.out.println(st.countTokens());
while (st.hasMoreTokens()) System.out.print(st.nextToken() + " ");
Output
3
19 10 2026
Part 7

✅Validating input

matches() checks whether the whole string fits the pattern, unlike find(), which looks for a piece of it.

Indian mobile numbers

  1. 10 digits, starting with 6, 7, 8 or 9: [6-9][0-9]{9}
  2. Optionally with a leading 0: 0?[6-9][0-9]{9}
  3. Optionally with 0 or 91 in front: (0|91)?[6-9][0-9]{9}
Mobile number checker · ▶ Runs
String regex = "(0|91)?[6-9][0-9]{9}";
for (String n : new String[]{"9876543210", "09876543210", "919876543210", "5876543210", "98765"})
    System.out.println(n + " → " + n.matches(regex));
Output
9876543210 → true
09876543210 → true
919876543210 → true
5876543210 → false
98765 → false

A custom identifier rule

Say identifiers must use letters, digits and #, be at least 2 characters long, and start with a lowercase a to k.

[a-k][a-zA-Z0-9#]+

String regex = "[a-k][a-zA-Z0-9#]+";
for (String id : new String[]{"apple", "kid#7", "z99", "b", "c-d"})

A simple email rule

Email checker (simplified) · ▶ Runs
String regex = "[a-zA-Z0-9][a-zA-Z0-9._]*@[a-zA-Z0-9]+([.][a-zA-Z]+)+";
for (String e : new String[]{"asha.k@gmail.com", "ravi@company.co.in", "@nope.com", "two@@at.com", "x@y"})
    System.out.println(e + " → " + e.matches(regex));
Output
asha.k@gmail.com → true
ravi@company.co.in → true
@nope.com → false
two@@at.com → false
x@y → false
Real email rules are very complicated. For production, use a well tested library and confirm the address by sending a mail.
Part 8

🔁Find, extract and replace

Round brackets create capturing groups, which you can read with group(1), group(2) and so on, or reuse in a replacement as $1.

Reformat dates from day-month-year to year-month-day · ▶ Runs
String text = "Exam on 19-10-2026, results on 05-11-2026.";
System.out.println(text.replaceAll("(\\d{2})-(\\d{2})-(\\d{4})", "$3/$2/$1"));
Matcher m = Pattern.compile("(\\d{2})-(\\d{2})-(\\d{4})").matcher(text);
while (m.find()) System.out.println("day " + m.group(1) + ", month " + m.group(2) + ", year " + m.group(3));
Output
Exam on 2026/10/19, results on 2026/11/05.
day 19, month 10, year 2026
day 05, month 11, year 2026
Tidy up spaces and add up every number · ▶ Runs
String messy = "  apples 12   bananas 5  cherries   30 ";
System.out.println("[" + messy.trim().replaceAll("\\s+", " ") + "]");
Matcher m = Pattern.compile("\\d+").matcher(messy);
int total = 0;
while (m.find()) total += Integer.parseInt(m.group());
System.out.println("total fruit: " + total);
Output
[apples 12 bananas 5 cherries 30]
total fruit: 47

Pulling mobile numbers out of a file

Write a file, then extract valid numbers from it · ▶ Runs
import java.nio.file.*;
import java.util.regex.*;
class Main {
    public static void main(String[] args) throws Exception {
        Path in = Path.of("contacts.txt");
        Files.writeString(in, "Asha 9876543210\nshop 12345\nRavi 8123456789 or 7012345678\n");
        Pattern p = Pattern.compile("\\b[6-9]\\d{9}\\b");
        for (String line : Files.readAllLines(in)) {
            Matcher m = p.matcher(line);
            while (m.find()) System.out.println(m.group());
        }
    }
}
Output
9876543210
8123456789
7012345678
If you use the same regex many times, compile it once into a Pattern and reuse it. String.matches compiles the pattern again on every call.
