File I/O

Programs forget everything when they stop, unless they write it down. File I/O is how Java saves data to disk and reads it back, from a single word to a million lines.

Part 1

🗂️The File class

A java.io.File object represents a path to a file or folder. Creating the object does not create anything on disk.

A File object is only a name until you act · ▶ Runs
import java.io.*;
class Main {
    public static void main(String[] args) throws IOException {
        File f = new File("notes.txt");
        System.out.println(f.exists());
        System.out.println(f.createNewFile());        // now it really exists
        System.out.println(f.exists() + " " + f.isFile() + " " + f.length());
        System.out.println(f.createNewFile());        // already there, so false
    }
}
Output
false
true
true true 0
false
Folders and listing · ▶ Runs
import java.io.*;
import java.util.*;
class Main {
    public static void main(String[] args) throws IOException {
        File dir = new File("project");
        System.out.println(dir.mkdir() + " " + dir.isDirectory());
        new File(dir, "a.txt").createNewFile();
        new File(dir, "b.java").createNewFile();
        new File(dir, "docs").mkdir();
        String[] names = dir.list();
        Arrays.sort(names);
        System.out.println(Arrays.toString(names));
        int files = 0, dirs = 0;
        for (File f : dir.listFiles()) { if (f.isFile()) files++; else dirs++; }
        System.out.println(files + " files, " + dirs + " folder");
    }
}
Output
true true
[a.txt, b.java, docs]
2 files, 1 folder
MethodDoes
exists()is there something at this path
createNewFile()creates an empty file, false if it already exists
mkdir(), mkdirs()creates a folder (mkdirs also creates missing parents)
isFile(), isDirectory()what kind of thing is it
list(), listFiles()names or File objects inside a folder
length()file size in bytes
delete()removes a file or an empty folder
In Java, a directory is a File too. The same class handles both.
Part 2

✍️FileWriter

FileWriter writes characters to a file. By default it overwrites the file. Pass true as a second argument to append instead.

Writing, then appending · ▶ Runs
import java.io.*;
import java.nio.file.*;
class Main {
    public static void main(String[] args) throws IOException {
        FileWriter fw = new FileWriter("diary.txt");
        fw.write(68);                                 // the char with code 68: D
        fw.write("ear diary\n");
        fw.write(new char[]{'H', 'i', '\n'});
        fw.close();
        FileWriter more = new FileWriter("diary.txt", true);   // append
        more.write("Second entry\n");
        more.close();
        System.out.print(Files.readString(Path.of("diary.txt")));
    }
}
Output
Dear diary
Hi
Second entry
  • write(int) writes one character, write(String) and write(char[]) write many.
  • flush() pushes buffered characters to the disk. close() flushes and releases the file.
  • FileWriter has no method for line breaks, so you write \n yourself. That is its biggest weakness.
Forgetting close() (or flush()) can leave the last characters unwritten. Use try-with-resources so files always close.
Part 3

📖FileReader

FileReader reads characters. read() returns the next character as an int, or −1 at the end of the file.

Character by character, and all at once · ▶ Runs
import java.io.*;
class Main {
    public static void main(String[] args) throws IOException {
        try (FileWriter fw = new FileWriter("abc.txt")) { fw.write("Hello\nJava"); }
        try (FileReader fr = new FileReader("abc.txt")) {
            int c;
            int count = 0;
            while ((c = fr.read()) != -1) { System.out.print((char) c); count++; }
            System.out.println("\n(" + count + " characters)");
        }
        File f = new File("abc.txt");
        char[] buffer = new char[(int) f.length()];
        try (FileReader fr = new FileReader(f)) { fr.read(buffer); }
        System.out.println(new String(buffer).toUpperCase());
    }
}
Output
Hello
Java
(10 characters)
HELLO
JAVA

Reading one character at a time is slow and has no idea of lines. That is what the buffered classes fix.

Part 4

🚚BufferedWriter and BufferedReader

Buffered classes collect characters in memory and move them in big chunks, which is much faster. They also understand lines.

  • BufferedWriter.newLine() writes the correct line break for the operating system.
  • BufferedReader.readLine() returns one whole line, or null at the end.
  • They cannot open a file by name themselves: wrap a FileWriter or FileReader.
Write lines, read lines · ▶ Runs
import java.io.*;
class Main {
    public static void main(String[] args) throws IOException {
        try (BufferedWriter bw = new BufferedWriter(new FileWriter("cities.txt"))) {
            for (String city : new String[]{"Pune", "Mysuru", "Cuttack", "Dubai"}) {
                bw.write(city);
                bw.newLine();
            }
        }
        try (BufferedReader br = new BufferedReader(new FileReader("cities.txt"))) {
            String line;
            int n = 0;
            while ((line = br.readLine()) != null) System.out.println(++n + ". " + line);
        }
    }
}
Output
1. Pune
2. Mysuru
3. Cuttack
4. Dubai
BufferedWriter needs a Writer, not a file name · ❌ Does not compile
import java.io.*;
class Main {
    public static void main(String[] args) throws IOException {
        BufferedWriter bw = new BufferedWriter("cities.txt");
    }
}
❌ Compile error
incompatible types: String cannot be converted to Writer
Closing the outer BufferedWriter or BufferedReader automatically closes the FileWriter or FileReader inside it.
Part 5

🖨️PrintWriter

PrintWriter is the most convenient writer. It can wrap a file name, a File or another Writer, and its print, println and printf accept any type, just like System.out.

write(100) versus print(100) · ▶ Runs
import java.io.*;
import java.nio.file.*;
class Main {
    public static void main(String[] args) throws IOException {
        try (PrintWriter pw = new PrintWriter("report.txt")) {
            pw.write(100);                    // writes the character with code 100: d
            pw.println();
            pw.println(100);                  // writes the text 100
            pw.println(true);
            pw.println(9.75);
            pw.printf("%-6s|%5.1f%n", "avg", 87.456);
        }
        System.out.print(Files.readString(Path.of("report.txt")));
    }
}
Output
d
100
true
9.75
avg   | 87.5
write(100) writes the character d. print(100) writes the three characters 100.
ClassBest for
FileWriter / FileReaderthe simplest character access
BufferedWriter / BufferedReaderfast, line by line work
PrintWriterwriting any type of value with print, println and printf
Part 6

🧩Classic file programs

These small programs combine the classes above. They are common interview and lab exercises.

Merge two files into a third

file3 = file1 + file2 · ▶ Runs
import java.io.*;
import java.nio.file.*;
class Main {
    static void write(String name, String... lines) throws IOException {
        try (PrintWriter pw = new PrintWriter(name)) { for (String l : lines) pw.println(l); }
    }
    public static void main(String[] args) throws IOException {
        write("file1.txt", "AAA", "BBB");
        write("file2.txt", "111", "222", "333");
        try (PrintWriter out = new PrintWriter("file3.txt")) {
            for (String name : new String[]{"file1.txt", "file2.txt"})
                try (BufferedReader br = new BufferedReader(new FileReader(name))) {
                    String line;
                    while ((line = br.readLine()) != null) out.println(line);
                }
        }
        System.out.print(Files.readString(Path.of("file3.txt")));
    }
}
Output
AAA
BBB
111
222
333

Merge line by line, alternately

One line from each file in turn · ▶ Runs
import java.io.*;
class Main {
    public static void main(String[] args) throws IOException {
        try (PrintWriter a = new PrintWriter("left.txt"); PrintWriter b = new PrintWriter("right.txt")) {
            a.println("L1"); a.println("L2"); a.println("L3");
            b.println("R1"); b.println("R2");
        }
        try (BufferedReader l = new BufferedReader(new FileReader("left.txt"));
             BufferedReader r = new BufferedReader(new FileReader("right.txt"))) {
            String x = l.readLine(), y = r.readLine();
            while (x != null || y != null) {
                if (x != null) { System.out.println(x); x = l.readLine(); }
                if (y != null) { System.out.println(y); y = r.readLine(); }
            }
        }
    }
}
Output
L1
R1
L2
R2
L3

Remove duplicate lines and lines found in a block list

Clean a list of mobile numbers · ▶ Runs
import java.io.*;
import java.util.*;
class Main {
    public static void main(String[] args) throws IOException {
        try (PrintWriter in = new PrintWriter("input.txt"); PrintWriter block = new PrintWriter("blocked.txt")) {
            for (String n : new String[]{"9876500001", "9876500002", "9876500001", "9876500003", "9876500004"}) in.println(n);
            block.println("9876500003");
        }
        Set<String> blocked = new HashSet<>();
        try (BufferedReader br = new BufferedReader(new FileReader("blocked.txt"))) {
            String s;
            while ((s = br.readLine()) != null) blocked.add(s);
        }
        Set<String> seen = new LinkedHashSet<>();
        try (BufferedReader br = new BufferedReader(new FileReader("input.txt"))) {
            String s;
            while ((s = br.readLine()) != null) if (!blocked.contains(s)) seen.add(s);
        }
        System.out.println(seen);
    }
}
Output
[9876500001, 9876500002, 9876500004]
Part 7

🔢Byte streams and character streams

Character streams

Reader and Writer classes. They handle text and know about character encodings.

Byte streams

InputStream and OutputStream classes. They handle raw bytes: images, audio, zip files, serialized objects.

Copy any file byte by byte · ▶ Runs
import java.io.*;
class Main {
    public static void main(String[] args) throws IOException {
        try (FileOutputStream out = new FileOutputStream("pixels.bin")) {
            out.write(new byte[]{(byte) 0x89, 'P', 'N', 'G', 13, 10});
        }
        try (FileInputStream in = new FileInputStream("pixels.bin");
             FileOutputStream copy = new FileOutputStream("copy.bin")) {
            byte[] buf = new byte[1024];
            int n, total = 0;
            while ((n = in.read(buf)) != -1) { copy.write(buf, 0, n); total += n; }
            System.out.println("copied " + total + " bytes");
        }
        System.out.println(new File("copy.bin").length());
    }
}
Output
copied 6 bytes
6
Never copy an image with FileReader and FileWriter. They try to decode bytes as text and will damage binary data.
Part 8

🆕Modern file handling with java.nio

Java 7 added java.nio.file with Path and Files, and Java 11 added handy shortcuts. Most new code uses these.
One line jobs with Files · ▶ Runs
import java.nio.file.*;
import java.util.*;
class Main {
    public static void main(String[] args) throws Exception {
        Path p = Path.of("marks.csv");
        Files.writeString(p, "Asha,91\nRavi,78\nMeera,88\n");
        List<String> lines = Files.readAllLines(p);
        System.out.println(lines.size() + " lines, first: " + lines.get(0));
        double avg = Files.lines(p).mapToInt(l -> Integer.parseInt(l.split(",")[1])).average().orElse(0);
        System.out.printf("average %.2f%n", avg);
        Files.writeString(p, "Kiran,95\n", StandardOpenOption.APPEND);
        System.out.println(Files.readAllLines(p).size() + " lines after append, " + Files.size(p) + " bytes");
    }
}
Output
3 lines, first: Asha,91
average 85.67
4 lines after append, 34 bytes
Text files should state their encoding. Files methods use UTF-8 by default, and since Java 18 so does FileReader and FileWriter, so Hindi, Kannada, Odia and Arabic text survive the round trip.
Unicode text round trip · ▶ Runs
import java.nio.file.*;
class Main {
    public static void main(String[] args) throws Exception {
        Path p = Path.of("hello.txt");
        Files.writeString(p, "नमस्ते ಹಲೋ ନମସ୍କାର مرحبا Hallo");
        String back = Files.readString(p);
        System.out.println(back + " (" + back.length() + " chars, " + Files.size(p) + " bytes)");
    }
}
Output
नमस्ते ಹಲೋ ନମସ୍କାର مرحبا Hallo (30 chars, 67 bytes)
