🏨 The practice API used everywhere

Every example calls Restful Booker, a free hotel booking API made for testers. Its public address is https://restful-booker.herokuapp.com. The username is admin and the password is password123. Its data resets every few minutes, so create the bookings you need inside each test.

CallWhat it doesSuccess
GET /pingHealth check201
POST /authReturns a token for admin and password123200 with token
GET /bookingLists booking ids, filters by firstname, lastname, checkin and checkout200
GET /booking/{id}One booking200, or 404 when missing
POST /bookingCreates a booking, returns bookingid and booking200
PUT /booking/{id}Replaces a booking. Needs the token cookie or Basic auth200, or 403 without auth
PATCH /booking/{id}Changes some fields. Same auth rule200
DELETE /booking/{id}Deletes a booking. Same auth rule201 (a quirk of this API)

A booking looks like {"firstname":"Sally","lastname":"Brown","totalprice":111,"depositpaid":true,"bookingdates":{"checkin":"2026-01-01","checkout":"2026-01-05"},"additionalneeds":"Breakfast"}
