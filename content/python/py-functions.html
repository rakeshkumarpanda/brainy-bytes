Lesson 1 of 13

What a function is

Source: Python 3.14 tutorial section 4.8, language reference section 8.7, PCEP-30-02 sections 4.1 and 4.2 and PCAP-31-03.

What it is
A function is a named block of code that does one job. You define it once with def and then call it by name as often as you like, giving it different inputs each time.
Why we need it
Without functions you copy the same lines again and again. When there is a bug, you must fix every copy, and the program becomes long and hard to read. A function lets you write the job once, give it a clear name, test it alone and reuse it everywhere. This idea is called DRY: do not repeat yourself.
How it works
def name(parameters): followed by an indented body creates a function object and binds it to the name. A call name(arguments) gives each parameter a value, runs the body, and the call itself becomes the value after return.
Real world scenario: a recipe card

A recipe card for "masala tea" says: take water, milk, tea leaves and sugar, then boil, add, strain. The card is the function definition. Making tea for 2 people or 10 people with less sugar is a call with different arguments. You do not rewrite the card each time, and if you improve the recipe, every future cup gets better.

The mutable default trap

Download this program (.py)Save it, open it in any editor and run it with python3 mutdef.py.
What it is
A default value is worked out once, when the def line runs, and kept in the function object (func.__defaults__).
Why we need it
For numbers, strings and None this never matters, because they cannot change. For a list or dict it does: every call that uses the default shares the same object, so changes pile up from one call to the next.
How it works
Use None as the default and create a new list inside the function. This is one of the most common Python bugs, and a favourite interview question.

Lesson 10 of 13

Functions in maths and in code

A function maps each input to one outputExam favourite
f: X → Y, x ↦ f(x)
area(width, height) maps each pair of numbers to one number.
CompositionExam favourite
(f ∘ g)(x) = f(g(x))
apply_twice(f, x) is f(f(x)). len(str(n)) is len ∘ str.
Idempotent function
f(f(x)) = f(x)
abs, str.strip and sorted are idempotent: doing them twice changes nothing more.
How many functions from a set of m inputs to n outputs
nm
Each of the m inputs can go to any of the n outputs. From {1, 2, 3} to {a, b}: 23 = 8.
Arguments a call may give with p positional parameters, d of them with defaults and no *args
between p − d and p positional arguments
describe has p = 3, d = 1, so 2 or 3 positional arguments.
Worked example: what does apply_twice(lambda n: n * 3, 2) return?
  1. apply_twice(f, v) returns f(f(v)).
  2. Inner call: f(2) = 6.
  3. Outer call: f(6) = 18.
  4. (f ∘ f)(2) = 18
Going deeper: Pure functions

A pure function gives the same output for the same input and changes nothing outside itself: no printing, no changing global variables or arguments. area and double are pure, add_bad is not. Pure functions are easy to test, to cache (Core 4.2) and to run in parallel (Advanced 5.1), which is why functional programming prefers them.

Lesson 11 of 13

From beginner to expert

One idea, four depths

def makes a function, a call runs it, and return gives a value back. A function without return gives None.

Arguments can be positional or keyword, and parameters can have defaults. *args collects extra positional arguments into a tuple and **kwargs collects extra keyword arguments into a dict.

Use / and * to make parameters positional-only or keyword-only, spread arguments with * and **, avoid mutable defaults, and write docstrings and type hints. Functions are objects you can pass around.

Calling a function creates a frame object with its local variables. CPython binds arguments in C (the rules shown in the animation), stores defaults in __defaults__ and __kwdefaults__, and inspect.signature(f).bind(*args, **kwargs) reproduces the same binding in Python. Since 3.11 calls between Python functions avoid creating C stack frames, which made calls much cheaper.

Beginner
Write a function with parameters, call it and return a value.
Intermediate
Use keyword and default arguments, *args and **kwargs, and return several values as a tuple.
Expert
Design clean signatures with / and *, explain the mutable default trap, and use functions as objects.
Real world scenario: the API of a payment app

A payment function might be pay(amount, /, *, to, note="", notify=True). amount must be passed by position, the receiver must be named (to="Asha") so nobody swaps the two numbers by mistake, and note and notify are optional. Good signatures prevent costly mistakes before the code even runs.

Chapter summary

  1. def name(parameters): defines a function. name(arguments) calls it.
  2. return sends a value back and leaves the function. No return means the call gives None.
  3. Arguments are matched by position or by name. Positional arguments come first. Defaults make a parameter optional.
  4. *args collects extra positional arguments into a tuple, **kwargs extra keyword arguments into a dict.
  5. After * parameters are keyword-only. Before / they are positional-only.
  6. In a call, *list and **dict spread values out into arguments.
  7. Default values are made once. Use None instead of [] or {} as a default.
  8. Functions are objects: name them, store them and pass them to other functions.
