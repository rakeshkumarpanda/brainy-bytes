Lesson 1 of 11

Windows, buttons and the event loop

Source: Python 3.14 documentation of tkinter and tkinter.ttk, and the PCPP-32-101 GUI programming section.

What it is
A GUI (graphical user interface) is a program with windows, buttons, text boxes and menus instead of typed commands. tkinter is the GUI toolkit that comes with Python. It wraps Tk, a toolkit that runs on Windows, macOS and Linux.
Why we need it
Many users never open a terminal. A small window lets them pick a file, fill in a form or press a button, and it can show pictures, charts and live data. Office tools, installers and lab instruments often need exactly this.
How it works
You build a tree of widgets (the window, frames, labels, buttons), place them with a geometry manager (pack, grid or place), connect events such as clicks to your functions, and hand control to mainloop(). From then on your code runs only when an event calls it.

Common mistake
Never mix pack and grid for widgets with the same parent: Tk raises TclError ("cannot use geometry manager grid inside . which already has slaves managed by pack"). Put each group in its own Frame instead, and each Frame can use its own manager.

The maths: pixels, frames and how fast people click

Screen coordinates
x grows to the right, y grows DOWN, (0, 0) is the top left corner
A point 50 pixels from the top has y = 50, not y = height − 50.
Centre a windowExam favourite
x = (screen width − window width) // 2, y = (screen height − window height) // 2
A 300 × 200 window on 1920 × 1080: x = 810, y = 440, geometry "300x200+810+440".
Frames and speed
delay = 1000 / fps ms, speed = pixels per step × 1000 / delay
after(20, ...) gives 50 frames a second. 4 pixels a step is 200 pixels a second.
Sharing extra space
extra for column i = extra × weighti / sum of weights
300 extra pixels, weights 1 and 2: 100 and 200 pixels.
Fitts's lawExam favourite
time = a + b × log2(D / W + 1)
D = distance to the target, W = its width. Big, close buttons are faster to hit.
Hick's law
time = b × log2(n + 1)
n equal choices. 7 menu items: log2 8 = 3 times b.
Worked example: how long does it take to hit a small button far away?
  1. Take a = 0.1 s and b = 0.15 s, typical numbers for a mouse.
  2. The button is 20 pixels wide and 300 pixels away: D / W + 1 = 15 + 1 = 16.
  3. log2 16 = 4, so the time is 0.1 + 0.15 × 4 = 0.7 s.
  4. Make the button 80 pixels wide: D / W + 1 = 4.75, log2 4.75 ≈ 2.25, time ≈ 0.44 s.
  5. A 4 times wider button saves about 0.26 s on every click

Lesson 11 of 11

Chapter summary

  1. tkinter comes with Python. Make root = tk.Tk(), add widgets with their parent, place them, then call root.mainloop().
  2. mainloop waits for events and calls your functions. command=function, without brackets. bind(event, function) for keys and mouse.
  3. grid with sticky and weight for forms, pack for simple stacks, never both in one parent.
  4. StringVar, IntVar and BooleanVar keep widgets in step. The Canvas draws items you move with move and coords, animated with after().
  5. Callbacks must return fast: after() for timers and steps, threads with a queue for slow work. Keep the model apart from the view so you can test it.
