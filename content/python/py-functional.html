Lesson 1 of 14

Functions as values: the functional style

Source: Python 3.14 tutorial sections 4.9.6 and 5.1.3 to 5.1.4, the Functional Programming HOWTO, and PCAP-31-03 section 4.

What it is
A lambda is a small function written in one expression. map and filter apply a function to every item of a collection. A comprehension builds a new list, dict or set from an old one in a single readable line.
Why we need it
Many jobs are "do something to every item" or "keep the items that pass a test". Writing a full loop with an empty list and append each time is long and hides the idea. These tools say the idea directly: squares of all numbers, prices under 100, names in upper case.
How it works
Because functions are objects (Core 4.1), you can hand a small function to sorted, max, map or filter. A comprehension is a loop and an optional if folded into brackets. Python runs it like the loop, but you read it like a sentence.
Real world scenario: a mark sheet in a spreadsheet

A teacher has a column of marks. "Add 5 grace marks to everyone" is map. "Show only students below 40" is filter. "Sort by mark, highest first" is sorted with a key. "Make a new column that says Pass or Fail" is a comprehension with if-else. One line each, and the original column is not changed.

In the exam
A lambda cannot contain statements such as if blocks, for loops, return or assignment with =. It can contain a conditional expression: lambda n: "even" if n % 2 == 0 else "odd".

Common mistake
map and filter return iterators, not lists. They give each value once, only when asked. Wrap them in list() to see all the values, and do not loop over the same map object twice.

List comprehensions

Download this program (.py)Save it, open it in any editor and run it with python3 listcomp.py.
List comprehensionExam favourite
[expression for item in iterable if condition]
Read it as: the expression, for each item, but only if the condition holds.
With if-elseExam favourite
[a if test else b for item in iterable]
The if-else is part of the expression, so it comes before for. A filter if comes after.
In the exam
[n for n in nums if n % 2 == 0 else 0] is a SyntaxError. An if after for only filters and has no else.

The maths behind comprehensions

Set builder notationExam favourite
{ f(x) | x ∈ S, p(x) }
Maths wrote "the set of f(x) for x in S where p(x)" long before Python. {f(x) for x in S if p(x)} is the same idea.
map is f applied to each item
map(f, [a1, ..., an]) = [f(a1), ..., f(an)]
The length does not change.
reduce is a foldExam favourite
reduce(⊕, [a1, a2, a3], s) = ((s ⊕ a1) ⊕ a2) ⊕ a3
With + this is the sum, with max it is the maximum.
Size of a comprehension with two for clauses
|A| × |B|
[(x, y) for x in range(1, 4) for y in "ab"] has 3 × 2 = 6 pairs, the Cartesian product A × B.
Sum of squares
12 + 22 + ... + n2 = n(n + 1)(2n + 1)/6
sum(n * n for n in range(1, 11)) = 10 × 11 × 21 / 6 = 385.
Worked example: what is reduce(lambda a, b: a * 10 + b, [4, 0, 7], 0)?
  1. Start with 0.
  2. 0 × 10 + 4 = 4.
  3. 4 × 10 + 0 = 40.
  4. 40 × 10 + 7 = 407
  5. This fold turns a list of digits into a number.
Lesson 12 of 14

From beginner to expert

One idea, four depths

A lambda is a one line function. [x * 2 for x in items] builds a new list from an old one.

Use key= with sorted, min and max. Filter in a comprehension with if after for, and choose between two values with if-else before for. Build dicts and sets the same way.

map and filter are lazy iterators, reduce folds a list into one value, and generator expressions save memory. Use partial and compose to build functions from functions.

Comprehensions run in their own scope (since Python 3.12 they are inlined for speed, PEP 709, but the loop name still does not leak). Lambdas capture names, not values, so callbacks made in a loop all see the last value unless you bind it with a default argument. These ideas come from the lambda calculus of Alonzo Church (1936) and from languages such as Haskell.

Chapter summary

  1. lambda args: expression makes a small anonymous function. Use it as an argument, use def for anything you name.
  2. sorted, min and max take key=, a function called once per item. Return a tuple to sort by several things.
  3. map(f, items) applies f to every item, filter(test, items) keeps the items that pass. Both are lazy. reduce folds a list into one value.
  4. List comprehension: [expr for x in items if test]. if-else goes before for, a filter if after it.
  5. Several for clauses run like nested loops, outer first. Comprehensions also build dicts and sets.
  6. A generator expression (expr for x in items) makes values one at a time and saves memory. It can be used once.
  7. Higher-order functions take or return functions: make_greeter, compose, functools.partial.
