Input and output: how a program talks to people

Source: Python 3.14 tutorial chapter 7 (Input and Output), the Format Specification Mini-Language, and PCEP-30-02 section 1.5.

What it is
Output is what a program shows (print). Input is what it reads from the user while it runs (input). Together they make the program interactive.
Why we need it
A program that always uses the same numbers is not very useful. Reading input lets one program work for any user, any shop bill, any set of marks.
How it works
input(prompt) shows the prompt, waits for the user to press Enter and returns what was typed as text. You convert it with int() or float() before doing maths. print() and f-strings turn values back into neat text.

Real world scenario: a ticket machine at a metro station

The machine shows "Choose your station" (output), you press a station (input), it shows the fare (output), you insert money (input) and it prints a ticket (output). Every interactive program, from an ATM to a quiz app, is this loop of asking, reading, working out and showing.

f-strings: the modern way to build text

What it is
An f-string is a text with an f before the quotes: f"Total: {total}". Anything inside curly brackets is worked out and put into the text.
Why we need it
Joining texts with + and str() is long and easy to get wrong ("Total: " + str(total)). f-strings are shorter, easier to read and also the fastest way.
How it works
Python finds each {...} field, works out the expression, formats it with the optional spec after a colon, and joins all the pieces.

Inside the bracketsMeaningExampleGives

Remember
Since Python 3.12 (PEP 701) you may reuse the same quotes inside an f-string expression, for example f"{", ".join(names)}". Older versions need the other kind of quote inside.

The format spec: width, alignment, decimals and more

Format spec grammarExam favourite
[[fill]align][sign][#][0][width][grouping][.precision][type]
Every part is optional, but the order is fixed. align is < > ^ or =.
Common types
d (int), f (fixed), e (scientific), % (percent), b o x X (bases), s (text)
No type means the same as str() for most values.

Reading input safely

Users make typing mistakes. A good program checks the input and asks again instead of crashing with a ValueError.

Download this program (.py)Save it, open it in any editor and run it with python3 robust.py.
The ask again pattern
  1. Loop for ever with while True.
  2. Read the text and try to convert it inside try.
  3. On ValueError, explain the problem and continue (go back to the top of the loop).
  4. If the number is out of range, explain and continue.
  5. Only a good value reaches break, which leaves the loop

Going deeper: why input() is slow in competitive programming

input() reads one line at a time and does extra work for the prompt. For a million lines, sys.stdin.readline() or sys.stdin.read().split() is several times faster. Competitive programmers often write input = sys.stdin.readline at the top of their file.

The maths: widths and rounding

Padding added by a widthExam favourite
pad = max(0, width − len(text))
Width is a minimum. It never cuts the text.
Centre alignmentExam favourite
left = ⌊pad / 2⌋, right = pad − left
With an odd pad the extra character goes on the right.
Rounding to p places
round half to even on the exact binary value
f"{0.125:.2f}" is 0.12 because 0.125 is exact and 2 is even.
Digits of a number
len(str(n)) = ⌊log10 n⌋ + 1
For a whole number n > 0.
Worked example: f"{'Menu':*^11}"
  1. The text Menu has 4 characters.
  2. pad = 11 − 4 = 7.
  3. left = 7 // 2 = 3, right = 7 − 3 = 4.
  4. ***Menu****
Lesson 9 of 11

From beginner to expert

One idea, four depths

input() asks a question and gives you the answer as text. f-strings let you put values into a sentence.

Convert input with int() or float(), split lines with split(). Use the format spec for width, alignment, decimals and separators. Check input with try and a loop.

f-strings compile to fast bytecode (FORMAT_VALUE, BUILD_STRING). The spec is passed to the value's __format__ method, so dates, Decimal and your own classes can define their own codes, for example f"{today:%d %B %Y}".

Python 3.14 adds template strings (t-strings, PEP 750): t"..." gives a Template object with the static parts and the values kept apart, so a library can escape values safely for HTML or SQL before joining them.

Beginner
Read a name and a number, and print a sentence with an f-string.
Intermediate
Format a bill as a neat table and keep asking until the input is valid.
Expert
Write __format__ for your own class and explain why t-strings help against injection.
Real world scenario: printing a pay slip

A payroll script reads hours and rate for each worker, works out the pay and prints a pay slip where every column lines up: names left aligned in 15 characters, amounts right aligned with two decimals and thousands separators. This is exactly f"{name:<15}{pay:>12,.2f}". Without widths, columns zigzag and the slip is hard to check.

Chapter summary

  1. input(prompt) shows the prompt, waits for Enter and returns text. Use int() or float() before doing maths.
  2. Several values on one line: a, b = map(int, input().split()).
  3. f-strings put values into text: f"{name} is {age}". {x!r} uses repr, {x = } shows the expression too.
  4. Format spec: [[fill]align][sign][#][0][width][grouping][.precision][type], for example {amount:>12,.2f}.
  5. Width is a minimum, centre puts the extra pad on the right, rounding goes half to even on the stored value.
  6. % formatting and str.format() are older. Know them, but use f-strings in new code.
  7. Check input in a loop with try and except ValueError, so typing mistakes do not crash the program.
