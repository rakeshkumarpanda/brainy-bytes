Lesson 1 of 11

Why we need loops

Source: Python 3.14 tutorial sections 4.2 to 4.6 and PCEP-30-02 section 2.2.

What it is
A loop runs the same block of code again and again. Python has two loops: while repeats as long as a condition is True, and for repeats once for each item of a sequence.
Why we need it
Computers are good at boring, repeated work: printing 1,000 pay slips, checking every row of a file, trying every password on a list. Writing the same line 1,000 times is impossible to maintain. A loop writes it once.
How it works
Each repetition is called an iteration or a turn. Before every turn, Python checks if it should go on: is the condition still True (while), or is there another item (for)?
Real world scenario: washing a pile of plates

"While there are dirty plates, take one and wash it" is a while loop: you do not know how many plates there are, you just check before each one. "For each of the 12 plates on the table, wash it" is a for loop: you walk through a known collection. If you forget to take a plate off the pile, the while loop never ends. In code that is an infinite loop.

for loops and range()

range(start, stop, step)Exam favourite
start, start + step, start + 2·step, ... while still before stop
stop is never included. start defaults to 0, step to 1. step must not be 0.
How many numbers range givesExam favourite
len = max(0, ⌈(stop − start) / step⌉)
range(1, 10, 3) has ⌈9/3⌉ = 3 numbers: 1, 4, 7.
Download this program (.py)Save it, open it in any editor and run it with python3 range.py.
In the exam
range(5) is 0, 1, 2, 3, 4: five numbers, but 5 itself is not included. This "stop is excluded" rule matches list indexes, so range(len(items)) gives every valid index.
Going deeper: range is lazy

range(10**12) does not build a trillion numbers. It is a small object that knows start, stop and step and works out each number when asked. len(), indexing and the in test are all O(1) maths, for example 999 in range(0, 10**12, 3) is answered instantly.

Turns of a nested loopExam favourite
outer × inner
3 rows × 5 columns = 15 prints. Three nested loops of n each run n3 times.
Triangle loopExam favourite
1 + 2 + ... + n = n(n + 1)/2
When the inner loop runs i times on turn i, the total is a triangular number.
Common mistake
break only leaves the inner loop. To leave two loops at once, put them in a function and use return, or set a flag and check it in the outer loop.

Common mistake
zip stops at the shortest list. zip([1, 2, 3], "ab") gives only two pairs. Python 3.10 added zip(..., strict=True) to raise an error when the lengths differ.

Bottom line: use for whenever you walk over a collection or a range. Use while when you wait for something to happen.

Remember
An infinite loop is not always a bug: servers and games run while True: with a break or return inside. In the REPL or a terminal, press Ctrl+C to stop a runaway loop.

The maths of loops

Length of a rangeExam favourite
len(range(a, b, s)) = max(0, ⌈(b − a)/s⌉)
Works for negative steps too: range(10, 0, -3) has ⌈-10/-3⌉ = 4 numbers.
Last number of a range
a + (len − 1) · s
range(0, 100, 7)[-1] = 0 + 14 × 7 = 98.
Sum of an arithmetic sequenceExam favourite
S = n(first + last)/2
sum(range(1, 101)) = 100 × 101 / 2 = 5050 (the young Gauss story).
Turns to halve n down to 1
⌊log2 n⌋
while n > 1: n //= 2 runs about log2 n times. This is why binary search is fast.
Digits of n (turns of the digit loop)
⌊log10 n⌋ + 1
The digit loop above ran 5 times for 90731.
Worked example: how many times does the inner print run?
  1. for i in range(1, 5): for j in range(i): print(j)
  2. On turn i, the inner loop runs i times: 1, 2, 3, 4.
  3. Total = 1 + 2 + 3 + 4.
  4. 4 × 5 / 2 = 10
Lesson 9 of 11

From beginner to expert

One idea, four depths

A loop repeats a job. for does it once per item, while keeps going until a condition says stop.

range(start, stop, step) excludes stop. break leaves, continue skips, else runs when no break happened. Use accumulator, counter, maximum and search patterns, and enumerate and zip instead of index loops.

for works with any iterable: it calls iter() once and next() each turn until StopIteration (Advanced 2.1). Changing a list while looping over it skips items, so loop over a copy (items[:]) or build a new list.

Loop analysis is the start of algorithm analysis: counting turns gives the running time, O(n) for one loop, O(n2) for two nested loops. Loop invariants (a statement true before and after every turn) are how computer scientists prove that a loop is correct, as in Hoare logic.

Beginner
Write while and for loops, use range() correctly, and stop with break.
Intermediate
Use the standard patterns, nested loops, enumerate and zip, and count how many times a loop runs.
Expert
Explain the iterator protocol behind for, avoid changing a list while looping, and prove a loop correct with an invariant.
Real world scenario: an ATM PIN check

An ATM gives you three tries for your PIN. That is a loop of at most 3 turns: if the PIN is right, break and show the menu. If all three turns end without a break, the else block keeps the card. The for loop with else says this exactly: for attempt in range(3): ... break, else: keep the card.

Chapter summary

  1. while repeats while a condition is True. Something in the body must change the condition, or the loop never ends.
  2. for repeats once per item of a list, text, range or any other iterable.
  3. range(start, stop, step) excludes stop. Its length is max(0, ⌈(stop − start)/step⌉).
  4. break leaves the loop, continue skips to the next turn, pass does nothing, and a loop else runs when no break happened.
  5. Patterns: accumulator, counter, running maximum, search with break, building a list, sentinel loop.
  6. Nested loops run outer × inner times. A triangle loop runs n(n + 1)/2 times.
  7. Use enumerate for positions, zip for walking lists together, reversed and sorted for order.
