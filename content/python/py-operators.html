Operators: the verbs of a program

Source: Python 3.14 Language Reference, chapter 6 (Expressions), and PCEP-30-02 section 1.4.

What it is
An operator is a symbol that does something with values, called operands. In 7 + 2 the operator is + and the operands are 7 and 2. A combination of values and operators is an expression, and it always produces a value.
Why we need it
Programs exist to work things out: a bill total, an average, whether a user may log in. Operators are how we tell Python to calculate, compare and decide.
How it works
Python reads an expression, decides the order of the operations with fixed priority rules, and works them out one at a time until one value is left.

How and and or really work
  1. a and b: look at a. If a is falsy (False, 0, "", [], None), the answer is a and b is never looked at.
  2. Otherwise the answer is b.
  3. a or b: look at a. If a is truthy, the answer is a and b is skipped. Otherwise the answer is b.
  4. Skipping the right side is called short circuit evaluation
In the exam
not has a higher priority than and, and and is higher than or. So True or False and False is True or (False and False) = True.

Bitwise operators

Bitwise notExam favourite
~x = −x − 1
Python ints act like two's complement numbers with endless bits.
ShiftsExam favourite
x << k = x · 2k, x >> k = x // 2k
Shifting is a fast way to multiply or divide by powers of 2.
Useful tricks
x & 1 (odd?), x & (x − 1) == 0 (power of 2?), x ^ x == 0
Used in LeetCode problems such as Single Number and Power of Two.
Real world scenario: file permissions on Linux

Read, write and run permissions are three bits: 4, 2 and 1. 7 (111) means all three, 5 (101) means read and run. A program checks "can this user write?" with perm & 2 != 0. Python's os and stat modules use exactly these bitwise operators.

The maths behind the operators

Euclidean style division in PythonExam favourite
a = q · b + r, q = ⌊a/b⌋, 0 ≤ r < b (b > 0)
For b < 0, b < r ≤ 0.
Last digit and dropping itExam favourite

n % 9 == digit_sum(n) % 9
Because 10 % 9 = 1, every place value leaves remainder 1.

ulp(x) ≈ |x| · 2−52
math.ulp(x). Bigger numbers have bigger gaps between floats.

Worked example: -17 // 5 and -17 % 5
  1. -17 / 5 = -3.4.
  2. Floor (round down) of -3.4 is -4, so -17 // 5 = -4.
  3. r = a − b · q = -17 − 5 × (-4) = -17 + 20 = 3.
  4. -17 // 5 = -4 and -17 % 5 = 3. Check: -4 × 5 + 3 = -17

From beginner to expert

One idea, four depths

Operators are like buttons on a calculator. Python presses them in a fixed order: brackets, powers, times and divide, then plus and minus.

// floors and % follows the sign of the divisor, so a == (a // b) * b + a % b always holds. and and or short circuit and return an operand. Floats are binary fractions, so compare them with math.isclose().

Every operator calls a special method: a + b tries a.__add__(b), then b.__radd__(a). Comparisons can be chained because a < b < c compiles to a < b and b < c with b evaluated once. Advanced 1.1 builds your own operators.

IEEE 754 binary64 gives correctly rounded + - * / and sqrt. Python's repr uses the shortest round trip algorithm (David Gay), and its int ** int uses binary exponentiation in O(log n) multiplications. Errors in long float sums can be cut with math.fsum (Shewchuk's exact summation).

Beginner
Use + - * / // % ** and comparisons, and add brackets when unsure.
Intermediate
Know floor division with negatives, short circuit, chained comparisons, bit tricks and float pitfalls.
Expert
Explain operator dispatch to special methods, IEEE 754 rounding, math.fsum and exponentiation by squaring.
Real world scenario: splitting a restaurant bill

Six friends share a bill of 1,000 rupees. 1000 // 6 = 166 rupees each, and 1000 % 6 = 4 rupees are left over, so four friends pay 167. With floats, 1000 / 6 = 166.666... cannot be paid exactly. Apps that split bills use // and % exactly like this, and Decimal for the money itself.
