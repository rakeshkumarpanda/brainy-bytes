Step 1Core Python · Getting started

1.1What a program is and your first Python program

  • Program and language A program is a list of exact instructions. Lexis is the vocabulary, syntax the grammar, semantics the meaning.
  • How CPython runs a file Source is checked and compiled to bytecode, then the virtual machine runs it top to bottom. A SyntaxError anywhere stops everything.
  • print() print(*values, sep=" ", end="\n"). str() on each value, sep between, end after. N = L + (n − 1)s + e.
  • Keywords and blocks 35 keywords in 3.14, soft keywords match, case, type, _. # starts a comment. Indent blocks with 4 spaces.
  • Three errors Syntax error before running, runtime error at the bad line, logic error never reported.
  • The full form of print()print(*values, sep=" ", end="\n", file=sys.stdout, flush=False)
  • Characters written by one print()N = ∑ len(str(vi)) + (n − 1) · len(sep) + len(end)
  • Characters from one print()N = L + (n − 1) · s + e
  • Trap In the REPL, typing 2 + 3 shows 5 without print(). In a .py file, nothing appears unless you call print(). Beginners often expect the REPL behaviour inside a file.
  • Exam sep and end must be given by name (keyword arguments). print("A", "B", "-") prints A B - with the dash as a third value, it does not change sep.
  • Trap Python uses indentation where many languages use curly brackets. Mixing tabs and spaces, or using 3 spaces on one line and 4 on the next, gives IndentationError. PEP 8 says: always 4 spaces.
  • Exam PCEP asks which names follow PEP 8 conventions. snake_case for variables and functions, CapWords for classes, UPPER_CASE for constants.

1.2Variables, values, types and numeral systems

  • Names and objects name = value binds a name to an object. b = a gives a second name to the same object. Objects have id, type, value.
  • Basic types int (unlimited), float (about 15 to 17 digits), complex, bool (subclass of int), str, None. All immutable.
  • Bases 0b, 0o, 0x literals. bin(), oct(), hex() to text. int(text, base) back. N = sum of di bi.
  • Conversions int() cuts towards zero, int("3.5") is ValueError, round() ties to even, bool("0") is True.
  • Naming Letters, digits, _ , no leading digit, no keyword, case sensitive, snake_case, do not shadow built ins.
  • Scientific notationa e b = a × 10b
  • Value of a number written in base bvalue = dkbk + ... + d1b1 + d0b0
  • Base b to decimalN = ∑i=0k di · bi
  • Decimal to base bd0 = N mod b, N ← N // b, repeat
  • Exam bool is a kind of int: True == 1 and False == 0, so True + True is 2. This surprises many people in exams.
  • Trap A leading zero is not allowed on a decimal literal in Python 3: 017 is a SyntaxError. Write 0o17 for octal.
  • Exam int(-3.99) is -3, not -4. int() cuts towards zero. math.floor(-3.99) is -4 because floor goes down.
  • Trap Naming a variable list or str hides the built in. After list = [1, 2], calling list("abc") fails with TypeError: 'list' object is not callable.

1.3Operators, expressions and the order Python works them out

  • Division / gives float. // floors (towards minus infinity). % has the sign of the divisor. a == (a // b) * b + a % b.
  • Priority brackets, **, unary, * / // %, + -, shifts, & ^ |, comparisons, not, and, or. ** right to left. -2 ** 2 = -4.
  • Comparisons Chained 1 < x < 10. Floats: use math.isclose(). 0.1 + 0.2 == 0.3 is False.
  • Logic and, or short circuit and return an operand. not > and > or.
  • Bits ~x = -x - 1. x << k = x * 2**k. x & 1 tests odd. x & (x - 1) == 0 tests power of 2.
  • Floor divisiona // b = ⌊a ÷ b⌋
  • Remainder (modulo)a % b = a − b · (a // b)
  • The division identitya == (a // b) * b + a % b
  • Safe float comparison|a − b| ≤ max(rel · max(|a|, |b|), abs_tol)
  • Bitwise not~x = −x − 1
  • Shiftsx << k = x · 2k, x >> k = x // 2k
  • Euclidean style division in Pythona = q · b + r, q = ⌊a/b⌋, 0 ≤ r < b (b > 0)
  • Last digit and dropping itn % 10, n // 10
  • Exam A unary operator has one operand (-x, not x, ~x). A binary operator has two (a + b). The same symbol - can be either.
  • Exam C and Java cut integer division towards zero, so -7 / 2 is -3 there. Python floors, so -7 // 2 is -4. Exams love this difference.
  • Trap -2 ** 2 is -4, not 4. The power is done first, then the minus. Write (-2) ** 2 when you mean minus two squared.
  • Exam not has a higher priority than and, and and is higher than or. So True or False and False is True or (False and False) = True.
  • Trap "5" + 5 is a TypeError. Python never turns a number into text by itself. Use str(5) or an f-string.

1.4Input, output and formatting text

  • input() Shows a prompt, waits, returns text. Convert with int() or float(). a, b = map(int, input().split()).
  • f-strings f"{expr}", {x!r}, {x = }, {x:spec}. {{ and }} for real brackets.
  • Format spec [[fill]align][sign][#][0][width][grouping][.precision][type]. Width is a minimum. .2f rounds half to even.
  • Older formatting "%s %d" % (a, b) and "{} {}".format(a, b). Prefer f-strings.
  • Safe input while True + try int(text) except ValueError + range check + break.
  • Format spec grammar[[fill]align][sign][#][0][width][grouping][.precision][type]
  • Padding added by a widthpad = max(0, width − len(text))
  • Centre alignmentleft = ⌊pad / 2⌋, right = pad − left
  • Trap input() returns text even when the user types digits. "5" + "5" is "55". Convert first, then calculate.
  • Exam .2f rounds the stored binary value, and exact halves go to the even digit: f"{2.5:.0f}" gives 2 and f"{2.675:.2f}" gives 2.67.

Step 2Core Python · Control flow

2.1Making decisions: if, elif, else and match

  • Chains if, any number of elif, optional else. First truthy condition wins, the rest are skipped. Strictest test first.
  • Truthiness Falsy: False, None, 0, 0.0, "", empty collections. "0" and [0] are truthy.
  • Combining and, or, not, 13 <= x <= 19, x in (a, b). x == a or b is always truthy.
  • One liners a if cond else b. (n := len(x)) assigns inside an expression.
  • match Literal, capture, _, |, [a, *rest], {"k": v}, Class(), guard if. A bare name captures.
  • Conditional expressionvalue_if_true if condition else value_if_false
  • De Morgan lawsnot (a and b) == (not a) or (not b), not (a or b) == (not a) and (not b)
  • Number of pathsk independent if statements give up to 2k combinations
  • Trap if day == "Sat" or "Sun": is always True. Python reads it as (day == "Sat") or "Sun", and "Sun" is truthy. Write day in ("Sat", "Sun").
  • Trap A plain name in a case is a capture, not a comparison. case RED: catches everything and binds it to RED. To compare with a constant, use a dotted name such as case Color.RED:.

2.2Loops: while, for, range, break and continue

  • while and for while repeats while a condition is True. for repeats once per item of an iterable.
  • range range(start, stop, step) excludes stop. len = max(0, ceil((stop - start)/step)). step 0 is an error.
  • Loop control break leaves, continue skips, pass does nothing, loop else runs when no break happened.
  • Patterns Accumulator, counter, running max, search with break, build a list. Nested loops: outer x inner turns.
  • Pythonic loops enumerate(items, start=1), zip(a, b) stops at the shortest, reversed(), sorted().
  • range(start, stop, step)start, start + step, start + 2·step, ... while still before stop
  • How many numbers range giveslen = max(0, ⌈(stop − start) / step⌉)
  • Turns of a nested loopouter × inner
  • Triangle loop1 + 2 + ... + n = n(n + 1)/2
  • Length of a rangelen(range(a, b, s)) = max(0, ⌈(b − a)/s⌉)
  • Sum of an arithmetic sequenceS = n(first + last)/2
  • Exam range(5) is 0, 1, 2, 3, 4: five numbers, but 5 itself is not included. This "stop is excluded" rule matches list indexes, so range(len(items)) gives every valid index.
  • Exam The loop else is not "else if the loop did not run". It means "no break happened". A for loop over an empty list runs its else block.
  • Trap break only leaves the inner loop. To leave two loops at once, put them in a function and use return, or set a flag and check it in the outer loop.
  • Trap zip stops at the shortest list. zip([1, 2, 3], "ab") gives only two pairs. Python 3.10 added zip(..., strict=True) to raise an error when the lengths differ.

Step 3Core Python · Data collections

3.1Strings: text, slicing, methods and Unicode

  • Making strings Quotes: single, double or triple. Escapes start with a backslash. r"..." is a raw string. len() counts characters.
  • Index and slice s[0] first, s[-1] last. s[a:b:c] includes a, excludes b. s[::-1] reverses. Slices never raise IndexError.
  • Immutable You cannot change a character. Methods return new strings: write s = s.upper().
  • Key methods strip, split, join, replace, find (-1) vs index (ValueError), count, startswith, isdigit, isalpha, upper, lower.
  • Unicode ord("A") = 65, chr(97) = "a". UTF-8 uses 1 to 4 bytes per character. Compare strings by code point.
  • Index of a character0, 1, ..., len(s) − 1 from the left, and −1, −2, ..., −len(s) from the right
  • Slices[start:stop:step]
  • Number of substrings of a text of length nn(n + 1) / 2
  • Number of different arrangements (anagrams)n! / (c1! · c2! · ...)
  • Exam A backslash starts an escape sequence: the backslash and the next character together stand for one special character. That is why len of the new line escape is 1. In a raw string (r before the quote) Python keeps every backslash, which is handy for Windows paths and regular expressions (Advanced 6.1).
  • Exam A single index outside the string raises IndexError. A slice outside the string never fails: it just gives what is there, or an empty string.
  • Trap Strings are compared letter by letter by code point, not by dictionary order. All upper case letters (65 to 90) come before all lower case letters (97 to 122), so "Zebra" < "apple" is True. "10" < "9" is True too, because "1" comes before "9". Turn text into numbers before comparing numbers.
  • Trap Every method returns a new string. s.upper() alone on a line does nothing useful. Write s = s.upper() to keep the result.
  • Exam split() with no argument and split(" ") are different. "a b".split() gives ["a", "b"], but "a b".split(" ") gives ["a", "", "b"] because there are two spaces.
  • Trap Always say the encoding when you open a text file: open(name, encoding="utf-8"). Otherwise Python uses the system default, which is not UTF-8 on every Windows computer (Core 5.3).

3.2Lists: storing, changing, sorting and copying

  • Lists Ordered, changeable, any types. Index from 0, slice like strings. len, min, max, sum, in.
  • Add and remove append (one item), extend (many), insert(i, x). remove(x) first match, pop() last, pop(i), del items[i].
  • Sorting sort() changes the list and returns None. sorted() returns a new list. key= and reverse=. Stable.
  • Copies b = a is the same list. a[:] or a.copy() is a shallow copy. copy.deepcopy for nested lists. [[0]*n for _ in range(m)].
  • Costs append, pop(), index access O(1). insert(0), pop(0), in, remove O(n). Bubble sort n(n-1)/2 comparisons.
  • Item of a matrixmatrix[row][col]
  • Comparisons in the worst case(n − 1) + (n − 2) + ... + 1 = n(n − 1)/2
  • Average cost of an append (amortised)(n + total copies) / n < a small constant
  • Bubble sort comparisonsn(n − 1)/2
  • Exam append adds one item, even if that item is a list. [1, 2].append([3, 4]) gives [1, 2, [3, 4]]. extend adds the items one by one and gives [1, 2, 3, 4].
  • Trap Do not remove items from a list while a for loop is walking over it. The loop skips the item after each removal. Loop over a copy (for x in items[:]) or build a new list instead.
  • Exam [[0] * 3] * 3 makes one inner list and three references to it, so changing one row changes all three. Build a grid with a comprehension: [[0] * 3 for _ in range(3)].
  • Exam The number of names must match the number of items, unless one name has a star. a, b = [1, 2, 3] raises ValueError: too many values to unpack.

3.3Tuples and sets: fixed records and unique items

  • Tuples Immutable ordered sequence. (5,) is a tuple, (5) is not. count and index only. Unpack with a, b = t.
  • Hashable Dict keys and set items must be hashable: numbers, strings, tuples of hashables, frozensets. Not lists, sets or dicts.
  • Sets Unique items, no order. set() is empty. add, remove (KeyError), discard (safe), pop (any item).
  • Set algebra | union, & intersection, - difference, ^ symmetric difference, <= subset. Methods accept any iterable.
  • Counting |A u B| = |A| + |B| - |A n B|. A set of n items has 2^n subsets. x in set is O(1) on average.
  • Size of a union (inclusion and exclusion)|A ∪ B| = |A| + |B| − |A ∩ B|
  • Number of subsets (the power set)2n
  • Exam The comma makes a tuple, not the brackets. (5) is the number 5. (5,) is a tuple with one item. This is a favourite exam trick.
  • Trap A tuple holds references. You cannot change which objects it holds, but if one of them is a list, that list can still change. Such a tuple is not hashable, so it cannot be a dict key.
  • Exam {} is an empty dict, not an empty set. Write set() for an empty set. Also, a set can only hold hashable items: numbers, strings, tuples of them, but not lists or other sets.
  • Exam The operators need two sets. The methods accept any iterable, so A.union([1, 2]) works but A | [1, 2] raises TypeError.

3.4Dictionaries: keys, values and hash tables

  • Dicts Key to value mapping. Keys unique and hashable, values anything. Ordered by insertion since 3.7.
  • Read safely d[k] raises KeyError. d.get(k, default) does not. k in d checks keys only.
  • Change d[k] = v adds or replaces. del d[k], d.pop(k, default), d.popitem() (last added), update, |, |=.
  • Loop for k in d (keys), d.values(), d.items(). Do not add or remove keys while looping, use list(d).
  • Patterns Count: d[k] = d.get(k, 0) + 1 or Counter. Group: dict of lists or defaultdict(list). Two Sum: dict of seen values.
  • Slot of a keyslot = hash(key) mod table size
  • Load factorα = used slots / table size ≤ 2/3
  • Exam for x in d gives the keys, not the values and not the pairs. Use d.values() for values and d.items() for (key, value) pairs. x in d also checks keys only.
  • Trap keys(), values() and items() return views: windows onto the dict that update by themselves. Adding or removing keys while you loop over a dict raises RuntimeError. Loop over list(d) instead.
  • Trap dict.fromkeys(keys, []) gives every key the same list object. Appending to one changes all of them. Use a comprehension {k: [] for k in keys} instead.
  • Exam Keys are compared with ==. Because 1 == 1.0 == True and they have the same hash, they are the same key: the dict keeps the first key object and the last value. Use one type for your keys.

Step 4Core Python · Functions

4.1Functions: def, return and every kind of argument

  • def and return def name(params): body. return value leaves the function. No return gives None. print is not return.
  • Argument kinds Positional by order, keyword by name, positional before keyword. Defaults make parameters optional.
  • Star parameters *args tuple of extra positionals, **kwargs dict of extra keywords. Bare * means keyword-only after it, / means positional-only before it.
  • Mutable default Defaults are made once at def time. Use None, then create the list inside.
  • Functions are objects Assign them, store them, pass them: sorted(key=f), map(f, items). Docstring on the first line, type hints are not enforced.
  • A function maps each input to one outputf: X → Y, x ↦ f(x)
  • Composition(f ∘ g)(x) = f(g(x))
  • Exam A parameter is the name in the def line (name, width). An argument is the value you pass in the call ("Asha", 4). Exams use both words, so learn the difference.
  • Exam A function with no return, or with a bare return, gives back None. That is why a = show_double(5) printed 10 but left a as None.
  • Exam describe(name="Sara", 25) is a SyntaxError: a positional argument may not follow a keyword argument. Python refuses to even start the program.
  • Exam In a def line, * and ** collect arguments. In a call, * and ** spread a list or dict out into separate arguments. Same symbols, opposite jobs.

4.2Scope and recursion: LEGB, closures and the call stack

  • Scopes Local (inside a call), Enclosing, Global (module), Built-in: LEGB. Assigning makes a name local in the whole function.
  • global and nonlocal global x assigns the module x. nonlocal x assigns the enclosing function x. Reading needs neither.
  • Closures An inner function that remembers enclosing names (cells). Used for counters, factories and decorators.
  • Recursion Base case + smaller recursive case. Each call is a frame. Limit about 1000, RecursionError.
  • Costs T(n) = T(n-1) + c is O(n). Naive fib 2F(n+1) - 1 calls, lru_cache makes it n + 1. Hanoi 2^n - 1. Fast power O(log n).
  • Recurrence for a simple recursionT(n) = T(n − 1) + c gives T(n) = O(n)
  • Calls made by naive fib(n)C(n) = C(n − 1) + C(n − 2) + 1 = 2F(n + 1) − 1
  • Tower of Hanoi movesM(n) = 2M(n − 1) + 1 = 2n − 1
  • Exam Assigning to a name inside a function makes a new local name, even if a global with the same name exists. This is called shadowing. Changing an object (items.append) is different from rebinding a name (items = [...]): the first is seen by the caller, the second is not.
  • Exam Python decides which names are local when it compiles the function, not while it runs. If a name is assigned anywhere in the function, it is local in the whole function.
  • Exam global reaches the module scope. nonlocal reaches the nearest enclosing function scope and is a SyntaxError at the top level. Decorators (Advanced 1.2) are built from closures.
  • Trap Each call uses a frame on the call stack. To protect the program, CPython stops at about 1,000 frames deep with RecursionError. sys.setrecursionlimit can raise the limit, but a recursion that deep is usually better written as a loop.

4.3lambda, map, filter and comprehensions

  • lambda lambda args: expression. One expression, no statements. Best as an argument, def otherwise.
  • key functions sorted/min/max(items, key=f). Tuple keys sort by several fields. -x reverses a number key.
  • map, filter, reduce Lazy iterators: list(map(f, a)), list(filter(test, a)). functools.reduce(f, a, start) folds to one value.
  • Comprehensions [expr for x in a if test], [a if t else b for x in s], {k: v for ...}, {x for ...}. Outer for first.
  • Generator expressions (expr for x in a): lazy, one use, tiny memory. sum(x*x for x in a), any(...), all(...).
  • List comprehension[expression for item in iterable if condition]
  • With if-else[a if test else b for item in iterable]
  • Set builder notation{ f(x) | x ∈ S, p(x) }
  • reduce is a foldreduce(⊕, [a1, a2, a3], s) = ((s ⊕ a1) ⊕ a2) ⊕ a3
  • Exam A lambda cannot contain statements such as if blocks, for loops, return or assignment with =. It can contain a conditional expression: lambda n: "even" if n % 2 == 0 else "odd".
  • Trap map and filter return iterators, not lists. They give each value once, only when asked. Wrap them in list() to see all the values, and do not loop over the same map object twice.
  • Exam [n for n in nums if n % 2 == 0 else 0] is a SyntaxError. An if after for only filters and has no else.

Step 5Core Python · Errors, modules and files

5.1Exceptions: try, except, else, finally and raise

  • try and except try: risky code. except X as err: handles X and its children. First matching handler only.
  • else and finally else runs if no exception. finally always runs (cleanup). Order: try, except..., else, finally.
  • Hierarchy BaseException > Exception > ArithmeticError > ZeroDivisionError. LookupError > KeyError, IndexError. KeyboardInterrupt is not an Exception.
  • raise raise ValueError("msg"). Bare raise re-raises. raise New() from err sets __cause__. Custom: class MyError(Exception).
  • Style Catch specific classes, never bare except. assert is for programmer checks (-O removes it). EAFP. with closes resources.
  • Handlers checked before a matchposition of the first matching except clause
  • Chance that at least one of n independent steps fails1 − (1 − p)n
  • Trap Avoid a bare except: or except BaseException:. They also catch KeyboardInterrupt and SystemExit, so Ctrl+C stops working. Catch Exception at most, and only where you log or report the error.
  • Exam The order is fixed: try, then except clauses, then else, then finally. You need at least one except or a finally. else keeps code out of the try block, so you do not accidentally catch errors from it.

5.2Modules and packages: import, the standard library and pip

  • import forms import m, import m as a, from m import x, from m import x as y. Avoid import *. Relative: from . import x.
  • How import works Check sys.modules, search sys.path, run the file once, cache it, bind the name. importlib.reload re-runs.
  • math and random ceil, floor, trunc, sqrt, isqrt, hypot, factorial, comb, gcd, log, isclose. randint(a, b) includes b, randrange excludes stop, seed repeats.
  • Packages Folder + __init__.py. _name is private by convention. __all__ controls import *. __pycache__ holds .pyc files.
  • Main guard and pip if __name__ == "__main__": main(). pip install inside a venv. pip freeze > requirements.txt.
  • Combinations and permutationsC(n, k) = n! / (k!(n − k)!), P(n, k) = n! / (n − k)!
  • Euclid: greatest common divisorgcd(a, b) = gcd(b, a mod b), gcd(a, 0) = a
  • Exam floor goes down and trunc goes toward zero. They agree for positive numbers and differ for negative ones: floor(−4.8) is −5, trunc(−4.8) is −4. round() is a built-in, not in math, and rounds halves to the even number.
  • Trap random gives pseudo-random numbers from the Mersenne Twister algorithm: good for games and simulations, but predictable. For passwords, tokens and anything secret use the secrets module (secrets.token_hex(16)).
  • Trap Any file name.py that Python can find is a module called name. Use lower case names with underscores, and never name your file after a standard module: a file called random.py in your folder hides the real random module, and import random gives you your own file.

5.3Files: reading, writing, modes, paths and streams

  • open and with with open(path, mode, encoding="utf-8") as f: closes automatically. Modes r, w (empties), a, x (new only), +, b.
  • Reading read(), read(n), readline() ("" at end), readlines(), for line in f (best for big files). Lines keep their new line.
  • Writing write(s) and writelines(list) add no new lines. print(x, file=f) does. write returns characters written.
  • Binary and cursor "rb"/"wb" use bytes. bytearray + readinto. seek(n) moves, tell() reports.
  • Errors and paths OSError family: FileNotFoundError (ENOENT), FileExistsError, PermissionError. pathlib.Path / "x", glob, read_text.
  • File size in bytes of an ASCII textsum of len(line) for all lines, new lines included
  • UTF-8 size1 byte for code points 0 to 127, 2 up to 2,047, 3 up to 65,535, 4 above
  • Exam Lines keep their new line character. Use line.strip() or line.rstrip("\n") before you compare or split them. For big files loop with for line in f, which reads one line at a time instead of loading gigabytes into memory.
  • Trap Add t (text, the default) or b (binary) to any mode: "rb", "wb", "ab", "r+b". The most common accident is opening a file with "w" when you meant "a": the old contents are gone at once.
  • Trap Without encoding=..., open() uses a default that depends on the computer. It is UTF-8 on Linux and macOS but can be an old code page on Windows, so a file written on one computer may not read on another. Since Python 3.15 the default becomes UTF-8 everywhere (PEP 686), but writing encoding="utf-8" is still the safe habit.
  • Trap os.remove, os.rename and shutil.rmtree do not use a recycle bin: deleted files are gone. Print the paths and check them before you delete anything in a loop.
  • Trap Never split CSV lines with line.split(","). A value like "Ravi, Jr" contains a comma and is stored in quotes. The csv module handles quotes, commas and new lines inside values correctly. Advanced 6.2 covers csv, json, xml and sqlite3 in depth.

Step 6Core Python · Object oriented programming

6.1Classes and objects: attributes, methods, self and encapsulation

  • Class and object class C: defines a blueprint. C(...) makes an object and runs __init__(self, ...). self is the object.
  • Two kinds of attribute self.x is per object (in obj.__dict__). x = ... in the class body is shared. Read looks in the object, then the class. Write goes to the object.
  • Shared list trap A list or dict class attribute is shared by all objects. Create it in __init__.
  • Text forms __str__ for print and str, __repr__ for repr, lists and debugging. Write __repr__ at least.
  • Introspection and privacy type, isinstance, hasattr, getattr, setattr, vars, __name__, __module__, __bases__. _x is a convention, __x becomes _Class__x. is = same object.
  • Length of a vector (Pythagoras)|v| = √(x2 + y2)
  • Dot producta · b = axbx + ayby
  • Exam self is not a keyword. It is only the name every Python programmer uses for the first parameter of a method. Python fills it in for you: rex.bark() becomes Dog.bark(rex). Forget self in the def line and the call fails with "takes 0 positional arguments but 1 was given".
  • Exam Writing obj.attr = value never goes to the class. It always creates or changes the attribute on that one object. That is why a.species = "wolf" left b.species and Dog.species alone.
  • Trap A class attribute that holds a list, dict or set is ONE object for all instances. Changing it with append or update through any object changes it for every object. Create such data in __init__ with self.items = [] instead. This is the same trap as a mutable default argument (4.1).
  • Exam Inside a method, change a class attribute through the class name: Student.count += 1. Writing self.count += 1 reads the class value but then stores the result on the object, so the class counter would never change.
  • Exam Encapsulation means an object guards its own data and offers methods to work with it, so outside code cannot put it into a bad state (like a negative balance). Python trusts programmers: it has no real private keyword like Java. Use one underscore for internal things, and properties (Advanced 1.3) when you need checks on reading or writing.

6.2Inheritance: super(), overriding, polymorphism and the MRO

  • Inherit and override class Child(Parent): reuses Parent. Writing a method again overrides it. Lookup: object, class, then parents in MRO order, ending at object.
  • super() super().__init__(...) runs parent setup. super().m() extends a method. super() means the next class in the MRO of the object.
  • Checks isinstance counts children, type(x) is C does not. issubclass(bool, int) is True. __bases__ and __mro__ show the family.
  • Polymorphism One call works on many types. Duck typing needs only the method. Abstract methods: NotImplementedError or abc with @abstractmethod.
  • MRO and composition C3: child before parents, parents in written order, each once. Impossible order is TypeError. Prefer has a over is a.
  • C3 linearisationL[C] = C + merge(L[B1], ..., L[Bn], [B1, ..., Bn])
  • CircleA = πr2
  • Heron for a triangles = (a + b + c) / 2, A = √(s(s − a)(s − b)(s − c))
  • Exam An overriding method normally keeps the same parameters as the parent one, so code that works with an Animal also works with a Dog. This rule is called the Liskov substitution principle.
  • Trap A child __init__ replaces the parent one completely. If it does not call super().__init__(...), the attributes the parent sets are never created.
  • Exam Prefer isinstance over type(x) == C, because a child object is also a valid parent object. Every class inherits from object in the end, and bool is a child of int, which is why True + True is 2.
  • Exam super() does not mean "my parent". It means "the next class in the MRO of the object I am working on". Inside B, super().hello() went to C for a D object but to A for a B object. That is what lets every class in a diamond run exactly once.

Step 2Advanced Python · Iterators, generators and context managers

2.1Iterators and generators

  • Iterator protocol iter(x) gives an iterator. next(it) gives a value or raises StopIteration. next(it, default) avoids the error. A for loop does this for you.
  • Iterable versus iterator Iterables (list, range, dict) give a fresh iterator each time. Iterators (zip, map, files, generators) are used up after one pass.
  • Generators A function with yield returns a generator. Nothing runs until next(). It pauses at each yield and keeps its locals. Return ends it.
  • Pipelines and laziness Chain generators: values are made only when asked, memory stays constant, and islice or break stops work early.
  • Advanced control yield from delegates and returns the inner return value. send(v), throw(e), close() (GeneratorExit). Prime with next() before send.
  • Memory of a list against a generatorlist: about 8n bytes of pointers plus the items, generator: a constant (about 200 bytes)
  • Work done by a lazy searchitems read = position of the first match (k), not n
  • Exam iter(nums) gave a NEW iterator each time, so the first answer was False. An iterator returns itself from iter(), so the second was True. That is the whole difference: an iterable can make many iterators, an iterator is one walk that can be used once.
  • Trap Raising StopIteration ends the loop. Do not raise it inside a generator body: since Python 3.7 (PEP 479) it is turned into RuntimeError. In a generator, simply return.
  • Exam A function that contains yield anywhere is a generator function. Calling it runs nothing: the first line, print("start"), only ran at the first next(). After the last value the generator is closed, and list() on a used generator gives an empty list.
  • Trap A common bug: saving map(...) or zip(...) in a variable, looping over it once for a check, and then finding it empty the second time. Wrap it in list(...) if you need it twice.

4.1Complexity, timing and profiling

  • Big O Drop constants, keep the biggest term. Loops in a row add, nested loops multiply. O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2n).
  • Costs list: index O(1), append O(1) amortized, x in list O(n), insert(0)/pop(0) O(n). dict and set: O(1) average. sort O(n log n).
  • Measure timeit (python -m timeit -s setup stmt, best of several runs), time.perf_counter, realistic n.
  • Profile python -m cProfile -s cumulative file.py, tottime vs cumtime, fix only the hot spot. tracemalloc for memory, getsizeof is shallow.
  • Trade offs A better algorithm first. Sets for lookups, lru_cache for repeated work, generators to save memory.
  • Definition of Big Of(n) = O(g(n)) if there are numbers c > 0 and n0 with f(n) ≤ c · g(n) for every n ≥ n0
  • Sum of a loop inside a loop1 + 2 + ... + n = n(n + 1) / 2 = O(n²)
  • Geometric sum (doubling)1 + 2 + 4 + ... + n = 2n − 1 < 2n
  • Master theoremT(n) = a·T(n/b) + O(nd) gives O(nd) if d > logb a, O(nd log n) if d = logb a, O(nlogb a) if d < logb a
  • Trap Hidden loops count too. x in my_list, my_list.index(x), my_list.remove(x), my_list.insert(0, x), "".join and slicing a[i:j] each walk through items. Putting one of them inside a loop is the most common way Python code becomes quadratic by accident.
  • Exam Average case versus worst case: a dict lookup is O(1) on average, but if many keys had the same hash it could take O(n). Python adds random salt to str hashes so attackers cannot cause this on purpose. For interviews and exams, dict and set operations are O(1).
  • Exam sys.getsizeof is shallow. 5.1Threads and processes

  • When to use what I/O bound: threads or asyncio. CPU bound: processes (or python3.14t). Measure first.
  • Threads Thread(target, args), start, join, daemon. Shared memory means races: protect with with lock:.
  • Sync tools Lock, RLock, Semaphore(n), Event, Condition, Barrier, queue.Queue. Same lock order everywhere to avoid deadlock.

  • Speedup and efficiencyS = T1 / Tn, E = S / n
  • Amdahl's lawS(n) = 1 / ((1 − p) + p / n)
  • Threads for I/O workthreads ≈ cores × (1 + wait time / compute time)
  • Trap Every thread in a process shares the same global variables and objects. That makes it easy to pass data, and also easy to break data: two threads changing the same object at the same time is a race condition.
  • Trap counter = counter + 1 is really three steps: read, add, write. If another thread writes between your read and your write, your write wipes out its update. time.sleep(0) here forces a switch at the worst moment, but real programs hit the same bug by chance, often only under heavy load.
  • Exam A deadlock happens when thread 1 holds lock A and waits for lock B while thread 2 holds B and waits for A. Neither can go on. Prevent it by always taking locks in the same order, holding them briefly, or using a timeout.

  • Basics async def, await (only inside async def), asyncio.run(main()) once. Calling a coroutine function does not run it.

  • Control asyncio.timeout(s) and wait_for, task.cancel() and CancelledError (raise it again), Semaphore(k) to limit.
  • Pipelines asyncio.Queue(maxsize) with await put and get for back pressure. Async generators, async for, async with.
  • Never block No time.sleep or requests in coroutines. Use asyncio.sleep, httpx.AsyncClient, asyncio.to_thread or run_in_executor.
  • Time one by oneT = n × t
  • Time with all at onceT ≈ max(ti) + overhead
  • With a limit of k at onceT ≈ ⌈n / k⌉ × t
  • Trap Calling make_tea(...) only creates a coroutine object, it runs nothing. The code runs when it is awaited, or when it is wrapped in a task (gather, create_task, TaskGroup). Forgetting await is the most common asyncio bug: Python warns "coroutine ... was never awaited".
  • Trap Keep a reference to every task you create with create_task (in a list or a set), or use a TaskGroup. The loop holds tasks only weakly, so a task nobody refers to can disappear before it finishes.
  • Exam Cancelling a task raises CancelledError inside it at its current await. Clean up in finally blocks, and do not swallow CancelledError without raising it again, or the task cannot be stopped.
  • Trap A normal blocking call (time.sleep, requests.get, a slow calculation) inside a coroutine freezes the whole loop. Use the async version (asyncio.sleep, httpx.AsyncClient, aiofiles), or push the blocking call to a thread with asyncio.to_thread, or to a process pool with loop.run_in_executor.

1.2Sockets, TCP and UDP: under HTTP

  • Sockets socket(AF_INET, SOCK_STREAM) for TCP, SOCK_DGRAM for UDP. An address is (host, port). Ports 0 to 65,535. 127.0.0.1 local only, 0.0.0.0 every network card.
  • TCP calls Server: bind, listen, accept (new socket per client). Client: create_connection(addr, timeout). sendall, recv(n) gives 1 to n bytes, b"" means closed.
  • Framing TCP keeps no message borders. Length prefix with struct.pack("!I", n), or an end marker such as a new line. Loop until a message is complete.
  • UDP sendto and recvfrom, no handshake, borders kept, may lose or reorder. Used for DNS, games, video. 8 byte header.
  • Numbers MSS = MTU − 40. throughput ≤ window / RTT. window = bandwidth × RTT. /n network has 232 − n addresses.
  • Addresses in a networkaddresses = 232 − prefix, usable = addresses − 2
  • Window limit on speedthroughput ≤ window / RTT
  • TCP with loss (Mathis formula)throughput ≈ (MSS / RTT) × 1.22 / √p
  • Exam A socket only knows bytes. Turn text into bytes with .encode("utf-8") before sending and back with .decode("utf-8") after receiving. "é" is one letter but 2 bytes, so always measure the length of the bytes, never of the text.
  • Trap Host "127.0.0.1" (localhost) only accepts connections from the same computer. "0.0.0.0" accepts them from every network card, so other computers can connect. Use 127.0.0.1 while you learn.
  • Trap A very common bug: the sender calls sendall twice and the receiver expects two recv calls to return the two messages. On a fast local test it often works, and then it fails on a real network. recv only promises "some bytes", so always loop until you have a whole message.
  • Exam A /24 network has 232 − 24 = 256 addresses. The first is the network address and the last is the broadcast address, so 254 are left for computers. Ports go from 0 to 65,535, and ports below 1024 usually need admin rights.
