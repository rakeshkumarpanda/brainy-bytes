Files: data that lasts

Source: Python 3.14 tutorial section 7.2, the io, os, pathlib, errno, csv and json documentation, and PCAP-31-03 section 4.

What it is
A file is named data stored on a disk. Python reaches it through a file object (a stream) that open() gives you. Text files hold characters, binary files hold raw bytes.
Why we need it
Variables vanish when a program ends. Files keep data between runs: settings, saved games, reports, logs, photos. They are also how programs exchange data, as CSV, JSON or plain text.
How it works
open(name, mode) connects to the file and returns a file object with a cursor. read and write work at the cursor and move it on. close() (or the end of a with block) saves everything and frees the file. In text mode Python decodes bytes to str with an encoding such as UTF-8.
Real world scenario: a notebook and a bookmark

Opening a notebook to read puts a bookmark at page 1. Each page you read moves the bookmark forward. Opening it to write a fresh story ("w") tears out every old page first. Opening it to add notes ("a") turns to the last page. Closing the notebook puts it back on the shelf. The bookmark is the file cursor.

Common mistake

Encodings: always say utf-8

Download this program (.py)Save it, open it in any editor and run it with python3 encoding.py.
Common mistake
Without encoding=..., open() uses a default that depends on the computer. It is UTF-8 on Linux and macOS but can be an old code page on Windows, so a file written on one computer may not read on another. Since Python 3.15 the default becomes UTF-8 everywhere (PEP 686), but writing encoding="utf-8" is still the safe habit.

Sizes, bytes and cursors

File size in bytes of an ASCII textExam favourite
sum of len(line) for all lines, new lines included
"milk\n" is 5 bytes. On Windows a text file stores each new line as 2 bytes (\r\n).
UTF-8 sizeExam favourite
1 byte for code points 0 to 127, 2 up to 2,047, 3 up to 65,535, 4 above
"नमस्ते ₹100 café\n" has 16 characters but 31 bytes.
Units
1 KB = 1,000 bytes, 1 KiB = 1,024 bytes
Disks are sold in KB, MB, GB (powers of 10). Operating systems often show KiB, MiB, GiB (powers of 2).
Cursor after a read in text mode (ASCII)
new position = old position + characters read
In binary mode tell() is always a byte offset. In text mode it is an opaque number, so only seek() to values that tell() gave you.
Lines in memory
readlines(): O(file size). for line in f: O(longest line)
A 10 GB log can be processed with a for loop on a laptop with 8 GB of memory.
Worked example: size of the shopping file
  1. Lines: "milk\n", "eggs\n", "rice\n", "tea\n", "bread\n".
  2. Lengths: 5, 5, 5, 4, 6.
  3. 5 + 5 + 5 + 4 + 6 = 25 bytes, which is what os.path.getsize printed

From beginner to expert

One idea, four depths

open a file with "w" to write and "r" to read, and use with so it closes itself.

Know every mode, read with read, readline, readlines and a for loop, write with write and writelines, say encoding="utf-8", and catch FileNotFoundError.

Use binary mode for non text data, bytearray and readinto for buffers, pathlib for paths, os and shutil for folders, errno to tell OSErrors apart, and csv and json for structured data.

open() builds a layered stack: a raw FileIO (system calls), a BufferedReader or BufferedWriter (fewer system calls), and a TextIOWrapper (decoding and new line translation). flush() pushes the buffer to the operating system, and os.fsync() asks it to write to the disk. Writing to a temporary file and then os.replace() makes saving atomic, so a crash never leaves a half written file.

Beginner
Write and read a text file with with and a for loop.
Intermediate
Choose the right mode, handle file errors, use encodings, binary files, pathlib and csv.
Expert
Explain the io layers and buffering, write files atomically, and process files bigger than memory.

Chapter summary

  1. open(name, mode, encoding="utf-8") returns a file object with a cursor. Always use with so it closes.
  2. Modes: r read (must exist), w write (empties), a append, x create new only, + adds the other direction, b for binary.
  3. read(), read(n), readline(), readlines(), and for line in f, which is best for big files. Lines keep their new line.
  4. write() and writelines() do not add new lines. print(..., file=f) does.
  5. Binary mode reads and writes bytes. bytearray and readinto fill a buffer. seek and tell move and report the cursor.
  6. File errors are OSErrors: FileNotFoundError, FileExistsError, PermissionError. err.errno matches errno.ENOENT and friends.
  7. pathlib.Path joins with /, and has name, suffix, glob, read_text and write_text. os and shutil handle folders.
  8. sys.stdin, sys.stdout, sys.stderr are the standard streams. Use csv and json for structured files.
