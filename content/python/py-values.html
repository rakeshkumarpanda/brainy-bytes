Lesson 1 of 11

What a variable really is

Source: Python 3.14 Language Reference, section 3.1 (objects, values and types), and PCEP-30-02 section 1.3.

In maths class, x = 5 means "x is equal to 5". In Python, x = 5 is an action: "make the value 5, and stick the label x on it".

What it is
A variable is a name that points to an object. Every object has three things: an identity (where it lives, id()), a type (what kind of thing it is, type()) and a value.
Why we need it
Programs need to remember things: a price, a name, a score. Names let us refer to values again later without typing them again, and let the value change while the name stays the same.
How it works
The assignment name = expression first works out the right side, which gives an object. Then it binds (sticks) the name on the left to that object. The old object is not changed.
Real world scenario: name tags at a party

Think of objects as people at a party and names as sticky name tags. age = 25 puts the tag "age" on the person 25. my_age = age puts a second tag on the same person. age = age + 1 does not change that person into 26. It finds the person 26 and moves the "age" tag over. my_age is still stuck on 25.

Remember

In the exam
bool is a kind of int: True == 1 and False == 0, so True + True is 2. This surprises many people in exams.
Going deeper: why int has no size limit

In C or Java an int has a fixed number of bits (32 or 64), so very big numbers overflow. CPython stores an int as a list of 30 bit digits and adds more digits when needed, so 2 ** 1000 is exact. The cost: big numbers are slower and use more memory. Since 3.11 CPython limits int to str conversion to 4,300 digits by default (sys.set_int_max_str_digits) to stop denial of service attacks.

Changing one type into another

What it is
Type conversion (casting) makes a new object of another type from a value: int("42") gives the int 42.
Why we need it
Data often arrives as text: from input(), a file, a web form. To do maths with it you must turn it into a number first. To join a number into a message you may need str().
How it works
Call the type like a function: int(), float(), str(), bool(), complex(). Each one has rules about what it accepts. When the value does not fit the rules you get ValueError.

Going deeper: what swap does inside

a, b = b, a first evaluates b and a and packs them into a temporary tuple, then unpacks the tuple into a and b. CPython optimises the two name case with a SWAP bytecode instruction instead of building a real tuple, but the meaning is the same.

The maths: place value and conversions

Base b to decimalExam favourite
N = ∑i=0k di · bi
di is the digit at position i from the right.
Decimal to base bExam favourite
d0 = N mod b, N ← N // b, repeat
The remainders in reverse order are the digits.
Largest number in k bits
2k − 1
8 bits hold 0 to 255. 16 bits hold 0 to 65,535.
One hex digit
= 4 bits, one octal digit = 3 bits
So 0xFF is 1111 1111 and 0o7 is 111.
Worked example: 0x2F to decimal
  1. 2F has digits 2 and F. F means 15.
  2. Position 1: 2 × 161 = 32.
  3. Position 0: 15 × 160 = 15.
  4. 32 + 15 = 47
Worked example: 45 to binary
  1. 45 // 2 = 22 remainder 1. 22 // 2 = 11 remainder 0.
  2. 11 // 2 = 5 remainder 1. 5 // 2 = 2 remainder 1.
  3. 2 // 2 = 1 remainder 0. 1 // 2 = 0 remainder 1.
  4. Read upwards: 101101, so bin(45) is "0b101101"
Lesson 9 of 11

From beginner to expert

One idea, four depths

A variable is a name tag on a value. You can move the tag to another value at any time.

Every value is an object with an id, a type and a value. Assignment binds a name to an object and never copies it. int, float, str, bool and None are immutable, so "changing" them really makes a new object.

Names live in namespaces (dictionaries such as globals()). CPython caches the small ints from -5 to 256 and some strings, so id() can be equal for equal small values, but code must never rely on that. Use == for value, is only for None.

CPython objects start with a reference count and a type pointer (PyObject header). An int is a PyLongObject with an array of 30 bit digits. Since 3.12 some objects are immortal (their count never changes), which matters for free threaded builds.

Beginner
Use clear names, know the six basic types and convert text with int() and float().
Intermediate
Explain names and objects, use bin/oct/hex and int(text, base), know why int(3.99) is 3 and round(2.5) is 2.
Expert
Explain small int caching, immortal objects, int digit storage and why float has about 15.95 decimal digits of precision.
Real world scenario: a bank app reading an amount

A banking app reads "1,500.75" from a text box. It is text, so the app first removes the comma, then calls float() or better decimal.Decimal() for money, checks it is above zero, and only then adds it to the balance. Forgetting the conversion would join texts ("1500.75" + "100" gives "1500.75100") instead of adding numbers.

Chapter summary

  1. A variable is a name bound to an object. Assignment works out the right side, then sticks the name on the result. It never copies.
  2. Every object has an id, a type and a value. The type belongs to the object, not the name (dynamic typing).
  3. Basic types: int (any size), float (about 15 to 17 digits), complex, bool (True == 1), str and None. All of them are immutable.
  4. Literals: 1_000_000, 1.5e3, 0b1010, 0o17, 0xFF. bin(), oct(), hex() give text, int(text, base) reads it back.
  5. Conversions: int() cuts towards zero, round() rounds ties to even, bool() is False only for zero and empty values.
  6. Names: letters, digits, underscores, not starting with a digit, not a keyword, case sensitive. Use snake_case and never name a variable list or str.
