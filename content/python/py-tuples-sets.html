Lesson 1 of 15

Two new collections: tuples and sets

Source: Python 3.14 tutorial sections 5.3 and 5.4, the library reference section on set and frozenset, and PCEP-30-02 section 3.2.

What it is
A tuple is an ordered sequence like a list, written with round brackets, that can never change. A set is a collection with no order and no repeats, written with curly brackets.
Why we need it
A list is great for data that changes. But some data should not change (a date, a point on a map, a row from a database), and sometimes you only care whether something is present, not where. Tuples protect fixed data. Sets remove repeats and answer "is it in here?" almost instantly.
How it works
A tuple is a fixed array of references, so it is a little smaller and faster than a list and can be used as a dict key. A set is a hash table (like a dict without values), so adding, removing and the in test take O(1) on average.
Real world scenario: a train seat and a guest list

Your train seat is (coach "B2", seat 34). That pair must not change after booking: it is a tuple. A wedding guest list written by two families has many names twice. Turn both lists into sets, take the union, and every guest appears once. To find the guests both families invited, take the intersection.

Packing, unpacking and returning many values

Download this program (.py)Save it, open it in any editor and run it with python3 unpack.py.
What it is
Packing puts several values into one tuple: t = 1, 2, 3. Unpacking takes them out into names: a, b, c = t.
Why we need it
A function can return only one object. Returning a tuple lets it give back several results at once, and unpacking gives each result a clear name.
How it works
Python evaluates the right side fully first, packs it into a tuple, then assigns each item to the names on the left in order. That is why a, b = b, a swaps safely.

Why sets are fast

Download this program (.py)Save it, open it in any editor and run it with python3 speed.py.
What it is
A set stores each item in a table at a place worked out from the item hash, a number made from its value.
Why we need it
To check x in a list, Python may have to look at every item. With a million items that is a million checks.
How it works
To check x in a set, Python works out hash(x), jumps straight to that place in the table and looks at one or a few slots. The number of checks stays about the same for 10 items or 10 million items: O(1) on average. Core 3.4 shows the hash table step by step with the dict animation.

The maths of sets

Size of a union (inclusion and exclusion)Exam favourite
|A ∪ B| = |A| + |B| − |A ∩ B|
The middle part was counted twice, so take it away once.
Three sets
|A ∪ B ∪ C| = |A| + |B| + |C| − |A ∩ B| − |A ∩ C| − |B ∩ C| + |A ∩ B ∩ C|
Add singles, take away pairs, add back the triple.
Symmetric difference
|A Δ B| = |A| + |B| − 2|A ∩ B|
A ^ B in Python.
Number of subsets (the power set)Exam favourite
2n
Each item is in or out. {1, 2, 3} has 8 subsets.
De Morgan's laws
not (A or B) = (not A) and (not B)
For sets inside a universe U: U − (A ∪ B) = (U − A) ∩ (U − B).
Worked example: students in at least one class
  1. 40 students take Python, 30 take Java and 12 take both.
  2. Use |A ∪ B| = |A| + |B| − |A ∩ B|.
  3. 40 + 30 − 12 = 58 students
  4. Students in exactly one class: 58 − 12 = 46, which is |A ^ B|.
Lesson 13 of 15

From beginner to expert

One idea, four depths

A tuple is a list that cannot change. A set is a bag of unique items with no order.

(5,) is a tuple, (5) is not. Tuples unpack and can be dict keys. Sets give union, intersection and difference, and set() is the empty set.

Hashable means "has a hash that never changes", which needs an immutable value. Sets and dict keys need hashable items. Use a set to turn O(n) membership tests into O(1), and dict.fromkeys to remove repeats while keeping order.

CPython sets use open addressing with a mix of linear and random probing and keep the table at most about 60 percent full. Set algebra is Boolean algebra: union is OR, intersection is AND, and the power set of an n item set has 2n members, which is why "try every subset" algorithms take exponential time.

Beginner
Make tuples and sets, unpack a tuple, and remove duplicates with set().
Intermediate
Return several values, use tuples as keys, and solve problems with |, &, − and ^.
Expert
Explain hashability, choose between list, tuple and set by their costs, and use inclusion and exclusion to count.

Chapter summary

  1. A tuple is an ordered sequence that cannot change. The comma makes it: (5,) is a tuple, (5) is an int.
  2. Tuples pack and unpack: return a, b gives a tuple, and x, y = point takes it apart.
  3. Tuples of hashable items can be dict keys and set items. Lists cannot.
  4. A set holds unique hashable items with no order. set() is empty, {} is a dict.
  5. add, remove (KeyError), discard (no error), pop (any item). | union, & both, − only in the first, ^ in exactly one.
  6. x in a set is O(1) on average, x in a list is O(n).
  7. |A ∪ B| = |A| + |B| − |A ∩ B|, and a set of n items has 2n subsets.
