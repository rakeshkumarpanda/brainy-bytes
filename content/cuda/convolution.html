Convolution: slide, multiply, add

A 2-D convolution slides a small grid of weights (the filter or kernel) over a picture. At each place it multiplies the weights by the pixels under them and adds the products. One GPU thread computes one output pixel.

Output sizeExam favourite
out = ⌊(W + 2P − K) ÷ S⌋ + 1
W input width, K filter size, P padding, S stride.
"Same" padding
P = (K − 1) ÷ 2
3 × 3 needs 1, 5 × 5 needs 2.
WorkExam favourite
multiply-adds = out² × K² × Cin × Cout
AlexNet layer 1: 55² × 11² × 3 × 96 = 105,415,200.
Common mistake
Lecture 8 sharpens the pixel 30 at (2, 1) to 35. With neighbours 25, 35, 20 and 40 the result is 5 × 30 − 120 = 30. On a smooth slope sharpening changes nothing.

Sobel edge detection (lecture 4)

Sobel uses two 3 × 3 filters. Gx responds to changes from left to right, Gy to changes from top to bottom. A flat area gives 0, an edge gives a big value.

Edge strengthExam favourite
M1 = |Sx| + |Sy|, M2 = √(Sx² + Sy²)
M1 is cheaper and is what the lecture code uses. Both are clamped to 255.
sobel.cu
#include <cstdlib> __constant__ int GX[9] = {-1, 0, 1, -2, 0, 2, -1, 0, 1};__constant__ int GY[9] = {-1, -2, -1, 0, 0, 0, 1, 2, 1}; __global__ void sobel(const unsigned char *in, unsigned char *out, int w, int h) {    int x = blockIdx.x * blockDim.x + threadIdx.x;    int y = blockIdx.y * blockDim.y + threadIdx.y;    if (x < 1 || y < 1 || x >= w - 1 || y >= h - 1) return;    int sx = 0, sy = 0;    for (int dy = -1; dy <= 1; ++dy)        for (int dx = -1; dx <= 1; ++dx) {            int p = in[(y + dy) * w + (x + dx)];            int k = (dy + 1) * 3 + (dx + 1);            sx += GX[k] * p;            sy += GY[k] * p;        }    int m = abs(sx) + abs(sy);              // M1 = |Sx| + |Sy|, cheaper than a square root    out[y * w + x] = m > 255 ? 255 : m;     // clamp to the 8 bit range}
What each marked line does and why
  1. Line 3__constant__ int GX[9] = {-1, 0, 1, -2, 0, 2, -1, 0, 1};The two filters live in constant memory: every thread reads the same weight at the same moment, so it is broadcast.
  2. Line 9if (x < 1 || y < 1 || x >= w - 1 || y >= h - 1) return;Border pixels have no full 3 × 3 neighbourhood, so they are skipped.
  3. Line 13int p = in[(y + dy) * w + (x + dx)];Row major neighbour read. A warp reads 32 neighbouring x values, so it is coalesced.
  4. Line 18int m = abs(sx) + abs(sy); // M1 = |Sx| + |Sy|, cheaper than a square rootM1 = |Sx| + |Sy|.
  5. Line 19out[y * w + x] = m > 255 ? 255 : m; // clamp to the 8 bit rangeClamp because the output is one byte.

Halo tiles for convolution

Neighbouring outputs share most of their inputs, as with stencils. A block of B × B threads loads a (B + 2r) × (B + 2r) tile into shared memory once, then each thread reads its K × K inputs from the tile.

Tile sideExam favourite
B + 2r, with r = (K − 1) ÷ 2
B = 32, 3 × 3: 34 × 34.
Loads per outputExam favourite
(B + 2r)² ÷ B²
Against K² without a tile. B = 16, 5 × 5: 1.5625 against 25.
Saving
1 − (B + 2r)² ÷ (K² B²)
Best possible for large B: 1 − 1/K². 3 × 3 gives 88.9 percent.
Workbook 8.3: N = 1024, B = 16, 3 × 3
  1. Plain: 9 reads per output × 1024² = 9,437,184.
  2. Blocks 64 × 64 = 4096, each loads 18 × 18 = 324.
  3. Tiled: 4096 × 324 = 1,327,104.
  4. 85.9 percent fewer reads
conv_tiled.cu
#define BS 16#define R 1 __constant__ float W[(2 * R + 1) * (2 * R + 1)]; // Each block loads a (BS + 2R) x (BS + 2R) tile, then computes BS x BS outputs__global__ void convTiled(const float *in, float *out, int w, int h) {    __shared__ float tile[BS + 2 * R][BS + 2 * R];    int ox = blockIdx.x * BS, oy = blockIdx.y * BS;          // top left output of this block    for (int i = threadIdx.y; i < BS + 2 * R; i += BS)        for (int j = threadIdx.x; j < BS + 2 * R; j += BS) {            int gx = ox + j - R, gy = oy + i - R;            tile[i][j] = (gx >= 0 && gy >= 0 && gx < w && gy < h) ? in[gy * w + gx] : 0.0f;        }    __syncthreads();    int x = ox + threadIdx.x, y = oy + threadIdx.y;    if (x >= w || y >= h) return;    float s = 0.0f;    for (int a = 0; a <= 2 * R; ++a)        for (int b = 0; b <= 2 * R; ++b)            s += W[a * (2 * R + 1) + b] * tile[threadIdx.y + a][threadIdx.x + b];    out[y * w + x] = s;}
What each marked line does and why
  1. Line 4__constant__ float W[(2 * R + 1) * (2 * R + 1)];Filter weights in constant memory, filled by the host with cudaMemcpyToSymbol.
  2. Line 8__shared__ float tile[BS + 2 * R][BS + 2 * R];The tile is (BS + 2R) wide, so the block has fewer threads than tile cells.
  3. Line 10for (int i = threadIdx.y; i < BS + 2 * R; i += BS)The loops let 16 × 16 threads cover an 18 × 18 tile: some threads load two values.
  4. Line 13tile[i][j] = (gx >= 0 && gy >= 0 && gx < w && gy < h) ? in[gy * w + gx] : 0.0f;Outside the picture we load 0 (zero padding).
  5. Line 15__syncthreads();All of the tile must be loaded before any thread reads its neighbours.
  6. Line 21s += W[a * (2 * R + 1) + b] * tile[threadIdx.y + a][threadIdx.x + b];K × K reads from shared memory instead of global memory.

From intuition to research

One idea, four depths

Slide a small stamp across a picture, multiply and add at each place. Sobel finds edges by comparing one side with the other.

out = (W + 2P − K)/S + 1. Work out² K² Cin Cout. Tile (B + 2r)², loads per output (B + 2r)²/B². Weights in constant memory.

Deep learning convolutions are turned into matrix multiplies (im2col, chapter 8.2) or use Winograd and FFT methods, so tensor cores can run them. cuDNN picks the fastest algorithm per layer.

Depthwise separable convolutions (chapter 1.3) cut the work by about K² and are memory bound. Implicit GEMM builds the im2col matrix on the fly in shared memory instead of storing it.
