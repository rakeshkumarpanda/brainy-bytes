Bit Manipulation

Every number inside a computer is a row of tiny switches. Learn to read them, flip them, slide them and mask them, then use the famous tricks that make code faster and solve classic interview problems in one line.

Part 1

💡Binary: counting with light switches

A computer stores everything as tiny switches that are either off (0) or on (1). One switch is a bit. Eight bits make a byte. With only two digits, each place is worth twice the place to its right: 1, 2, 4, 8, 16 and so on, just as each place in normal numbers is worth ten times the next.

Place value1286432168421Total
13000011018 + 4 + 1 = 13
20011001000128 + 64 + 8 = 200

To turn a number into binary, keep dividing by 2. Each remainder is the next bit from the right. To turn binary back, read the bits from the left and do value = value × 2 + bit.

🔢 How big can it get

n bits can count from 0 to 2n − 1. A byte holds 0 to 255. A 32 bit int holds about 4.3 billion patterns, which is why old systems ran out of IPv4 addresses.

➖ Negative numbers

Java, JavaScript bit operators and most CPUs use two's complement: to make −x, flip every bit of x and add 1. The top bit then works as the sign. Python integers have no fixed width but behave as if they had endless sign bits.

Hex is just binary in groups of four: each hex digit is exactly four bits. 0xFF is 1111 1111, which is 255.
Part 2

🔀AND, OR, XOR and NOT

Bitwise operators work on every pair of bits in the same place, all at once. Picture two rows of light switches lined up, and a rule that decides each result switch.

aba & b (AND)a | b (OR)a ^ b (XOR)
00000
01011
10011
11110

AND is strict: both must agree on 1. OR is generous: one 1 is enough. XOR (exclusive or) asks "are they different". NOT (~) flips every bit, and in two's complement ~x equals −x − 1.

✨ XOR superpowers

x ^ x = 0, x ^ 0 = x, and the order never matters. That is why XOR finds a lonely number among pairs and why simple ciphers use it: XOR with a key hides the data, and XOR with the same key again brings it back.

⚠️ Not the same as and, or

&&, || and Python's and, or work on true or false and can skip the right side. & and | always work bit by bit on numbers.

Precedence trap: in Java, JavaScript and C, x & 1 == 0 means x & (1 == 0). Always write (x & 1) == 0.

⏩Shifts: sliding every bit

A left shift x << k slides every bit k places to the left and fills the gap with zeros. Each place left doubles the value, so x << k is x × 2k. A right shift x >> k slides bits to the right and the rightmost bits fall off, which is x ÷ 2k rounded down.

In Java and JavaScript a 32 bit shift uses only the low 5 bits of k, so 1 << 32 is 1, not 0. In JavaScript every bit operator first turns the number into a 32 bit signed int, so 2 ** 31 | 0 is negative. Use BigInt for wider values.

🎭Masks: check, set, clear and toggle one bit

A mask is a number with 1s only where you want to act. 1 << k is a mask with a single 1 at position k (counted from 0 on the right). With one mask and one operator you can do four jobs.

JobCodeWhy it works
Check bit k(n >> k) & 1slide bit k to the end and keep only it
Set bit kn | (1 << k)OR with 1 is always 1
Clear bit kn & ~(1 << k)AND with 0 is always 0
Toggle bit kn ^ (1 << k)XOR with 1 flips

Masks pack many yes or no flags into one number. A game can store which of 32 achievements you unlocked in a single int, and a database can test a whole set of options with one AND.

The Fenwick tree in the Arrays chapter jumps from index i to i + (i & −i). That single trick gives it O(log n) prefix sums.

Part 6

🎒Subsets as bitmasks

Packing for a trip with 3 items: for each item you either take it or leave it. That is 2 × 2 × 2 = 8 choices, the same as the 8 numbers from 0 to 7. If bit i is 1, item i goes in the bag. Counting from 0 to 2n − 1 visits every possible bag exactly once.

📈 It grows fast

2n doubles with every item. 20 items give about a million subsets, which is fine. 40 items give a trillion, which is not.

🧭 Bitmask dynamic programming

The travelling salesman for up to about 20 cities stores "which cities are visited" as a mask. The Dynamic programming part 2 chapter builds it.

Part 7

🛰️Bits in everyday systems

Bits are not only an interview topic. They run quietly inside the tools you use every day.

🔐 File permissions

On Linux and macOS, chmod 755 is three groups of three bits: read is 4, write is 2, run is 1. 7 = 4 + 2 + 1 gives the owner everything, 5 = 4 + 1 lets everyone else read and run but not write.

🎨 Colours

The web colour #FF8800 packs red, green and blue into one 24 bit number. Shifting right by 16 and masking with 0xFF pulls the red byte back out.

🌐 Networks

A router ANDs your IP address with the subnet mask to find your network. 192.168.1.77 AND 255.255.255.0 is 192.168.1.0, so it knows the device is on the home network.

🚩 Feature flags

Operating systems and game engines pass options as OR-ed flags, such as O_CREAT | O_WRONLY when opening a file in C.
